# LLM 추론의 실제 비용은 사용하지 않는 GPU다

> 과거 API 입력 토큰 요금의 두 기준값은 600배 차이가 났습니다. GPU 사용률, 대여 중 유휴 시간, 피크 요금이 LLM 추론 비용에 미치는 영향을 살펴봅니다.



2026년의 한 연구(arXiv:2603.28576, §4)는 API 요금 벤치마크 두 건을 비교했습니다. 연구에서는 입력 토큰 100만 개당 2020년 GPT-3의 벤치마크에 60달러, 2025년 2월의 저가형 Gemini 2.0 Flash에 0.10달러를 적용했습니다. 두 값에는 600배 차이가 있었습니다. 연구는 저가형 구간에서 요금이 절반으로 줄어드는 데 1.1년이 걸린다고 추정했습니다.

디플레이션을 다루는 헤드라인이 가리는 것은 실제 청구액을 좌우하는 요소, 즉 GPU 사용 시간 중 얼마나 많은 시간이 유용한 작업에 쓰이는가입니다. 추론은 토큰 단위로 청구되지만 시간 단위로 제공됩니다.

GPU 서버가 늘어선 데이터 센터 통로. 대부분은 작동하며 빛나고 있지만 하나는 꺼진 채 유휴 상태다

## 팀들이 놓치는 수치

2026년 6월 vLLM 벤치마크(arXiv:2606.11690, §§4–5)에서는 H100 NVL GPU 두 대에 텐서 병렬 처리(TP=2)를 적용해 Mixtral 8x7B Instruct를 FP16으로 실행했습니다. GPU 전체 대여료는 시간당 13.96달러였습니다. 프리픽스 캐시는 끄고, 입력 토큰 512개와 출력 토큰 256개로 구성된 합성 요청을 사용했습니다. 표의 비용은 GPU 대여료를 같은 기간에 실측한 출력 토큰 수로 나눈 값입니다. 요청률은 서버에 보낸 요청 건수를 기준으로 계산했습니다.

| H100 NVL GPU 두 대에서 실행한 Mixtral 8x7B | 출력 토큰 1M개당 실효 비용 |
|----------------------------------------|----------------------------|
| 초당 요청 1건 (거의 유휴 상태)         | 약 15.25달러               |
| 초당 요청 100건 전송(포화 상태에 근접)                         | 약 0.87달러                |

두 측정값은 17.5배 차이가 납니다. 서버에 초당 요청 25건을 보냈을 때 출력 토큰 100만 개당 비용은 약 0.95달러였습니다. 초당 요청 100건을 보냈을 때 서버는 초당 약 17.4건의 처리를 완료했습니다. 연구에서는 H100 구성 여섯 가지와 측정 대상 부하에 걸쳐 출력 토큰 100만 개당 0.21달러에서 15.25달러까지의 비용이 관측됐습니다. 이 수치는 해당 테스트 작업 부하에서 얻은 측정값입니다. 실제 운영 환경에서는 목표 지연 시간을 충족하는 부하에서 처리량을 측정하세요.

시간당 대여료가 같을 때 출력 처리량이 최대치의 40%라면 출력 토큰당 비용은 2.5배로 늘어납니다. 아래 예에서 사용률은 실제 출력 처리량을 최대 출력 처리량으로 나눈 비율입니다. 출력 토큰이 적어도 GPU 활동 지표가 높게 나올 수 있습니다.

그래서 같은 모델을 실행하는 두 팀도 단위 비용을 크게 다르게 제시할 수 있습니다. 한 팀은 사용률 40퍼센트로 트래픽이 몰리는 챗봇을 운영하고, 다른 팀은 사용률 90퍼센트로 포화된 배치 파이프라인을 실행합니다. 모델, 하드웨어, 표시 가격은 같습니다. 단위 비용은 다릅니다. 공급업체가 토큰당 비용을 제시하면 어떤 사용률을 전제로 계산했는지 물어보세요.

## 오픈 웨이트 모델은 문제를 더 악화시켰다

전문가 혼합(MoE) 모델은 토큰마다 가중치의 일부를 사용합니다. Mixtral 8x7B는 토큰당 약 129억 개의 매개변수를 활성화하며 전체 매개변수는 467억 개입니다. 모든 가중치를 GPU에 올려 배포한다면 가중치가 저장된 정밀도를 기준으로 전체 가중치를 담을 메모리를 계산하고, KV 캐시와 런타임 오버헤드에 필요한 용량을 더하세요. 활성 매개변수 수는 토큰당 연산량을 추정하는 데 도움이 됩니다. 메모리 대역폭, 전문가 라우팅, 배치 크기도 처리량에 영향을 줍니다.

자신의 작업 부하에 맞춰 손익분기점을 추정하세요. 입력과 출력 토큰 구성은 동일하게 두고, API 요금과 GPU 대여료 및 서비스 운영비를 비교하세요. 필요한 대여 시간에는 GPU가 유휴 상태인 시간도 포함하세요. 실제 트래픽 패턴을 적용해 목표 지연 시간을 충족하는 조건에서 출력 처리량을 측정하세요. API 요금, 모델 구성, 사용률은 모두 결과에 영향을 줍니다.

## 두 번째 숨은 비용: 시간대

2026년 11월 25일 기준으로 DeepSeek API를 직접 이용하면 중국 공휴일을 제외한 월요일부터 금요일까지 01:00–04:00 및 06:00–10:00(UTC)에 피크 요금이 적용됩니다. 인도 표준시(IST, UTC+05:30)로는 06:30–09:30 및 11:30–15:30입니다. 그 밖의 시간에는 비피크 요금이 적용되며, 주말과 중국 공휴일에는 하루 종일 비피크 요금이 적용됩니다. [DeepSeek API 요금](https://api-docs.deepseek.com/quick_start/pricing/)

피크 요금이 적용되는 평일에 10:00 IST(04:30 UTC)는 비피크 시간이고, 15:00 IST(09:30 UTC)는 피크 시간입니다. 토큰 100만 개당 미국 달러 기준으로, `deepseek-flash`의 비피크 요금과 피크 요금은 캐시 적중 입력에 0.003과 0.006, 캐시 미스 입력에 0.15와 0.30, 출력에 0.60과 1.20입니다. `deepseek-v4-pro`는 같은 순서로 0.022와 0.044, 0.66과 1.32, 1.98과 3.96입니다.

## 실제로 비용을 좌우하는 요소

추론 예산을 책정한다면 모델 가격을 비교하기 전에 다음 항목부터 검토하세요.

1.  하드웨어보다 사용률을 먼저 보세요. 사용률 40퍼센트인 H200은 완전히 가동 중인 H100보다 토큰당 비용이 더 높을 수 있습니다.
2.  공급업체가 캐시 적중 시 요금을 할인하는지 확인하세요. 긴 시스템 프롬프트나 공통 프리픽스를 재사용할 때 캐시 적중 요금이 적용되면 입력 비용을 줄일 수 있습니다.
3.  시간대별 트래픽 비중을 기준으로 피크 요금과 비피크 요금을 가중 평균하세요. DeepSeek API를 직접 이용하면 토큰 사용량과 캐시 조건이 같을 때 피크 시간 비용은 비피크 시간의 두 배입니다.
4.  RAG 색인화나 대량 추출처럼 처리를 미룰 수 있는 백그라운드 작업은 배치로 묶으세요. 실제로 사용할 배치 설정에서 출력 처리량과 지연 시간을 측정하세요.
5.  MoE 모델의 연산량은 활성 매개변수 수로 추정하고, 메모리는 전체 가중치와 KV 캐시, 런타임 오버헤드에 필요한 용량을 확보하세요.
