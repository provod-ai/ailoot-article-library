# 초보자를 위한 Claude API: 시작을 위한 실용 가이드

> Claude API 초보자 가이드: 설정, 첫 요청, 모델 선택, 주요 기능과 프로덕션 실무를 다룹니다.



개발자가 첫 Claude API 호출을 하는 데 필요한 모든 내용을 다룹니다. 키, Messages API, 모델 선택, 첫 요청부터 프로덕션까지 이어지는 핵심 개념을 소개합니다.

## Claude API란?

Claude API는 Anthropic의 개발자 플랫폼입니다. Messages API를 통해 Claude 모델에 프로그래밍 방식으로 접근할 수 있으며, 시스템 프롬프트, 도구 사용, 스트리밍, 비전, 구조화된 출력을 지원합니다.

Messages API는 상태를 저장하지 않는 HTTP 엔드포인트입니다. 사용자 및 어시스턴트 메시지 목록, 모델 ID, 토큰 한도를 보내면 Claude가 구조화된 응답을 반환합니다. 배치, 파일, 토큰 계산을 위한 보조 엔드포인트도 제공됩니다.

- **상태 비저장:** API는 기억을 보관하지 않습니다. 호출할 때마다 대화 기록을 다시 보내야 합니다.
- **모델 선택:** 모델을 바꾸려면 보통 모델 ID를 변경하면 됩니다.
- **SDK:** 공식 Python(anthropic) 및 TypeScript(@anthropic-ai/sdk) 라이브러리는 각각 대응하는 요청 형식을 사용합니다.

이 구조를 이해하면 API가 이전 요청을 기억할 것이라고 기대하는 초보자의 흔한 실수를 피할 수 있습니다.

## 1단계: 키를 발급받고 Console 설정하기

**console.anthropic.com**으로 이동해 계정이나 팀 조직을 만들고 설정 영역에서 API 키를 발급받으세요. 키는 비밀번호처럼 취급하고 환경 변수에 보관하며 소스 코드 저장소에는 절대 넣지 마세요.

직접 보내는 HTTP 요청에는 **x-api-key** 헤더와 **anthropic-version** 헤더가 필요합니다. SDK는 환경 변수의 **ANTHROPIC_API_KEY**를 자동으로 읽으므로 대부분의 코드는 키를 직접 다루지 않습니다.

- 개발, 스테이징, 프로덕션용 키를 따로 만드세요.
- 워크스페이스를 사용해 팀 프로젝트와 지출을 분리하세요.
- 더 넓은 팀에 키를 배포하기 전에 Console에서 사용 한도를 설정하세요.

## 2단계: 첫 Messages API 호출하기

**pip install anthropic**으로 SDK를 설치하고, 키를 환경 변수로 내보낸 뒤 다음을 실행하세요.

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

필수 매개변수는 세 가지입니다. **model**, 출력 상한인 **max_tokens**, 그리고 **messages**입니다. 응답에는 콘텐츠 블록 목록이 들어 있습니다. 도구 사용이나 사고 과정에 따라 다른 유형의 블록이 추가될 수 있으므로 모두 일반 텍스트라고 가정하지 말고 각 블록의 유형을 확인하세요. **usage** 객체는 입력 및 출력 토큰을 보고하며, 비용 측정 자료로 활용할 수 있습니다.

## 3단계: 모델 선택하기

Anthropic의 현재 Claude 모델과 API ID는 다음과 같습니다.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — 빠르고 저렴한 모델로, 분류와 대량의 단순 작업에 적합하다고 설명합니다.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — 코딩을 포함한 프로덕션 작업의 균형 잡힌 선택지라고 설명합니다.
- **Claude Opus 5.5** (**claude-opus-5-5**) — 어려운 추론과 장기 에이전트 작업용이라고 설명합니다.
- **Claude Fable 5.2** (**claude-fable-5-2**) — 까다로운 추론 작업을 위한 대표 모델이라고 설명합니다.

Opus 5.5로 시작하세요. 속도와 품질의 균형이 필요하면 Sonnet 5.5를, 대량의 단순 작업에는 Haiku 5.5를, 복잡한 추론에는 Fable 5.2를 평가하세요. 현재 요금은 Anthropic 가격 페이지에서 확인하세요.

## 다음으로 배울 다섯 가지 개념

첫 요청이 작동하면 다음 기능들이 다양한 애플리케이션 요구를 충족합니다.

- **시스템 프롬프트** — 사용자 메시지와 별도로 역할, 어조, 규칙을 설정하는 최상위 **system** 매개변수입니다.
- **다중 턴 대화** — 어시스턴트의 답변을 messages 배열에 추가해 다시 보내세요. 첫 메시지는 사용자 턴이어야 합니다.
- **스트리밍** — 서버 전송 이벤트는 토큰이 생성되는 즉시 전달하므로 채팅 인터페이스와 긴 출력에 유용할 수 있습니다.
- **비전** — 텍스트와 함께 이미지 콘텐츠 블록을 base64 또는 URL로 전달하세요.
- **도구 사용** — JSON 스키마로 함수를 정의하면 Claude가 호출 시점을 판단할 수 있으며, 코드는 함수를 실행하고 결과를 반환합니다.

비용이 중요하다면 **프롬프트 캐싱**과 **배치 처리**를 고려하고, 후속 코드가 응답을 분석해야 한다면 **구조화된 출력**을 사용하세요.

## 튜토리얼에서 프로덕션으로

작동하는 스크립트를 프로덕션 통합으로 발전시키려면 엔지니어링 원칙이 필요합니다.

- **오류 처리:** 속도 제한(429) 오류와 서버 오류를 구분해 처리하세요. 자료에 따르면 SDK는 백오프로 이러한 오류를 자동 재시도합니다. 현재 동작은 해당 SDK 문서에서 확인하세요.
- **비용 가시성:** 모든 응답의 **usage**를 메트릭 시스템에 기록하세요.
- **프롬프트 버전 관리:** 프롬프트를 코드처럼 검토하고 버전을 관리하며, 소규모 평가 세트로 테스트하세요.
- **모델 고정:** 설정에서 모델 ID를 참조해 업그레이드를 의도적으로 테스트한 뒤 적용하세요.

### 핵심 요점

- Messages API는 상태를 저장하지 않으므로 호출할 때마다 대화 기록을 다시 보내야 합니다.
- 직접 HTTP 인증에는 x-api-key 헤더가 사용되며, SDK는 환경 변수의 ANTHROPIC_API_KEY를 읽을 수 있습니다.
- 필수 요청 매개변수는 model, max_tokens, messages입니다.
- Opus 5.5로 시작하고 자체 데이터로 다른 후보와 비교하세요.
- 시스템 프롬프트, 스트리밍, 비전, 도구 사용, 다중 턴 기록은 여러 애플리케이션 패턴을 지원합니다.
- 비용 확인과 용량 계획을 위해 토큰 사용량을 기록하세요.

## 자주 묻는 질문

### Claude API를 사용하려면 머신러닝을 알아야 하나요?

아니요. Claude API는 공식 Python 및 TypeScript SDK를 제공하는 REST API입니다. HTTP 엔드포인트를 호출하고 JSON을 분석할 수 있으면 Claude로 개발할 수 있습니다. 프롬프트 설계, 오류 처리, 비용 관리는 유용한 엔지니어링 기술이지만, 첫 API 호출에 기계 학습 이론은 필요하지 않습니다.

### 초보자는 어떤 Claude 모델로 시작해야 하나요?

Anthropic은 대부분의 작업에 Claude Opus 5.5(API ID `claude-opus-5-5`)로 시작할 것을 권장합니다. 프롬프트가 안정되면 자체 데이터로 다른 모델과 비교하세요.

### Claude API는 이전 대화를 기억하나요?

아니요. Messages API는 상태를 저장하지 않습니다. 애플리케이션이 대화를 저장하고 요청할 때마다 전체 메시지 기록을 다시 보내야 합니다. 이렇게 하면 컨텍스트를 직접 관리하고 오래된 턴을 줄이거나 요약할 수 있으며, 프롬프트 캐싱과 함께 사용할 수도 있습니다.
