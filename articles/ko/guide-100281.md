# OpenAI Moderation API 가격: 무료, 요청 제한 및 대안

> OpenAI Moderation 모델은 무료입니다. 사용 등급별 가격과 요청 제한, Python 예제, OpenAI 호환 대안이 더 적합한 경우를 알아보세요.




OpenAI의 Moderation 엔드포인트는 OpenAI API 사용자가 무료로 이용할 수 있습니다. 프로덕션 워크플로를 정할 때는 지원하는 입력 유형과 카테고리, 계정의 요청 제한을 확인하고 이 엔드포인트를 검토 절차에 어떻게 적용할지 살펴보세요.

이 가이드에서는 공식 가격 안내와 실무적인 엔지니어링 결정을 구분해 설명합니다.

## 요약

- OpenAI Help Center에 따르면 **OpenAI의 Moderation 엔드포인트는 OpenAI API 사용자에게 무료입니다**.
- OpenAI의 `omni-moderation-latest` 모델은 유해 콘텐츠를 감지하도록 설계되었으며, 공식 OpenAI 모델 페이지에 따르면 텍스트와 이미지를 입력으로 받습니다.
- 무료라고 해서 로깅, 검토 대기열, 정책 매핑, 재시도, 대체 동작, 애플리케이션별 의사결정 같은 워크플로 비용까지 없어지는 것은 아닙니다.
- 이미 OpenAI를 직접 사용하고 있고 모더레이션 워크플로가 OpenAI의 카테고리와 응답 형식에 맞는다면 OpenAI 무료 엔드포인트를 선택하세요.
- 이미 EvoLink를 사용 중이고 멀티모달 검사, 위험 요약, 호출당 과금을 같은 워크플로에 통합하려면 EvoLink Moderation 1.0을 고려하세요.

## OpenAI Moderation API는 무료인가요?

네. OpenAI 공식 Help Center에 따르면 Moderation 엔드포인트는 OpenAI API 사용자에게 무료이며, 이 도구의 사용량은 월간 사용 한도에 포함되지 않습니다.

출처: [OpenAI Help Center: Is the Moderation endpoint free to use?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

이것이 가격에 대한 답입니다. 다음 질문은 운영과 관련된 것입니다.

**무료 모더레이션 엔드포인트만으로 프로덕션 워크플로를 충분히 처리할 수 있을까요?**

프로토타입, 내부 도구, 단순한 텍스트 중심 모더레이션에는 충분할 수 있습니다. 사용자 생성 콘텐츠, 이미지 업로드, AI 에이전트 또는 검토 대기열을 처리하는 애플리케이션에서는 API 호출이 시스템의 일부에 불과합니다.

## OpenAI 모더레이션은 무엇을 다루나요?

OpenAI는 `omni-moderation-latest`를 텍스트와 이미지에서 잠재적으로 유해한 콘텐츠를 식별하도록 설계된 모더레이션 모델로 설명합니다. 공식 모델 페이지에서는 이 모델을 OpenAI의 가장 강력한 모더레이션 모델로 소개하며 텍스트 입력 및 출력과 이미지 입력을 지원한다고 명시합니다. 출처: [omni-moderation-latest OpenAI 모델 페이지](https://platform.openai.com/docs/models/omni-moderation-latest) OpenAI 모더레이션 가이드에서는 콘텐츠 분류 카테고리도 설명하며, 일부 카테고리는 텍스트만 지원한다고 안내합니다. `omni-moderation-latest`에 이미지만 보내면 이미지 입력을 지원하지 않는 카테고리의 점수는 0으로 반환됩니다. 출처: [OpenAI Moderation 가이드](https://developers.openai.com/api/docs/guides/moderation)

따라서 각 텍스트 카테고리가 이미지 모더레이션에도 그대로 적용된다고 가정하기 전에 카테고리 표를 꼼꼼히 살펴봐야 합니다.

## 실제 비용은 API 가격이 아니라 워크플로에서 발생합니다

Moderation 엔드포인트는 무료일 수 있지만, 프로덕션 모더레이션 시스템을 구축하려면 다음과 같은 사항을 결정해야 합니다.

- 검사를 실행할 시점: 모델 호출 전, 모델 응답 후 또는 두 시점 모두
- 카테고리를 허용, 검토 또는 차단 결정에 매핑하는 방법
- 민감한 콘텐츠를 불필요하게 저장하지 않고 모더레이션 결과를 기록하는 방법
- 오탐과 이의 제기를 처리하는 방법
- 이미지 업로드를 텍스트 입력과 별도로 모더레이션하는 방법
- 지연 시간, 오류 및 요청 제한을 모니터링하는 방법
- 제품의 여러 접점에서 정책 동작을 일관되게 유지하는 방법

이것들은 엔지니어링 및 운영 비용입니다. 가격 페이지에는 표시되지 않지만 모더레이션 계층을 실제로 유지 관리할 수 있는지를 좌우합니다.

일반적인 워크플로에서는 프롬프트를 모델에 보내기 전에 검사하고, 출력을 전달하기 전에 검사합니다. 판단이 어려운 결과는 검토로 넘기고, 결정에 대한 기록은 최소한으로 남기며, 재시도와 이의 제기 절차를 마련하세요.

## OpenAI의 무료 엔드포인트가 적합한 경우

다음 조건에 해당한다면 OpenAI의 무료 Moderation 엔드포인트를 첫 번째 선택지로 삼기 좋습니다.

- 이미 OpenAI를 직접 사용하고 있음
- 앱이 주로 텍스트를 다룸
- OpenAI가 문서화한 모더레이션 카테고리만 필요함
- 자체 검토 및 에스컬레이션 워크플로를 구축할 수 있음
- 팀에서 응답 파싱, 임계값 및 로그를 관리할 수 있음

그런 경우 무료 엔드포인트를 마다할 이유는 거의 없습니다. 먼저 사용해 보고 실제 콘텐츠로 테스트한 다음, 프로덕션 트래픽을 보내기 전에 오탐과 놓친 사례를 측정하세요.

## OpenAI 호환 대안이 유용한 경우

EvoLink Moderation 1.0은 OpenAI와 호환되는 `/v1/moderations` 경로를 제공하는 유료 대안입니다. EvoLink는 요청당 이미지를 한 장까지 받습니다.

- 하나의 엔드포인트로 텍스트 전용, 이미지 전용, 텍스트와 이미지 조합 검사를 수행할 수 있음
- 유해 콘텐츠 카테고리 13개와 카테고리별 점수를 제공함
- `evolink_summary` 객체에 `risk_level`, `flagged`, `violations`, `max_score`, `max_category` 필드를 제공함
- 토큰 계산 대신 호출당 정액 요금을 적용함
- 허용, 검토 또는 차단 로직에 매핑하기 쉬운 응답 형식을 제공함

## Python에서 OpenAI Moderation API 사용하는 방법

이미 OpenAI SDK를 사용하고 있다면 기본 텍스트 모더레이션 호출은 다음과 같습니다.

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

EvoLink를 사용하려면 `EVOLINK_API_KEY`에 EvoLink 키를 설정하세요. `EVOLINK_BASE_URL`에는 EvoLink API 설정에서 확인할 수 있는 HTTPS API 기본 URL을 설정하세요. 이 URL은 `/v1`로 끝납니다. 응답에는 `evolink_summary` 객체가 추가됩니다.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## OpenAI와 EvoLink의 요금 및 워크플로 비교

| 비교 기준 | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| 요금 | OpenAI API 사용자에게 무료 | 호출당 고정 요금 부과 |
| 주요 엔드포인트 형식 | `/v1/moderations` | OpenAI 호환 `/v1/moderations` |
| 텍스트 모더레이션 | 지원 | 지원 |
| 이미지 모더레이션 | `omni-moderation-latest`에서 지원하며, 입력 지원 여부는 카테고리마다 다름 | 이미지 전용 요청과 텍스트 및 이미지 요청을 지원 |
| 정책에 따른 판단에 사용하는 필드 | `results`의 `flagged`, `categories`, `category_scores` 값을 해석 | `evolink_summary.risk_level`과 `violations`를 카테고리별 점수와 함께 사용 |
| 적합한 팀 | 이미 OpenAI를 직접 호출하는 팀 | 기존 EvoLink 워크플로에 모더레이션을 통합하는 팀 |

## 실용적인 권장 사항

애플리케이션이 이미 OpenAI를 중심으로 구축되어 있고 모더레이션 정책이 OpenAI가 문서화한 카테고리에 명확히 부합한다면 OpenAI의 무료 Moderation 엔드포인트를 사용하세요.

이미 EvoLink를 사용하는 팀이라면 호출당 비용을 평가하고, 애플리케이션에서 허용, 검토 또는 차단을 결정할 때 `evolink_summary.risk_level`을 판단 근거 중 하나로 활용하세요.

브랜드 규칙, 사람의 검토, 이의 제기 또는 단일 모더레이션 API를 넘어서는 규정 준수 워크플로가 필요한 맞춤 정책 요건이 있다면 다계층 모더레이션 시스템을 사용하세요.

## 자주 묻는 질문

### OpenAI Moderation API는 무료인가요?

네. OpenAI Help Center에 따르면 Moderation 엔드포인트는 OpenAI API 사용자에게 무료이며, 사용량은 월간 사용 한도에 포함되지 않습니다.

### OpenAI 모더레이션은 이미지를 지원하나요?

네. OpenAI 공식 모델 페이지에 따르면 `omni-moderation-latest`는 이미지를 입력으로 받습니다. 다만 OpenAI 모더레이션 가이드에서는 일부 카테고리가 텍스트만 지원한다고 안내하므로, 이미지 전용 모더레이션에 의존하기 전에 카테고리별 입력 지원 여부를 확인해야 합니다.

### EvoLink Moderation이 OpenAI Moderation보다 저렴한가요?

OpenAI의 Moderation 엔드포인트는 OpenAI API 사용자에게 무료입니다. EvoLink는 호출당 고정 요금을 부과합니다. 검토와 유지 관리를 포함해 전체 워크플로의 비용을 비교하세요.

### OpenAI Moderation API 대신 EvoLink를 사용할 수 있나요?

네. EvoLink API 키와 `evolink-moderation-1.0` 모델을 사용해 EvoLink의 호환 경로인 `/v1/moderations`로 요청하세요. EvoLink 응답에 포함된 별도의 `evolink_summary` 객체를 처리할 수 있도록 응답 처리 로직을 수정하세요.

### 프롬프트, 출력 또는 둘 다를 모더레이션해야 하나요?

프로덕션 AI 애플리케이션에서는 입력과 출력을 모두 모더레이션하는 팀이 많습니다. 입력 모더레이션은 안전하지 않은 요청이 모델에 도달하기 전에 줄일 수 있습니다. 출력 모더레이션은 생성된 안전하지 않은 응답이 사용자에게 전달되기 전에 감지할 수 있습니다.

### omni-moderation-latest란 무엇인가요?

텍스트와 이미지에 사용하는 OpenAI의 모더레이션 모델입니다. `results`에서 `flagged`, `categories`, `category_scores`를 읽고 자체 모더레이션 정책을 적용하세요.

### OpenAI Moderation API의 요청 제한은 어떻게 되나요?

무료 이용은 요금에 관한 설명입니다. 요청 수와 토큰 수에는 제한이 적용됩니다. [모델 레퍼런스](https://developers.openai.com/api/docs/models/omni-moderation-latest)에서 RPM은 분당 요청 수, RPD는 표시된 경우 일일 요청 수, TPM은 분당 토큰 수를 뜻합니다.

OpenAI Moderation API의 요청 제한은 계정 등급에 따라 다르며 시간이 지나면서 바뀔 수 있습니다. 프로덕션 처리량을 계획하기 전에 [OpenAI 요청 제한 문서](https://platform.openai.com/docs/guides/rate-limits)와 계정의 [사용 한도 페이지](https://platform.openai.com/settings/organization/limits)를 확인하세요.

### Python에서 OpenAI Moderation API를 어떻게 사용하나요?

`openai` 패키지를 설치하고 `OPENAI_API_KEY`를 설정하세요. `client.moderations.create()`를 호출할 때 모델로 `omni-moderation-latest`를 지정하고 검사할 텍스트를 전달하세요. 이미지를 검사하려면 아래에 링크된 OpenAI API 레퍼런스의 예시처럼 `input`에 객체 배열을 전달하세요. 이미지를 나타내는 각 요소에는 `type: "image_url"`을 지정하고, `image_url` 객체 안에 `url`을 넣으세요.
