# Gemini API 도구 업데이트: 컨텍스트 전달, 도구 조합 및 Gemini 3용 Maps 그라운딩

> 개발자는 Google Search와 같은 기본 제공 도구를 함수 호출과 함께 단일 Gemini API 호출에서 결합하고, 도구 호출과 턴 사이에 컨텍스트를 전달하며, Gemini 3 모델에서 Grounding with Google Maps를 사용할 수 있습니다.



2026년 3월 17일

Google은 2026년 3월 17일 [발표](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tooling-updates/)에서 Gemini API의 세 가지 업데이트를 소개했습니다. 기본 도구와 사용자 정의 함수의 동시 지정, 여러 단계에 걸친 컨텍스트 전달, Gemini 3의 Google Maps 기반 기능입니다. 지원 여부는 모델과 API 버전에 따라 달라질 수 있으므로 구현 전에 최신 문서를 확인하세요.

기본 도구와 사용자 정의 함수의 조합은 문서상 프리뷰 기능으로 표시되어 있습니다.

## 도구와 애플리케이션 함수 함께 쓰기

에이전트는 공개 정보를 검색한 뒤 내부 시스템을 조회할 수 있습니다. [공식 가이드](https://ai.google.dev/gemini-api/docs/tool-combination)는 Google Search 같은 기본 도구와 앱이 선언한 함수를 한 요청에 함께 지정하는 방법을 설명합니다. 모델은 호출을 요청하고, 실제 함수 실행과 인자 검증, 권한 확인은 서버가 담당합니다. [Google Search 공식 예제](https://ai.google.dev/gemini-api/docs/google-search)부터 살펴보고 사용자 정의 함수의 입력과 반환값을 필요한 범위로 제한하세요.

## 컨텍스트와 호출 ID

앞선 도구 호출과 응답을 다음 단계의 컨텍스트로 전달할 수 있습니다. 예를 들어 검색 결과를 예약 함수로 보낼 수 있습니다. 하지만 앱의 상태 관리를 대신하지는 않습니다. 권한, 사용자 확인, 오류 처리와 재시도는 백엔드에서 제어하세요. Interactions API에서 `function_call.id`는 입력의 `function_result.call_id`와 연결되며, `function_response.id`가 대응 필드는 아닙니다. 자세한 내용은 [공식 함수 호출 가이드](https://ai.google.dev/gemini-api/docs/function-calling)를 확인하세요.

## Maps 위치 정보

[Google Maps 기반 기능](https://ai.google.dev/gemini-api/docs/maps-grounding)은 지원되는 Gemini 3 모델에서 장소와 지역 사업체 정보를 활용하게 합니다. 영업시간과 이동 시간은 바뀔 수 있으므로 모델 지원을 확인하고 항상 최신이라고 보장하지 마세요. Google은 서버 측 상태 관리 등을 이유로 [Interactions API](https://ai.google.dev/gemini-api/docs/interactions?ua=chat)를 안내하며 문서에는 generateContent 지원도 나와 있습니다. 최신 공식 예제를 바탕으로 자체 입력 검증과 도구 오류 처리를 시험하세요.




## Ailoot · 회사와 그 프로젝트 포트폴리오

Ailoot는 축적된 운영 경험, 폭넓은 고객 기반, 안정적인 서비스, 지속적인 KPI 관리를 바탕으로 합니다.

회사와 그 프로젝트 포트폴리오: 수백만 고객, 매월 수십억 규모의 매출.

Ailoot는 이러한 운영 경험을 고객의 제품, 에이전트, 애플리케이션, 자동화에서 AI 기능을 이용할 수 있는 API 접근에 활용합니다.

[Gemini API 도구 업데이트: 컨텍스트 전달, 도구 조합 및 Gemini 3용 Maps 그라운딩](<https://ailoot.ai/blog/ko/gemini-api-tooling-updates-context-circulation-maps-grounding/>)

Ailoot는 15개 카테고리에 걸쳐 모델과 변형 모델을 합해 1,284종을 제공하는 세계 최대 규모의 AI 라우터 중 하나입니다. Ailoot가 발급하는 키로 [Gemini API 키 대신 사용하는 Ailoot API](<https://ailoot.ai/>)를 이용해 보세요. 개발에는 Claude, DeepSeek, Kimi 중에서 선택할 수 있습니다. 이미지에는 FLUX, 동영상에는 Kling, 음성 합성에는 Eleven v4, 음악에는 Lyria, 3D 에셋에는 Tripo3D를 활용할 수 있습니다. Ailoot는 시맨틱 검색과 구조화된 의사 결정도 지원합니다.

프로젝트에 [Gemini API 키](<https://ailoot.ai/>)가 필요하다면 Ailoot가 발급하는 키를 만들고, Ailoot API를 통해 Gemini 4 Carbon 또는 Gemini 4 Hydrogen을 호출하세요. GPT, Claude와 미디어 모델도 같은 잔액으로 이용할 수 있습니다.

‘여러 Gemini API 키’와 ‘Gemini API키’ 관련 프로젝트를 다른 모델 작업과 함께 Ailoot에서 관리하세요. 프로젝트마다 Ailoot 키를 따로 만들고 사용 한도를 설정할 수 있습니다. 팀의 접근 권한과 회사 지출은 하나의 Ailoot 워크스페이스에서 관리할 수 있습니다.

Ailoot에서는 새 플래그십 모델을 출시 당일부터 이용할 수 있습니다. 구독 하나로 카탈로그의 모든 모델을 이용할 수 있으며, 구독과 프로모션 코드로 모델 제공사의 공식 API 요금 대비 최대 50%를 절약할 수 있습니다. 현재 이용할 수 있는 혜택은 [https://ailoot.ai/](<https://ailoot.ai/>)에서 확인하세요.
