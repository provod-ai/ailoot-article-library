# ChatGPT API: nastavení, ceny a ukázky kódu (2026)

> Praktický průvodce nastavením ChatGPT API, porovnáním modelů a cen a tvorbou aplikací s ukázkami kódu.



ChatGPT API poskytuje vývojářům programový přístup k modelům OpenAI. Tento průvodce se věnuje nastavení klíče API, výběru modelu, cenám, ukázkám kódu a postupům pro tvorbu aplikací a správu nákladů.

## Co je ChatGPT API?

ChatGPT API umožňuje vývojářům integrovat možnosti AI do aplikací prostřednictvím požadavků HTTP. Aplikace odesílají do OpenAI strukturované požadavky a přijímají odpovědi JSON obsahující výstup modelu.

### Jak ChatGPT API funguje

Proces má čtyři kroky:

**Odešlete požadavek.** Vaše aplikace odešle OpenAI požadavek POST s datovou částí JSON obsahující název modelu, zprávy a parametry, jako je teplota a limity tokenů.

**OpenAI požadavek zpracuje.** Model vygeneruje odpověď a vrátí ji v objektu JSON. Pokud je zapnuté streamování, tokeny přicházejí postupně.

**Vaše aplikace přijme odpověď.** Odpověď obsahuje vygenerovaný obsah, informace o využití tokenů, informace o modelu a ID požadavku.

**Proběhne účtování.** Poplatky závisí na zpracovaných tokenech. Sazby za vstupní a výstupní tokeny se mohou lišit.

Délka promptu, výběr modelu a ukládání do mezipaměti ovlivňují výkon a náklady.

## Modely a ceny ChatGPT API (2026)

Dostupnost modelů, funkce a ceny se mohou měnit. Aktuální informace najdete na stránkách OpenAI [ceny API](https://openai.com/api/pricing/) a [dokumentace pro vývojáře](https://developers.openai.com/api/docs). Ceny se obvykle odvíjejí od počtu vstupních a výstupních tokenů, jejichž sazby se mohou lišit.

## Jak nastavit ChatGPT API

K ověřování požadavků potřebujete klíč API. Zacházejte s ním jako s tajným údajem a bezpečně ho uchovávejte.

### Jak získat klíč API OpenAI

**Krok 1: Otevřete platformu OpenAI**

- Navštivte [platform.openai.com/api-keys](https://platform.openai.com/api-keys) a přihlaste se nebo si vytvořte účet.

**Krok 2: Vytvořte klíč API**

- V ovládacím panelu otevřete **API Keys**.
- Vyberte **Create new secret key** a případně klíči přiřaďte název konkrétního projektu.
- Až se klíč zobrazí, zkopírujte ho; později se už nemusí zobrazit.

**Krok 3: Bezpečně ho uložte**

- Uložte klíč do správce hesel nebo jako proměnnou prostředí.
- Nikdy neukládejte klíče API do systému správy verzí ani je nevystavujte v kódu na straně klienta.
- Pokud používáte soubor `.env`, přidejte ho do `.gitignore` a neukládejte ho do systému správy verzí.

**Bezpečnostní poznámky:**

- Klíč může udělovat přístup spojený s vaším účtem a fakturací.
- Pokud klíč ztratíte, vytvořte náhradní.
- Zneplatněte klíče, které mohly být kompromitovány.
- Pokud je to možné, používejte pro různé projekty samostatné klíče s odpovídajícím rozsahem oprávnění.

## Nastavení vývojového prostředí

API lze používat z jakéhokoli programovacího jazyka, který umí odesílat požadavky HTTP. Mezi běžné volby patří Python, JavaScript a Java.

### 1. Python: jednoduchost a bohatý ekosystém

Díky syntaxi a ekosystému knihoven je Python běžnou volbou. Balíček OpenAI pro Python může zjednodušit ověřování, formátování požadavků a zpracování chyb. Balíčky jako `python-dotenv` mohou usnadnit správu proměnných prostředí.

Python se používá také ve strojovém učení, datové vědě, vývoji webových aplikací a automatizaci, takže se hodí pro projekty, které kombinují volání API se zpracováním dat.

### 2. JavaScript: flexibilita pro webové aplikace

JavaScript se hodí pro backendové aplikace s Node.js i pro webové aplikace využívající frameworky jako React, Vue nebo Next.js. Jeho asynchronní funkce, včetně `async`/`await` a Promises, umožňují neblokující požadavky API.

### 3. Java: škálovatelnost a výkon

Java se běžně používá v podnikových aplikacích. Statické typování může některé chyby odhalit při kompilaci a její funkce pro souběžnost mohou aplikacím pomoci zpracovávat více požadavků. Může se hodit pro software, který se integruje se stávajícími systémy Java.

Níže uvedené příklady používají Python. Pokud používáte JavaScript nebo Javu, přizpůsobte syntaxi svému jazyku a SDK.

### 1. Pište jasné a konkrétní prompty

Příklad:

prompt.py

```python

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.

    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)

# Specify the audience, deliverable, and focus.

    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)

```

### 2. Pro spolehlivá data používejte strukturované výstupy

Pro data ve formátu JSON nebo jiná strukturovaná data používejte funkce API pro strukturované výstupy namísto parsování volného textu. V dokumentaci si ověřte podporovaný formát a jeho omezení.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Pro lepší uživatelský zážitek implementujte streamování

Streamování může zobrazovat obsah odpovědi průběžně, jak přichází, místo čekání na celou odpověď.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Chyby zpracovávejte vhodným způsobem

Požadavky mohou selhat kvůli problémům se sítí, limitům požadavků, neplatným vstupům nebo výpadkům služby. Chyby zpracovávejte podle dokumentace SDK a API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. K integraci nástrojů používejte volání funkcí

Volání funkcí umožňuje modelu požádat aplikaci o zavolání funkce nebo nástroje. Aplikace volání zpracuje a podle potřeby vrátí výsledky.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
