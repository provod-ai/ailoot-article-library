# Claude API pro začátečníky: praktický průvodce prvními kroky

> Průvodce Claude API pro začátečníky: nastavení, první požadavek, výběr modelu, hlavní funkce a postupy pro produkční provoz.



Vše, co vývojář potřebuje k prvnímu volání Claude API: klíče, Messages API, výběr modelu a základní pojmy pro přechod od prvního požadavku do produkčního provozu.

## Co je Claude API

Claude API je vývojářská platforma společnosti Anthropic. Prostřednictvím Messages API poskytuje programový přístup k modelům Claude, včetně systémových promptů, používání nástrojů, streamování, práce s obrazem a strukturovaných výstupů.

Messages API je bezstavový HTTP endpoint. Odešlete seznam zpráv uživatele a asistenta, ID modelu a limit tokenů; Claude vrátí strukturovanou odpověď. Mezi podpůrné endpointy patří dávky, soubory a počítání tokenů.

- **Bezstavovost:** API neuchovává paměť. Při každém volání znovu odešlete historii konverzace.
- **Výběr modelu:** Při změně modelu se obvykle mění jeho ID.
- **SDK:** Oficiální knihovny pro Python (anthropic) a TypeScript (@anthropic-ai/sdk) používají odpovídající struktury požadavků.

Pochopení této architektury pomáhá předejít časté začátečnické chybě: očekávání, že si API bude pamatovat předchozí požadavek.

## Krok 1: Získejte klíč a nastavte konzoli

Přejděte na **console.anthropic.com**, vytvořte účet nebo organizaci pro svůj tým a v nastavení vygenerujte API klíč. S klíčem zacházejte jako s heslem: uložte jej do proměnné prostředí a nikdy ho nevkládejte do správy zdrojového kódu.

Požadavky přes HTTP používají hlavičku **x-api-key** a hlavičku **anthropic-version**. SDK automaticky načítají **ANTHROPIC_API_KEY** z prostředí, takže většina kódu s klíčem přímo nepracuje.

- Vytvořte samostatné klíče pro vývoj, staging a produkci.
- Pomocí pracovních prostorů oddělte týmové projekty a výdaje.
- Před předáním klíčů širšímu týmu nastavte v konzoli limity používání.

## Krok 2: Proveďte první volání Messages API

Nainstalujte SDK příkazem **pip install anthropic**, exportujte svůj klíč a spusťte:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Požadovány jsou tři parametry: **model**, **max_tokens** (horní limit výstupu) a **messages**. Odpověď obsahuje seznam bloků obsahu. U každého bloku ověřte jeho typ a nepředpokládejte, že jde o prostý text, protože používání nástrojů a přemýšlení mohou přidat i jiné typy bloků. Objekt **usage** uvádí vstupní a výstupní tokeny, které mohou sloužit jako telemetrie nákladů.

## Krok 3: Vyberte model

Zde jsou aktuální modely Claude od společnosti Anthropic a jejich identifikátory API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — popisovaný jako rychlý a levný model pro klasifikaci a jednoduché úlohy ve velkém objemu.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — popisovaný jako vyvážená volba pro produkční úlohy včetně programování.
- **Claude Opus 5.5** (**claude-opus-5-5**) — popisovaný pro náročné uvažování a agentní práci s dlouhým horizontem.
- **Claude Fable 5.2** (**claude-fable-5-2**) — popisovaný jako vlajkový model pro náročné úlohy uvažování.

Začněte s modelem Opus 5.5. Vyzkoušejte Sonnet 5.5 pro vyvážený poměr rychlosti a kvality, Haiku 5.5 pro jednoduché úlohy ve velkém objemu a Fable 5.2 pro náročné uvažování. Aktuální sazby najdete na stránce cen Anthropic.

## Pět pojmů, které stojí za to poznat dál

Jakmile první požadavek funguje, tyto funkce pokrývají mnoho potřeb aplikací:

- **Systémové prompty** — parametr **system** nejvyšší úrovně, který nastavuje roli, tón a pravidla odděleně od zpráv uživatele.
- **Vícekolové konverzace** — připojte každou odpověď asistenta do pole messages a odešlete ji znovu; první zpráva musí pocházet od uživatele.
- **Streamování** — události odesílané serverem předávají tokeny při generování, což může pomoci v chatovacích rozhraních a při dlouhých výstupech.
- **Vidění** — předejte obrázky jako obsahové bloky ve formátu base64 nebo URL spolu s textem.
- **Používání nástrojů** — definujte funkce pomocí schémat JSON; Claude může rozhodnout, kdy je zavolat, zatímco váš kód je spustí a vrátí výsledky.

Když záleží na ceně, zvažte **ukládání promptů do mezipaměti** a **dávkové zpracování**; pokud musí navazující kód odpověď parsovat, zvažte **strukturované výstupy**.

## Od tutoriálu k produkci

Přechod od funkčního skriptu k produkční integraci vyžaduje technickou disciplínu:

- **Zpracování chyb:** Rozlišujte chyby limitu požadavků (429) a chyby serveru. Zdroj uvádí, že SDK je automaticky opakují s prodlevou; aktuální chování ověřte v dokumentaci příslušného SDK.
- **Přehled o nákladech:** Ve svém systému metrik zaznamenávejte **usage** z každé odpovědi.
- **Verzování promptů:** S prompty zacházejte jako s kódem: kontrolujte je, verzujte a testujte na malé evaluační sadě.
- **Připnutí modelu:** Na ID modelů odkazujte z konfigurace, aby aktualizace byly záměrné a otestované.

### Hlavní poznatky

- Messages API je bezstavové; při každém volání znovu odešlete historii konverzace.
- Ověření v surových HTTP požadavcích používá hlavičku x-api-key; SDK mohou načítat ANTHROPIC_API_KEY z prostředí.
- Tři povinné parametry požadavku jsou model, max_tokens a messages.
- Začněte s modelem Opus 5.5 a porovnejte alternativy na vlastních datech.
- Systémové prompty, streamování, vidění, používání nástrojů a vícekolová historie podporují řadu vzorců použití v aplikacích.
- Zaznamenávejte token usage pro přehled o nákladech a plánování kapacity.

## Časté dotazy

### Musím znát strojové učení, abych mohl používat Claude API?

Ne. Claude API je REST API s oficiálními SDK pro Python a TypeScript. Pokud umíte volat HTTP endpoint a parsovat JSON, můžete s Claude vytvářet aplikace. Návrh promptů, zpracování chyb a řízení nákladů jsou užitečné technické dovednosti; teorie strojového učení není pro první volání API nutná.

### S jakým modelem Claude by měl začátečník začít?

Anthropic pro většinu úloh doporučuje začít s modelem Claude Opus 5.5 (ID v API `claude-opus-5-5`). Jakmile jsou prompty stabilní, porovnejte ostatní modely na vlastních datech.

### Pamatuje si Claude API předchozí konverzace?

Ne. Messages API je bezstavové. Vaše aplikace uchovává konverzaci a při každém požadavku znovu odesílá celou historii zpráv. Díky tomu máte kontext pod kontrolou, můžete starší tahy zkrátit nebo shrnout a využít ukládání promptů do mezipaměti.
