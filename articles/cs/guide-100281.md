# Ceny OpenAI Moderation API: zdarma, limity požadavků a alternativy

> Modely OpenAI pro moderaci jsou zdarma. Podívejte se na ceny, limity požadavků podle úrovně používání, příklady v Pythonu a na to, kdy je vhodnější alternativa kompatibilní s OpenAI.




Endpoint Moderation od OpenAI je pro uživatele OpenAI API zdarma. Při výběru pracovního postupu pro produkci si ověřte podporované vstupy a kategorie, limity požadavků pro svůj účet a to, jak endpoint zapadá do vašeho procesu kontroly.

Tento průvodce odděluje oficiální informace o cenách od praktického inženýrského rozhodnutí.

## Stručně

- **Endpoint OpenAI pro moderaci je pro uživatele OpenAI API zdarma**, jak uvádí centrum nápovědy OpenAI.
- Model OpenAI `omni-moderation-latest` je navržen k detekci škodlivého obsahu a jako vstup přijímá text i obrázky, jak uvádí oficiální stránka modelu OpenAI.
- Bezplatné používání neodstraňuje náklady na pracovní postup, například na protokolování, fronty ke kontrole, mapování zásad, opakování požadavků, záložní chování a rozhodnutí specifická pro aplikaci.
- Bezplatný endpoint OpenAI zvolte, pokud už OpenAI používáte přímo a váš moderovací pracovní postup odpovídá jeho kategoriím a formátu odpovědi.
- Zvažte EvoLink Moderation 1.0, pokud už používáte EvoLink a chcete v jednom pracovním postupu multimodální kontroly, souhrn rizik a účtování za jednotlivá volání.

## Je OpenAI Moderation API zdarma?

Ano. Oficiální centrum nápovědy OpenAI uvádí, že endpoint pro moderaci je pro uživatele OpenAI API zdarma a jeho používání se nezapočítává do měsíčních limitů používání.

Zdroj: [Centrum nápovědy OpenAI: Je používání endpointu pro moderaci zdarma?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

To je odpověď ohledně ceny. Další otázka se týká provozu:

**Stačí bezplatný moderovací endpoint pro váš produkční pracovní postup?**

U prototypů, interních nástrojů a jednoduché moderace zaměřené především na text možná ano. U aplikací, které zpracovávají obsah vytvářený uživateli, nahrané obrázky, AI agenty nebo fronty ke kontrole, představuje samotné volání API pouze jednu část systému.

## Co moderace OpenAI pokrývá?

OpenAI popisuje `omni-moderation-latest` jako moderovací model určený k identifikaci potenciálně škodlivého obsahu v textu a obrázcích. Oficiální stránka modelu jej označuje za nejvýkonnější moderovací model OpenAI a uvádí podporu textu jako vstupu i výstupu a obrázků jako vstupu. Zdroj: [Stránka modelu OpenAI pro omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Průvodce moderací OpenAI také vysvětluje kategorie klasifikace obsahu a upozorňuje, že některé kategorie podporují pouze text. Pokud do `omni-moderation-latest` posíláte pouze obrázky, kategorie, které nepodporují obrazový vstup, vrátí skóre 0. Zdroj: [Průvodce moderací OpenAI](https://developers.openai.com/api/docs/guides/moderation)

Týmy by si proto měly pečlivě prostudovat tabulku kategorií, než předpokládají, že každá textová kategorie má přímý protějšek v moderaci obrázků.

## Skutečné náklady tvoří pracovní postup, nejen cena API

Endpoint pro moderaci může být zdarma, ale produkční moderovací systém stále vyžaduje rozhodnutí ohledně:

- toho, kdy kontroly spouštět: před voláním modelu, po odpovědích modelu, nebo v obou případech
- mapování kategorií na rozhodnutí povolit, předat ke kontrole nebo zablokovat
- protokolování výsledků moderace bez zbytečného ukládání citlivého obsahu
- řešení falešně pozitivních výsledků a odvolání
- samostatné moderace nahraných obrázků a textového vstupu
- monitorování latence, chyb a limitů požadavků
- zajištění konzistentního uplatňování zásad v různých částech produktu

Jde o náklady na inženýrství a provoz. V ceníku se neobjeví, ale rozhodují o tom, zda lze moderovací vrstvu skutečně dlouhodobě udržovat.

V běžném pracovním postupu kontrolujte prompty před odesláním do modelu a výstupy před předáním uživateli. Nejasné případy předejte ke kontrole, uchovávejte jen nezbytné záznamy o rozhodnutích a naplánujte, jak zpracujete opakované požadavky a odvolání.

## Kdy se bezplatný endpoint OpenAI hodí

Bezplatný moderovací endpoint OpenAI je často dobrou první volbou, když:

- už OpenAI používáte přímo
- vaše aplikace pracuje převážně s textem
- potřebujete pouze zdokumentované moderovací kategorie OpenAI
- můžete si vytvořit vlastní pracovní postup pro kontrolu a eskalaci
- váš tým je připraven zodpovídat za zpracování odpovědí, prahové hodnoty a protokoly

V takovém případě se bezplatný endpoint jen těžko odmítá. Začněte s ním, otestujte ho na skutečném obsahu a změřte falešně pozitivní výsledky i přehlédnuté případy, než na něj nasměrujete produkční provoz.

## Kdy dává smysl alternativa kompatibilní s OpenAI

EvoLink Moderation 1.0 je placená alternativa s cestou `/v1/moderations` kompatibilní s OpenAI. EvoLink přijímá nejvýše jeden obrázek na požadavek.

- kontroly pouze textu, pouze obrázků i kombinace textu a obrázků přes jeden endpoint
- 13 kategorií škodlivého obsahu se skóre pro každou kategorii
- objekt `evolink_summary` s poli `risk_level`, `flagged`, `violations`, `max_score` a `max_category`
- jednotná cena za volání namísto výpočtů podle počtu tokenů
- formát odpovědi, který se snadněji mapuje na logiku povolení, kontroly nebo blokování

## Jak používat OpenAI Moderation API v Pythonu

Pokud už používáte OpenAI SDK, základní volání pro moderaci textu vypadá takto:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Do `EVOLINK_API_KEY` uložte svůj klíč EvoLink a do `EVOLINK_BASE_URL` základní adresu API z konfigurace EvoLink. Adresa používá HTTPS a končí na `/v1`. Odpověď navíc obsahuje objekt `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Srovnání cen a pracovních postupů OpenAI a EvoLink

| Kritérium | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Účtování | Pro uživatele OpenAI API zdarma | Pevná cena za každé volání |
| Hlavní tvar endpointu | `/v1/moderations` | Kompatibilní s OpenAI `/v1/moderations` |
| Moderace textu | Podporována | Podporována |
| Moderace obrázků | Podporována modelem `omni-moderation-latest`, s podporou vstupů podle konkrétní kategorie | Podporována pro požadavky obsahující pouze obrázky i kombinaci textu a obrázků |
| Pole pro rozhodování podle pravidel | Vyhodnoťte `flagged`, `categories` a `category_scores` v `results` | Vedle skóre kategorií použijte `evolink_summary.risk_level` a `violations` |
| Pro koho se hodí | Týmy, které už volají OpenAI přímo | Týmy, které přidávají moderaci do stávajícího pracovního postupu s EvoLink |

## Praktické doporučení

Použijte bezplatný moderovací endpoint OpenAI, pokud vaše aplikace už nativně využívá OpenAI a vaše pravidla moderace dobře odpovídají zdokumentovaným kategoriím.

Pokud už váš tým používá EvoLink, posuďte cenu za jedno volání a využijte `evolink_summary.risk_level` jako jeden z podkladů, podle nichž pravidla aplikace rozhodnou, zda obsah povolit, předat ke kontrole nebo zablokovat.

Pokud má vaše aplikace vlastní požadavky na zásady, které vyžadují pravidla pro značku, kontrolu člověkem, odvolání nebo procesy zajištění souladu nad rámec možností jediného moderovacího API, použijte vícevrstvý moderovací systém.

## Časté otázky

### Je OpenAI Moderation API zdarma?

Ano. Centrum nápovědy OpenAI uvádí, že moderovací endpoint je pro uživatele OpenAI API zdarma a nezapočítává se do měsíčních limitů používání.

### Podporuje moderace OpenAI obrázky?

Ano, `omni-moderation-latest` přijímá obrázky jako vstup, jak uvádí oficiální stránka modelu OpenAI. Průvodce moderací OpenAI však upozorňuje, že některé kategorie podporují pouze text, takže by si týmy měly před spoléháním na moderaci samotných obrázků ověřit podporu vstupu pro jednotlivé kategorie.

### Je EvoLink Moderation levnější než OpenAI Moderation?

Endpoint Moderation od OpenAI je pro uživatele OpenAI API zdarma. EvoLink účtuje pevnou cenu za každé volání. Porovnejte náklady na celý pracovní postup včetně kontroly a údržby.

### Lze EvoLink použít jako alternativu k OpenAI Moderation API?

Ano. Použijte svůj klíč k EvoLink API a model `evolink-moderation-1.0` na kompatibilní cestě `/v1/moderations` služby EvoLink. Upravte zpracování odpovědi tak, aby počítalo se samostatným objektem `evolink_summary`.

### Mám moderovat prompty, výstupy, nebo obojí?

V produkčních AI aplikacích mnoho týmů moderuje vstupy i výstupy. Moderace vstupu může omezit počet nebezpečných požadavků, které se dostanou k modelu. Moderace výstupu může zachytit nebezpečné vygenerované odpovědi dříve, než se dostanou k uživatelům.

### Co je omni-moderation-latest?

Je to moderovací model OpenAI pro text a obrázky. Přečtěte pole `flagged`, `categories` a `category_scores` z `results` a použijte vlastní pravidla moderace.

### Jaký je limit požadavků OpenAI Moderation API?

Bezplatný přístup se týká účtování. Limity počtu požadavků a tokenů dál platí. V [dokumentaci modelu](https://developers.openai.com/api/docs/models/omni-moderation-latest) znamená RPM požadavky za minutu, RPD požadavky za den, pokud je tento limit uveden, a TPM tokeny za minutu.

Limity požadavků OpenAI Moderation API se liší podle úrovně účtu a mohou se v čase měnit. Než naplánujete produkční propustnost, zkontrolujte [dokumentaci OpenAI k limitům požadavků](https://platform.openai.com/docs/guides/rate-limits) a stránku [limitů používání vašeho účtu](https://platform.openai.com/settings/organization/limits).

### Jak používat OpenAI Moderation API v Pythonu?

Nainstalujte balíček `openai`, nastavte `OPENAI_API_KEY` a zavolejte `client.moderations.create()` s modelem `omni-moderation-latest` a svým textem. Pro obrázky předejte pole objektů v parametru `input`. Každá položka s obrázkem má `type: "image_url"` a objekt `image_url` obsahující `url` podle níže odkazované referenční dokumentace OpenAI API.
