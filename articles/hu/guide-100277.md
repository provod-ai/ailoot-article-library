# ChatGPT API: Beállítás, árazás és kódpéldák (2026)

> Gyakorlati útmutató a ChatGPT API beállításához, a modellek és árak összehasonlításához, valamint alkalmazások kódpéldákkal történő felépítéséhez.



A ChatGPT API programozott hozzáférést biztosít a fejlesztőknek az OpenAI modelljeihez. Ez az útmutató az API-kulcs beállítását, a modellválasztást, az árazást, a kódpéldákat, valamint az alkalmazásépítés és a költségkezelés bevált gyakorlatait mutatja be.

## Mi az a ChatGPT API?

A ChatGPT API lehetővé teszi a fejlesztők számára, hogy HTTP-kéréseken keresztül AI-képességeket integráljanak alkalmazásokba. Az alkalmazások strukturált kéréseket küldenek az OpenAI-nak, és a modell kimenetét tartalmazó JSON-válaszokat kapnak.

### Hogyan működik a ChatGPT API?

A folyamat négy lépésből áll:

**Ön elküld egy kérést.** Az alkalmazás POST-kérést küld az OpenAI-nak egy JSON-adattörzzsel, amely tartalmazza a modell nevét, az üzeneteket és olyan paramétereket, mint a hőmérséklet és a tokenkorlátok.

**Az OpenAI feldolgozza a kérést.** A modell választ generál, majd egy JSON-objektumban visszaküldi. A streamelés bekapcsolásakor a tokenek fokozatosan érkeznek.

**Az alkalmazás megkapja a választ.** A válasz tartalmazza a generált tartalmat, a tokenhasználatot, a modell adatait és a kérésazonosítót.

**A számlázás megtörténik.** A díjak a feldolgozott tokenektől függenek. A bemeneti és kimeneti tokenek díja eltérhet.

A prompt hossza, a modell kiválasztása és a gyorsítótárazás egyaránt hatással van a teljesítményre és a költségekre.

### 2. Használjon strukturált kimenetet a megbízható adatokért

JSON vagy más strukturált adatok esetén szabad szöveg elemzése helyett használja az API strukturált kimeneti funkcióit. A támogatott formátumokról és korlátozásokról a dokumentációban tájékozódjon.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Vezessen be streamelést a jobb felhasználói élményért

A streamelés lehetővé teszi, hogy a válasz tartalma érkezés közben jelenjen meg, ahelyett hogy a teljes válaszra kellene várni.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Kezelje megfelelően a hibákat

A kérések hálózati problémák, sebességkorlátozások, érvénytelen bemenet vagy szolgáltatáskiesés miatt meghiúsulhatnak. A hibákat az SDK és az API dokumentációjának megfelelően kezelje.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Használjon function callingot az eszközintegrációhoz

A function calling lehetővé teszi, hogy a modell kérje az alkalmazástól egy függvény vagy eszköz meghívását. Az alkalmazás kezeli a hívást, és szükség szerint visszaküldi az eredményeket.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
