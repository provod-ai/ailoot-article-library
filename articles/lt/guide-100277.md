# ChatGPT API: kaip nustatyti, kainodara ir kodo pavyzdžiai (2026)

> Praktinis vadovas, kaip nustatyti ChatGPT API, palyginti modelius ir kainas bei kurti programas naudojant kodo pavyzdžius.



ChatGPT API suteikia kūrėjams programinę prieigą prie OpenAI modelių. Šiame vadove aptariamas API rakto nustatymas, modelio pasirinkimas, kainodara, kodo pavyzdžiai ir programų kūrimo bei išlaidų valdymo praktika.

## Kas yra ChatGPT API?

ChatGPT API leidžia kūrėjams integruoti DI galimybes į programas siunčiant HTTP užklausas. Programos siunčia OpenAI struktūrizuotas užklausas ir gauna JSON atsakymus su modelio sugeneruotu turiniu.

### Kaip veikia ChatGPT API

Procesą sudaro keturi žingsniai:

**Jūs siunčiate užklausą.** Jūsų programa siunčia OpenAI POST užklausą su JSON duomenimis, kuriuose yra modelio pavadinimas, pranešimai ir tokie parametrai kaip temperatūra bei žetonų limitai.

**OpenAI apdoroja užklausą.** Modelis sugeneruoja atsakymą ir grąžina jį JSON objekte. Įjungus srautinį perdavimą, žetonai gaunami palaipsniui.

**Jūsų programa gauna atsakymą.** Atsakyme pateikiamas sugeneruotas turinys, žetonų naudojimo informacija, modelio informacija ir užklausos ID.

**Apskaičiuojami mokesčiai.** Mokesčiai priklauso nuo apdorotų žetonų skaičiaus. Įvesties ir išvesties žetonams gali būti taikomi skirtingi įkainiai.

Užklausos ilgis, modelio pasirinkimas ir spartinimas veikia našumą ir kainą.

## Kūrimo aplinkos nustatymas

API galima naudoti bet kuria programavimo kalba, kuria galima siųsti HTTP užklausas. Dažnai pasirenkamos Python, JavaScript ir Java.

### 1. Python: paprastumas ir plati ekosistema

Python sintaksė ir bibliotekų ekosistema lemia, kad ši kalba dažnai pasirenkama. OpenAI Python paketas gali supaprastinti autentifikavimą, užklausų formatavimą ir klaidų apdorojimą. Tokie paketai kaip `python-dotenv` gali padėti tvarkyti aplinkos kintamuosius.

Python taip pat naudojama mašininiam mokymuisi, duomenų mokslui, žiniatinklio kūrimui ir automatizavimui, todėl ji naudinga projektuose, kuriuose API iškvietimai derinami su duomenų apdorojimu.

### 2. JavaScript: lankstumas žiniatinklio programoms

JavaScript tinka ir serverio programoms su Node.js, ir žiniatinklio programoms, kuriose naudojamos tokios struktūros kaip React, Vue ar Next.js. Jos asinchroninės funkcijos, įskaitant `async`/`await` ir Promises, leidžia siųsti API užklausas neblokuojant kitų veiksmų.

### 3. Java: mastelio keitimas ir našumas

Java dažnai naudojama įmonių programose. Statinis tipavimas gali padėti aptikti kai kurias klaidas kompiliavimo metu, o lygiagretumo funkcijos gali padėti programoms apdoroti kelias užklausas. Ji gali tikti programinei įrangai, integruojamai su esamomis Java sistemomis.

Toliau pateiktuose pavyzdžiuose naudojama Python. Jei naudojate JavaScript arba Java, pritaikykite sintaksę savo kalbai ir SDK.

### 2. Naudokite struktūrizuotus rezultatus patikimiems duomenims

JSON ar kitiems struktūrizuotiems duomenims naudokite API struktūrizuoto išvesties funkcijas, o ne analizuokite laisvos formos tekstą. Palaikomą formatą ir apribojimus rasite dokumentacijoje.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Įdiekite srautinį perdavimą, kad pagerintumėte naudotojo patirtį

Srautinis perdavimas gali rodyti atsakymo turinį jam gaunant, užuot laukus viso atsakymo.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
```

### 5. Tinkamai apdorokite klaidas

Užklausos gali nepavykti dėl tinklo problemų, užklausų dažnio limitų, netinkamos įvesties arba paslaugos sutrikimų. Klaidų apdorojimą derinkite su SDK ir API dokumentacija.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Naudokite funkcijų iškvietimą įrankiams integruoti

Funkcijų iškvietimas leidžia modeliui paprašyti, kad jūsų programa iškviestų funkciją arba įrankį. Programa atlieka iškvietimą ir, kai reikia, grąžina rezultatus.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```

Jei jūsų projektui reikalingas [Chat GPT API raktas](<https://ailoot.ai/>), susikurkite Ailoot išduodamą raktą. Per Ailoot API naudokite GPT-6.2 Astra arba GPT-6.2 Sol. Iš to paties sąskaitos likučio mokėsite ir už Claude, Gemini bei medijos modelių naudojimą.

Ar kelioms jūsų programoms reikalingi atskiri ChatGPT API raktas? Ailoot sistemoje kiekvienam projektui sukurkite atskirą raktą ir nustatykite jo limitus. Tai tinka ir prototipui „ChatGPT API raktai“, ir paslaugoms, naudojančioms kelis modelius. Komandos prieigą ir įmonės išlaidas valdykite vienoje Ailoot darbo srityje.

Naujus pažangiausius modelius naudokite nuo jų išleidimo dienos, atsiskaitydami iš to paties Ailoot sąskaitos likučio. Viena prenumerata apima visą katalogą. Su prenumeratomis ir nuolaidų kodais modeliams galite išleisti iki 50 % mažiau, palyginti su oficialiais modelių tiekėjų API tarifais. Prisijunkite prie savo paskyros adresu [https://ailoot.ai/](<https://ailoot.ai/>) arba paprašykite nuolaidos kodo Ailoot komandos.
