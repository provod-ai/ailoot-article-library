# Claude API pradedantiesiems: praktinis pradžios vadovas

> Praktinis Claude API vadovas pradedantiesiems apima sąranką, pirmąją užklausą, modelio pasirinkimą, pagrindines funkcijas ir darbą gamybinėje aplinkoje.



Viskas, ko kūrėjui reikia pirmajam Claude API iškvietimui: raktai, Messages API, modelio pasirinkimas ir pagrindinės sąvokos, padedančios pereiti nuo pirmos užklausos prie gamybinės aplinkos.

## Kas yra Claude API

Claude API yra „Anthropic“ kūrėjų platforma. Ji suteikia programinę prieigą prie Claude modelių per Messages API, palaiko sistemos raginimus, įrankių naudojimą, srautinį perdavimą, vaizdų apdorojimą ir struktūrizuotus rezultatus.

Messages API yra būsenos nesaugantis HTTP galinis taškas. Siunčiate naudotojo ir asistento pranešimų sąrašą, modelio ID ir žetonų limitą; Claude grąžina struktūrizuotą atsakymą. Pagalbiniai galiniai taškai apima paketines užduotis, failus ir žetonų skaičiavimą.

- **Būsenos nesaugantis:** API nieko neatsimena. Kiekvieno iškvietimo metu iš naujo siųskite pokalbio istoriją.
- **Modelio pasirinkimas:** Keičiant modelį paprastai reikia pakeisti ir modelio ID.
- **SDK:** Oficialios Python (anthropic) ir TypeScript (@anthropic-ai/sdk) bibliotekos naudoja atitinkamus užklausų formatus.

Šios architektūros supratimas padeda išvengti dažnos pradedančiųjų klaidos – tikėtis, kad API prisimins ankstesnę užklausą.

## 1 žingsnis: Gaukite raktą ir nustatykite konsolę

Atidarykite **console.anthropic.com**, sukurkite paskyrą arba savo komandai skirtą organizaciją, tada nustatymuose sugeneruokite API raktą. Elkitės su juo kaip su slaptažodžiu: saugokite aplinkos kintamajame ir niekada nedėkite į šaltinio valdymo sistemą.

Tiesioginėms HTTP užklausoms naudojamos **x-api-key** ir **anthropic-version** antraštės. SDK automatiškai nuskaito **ANTHROPIC_API_KEY** iš aplinkos, todėl daugumoje kodo nereikia rakto tvarkyti tiesiogiai.

- Sukurkite atskirus raktus kūrimo, parengimo ir gamybinei aplinkai.
- Naudokite darbo sritis komandos projektams ir išlaidoms atskirti.
- Prieš suteikdami raktus daugiau komandos narių, konsolėje nustatykite naudojimo limitus.

## 2 žingsnis: Atlikite pirmą Messages API iškvietimą

Įdiekite SDK naudodami **pip install anthropic**, eksportuokite savo raktą ir paleiskite:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Būtini trys parametrai: **model**, **max_tokens** (didžiausia išvesties riba) ir **messages**. Atsakyme pateikiamas turinio blokų sąrašas. Patikrinkite kiekvieno bloko tipą ir nemanykite, kad jame bus tik paprastas tekstas, nes naudojant įrankius ir mąstymo funkcijas gali atsirasti kitų tipų blokų. **usage** objektas nurodo įvesties ir išvesties žetonų skaičių, todėl gali būti naudojamas išlaidų telemetrijai.

## 3 žingsnis: Pasirinkite modelį

Toliau pateikiami dabartiniai „Anthropic“ Claude modeliai ir jų API identifikatoriai.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — apibūdinamas kaip greitas ir nebrangus modelis klasifikavimo bei didelės apimties paprastoms užduotims.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — apibūdinamas kaip subalansuotas pasirinkimas gamybinėms užduotims, įskaitant programavimą.
- **Claude Opus 5.5** (**claude-opus-5-5**) — apibūdinamas kaip tinkamas sudėtingam samprotavimui ir ilgalaikiam agentiniam darbui.
- **Claude Fable 5.2** (**claude-fable-5-2**) — apibūdinamas kaip pavyzdinis modelis sudėtingoms samprotavimo užduotims.

Pradėkite nuo Opus 5.5. Išbandykite Sonnet 5.5, kai reikia spartos ir kokybės pusiausvyros, Haiku 5.5 – dideliam kiekiui paprastų užduočių, o Fable 5.2 – sudėtingam samprotavimui. Dabartinius įkainius tikrinkite „Anthropic“ kainų puslapyje.

## Penkios sąvokos, kurias verta išmokti toliau

Kai pirmoji užklausa jau veikia, šios funkcijos patenkina daugelį programoms keliamų poreikių:

- **Sistemos raginimai** — aukščiausio lygio **system** parametras, kuris atskirai nuo naudotojo pranešimų nustato vaidmenį, toną ir taisykles.
- **Kelių ėjimų pokalbiai** — pridėkite kiekvieną asistento atsakymą prie messages masyvo ir siųskite jį iš naujo; pirmasis pranešimas turi būti naudotojo.
- **Srautinis perdavimas** — serverio siunčiami įvykiai perduoda žetonus jiems generuojant, todėl tai gali būti naudinga pokalbių sąsajoms ir ilgoms išvestims.
- **Vaizdai** — kartu su tekstu perduokite vaizdus kaip base64 arba URL turinio blokus.
- **Įrankių naudojimas** — apibrėžkite funkcijas su JSON schemomis; Claude gali pasirinkti, kada jas iškviesti, o jūsų kodas jas įvykdo ir grąžina rezultatą.

Kai svarbios išlaidos, apsvarstykite **prompt caching** ir **batch processing**, o jei tolesnis kodas turi išanalizuoti atsakymą, – **structured outputs**.

## Nuo vadovėlio iki gamybinės aplinkos

Veikiančio scenarijaus pavertimas gamybine integracija reikalauja inžinerinės drausmės:

- **Klaidų tvarkymas:** Greičio limito (429) ir serverio klaidas tvarkykite atskirai. Šaltinyje nurodoma, kad SDK tokias užklausas automatiškai bando pakartoti su didėjančiomis pauzėmis; dabartinę elgseną tikrinkite atitinkamo SDK dokumentacijoje.
- **Išlaidų matomumas:** Savo metrikų sistemoje registruokite kiekvieno atsakymo **usage**.
- **Raginimų versijavimas:** Raginimus tvarkykite kaip kodą: juos peržiūrėkite, versijuokite ir išbandykite su nedideliu vertinimo rinkiniu.
- **Modelio prisegimas:** Modelių ID nurodykite konfigūracijoje, kad atnaujinimai būtų sąmoningai suplanuoti ir išbandyti.

### Svarbiausios išvados

- Messages API neišsaugo būsenos; kiekvieno iškvietimo metu iš naujo siųskite pokalbio istoriją.
- Tiesioginiam HTTP autentifikavimui naudojama x-api-key antraštė; SDK gali nuskaityti ANTHROPIC_API_KEY iš aplinkos.
- Trys būtini užklausos parametrai yra model, max_tokens ir messages.
- Pradėkite nuo Opus 5.5 ir palyginkite alternatyvas naudodami savo duomenis.
- Sistemos raginimai, srautinis perdavimas, vaizdai, įrankių naudojimas ir kelių ėjimų istorija tinka daugeliui programų modelių.
- Registruokite žetonų naudojimą, kad galėtumėte stebėti išlaidas ir planuoti pajėgumą.

## DUK

### Ar norint naudoti Claude API reikia išmanyti mašininį mokymąsi?

Ne. Claude API yra REST API su oficialiais Python ir TypeScript SDK. Jei galite iškviesti HTTP galinį tašką ir išanalizuoti JSON, galite kurti naudodami Claude. Raginimų kūrimas, klaidų tvarkymas ir išlaidų valdymas yra naudingi inžineriniai įgūdžiai; norint atlikti pirmą API iškvietimą mašininio mokymosi teorijos nereikia.

### Nuo kurio Claude modelio turėtų pradėti pradedantysis?

„Anthropic“ daugumai darbo krūvių rekomenduoja pradėti nuo Claude Opus 5.5 (API identifikatorius `claude-opus-5-5`). Kai raginimai nusistovės, palyginkite kitus modelius naudodami savo duomenis.

### Ar Claude API prisimena ankstesnius pokalbius?

Ne. Messages API neišsaugo būsenos. Jūsų programa išsaugo pokalbį ir su kiekviena užklausa iš naujo siunčia visą pranešimų istoriją. Taip galite valdyti kontekstą, sutrumpinti ar apibendrinti senesnius ėjimus ir naudoti raginimų spartinančiąją atmintinę.
