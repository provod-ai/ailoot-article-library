## Ar OpenAI Moderation API yra nemokama?

Taip. Oficialiajame OpenAI pagalbos centro puslapyje teigiama, kad Moderation sąsaja OpenAI API naudotojams yra nemokama ir kad įrankio naudojimas neįskaičiuojamas į mėnesio naudojimo limitus.

Šaltinis: [OpenAI pagalbos centras: ar Moderation sąsaja nemokama?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Tai atsakymas apie kainodarą. Kitas klausimas yra operacinis:

**Ar nemokamos moderavimo sąsajos pakanka jūsų gamybinei darbo eigai?**

Prototipams, vidiniams įrankiams ir paprastam, pirmiausia tekstu paremtam moderavimui jos gali pakakti. Programoms, kurios apdoroja naudotojų kuriamą turinį, įkeliamus vaizdus, DI agentus ar peržiūros eiles, API užklausa tėra viena sistemos dalis.

## Ką apima OpenAI moderavimas?

OpenAI nurodo, kad `omni-moderation-latest` yra moderavimo modelis, skirtas potencialiai žalingam tekstiniam ir vaizdiniam turiniui atpažinti. Oficialiajame modelio puslapyje jis apibūdinamas kaip pajėgiausias OpenAI moderavimo modelis; jame nurodyta, kad palaikomos tekstinės įvestys ir išvestys bei vaizdų įvestys. Šaltinis: [OpenAI modelio puslapis apie omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) OpenAI moderavimo vadove taip pat paaiškinamos turinio klasifikavimo kategorijos ir pažymima, kad kai kurios kategorijos taikomos tik tekstui. Jei į `omni-moderation-latest` siunčiate tik vaizdus, kategorijų, kurios nepalaiko vaizdų įvesties, įvertis bus 0. Šaltinis: [OpenAI moderavimo vadovas](https://developers.openai.com/api/docs/guides/moderation)

Tai reiškia, kad prieš manydamos, jog kiekviena tekstui skirta kategorija tiesiogiai pritaikoma vaizdų moderavimui, komandos turėtų atidžiai perskaityti kategorijų lentelę.

## Tikrosios sąnaudos susijusios su darbo eiga, o ne vien API kainodara

Moderation sąsaja gali būti nemokama, tačiau gamybinei moderavimo sistemai vis tiek reikia priimti sprendimus dėl šių dalykų:

- kur vykdyti patikras: prieš modelio užklausas, po modelio atsakymų ar ir prieš, ir po jų
- kaip susieti kategorijas su leidimo, peržiūros ar blokavimo sprendimais
- kaip registruoti moderavimo rezultatus be reikalo nesaugant jautraus turinio
- kaip tvarkyti klaidingus teigiamus rezultatus ir apeliacijas
- kaip moderuoti vaizdų įkėlimus atskirai nuo tekstinės įvesties
- kaip stebėti delsą, klaidas ir užklausų dažnio apribojimus
- kaip užtikrinti nuoseklų politikos taikymą įvairiose produkto dalyse

Tai inžinerijos ir operacijų sąnaudos. Kainodaros puslapyje jų nematyti, tačiau jos lemia, ar moderavimo sluoksnį iš tiesų įmanoma prižiūrėti.

Įprastoje darbo eigoje tikrinkite užklausas prieš siųsdami jas modeliui, o išvestis – prieš pateikdami naudotojui. Neaiškius atvejus perduokite peržiūrai, fiksuokite tik būtiną informaciją apie sprendimus ir numatykite, kaip tvarkysite pakartotinius bandymus bei skundus.

## Kada nemokama OpenAI sąsaja yra tinkamas pasirinkimas

Nemokama OpenAI Moderation sąsaja dažnai yra geras pirmasis pasirinkimas, kai:

- jau tiesiogiai naudojate OpenAI
- jūsų programa daugiausia apdoroja tekstą
- jums reikia tik OpenAI dokumentuotų moderavimo kategorijų
- galite patys sukurti peržiūros ir eskalavimo darbo eigą
- jūsų komanda pasirengusi prisiimti atsakomybę už atsakymų analizę, slenksčius ir žurnalus

Tokiu atveju sunku rasti argumentų prieš nemokamą sąsają. Pradėkite nuo jos, išbandykite su savo tikruoju turiniu ir prieš nukreipdami gamybinį srautą įvertinkite klaidingai teigiamus rezultatus bei praleistus atvejus.

## Kada tinka su OpenAI suderinama alternatyva

EvoLink Moderation 1.0 yra mokama alternatyva su OpenAI suderinamu `/v1/moderations` maršrutu. EvoLink priima ne daugiau kaip vieną vaizdą vienoje užklausoje.

- tekstas, tik vaizdai ir tekstas kartu su vaizdais tikrinami per vieną sąsają
- 13 žalos kategorijų su kiekvienos kategorijos įverčiais
- objektas `evolink_summary` su laukais `risk_level`, `flagged`, `violations`, `max_score` ir `max_category`
- fiksuota kaina už užklausą vietoj skaičiavimo pagal žetonus
- atsakymo struktūra, kurią lengviau susieti su leidimo, peržiūros ar blokavimo logika

## Kaip naudoti OpenAI Moderation API su Python

Jei jau naudojate OpenAI SDK, paprasta teksto moderavimo užklausa atrodo taip:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Į `EVOLINK_API_KEY` įrašykite savo EvoLink raktą, o į `EVOLINK_BASE_URL` – pagrindinį API HTTPS adresą iš EvoLink API konfigūracijos, kuris baigiasi `/v1`. Atsakyme papildomai pateikiamas objektas `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## OpenAI ir EvoLink kainodaros bei darbo eigos palyginimas

| Kriterijus | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Apmokestinimas | OpenAI API naudotojams nemokama | Fiksuotas mokestis už kiekvieną iškvietimą |
| Pagrindinės sąsajos forma | `/v1/moderations` | Su OpenAI suderinama `/v1/moderations` |
| Teksto moderavimas | Palaikomas | Palaikomas |
| Vaizdų moderavimas | Palaikomas modelyje `omni-moderation-latest`, taikant konkrečioms kategorijoms skirtą įvesties palaikymą | Palaikomas tik vaizdų ir teksto kartu su vaizdais užklausoms |
| Laukai sprendimams pagal moderavimo taisykles | Įvertinkite `flagged`, `categories` ir `category_scores` lauke `results` | Kartu su kategorijų įverčiais naudokite `evolink_summary.risk_level` ir `violations` |
| Kam labiausiai tinka | Komandoms, kurios jau siunčia užklausas tiesiogiai į OpenAI | Komandoms, kurios įtraukia moderavimą į esamą EvoLink darbo eigą |

## Praktinė rekomendacija

Naudokite nemokamą OpenAI Moderation sąsają, jei jūsų programa jau sukurta naudojant OpenAI ir jūsų moderavimo politika aiškiai atitinka dokumentuotas kategorijas.

Jei jūsų komanda jau naudoja EvoLink, įvertinkite vieno iškvietimo kainą ir įtraukite `evolink_summary.risk_level` kaip vieną iš kriterijų į programos taisykles, pagal kurias nusprendžiama, ar leisti turinį, perduoti jį peržiūrai, ar blokuoti.

Naudokite kelių sluoksnių moderavimo sistemą, jei jūsų programai reikia tinkintos politikos, apimančios prekės ženklo taisykles, žmonių atliekamą peržiūrą, apeliacijas ar atitikties procesus, kurių neapima viena moderavimo API.

## DUK

### Ar OpenAI Moderation API yra nemokama?

Taip. OpenAI pagalbos centro teigimu, Moderation sąsaja OpenAI API naudotojams yra nemokama ir neįskaičiuojama į mėnesio naudojimo limitus.

### Ar OpenAI moderavimas palaiko vaizdus?

Taip, pagal oficialų OpenAI modelio puslapį `omni-moderation-latest` priima vaizdus kaip įvestį. Tačiau OpenAI moderavimo vadove pažymima, kad kai kurios kategorijos taikomos tik tekstui, todėl komandos turėtų patikrinti, kokios įvestys palaikomos kiekvienoje kategorijoje, prieš pasikliaudamos vien vaizdų moderavimu.

### Ar EvoLink Moderation kainuoja mažiau nei OpenAI Moderation?

OpenAI Moderation sąsaja OpenAI API naudotojams yra nemokama. EvoLink taiko fiksuotą mokestį už kiekvieną iškvietimą. Palyginkite visos darbo eigos sąnaudas, įskaitant peržiūrą ir priežiūrą.

### Ar galiu naudoti EvoLink kaip OpenAI Moderation API alternatyvą?

Taip. Naudokite savo EvoLink API raktą ir modelį `evolink-moderation-1.0` suderinamame EvoLink maršrute `/v1/moderations`. Pritaikykite atsakymo apdorojimą taip, kad programa apdorotų ir atskirą objektą `evolink_summary`.

### Ar turėčiau moderuoti užklausas, atsakymus ar ir viena, ir kita?

Gamybines DI programas kuriančios komandos dažnai moderuoja ir įvestis, ir išvestis. Įvesties moderavimas gali sumažinti nesaugių užklausų skaičių dar prieš jas pasiekiant modeliui. Išvesties moderavimas gali aptikti nesaugius sugeneruotus atsakymus dar prieš jiems pasiekiant naudotojus.

### Kas yra omni-moderation-latest?

Tai OpenAI teksto ir vaizdų moderavimo modelis. Nuskaitykite `flagged`, `categories` ir `category_scores` iš `results` ir taikykite savo moderavimo politiką.

### Koks yra OpenAI Moderation API užklausų dažnio apribojimas?

Nemokama prieiga susijusi su apmokestinimu. Užklausų ir žetonų apribojimai tebegalioja. [Modelio dokumentacijoje](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM reiškia užklausų skaičių per minutę, RPD – užklausų skaičių per dieną, jei šis apribojimas nurodytas, o TPM – žetonų skaičių per minutę.

OpenAI Moderation API užklausų dažnio apribojimai priklauso nuo paskyros lygio ir laikui bėgant gali keistis. Prieš planuodami gamybinį pralaidumą, patikrinkite [OpenAI užklausų dažnio apribojimų dokumentaciją](https://platform.openai.com/docs/guides/rate-limits) ir savo paskyros [naudojimo limitų puslapį](https://platform.openai.com/settings/organization/limits).

### Kaip naudoti OpenAI Moderation API su Python?

Įdiekite paketą `openai`, nustatykite `OPENAI_API_KEY` ir iškvieskite `client.moderations.create()` su modeliu `omni-moderation-latest` ir savo tekstu. Vaizdams parametrą `input` perduokite kaip objektų masyvą. Kiekvienas vaizdo elementas turi `type: "image_url"` ir objektą `image_url` su lauku `url`, kaip parodyta toliau pateiktoje OpenAI API dokumentacijoje.
