# ChatGPT API：設定方式、定價與程式碼範例（2026）

> 實用指南：說明如何設定 ChatGPT API、比較模型與定價，並透過程式碼範例建立應用程式。



ChatGPT API 讓開發者能以程式方式存取 OpenAI 模型。本指南涵蓋 API 金鑰設定、模型選擇、定價、程式碼範例，以及建置應用程式和管理成本的實務做法。

## 什麼是 ChatGPT API？

ChatGPT API 讓開發者透過 HTTP 請求，將 AI 功能整合至應用程式。應用程式會向 OpenAI 傳送結構化請求，並接收包含模型輸出的 JSON 回應。

### ChatGPT API 的運作方式

這個流程分為四個步驟：

**你傳送請求。** 你的應用程式會向 OpenAI 傳送 POST 請求，並附上 JSON payload，其中包含模型名稱、訊息，以及 temperature 和 token 限制等參數。

**OpenAI 處理請求。** 模型會產生回應，並以 JSON 物件形式傳回。啟用串流後，token 會逐步傳送。

**你的應用程式接收回應。** 回應包含生成的內容、token 使用量、模型資訊和請求 ID。

**系統計費。** 費用取決於處理的 token 數量。輸入和輸出 token 的費率可能不同。

提示長度、模型選擇和快取都會影響效能與成本。

## 如何設定 ChatGPT API

你需要 API 金鑰來驗證請求。請將金鑰視為機密並妥善保存。

### 如何取得 OpenAI API 金鑰

**步驟 1：前往 OpenAI Platform**

- 前往 [platform.openai.com/api-keys](https://platform.openai.com/api-keys) 並登入或建立帳戶。

**步驟 2：建立 API 金鑰**

- 在控制台開啟 **API Keys**。
- 選取 **Create new secret key**，也可以選擇為金鑰設定專案專用名稱。
- 金鑰顯示時請立即複製；之後可能無法再次查看。

**步驟 3：妥善保存金鑰**

- 將金鑰存放在密碼管理工具或環境變數中。
- 切勿將 API 金鑰提交至版本控制，也不要在用戶端程式碼中公開。
- 如果使用 `.env` 檔案，請將它加入 `.gitignore`，並排除在版本控制之外。

**安全注意事項：**

- 金鑰可能會授予與你的帳戶和帳單相關的存取權限。
- 如果金鑰遺失，請建立替代金鑰。
- 如果金鑰可能已遭到入侵，請撤銷該金鑰。
- 如果可以，請為不同專案使用個別且權限範圍適當的金鑰。

## 常見問題

**ChatGPT 有 API 嗎？**

有。OpenAI 提供 API，讓使用者能以程式方式存取模型。應用程式可以傳送 HTTP 請求或使用官方 SDK；請查看最新文件，瞭解可用模型和功能。

**ChatGPT API 的費用是多少？**

價格取決於模型和使用量。請查看 [OpenAI 定價頁面](https://openai.com/api/pricing/)，瞭解目前費率和可用的成本管理選項。

**ChatGPT 和 ChatGPT API 有什麼不同？**

ChatGPT 是一項對話式產品。API 則讓開發者能以程式方式傳送請求，並將模型回應整合至應用程式；可用的控制項由 API 和所選模型決定。

**ChatGPT API 目前提供的最新模型是什麼？**

模型供應情況會變動。請參閱 OpenAI 最新的 [API 文件](https://developers.openai.com/api/docs)，瞭解最新模型和功能。

**我應該使用 Responses API 還是 Chat Completions？**

請依據應用程式及其所需功能選擇 API。OpenAI 文件說明了目前的端點和移轉指引。現有應用程式應依照其端點的文件化支援和移轉指示進行。

**我可以免費使用 ChatGPT API 嗎？**

費用和任何額度取決於目前的帳戶條款和使用量。規劃預算前，請先查看 OpenAI 的定價資訊。
