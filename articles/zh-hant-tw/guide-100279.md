# LLM 推論的實際成本，來自你沒有使用的 GPU

> API 輸入 Token 的兩項歷史價格基準相差 600 倍。了解 GPU 使用率、租用期間的閒置時數，以及尖峰費率如何影響 LLM 推論成本。



2026 年的一項研究（arXiv:2603.28576，§4）比較了兩個 API 定價基準。以每百萬個輸入 Token 計算，該研究對 2020 年的 GPT-3 採用 60 美元，對 2025 年 2 月的經濟級 Gemini 2.0 Flash 採用 0.10 美元，兩者相差 600 倍。研究估計，納入分析的經濟級模型，其 API 價格半衰期為 1.1 年。

價格通縮的新聞標題掩蓋了真正決定帳單的因素：GPU 有多少運作時間用在有效工作上。推論按 Token 計費，卻是按小時提供服務。

## 團隊容易忽略的數字

2026 年 6 月的 vLLM 基準測試（arXiv:2606.11690，§§4–5）使用兩張 H100 NVL GPU，以張量平行處理（TP=2）執行 FP16 精度的 Mixtral 8x7B Instruct。GPU 合計租金為每小時 13.96 美元。測試停用了前綴快取，並使用每筆包含 512 個輸入 Token 和 256 個輸出 Token 的合成請求。表中的成本是以 GPU 租金除以同一期間量測到的輸出 Token 數。請求速率以送往伺服器的請求數計算。

| 在兩張 H100 NVL GPU 上執行的 Mixtral 8x7B | 每百萬個輸出 Token 的實際成本 |
|--------------------------------------|-------------------------------|
| 每秒 1 個請求（接近閒置）           | 約 \$15.25                    |
| 每秒送出 100 筆請求（接近飽和）                      | 約 \$0.87                     |

兩項實測成本相差 17.5 倍。每秒送出 25 筆請求時，每百萬個輸出 Token 約需 0.95 美元。每秒送出 100 筆請求時，伺服器每秒約完成 17.4 筆。這項研究測試了六種 H100 組態和不同負載，每百萬個輸出 Token 的成本介於 0.21 與 15.25 美元之間。這些數字都是在這次測試工作負載下量測得出的結果。在正式環境中，請在符合延遲目標的負載下量測吞吐量。

每小時租金相同時，如果輸出吞吐量只達尖峰值的 40%，每個輸出 Token 的成本就會變成 2.5 倍。以下範例中的使用率，是服務實際達到的輸出吞吐量占尖峰值的比例。GPU 的活動指標可能很高，即使實際產出的 Token 很少。

這就是為什麼兩個使用相同模型的團隊，可能會報出差異懸殊的單位成本。一個團隊以 40% 的使用率執行流量時有時無的聊天機器人；另一個團隊則以 90% 的使用率執行滿載的批次處理管線。模型、硬體和標價都相同，單位成本卻不同。供應商向你報出每個 Token 的成本時，請問清楚其中假設的使用率是多少。

## 開放權重模型讓情況更糟

混合專家（MoE）模型處理每個 Token 時，會使用一部分權重。Mixtral 8x7B 每個 Token 約啟用 129 億個參數，全模型共有 467 億個參數。如果將模型完全放在 GPU 上執行，請依權重的儲存精度，估算容納全部權重所需的記憶體，再加上 KV 快取和執行時的額外記憶體用量。啟用的參數量有助於估算每個 Token 的運算量。記憶體頻寬、專家路由與批次大小也會影響吞吐量。

請按你自己的工作負載估算損益兩平點。以相同的輸入和輸出 Token 用量為基準，比較 API 帳單與 GPU 租金加上服務營運成本。GPU 租金要算進你需要租用的所有時數，包括閒置時數。請用你的流量型態，在符合延遲目標的條件下量測輸出吞吐量。API 價格、模型組態和使用率都會影響結果。

## 第二項隱藏成本：一天中的時段

截至 2026 年 11 月 25 日，直接使用 DeepSeek API 時，週一至週五的 01:00–04:00 和 06:00–10:00（UTC）適用尖峰費率，中國的法定假日除外。換算成印度標準時間（IST，UTC+05:30），這兩個時段為 06:30–09:30 和 11:30–15:30。其他時間均適用離峰費率，週末與中國法定假日也全天適用離峰費率。[DeepSeek API 定價](https://api-docs.deepseek.com/quick_start/pricing/)

在適用尖峰費率的平日，10:00 IST（04:30 UTC）是離峰時段，15:00 IST（09:30 UTC）是尖峰時段。以每百萬個 Token 的美元價格計，`deepseek-flash` 的離峰與尖峰費率，按命中快取的輸入、未命中快取的輸入、輸出的順序，分別為 0.003 和 0.006、0.15 和 0.30、0.60 和 1.20。`deepseek-v4-pro` 按相同順序分別為 0.022 和 0.044、0.66 和 1.32、1.98 和 3.96。

## 真正影響成本的因素

如果你正在編列推論預算，請先按以下順序檢視，再比較模型價格：

1.  先看使用率，再看硬體。使用率 40% 的 H200，每個 Token 的成本可能高於滿載的 H100。
2.  確認供應商是否對命中快取的輸入提供折扣。重複使用長系統提示詞或共用前綴時，若符合快取命中費率的條件，就有機會降低輸入費用。
3.  按你在尖峰及離峰時段的流量占比，對兩種費率加權。直接使用 DeepSeek API 時，在 Token 用量和快取條件相同的情況下，尖峰費用是離峰的兩倍。
4.  以批次處理可以等候的背景工作，例如建立 RAG 索引或大量擷取資料。用你預計採用的批次設定量測輸出吞吐量與延遲。
5.  對於 MoE 模型，請依啟用的參數量估算運算量，並預留全部權重、KV 快取與執行時額外開銷所需的記憶體。
