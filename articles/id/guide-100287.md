# Apa itu router LLM?

> Pelajari cara router LLM memilih model berdasarkan biaya, latensi, kerahasiaan, dan kualitas, serta hubungan perutean dengan gateway dan failover.



> **Definisi:** Router LLM adalah lapisan control plane di antara aplikasi Anda dan beberapa model AI yang mengirim setiap permintaan ke model paling sesuai berdasarkan biaya, latensi, kualitas, dan kerahasiaan. Router mengurangi pengeluaran, menghilangkan ketergantungan pada satu vendor, dan menambahkan failover otomatis.

Router LLM (juga disebut *gateway AI*, *router model*, atau *broker LLM*) adalah lapisan di antara aplikasi Anda dan banyak model. Alih-alih membuat kode yang terhubung ke API satu penyedia, aplikasi Anda memanggil router, yang memilih model terbaik untuk setiap permintaan dan menyediakan satu antarmuka terpadu.

- Menganalisis setiap permintaan (jenis tugas, kompleksitas, sensitivitas)
- Memilih model optimal (model murah untuk tugas sederhana, model terdepan untuk tugas sulit)
- Menangani penyeimbangan beban dan failover di berbagai penyedia
- Perutean dapat menekan biaya jika model yang dipilih memenuhi kebutuhan kualitas Anda.

## Router LLM vs. gateway AI: apa bedanya?

Keduanya memiliki fungsi yang tumpang tindih. **Router** menekankan pemilihan model untuk setiap permintaan; **gateway AI** menambahkan autentikasi, tata kelola, dan observabilitas; **broker** menekankan mediasi netral vendor di antara banyak penyedia. Solusi yang tangguh melakukan ketiganya.

## Bagaimana cara kerja perutean LLM?

Router memberi skor pada setiap permintaan berdasarkan empat kriteria:

- **Biaya** — tugas sederhana diarahkan ke model murah, model mahal hanya digunakan jika diperlukan.
- **Latensi** — permintaan yang sensitif terhadap waktu diarahkan ke model kecil yang cepat.
- **Kerahasiaan / kelas perlindungan** — Kirim permintaan sensitif hanya ke layanan dan lokasi yang telah disetujui.
- **Kualitas** — tugas kompleks diarahkan ke model terdepan.

Perutean dapat bersifat **statis** (aturan), **dinamis** (berbasis penilaian/model), **hibrida**, atau **dipelajari (RL)**.

## Berapa banyak biaya yang dihemat oleh perutean LLM? (buktinya)

- **RouteLLM** (UC Berkeley/LMSYS, arXiv 2406.18665): Pada MT Bench, penulis melaporkan biaya sekitar 85% lebih rendah dengan skor sekitar 95% dari skor GPT-4, dibandingkan dengan menggunakan GPT-4 untuk setiap permintaan \[R1\].
- **AWS Bedrock Intelligent Prompt Routing:** AWS memperkirakan penghematan biaya hingga 30% saat merutekan permintaan di antara model dalam satu keluarga [\[R2\]](https://aws.amazon.com/bedrock/intelligent-prompt-routing/).
- **Rentang biaya:** Harga bervariasi menurut model dan penyedia. Bandingkan tarif terbaru untuk token input dan output saat memilih model.


## Perutean netral vendor: cara mengakhiri vendor lock-in

Router milik penyedia mengunci Anda satu tingkat lebih tinggi. **Broker netral vendor** mengabstraksikan koneksi lintas penyedia (OpenAI, Anthropic, Google, Mistral, model dengan bobot terbuka), sehingga beralih model cukup dilakukan dengan konfigurasi, bukan kode. Ini solusi langsung untuk vendor lock-in AI.

## Perutean LLM berdaulat EU dan on-prem

Router dapat membatasi permintaan sensitif ke model yang telah disetujui dan dijalankan di Uni Eropa atau pada infrastruktur sendiri, serta mengirim permintaan publik ke model cloud yang lebih murah jika diizinkan. Periksa apakah cara setiap layanan memproses dan menyimpan data sesuai dengan persyaratan yang berlaku.

## Membangun sendiri vs. membeli

Total biaya kepemilikan — dan apakah kelas perlindungan serta kedaulatan EU harus terintegrasi sejak awal — menentukan pilihan.

## FAQ

**Apa itu router LLM?**

Router LLM adalah lapisan perangkat lunak di antara aplikasi Anda dan beberapa model AI yang merutekan setiap permintaan ke model paling sesuai berdasarkan biaya, latensi, kualitas, dan kerahasiaan, serta menyediakan satu API terpadu.

**Bagaimana cara kerja perutean LLM?**

Router memberi skor pada setiap permintaan dan memilih model menggunakan aturan statis, penilaian dinamis, atau kebijakan yang dipelajari — tugas sederhana dikirim ke model murah dan tugas sulit ke model terdepan.

**Apakah router LLM sama dengan gateway AI?**

Tidak persis. Router menekankan pemilihan model untuk setiap permintaan; gateway menambahkan autentikasi, tata kelola, dan observabilitas. Platform yang tangguh menggabungkan keduanya, ditambah perantaraan netral vendor.

**Berapa banyak biaya yang dihemat oleh router LLM?**

Pada MT Bench, penulis RouteLLM melaporkan biaya sekitar 85% lebih rendah dengan skor sekitar 95% dari skor GPT-4, dibandingkan dengan menggunakan GPT-4 untuk setiap permintaan. AWS melaporkan penghematan hingga 30% untuk perutean dalam satu keluarga model. Penghematan aktual bergantung pada beban kerja.

**Apakah perutean menurunkan kualitas jawaban?**

Kualitas bergantung pada tugas, model, dan aturan perutean. Uji aturan tersebut dengan permintaan yang mewakili beban kerja Anda.

**Bisakah saya menjalankan router LLM on-premise / di EU?**

Ya, jika router dan model mendukung penerapan ini. Tentukan layanan mana yang boleh menangani permintaan sensitif dan periksa persyaratan pemrosesan data yang berlaku.
