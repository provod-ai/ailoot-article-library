# Pembaruan alat Gemini API: pengaliran konteks, kombinasi alat, dan grounding Maps untuk Gemini 3

> Developer dapat menggabungkan pemanggilan fungsi dengan alat bawaan seperti Google Search dalam satu panggilan Gemini API, mengalirkan konteks di antara panggilan alat dan giliran, serta menggunakan Grounding with Google Maps dengan model Gemini 3.



17 Mar 2026

Dalam [pengumuman Google, 17 Maret 2026](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tooling-updates/), tiga pembaruan Gemini API dijelaskan: alat bawaan dan fungsi kustom dalam satu permintaan, penerusan konteks antar-langkah, serta perluasan Grounding with Google Maps ke Gemini 3. Dukungan nyata bergantung pada model dan versi API, jadi periksa dokumentasi terbaru sebelum integrasi.

Kombinasi alat bawaan dan fungsi kustom saat ini ditandai sebagai fitur preview dalam dokumentasi.

## Satukan alat dan fungsi aplikasi

Agen dapat mencari informasi publik lalu memeriksa sistem internal. [Panduan resmi](https://ai.google.dev/gemini-api/docs/tool-combination) menjelaskan bahwa Google Search dan fungsi yang dideklarasikan aplikasi dapat dikirim bersama. Model meminta pemanggilan alat; server Anda yang menjalankan fungsi, memvalidasi argumen, dan memeriksa izin. Mulailah dari [contoh Google Search](https://ai.google.dev/gemini-api/docs/google-search); batasi input fungsi kustom dan hanya kembalikan data yang dibutuhkan.

## Konteks dan ID panggilan

Konteks panggilan serta respons sebelumnya dapat diteruskan ke langkah berikutnya—misalnya, hasil pencarian diteruskan ke fungsi pemesanan. Ini tidak menggantikan pengelolaan status aplikasi: otorisasi, persetujuan pengguna, penanganan error, dan percobaan ulang tetap tanggung jawab backend. Dalam Interactions API, `function_call.id` dipasangkan dengan `function_result.call_id` pada input; `function_response.id` bukan pasangan yang digunakan. Lihat [panduan resmi pemanggilan fungsi](https://ai.google.dev/gemini-api/docs/function-calling) untuk detailnya.

## Informasi lokasi melalui Maps

[Grounding with Google Maps](https://ai.google.dev/gemini-api/docs/maps-grounding) dapat menyediakan informasi tempat dan bisnis lokal bagi model Gemini 3 yang didukung. Ini berguna untuk pertanyaan berbasis lokasi, tetapi jam buka dan waktu perjalanan dapat berubah; periksa dukungan model dan jangan menjanjikan data selalu mutakhir. Google menyarankan [Interactions API](https://ai.google.dev/gemini-api/docs/interactions?ua=chat) untuk pengelolaan status sisi server dan jejak terpadu; dokumentasi juga mencantumkan dukungan generateContent. Gunakan contoh resmi terkini, lalu uji validasi input dan kegagalan alat di backend Anda.
