# Claude API untuk Pemula: Panduan Praktis Memulai

> Panduan pemula untuk Claude API ini membahas penyiapan, permintaan pertama, pemilihan model, fitur utama, dan praktik produksi.



Semua yang dibutuhkan developer untuk melakukan panggilan Claude API pertama: kunci, Messages API, pemilihan model, dan konsep inti untuk beralih dari permintaan pertama ke lingkungan produksi.

## Apa Itu Claude API

Claude API adalah platform developer Anthropic. Platform ini menyediakan akses terprogram ke model Claude melalui Messages API, dengan system prompt, penggunaan alat, streaming, visi, dan output terstruktur.

Messages API adalah endpoint HTTP tanpa status. Anda mengirim daftar pesan pengguna dan asisten, ID model, serta batas token; Claude mengembalikan respons terstruktur. Endpoint pendukung mencakup batch, file, dan penghitungan token.

- **Tanpa status:** API tidak menyimpan memori. Kirim ulang riwayat percakapan pada setiap panggilan.
- **Pemilihan model:** Mengganti model biasanya berarti mengganti ID model.
- **SDK:** Pustaka Python resmi (anthropic) dan TypeScript (@anthropic-ai/sdk) menggunakan bentuk permintaan yang sesuai.

Memahami arsitektur ini membantu menghindari kesalahan umum pemula: mengira API akan mengingat permintaan sebelumnya.

## Langkah 1: Dapatkan Kunci dan Siapkan Console

Buka **console.anthropic.com**, buat akun atau organisasi untuk tim Anda, lalu buat kunci API di bagian pengaturan. Perlakukan kunci seperti kata sandi: simpan dalam variabel lingkungan dan jangan pernah memasukkannya ke kontrol sumber.

Permintaan HTTP langsung menggunakan header **x-api-key** dan **anthropic-version**. SDK secara otomatis membaca **ANTHROPIC_API_KEY** dari lingkungan, sehingga sebagian besar kode tidak menangani kunci secara langsung.

- Buat kunci terpisah untuk pengembangan, staging, dan produksi.
- Gunakan workspace untuk memisahkan proyek tim dan pengeluaran.
- Atur batas penggunaan di Console sebelum memberikan kunci kepada lebih banyak anggota tim.

## Langkah 2: Buat Panggilan Messages API Pertama

Pasang SDK dengan **pip install anthropic**, ekspor kunci Anda, lalu jalankan:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Tiga parameter wajib adalah **model**, **max_tokens** (batas maksimum output), dan **messages**. Respons berisi daftar blok konten. Periksa jenis setiap blok, jangan berasumsi isinya hanya teks, karena penggunaan alat dan proses berpikir dapat menambahkan jenis blok lain. Objek **usage** melaporkan token input dan output, yang dapat digunakan sebagai telemetri biaya.

## Langkah 3: Pilih Model

Berikut model Claude terkini dari Anthropic beserta ID API-nya.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — dijelaskan sebagai model cepat dan berbiaya rendah untuk klasifikasi serta tugas sederhana bervolume tinggi.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — dijelaskan sebagai pilihan seimbang untuk beban kerja produksi, termasuk pemrograman.
- **Claude Opus 5.5** (**claude-opus-5-5**) — dijelaskan untuk penalaran sulit dan pekerjaan agen jangka panjang.
- **Claude Fable 5.2** (**claude-fable-5-2**) — dijelaskan sebagai model unggulan untuk tugas penalaran yang menantang.

Mulai dengan Opus 5.5. Uji Sonnet 5.5 untuk menyeimbangkan kecepatan dan kualitas, Haiku 5.5 untuk tugas sederhana bervolume tinggi, dan Fable 5.2 untuk penalaran yang rumit. Periksa halaman harga Anthropic untuk tarif terkini.

## Lima Konsep yang Perlu Dipelajari Selanjutnya

Setelah permintaan pertama berhasil, fitur berikut mencakup banyak kebutuhan aplikasi:

- **System prompt** — parameter tingkat atas **system** yang menetapkan peran, nada, dan aturan, terpisah dari pesan pengguna.
- **Percakapan beberapa giliran** — tambahkan setiap balasan asisten ke array messages dan kirim ulang; pesan pertama harus berasal dari giliran pengguna.
- **Streaming** — server-sent events mengirim token saat dihasilkan, yang dapat membantu antarmuka chat dan keluaran panjang.
- **Visi** — sertakan gambar sebagai blok konten base64 atau URL bersama teks.
- **Penggunaan alat** — definisikan fungsi dengan skema JSON; Claude dapat menentukan kapan harus memanggilnya, sedangkan kode Anda menjalankan fungsi tersebut dan mengembalikan hasilnya.

Pertimbangkan **prompt caching** dan **batch processing** jika biaya menjadi pertimbangan, serta **structured outputs** jika kode berikutnya harus mengurai respons.

## Dari Tutorial ke Produksi

Mengubah skrip yang berfungsi menjadi integrasi produksi membutuhkan disiplin rekayasa:

- **Penanganan error:** Tangani batas laju (429) dan error server secara terpisah. Sumber menyebutkan bahwa SDK mencoba ulang error ini secara otomatis dengan jeda bertahap; periksa dokumentasi SDK terkait untuk perilaku terkini.
- **Visibilitas biaya:** Catat **usage** dari setiap respons ke sistem metrik Anda.
- **Versi prompt:** Perlakukan prompt seperti kode: tinjau dan beri versi, lalu uji dengan set evaluasi kecil.
- **Penguncian model:** Ambil ID model dari konfigurasi agar peningkatan versi direncanakan dan diuji.

### Inti penting

- Messages API tidak menyimpan status; kirim ulang riwayat percakapan pada setiap panggilan.
- Autentikasi HTTP langsung menggunakan header x-api-key; SDK dapat membaca ANTHROPIC_API_KEY dari lingkungan.
- Tiga parameter permintaan wajib adalah model, max_tokens, dan messages.
- Mulai dengan Opus 5.5 dan bandingkan alternatifnya menggunakan data Anda sendiri.
- System prompt, streaming, visi, penggunaan alat, dan riwayat beberapa giliran mendukung banyak pola aplikasi.
- Catat penggunaan token untuk memantau biaya dan merencanakan kapasitas.

## FAQ

### Apakah saya perlu memahami machine learning untuk menggunakan Claude API?

Tidak. Claude API adalah REST API dengan SDK resmi untuk Python dan TypeScript. Jika Anda dapat memanggil endpoint HTTP dan mengurai JSON, Anda dapat membuat aplikasi dengan Claude. Perancangan prompt, penanganan error, dan pengelolaan biaya adalah keterampilan rekayasa yang berguna; teori machine learning tidak diperlukan untuk panggilan API pertama.

### Model Claude mana yang sebaiknya dipilih pemula?

Anthropic menyarankan Claude Opus 5.5 (ID API `claude-opus-5-5`) sebagai titik awal untuk sebagian besar beban kerja. Setelah prompt Anda stabil, bandingkan model lain menggunakan data Anda sendiri.

### Apakah Claude API mengingat percakapan sebelumnya?

Tidak. Messages API tidak menyimpan status. Aplikasi Anda menyimpan percakapan dan mengirim ulang seluruh riwayat pesan pada setiap permintaan. Dengan begitu, Anda dapat mengendalikan konteks, memangkas atau merangkum giliran yang lebih lama, dan menggabungkannya dengan prompt caching.
