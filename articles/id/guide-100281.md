# Harga OpenAI Moderation API: Gratis, Batas Laju, dan Alternatif

> Model moderasi OpenAI gratis. Lihat harga, batas laju berdasarkan tingkat penggunaan, contoh Python, dan kapan alternatif yang kompatibel dengan OpenAI lebih cocok.




Endpoint Moderation OpenAI gratis bagi pengguna OpenAI API. Untuk memilih alur kerja produksi, periksa jenis input dan kategori yang didukung, batas laju akun Anda, serta cara memasukkan endpoint ini ke dalam proses peninjauan Anda.

Panduan ini memisahkan jawaban resmi mengenai harga dari keputusan rekayasa praktis.

## Ringkasan

- **Endpoint Moderation OpenAI gratis bagi pengguna OpenAI API**, menurut Pusat Bantuan OpenAI.
- Model `omni-moderation-latest` OpenAI dirancang untuk mendeteksi konten berbahaya dan menerima teks serta gambar sebagai input, menurut halaman model resmi OpenAI.
- Harga gratis tidak menghapus biaya alur kerja seperti pencatatan log, antrean peninjauan, pemetaan kebijakan, percobaan ulang, perilaku fallback, dan keputusan khusus aplikasi.
- Pilih endpoint gratis OpenAI jika Anda sudah menggunakan OpenAI secara langsung dan alur kerja moderasi Anda sesuai dengan kategori serta format responsnya.
- Pertimbangkan EvoLink Moderation 1.0 jika Anda sudah menggunakan EvoLink dan menginginkan pemeriksaan multimodal, ringkasan risiko, serta penagihan per panggilan dalam satu alur kerja.

## Apakah OpenAI Moderation API gratis?

Ya. Pusat Bantuan resmi OpenAI menyatakan bahwa endpoint Moderation gratis bagi pengguna OpenAI API dan penggunaan alat ini tidak dihitung dalam batas penggunaan bulanan.

Sumber: [Pusat Bantuan OpenAI: Apakah endpoint Moderation gratis digunakan?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Itulah jawaban mengenai harga. Pertanyaan berikutnya menyangkut operasional:

**Apakah endpoint moderasi gratis cukup untuk alur kerja produksi Anda?**

Untuk prototipe, alat internal, dan moderasi sederhana yang mengutamakan teks, jawabannya mungkin ya. Untuk aplikasi yang menangani konten buatan pengguna, unggahan gambar, agen AI, atau antrean peninjauan, panggilan API hanyalah salah satu bagian dari sistem.

## Apa saja yang dicakup OpenAI moderation?

OpenAI mendokumentasikan `omni-moderation-latest` sebagai model moderasi yang dirancang untuk mengidentifikasi konten yang berpotensi berbahaya dalam teks dan gambar. Halaman model resminya menyebutnya sebagai model moderasi OpenAI yang paling mumpuni dan mencantumkan dukungan untuk input/output teks serta input gambar. Sumber: [Halaman model OpenAI untuk omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Panduan moderasi OpenAI juga menjelaskan kategori klasifikasi konten dan menyebutkan bahwa beberapa kategori hanya mendukung teks. Jika Anda hanya mengirim gambar ke `omni-moderation-latest`, kategori yang tidak mendukung input gambar akan mengembalikan skor 0. Sumber: [Panduan Moderation OpenAI](https://developers.openai.com/api/docs/guides/moderation)

Artinya, tim harus membaca tabel kategori dengan cermat sebelum menganggap setiap kategori teks dapat langsung diterapkan pada moderasi gambar.

## Biaya sebenarnya ada pada alur kerja, bukan hanya harga API

Endpoint Moderation mungkin gratis, tetapi sistem moderasi produksi tetap membutuhkan keputusan tentang:

- kapan menjalankan pemeriksaan: sebelum panggilan model, setelah respons model, atau keduanya
- cara memetakan kategori ke keputusan izinkan, tinjau, atau blokir
- cara mencatat hasil moderasi tanpa menyimpan konten sensitif yang tidak diperlukan
- cara menangani positif palsu dan banding
- cara memoderasi unggahan gambar secara terpisah dari input teks
- cara memantau latensi, kesalahan, dan batas laju
- cara menjaga konsistensi perilaku kebijakan di seluruh permukaan produk

Itulah biaya rekayasa dan operasional. Biaya ini tidak tercantum di halaman harga, tetapi menentukan apakah lapisan moderasi benar-benar mudah dipelihara.

Dalam alur kerja yang umum, periksa prompt sebelum mengirimkannya ke model dan periksa output sebelum menyampaikannya kepada pengguna. Teruskan hasil yang meragukan untuk ditinjau, catat keputusan seperlunya, dan siapkan prosedur percobaan ulang serta banding.

## Kapan endpoint gratis OpenAI cocok digunakan

Endpoint Moderation gratis OpenAI sering menjadi pilihan pertama yang tepat ketika:

- Anda sudah menggunakan OpenAI secara langsung
- aplikasi Anda sebagian besar mengutamakan teks
- Anda hanya memerlukan kategori moderasi yang didokumentasikan OpenAI
- Anda dapat membangun alur kerja peninjauan dan eskalasi sendiri
- tim Anda siap menangani penguraian respons, ambang batas, dan log

Dalam hal itu, sulit mencari alasan untuk menolak endpoint gratis ini. Mulailah dengannya, uji menggunakan konten nyata Anda, lalu ukur positif palsu dan kasus yang terlewat sebelum mengarahkan lalu lintas produksi.

## Kapan alternatif yang kompatibel dengan OpenAI masuk akal

EvoLink Moderation 1.0 adalah alternatif berbayar dengan jalur `/v1/moderations` yang kompatibel dengan OpenAI. EvoLink menerima paling banyak satu gambar per permintaan.

- pemeriksaan khusus teks, khusus gambar, dan teks plus gambar melalui satu endpoint
- 13 kategori bahaya dengan skor per kategori
- objek `evolink_summary` berisi `risk_level`, `flagged`, `violations`, `max_score`, dan `max_category`
- harga tetap per panggilan, bukan perhitungan token
- bentuk respons yang lebih mudah dipetakan ke logika izinkan, tinjau, atau blokir

## Cara menggunakan OpenAI Moderation API di Python

Jika Anda sudah menggunakan OpenAI SDK, panggilan moderasi teks dasar terlihat seperti ini:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Untuk EvoLink, isi `EVOLINK_API_KEY` dengan kunci API EvoLink Anda dan `EVOLINK_BASE_URL` dengan URL dasar API berprotokol HTTPS yang berakhiran `/v1`, sesuai pengaturan API EvoLink Anda. Responsnya memuat objek tambahan `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Perbandingan harga dan alur kerja antara OpenAI dan EvoLink

| Kriteria | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Penagihan | Gratis bagi pengguna OpenAI API | Tarif tetap untuk setiap panggilan |
| Bentuk endpoint utama | `/v1/moderations` | `/v1/moderations` yang kompatibel dengan OpenAI |
| Moderasi teks | Didukung | Didukung |
| Moderasi gambar | Didukung oleh `omni-moderation-latest`, dengan dukungan input yang berbeda untuk tiap kategori | Didukung untuk permintaan khusus gambar dan teks plus gambar |
| Field untuk keputusan berdasarkan kebijakan | Tafsirkan nilai `flagged`, `categories`, dan `category_scores` di dalam `results` | Gunakan `evolink_summary.risk_level` dan `violations` bersama skor per kategori |
| Tim yang paling sesuai | Tim yang sudah memanggil OpenAI secara langsung | Tim yang mengintegrasikan moderasi ke dalam alur kerja EvoLink yang sudah ada |

## Rekomendasi praktis

Gunakan endpoint Moderation gratis OpenAI jika aplikasi Anda sudah beroperasi secara native dengan OpenAI dan kebijakan moderasi Anda dapat dipetakan dengan jelas ke kategori yang didokumentasikan.

Jika tim Anda sudah menggunakan EvoLink, evaluasi biaya per panggilan dan gunakan `evolink_summary.risk_level` sebagai salah satu masukan untuk aturan aplikasi yang menentukan apakah konten diizinkan, ditinjau, atau diblokir.

Gunakan sistem moderasi berlapis jika aplikasi Anda memiliki persyaratan kebijakan khusus yang memerlukan aturan merek, peninjauan manusia, banding, atau alur kerja kepatuhan di luar kemampuan satu API moderasi mana pun.

## FAQ

### Apakah OpenAI Moderation API gratis?

Ya. Pusat Bantuan OpenAI menyatakan bahwa endpoint Moderation gratis bagi pengguna OpenAI API dan tidak dihitung dalam batas penggunaan bulanan.

### Apakah OpenAI moderation mendukung gambar?

Ya, `omni-moderation-latest` menerima gambar sebagai input menurut halaman model resmi OpenAI. Namun, panduan moderasi OpenAI menyebutkan bahwa beberapa kategori hanya mendukung teks, jadi tim harus meninjau dukungan input pada tingkat kategori sebelum mengandalkan moderasi yang hanya menggunakan gambar.

### Apakah EvoLink Moderation lebih murah daripada OpenAI Moderation?

Endpoint Moderation OpenAI gratis bagi pengguna OpenAI API. EvoLink mengenakan tarif tetap per panggilan. Bandingkan biaya seluruh alur kerja, termasuk peninjauan dan pemeliharaan.

### Bisakah saya menggunakan EvoLink sebagai pengganti OpenAI Moderation API?

Ya. Gunakan kunci API EvoLink Anda dan model `evolink-moderation-1.0` melalui jalur `/v1/moderations` milik EvoLink yang kompatibel dengan OpenAI. Sesuaikan penanganan respons agar dapat membaca objek tambahan `evolink_summary` dalam respons dari EvoLink.

### Apakah saya harus memoderasi prompt, output, atau keduanya?

Untuk aplikasi AI produksi, banyak tim memoderasi input dan output. Moderasi input dapat mengurangi permintaan yang tidak aman sebelum mencapai model. Moderasi output dapat mendeteksi respons buatan yang tidak aman sebelum sampai kepada pengguna.

### Apa itu omni-moderation-latest?

Ini adalah model moderasi OpenAI untuk teks dan gambar. Baca `flagged`, `categories`, dan `category_scores` di dalam `results`, lalu terapkan kebijakan moderasi Anda sendiri.

### Berapa batas laju OpenAI Moderation API?

Akses gratis berkaitan dengan penagihan. Batas jumlah permintaan dan token tetap berlaku. Dalam [referensi model](https://developers.openai.com/api/docs/models/omni-moderation-latest), RPM berarti jumlah permintaan per menit, RPD berarti jumlah permintaan per hari jika tercantum, dan TPM berarti jumlah token per menit.

Batas laju OpenAI Moderation API berbeda-beda menurut tingkat akun dan dapat berubah seiring waktu. Periksa [dokumentasi batas laju OpenAI](https://platform.openai.com/docs/guides/rate-limits) dan [halaman batas penggunaan](https://platform.openai.com/settings/organization/limits) akun Anda sebelum merencanakan throughput produksi.

### Bagaimana cara menggunakan OpenAI Moderation API di Python?

Instal paket `openai`, atur `OPENAI_API_KEY`, lalu panggil `client.moderations.create()` dengan model `omni-moderation-latest` dan teks yang ingin diperiksa. Untuk gambar, berikan array objek sebagai nilai `input`. Setiap item gambar harus memiliki `type: "image_url"` dan objek `image_url` yang memuat `url`, seperti pada referensi OpenAI API yang ditautkan di bawah.
