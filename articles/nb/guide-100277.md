# ChatGPT API: Slik setter du opp, priser og kodeeksempler (2026)

> En praktisk veiledning til hvordan du setter opp ChatGPT API, sammenligner modeller og priser og bygger applikasjoner med kodeeksempler.



ChatGPT API gir utviklere programmatisk tilgang til OpenAI-modeller. Denne veiledningen dekker oppsett av API-nøkler, valg av modell, priser, kodeeksempler og fremgangsmåter for å bygge applikasjoner og håndtere kostnader.

## Hva er ChatGPT API?

ChatGPT API lar utviklere integrere KI-funksjoner i applikasjoner gjennom HTTP-forespørsler. Applikasjoner sender strukturerte forespørsler til OpenAI og mottar JSON-svar som inneholder modellens utdata.

### Slik fungerer ChatGPT API

Prosessen består av fire trinn:

**Du sender en forespørsel.** Applikasjonen din sender en POST-forespørsel til OpenAI med en JSON-payload som inneholder et modellnavn, meldinger og parametere som temperature og tokenbegrensninger.

**OpenAI behandler forespørselen.** Modellen genererer et svar og returnerer det i et JSON-objekt. Når strømming er aktivert, kommer tokenene trinnvis.

**Applikasjonen din mottar svaret.** Svaret inneholder generert innhold, tokenbruk, modellinformasjon og en forespørsels-ID.

**Fakturering skjer.** Kostnadene avhenger av behandlede token. Inndata- og utdata-token kan ha ulike priser.

Promptlengde, modellvalg og hurtigbufring påvirker ytelse og kostnader.

## Slik setter du opp ChatGPT API

Du trenger en API-nøkkel for å autentisere forespørsler. Behandle den som en hemmelighet, og oppbevar den sikkert.

### Slik skaffer du en OpenAI API-nøkkel

**Trinn 1: Gå til OpenAI-plattformen**

- Gå til [platform.openai.com/api-keys](https://platform.openai.com/api-keys), og logg inn eller opprett en konto.

**Trinn 2: Opprett API-nøkkelen din**

- Åpne **API Keys** i kontrollpanelet.
- Velg **Create new secret key**, og gi den eventuelt et prosjekttilpasset navn.
- Kopier nøkkelen når den vises; den vises kanskje ikke igjen.

**Trinn 3: Oppbevar den sikkert**

- Oppbevar nøkkelen i en passordbehandler eller miljøvariabel.
- Ikke legg API-nøkler i versjonskontroll eller eksponer dem i klientkode.
- Hvis du bruker en `.env`-fil, legg den til i `.gitignore` og hold filen utenfor versjonskontrollen.

**Sikkerhetsmerknader:**

- En nøkkel kan gi tilgang knyttet til kontoen din og faktureringen din.
- Hvis du mister en nøkkel, opprett en erstatning.
- Tilbakekall nøkler som kan ha blitt kompromittert.
- Bruk separate nøkler med passende tilgangsomfang for ulike prosjekter når det er mulig.

## Konfigurer utviklingsmiljøet

API-et kan brukes fra alle programmeringsspråk som kan sende HTTP-forespørsler. Python, JavaScript og Java er vanlige valg.

### 1. Python: enkelt og med et rikt økosystem

Pythons syntaks og biblioteksøkosystem gjør språket til et vanlig valg. OpenAIs Python-pakke kan forenkle autentisering, formatering av forespørsler og feilhåndtering. Pakker som `python-dotenv` kan hjelpe med å håndtere miljøvariabler.

Python brukes også innen maskinlæring, datavitenskap, webutvikling og automatisering, noe som gjør språket nyttig for prosjekter som kombinerer API-kall med databehandling.

### 2. JavaScript: fleksibelt for webapplikasjoner

JavaScript fungerer for backend-applikasjoner med Node.js og webapplikasjoner som bruker rammeverk som React, Vue eller Next.js. Asynkrone funksjoner, inkludert `async`/`await` og Promises, støtter API-forespørsler som ikke blokkerer.

### 3. Java: skalerbarhet og ytelse

Java brukes ofte til bedriftsapplikasjoner. Statisk typing kan fange opp enkelte feil ved kompilering, og samtidighetsfunksjonene kan hjelpe applikasjoner med å håndtere flere forespørsler. Språket kan passe for programvare som integreres med eksisterende Java-systemer.

Eksemplene nedenfor bruker Python. Hvis du bruker JavaScript eller Java, må du tilpasse syntaksen til språket og SDK-et ditt.

### 1. Skriv tydelige og konkrete prompter

Tydelige, konkrete instruksjoner kan gjøre svarene mer nyttige.

- Angi ønsket format, tone og lengde.

Eksempel:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.
vague = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)
print(vague.choices[0].message.content)

# Specify the audience, deliverable, and focus.

    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)
print(specific.choices[0].message.content)
```

### 2. Bruk strukturerte utdata for pålitelige data

For JSON eller andre strukturerte data bør du bruke API-ets funksjoner for strukturerte utdata i stedet for å tolke fritekst. Se dokumentasjonen for støttede formater og begrensninger.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Implementer strømming for en bedre brukeropplevelse

Strømming kan vise svarinnholdet etter hvert som det kommer, i stedet for at brukeren må vente på hele svaret.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Håndter feil på en god måte

Forespørsler kan mislykkes på grunn av nettverksproblemer, hastighetsbegrensninger, ugyldige inndata eller tjenesteavbrudd. Håndter feil i tråd med dokumentasjonen for SDK-et og API-et.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Bruk funksjonskall for verktøyintegrasjon

Funksjonskall lar en modell be applikasjonen din om å kalle en funksjon eller et verktøy. Applikasjonen håndterer kallet og returnerer resultater etter behov.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```

Modelltilgjengeligheten endres. Se OpenAIs gjeldende [API-dokumentasjon](https://developers.openai.com/api/docs) for de nyeste modellene og funksjonene.
