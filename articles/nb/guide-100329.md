# Oppdateringer av Gemini API-verktøy: kontekstvidereføring, verktøykombinasjoner og Maps-grounding for Gemini 3

> Utviklere kan kombinere funksjonskall med innebygde verktøy som Google Search i ett enkelt Gemini API-kall, videreføre kontekst på tvers av verktøykall og turer, og bruke Grounding with Google Maps med Gemini 3-modeller.



17. mars 2026

I [Googles kunngjøring 17. mars 2026](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tooling-updates/) beskrives tre Gemini API-oppdateringer: innebygde verktøy kan brukes sammen med egne funksjoner, kontekst kan føres videre mellom trinn, og Grounding with Google Maps utvides til Gemini 3. Sjekk oppdatert dokumentasjon for å bekrefte støtte i modellen og API-et du bruker.

Kombinasjon av innebygde verktøy og egne funksjoner er merket som en forhåndsversjon i dokumentasjonen.

## Innebygde verktøy og appfunksjoner

En agent kan søke etter offentlig informasjon og deretter sjekke et internt system. Den [offisielle veiledningen](https://ai.google.dev/gemini-api/docs/tool-combination) viser hvordan Google Search kan oppgis sammen med en funksjon som appen selv deklarerer. Modellen ber om et kall; serveren utfører funksjonen, validerer argumentene og styrer tilgang. Start med [Googles Search-eksempel](https://ai.google.dev/gemini-api/docs/google-search), og begrens både funksjonsinndata og dataene som returneres.

## Kontekst og kall-ID-er

Tidligere verktøykall og svar kan følge med til neste trinn, for eksempel når søkeresultater sendes til en bestillingsfunksjon. Dette erstatter ikke appens tilstandshåndtering. Backend må fortsatt styre tillatelser, brukerbekreftelse, feil og gjentatte forsøk. I Interactions API kobles `function_call.id` til `function_result.call_id` i inndata; `function_response.id` er ikke det tilsvarende feltet. Se [den offisielle veiledningen for funksjonskall](https://ai.google.dev/gemini-api/docs/function-calling) for detaljer.

## Stedsdata med Maps

[Grounding with Google Maps](https://ai.google.dev/gemini-api/docs/maps-grounding) kan gi støttede Gemini 3-modeller informasjon om steder og lokale virksomheter. Åpningstider og reisetider kan endres; kontroller modellstøtten og ikke lov at data alltid er oppdaterte. Google peker på [Interactions API](https://ai.google.dev/gemini-api/docs/interactions?ua=chat) for tilstandshåndtering på serversiden og samlede spor; dokumentasjonen omtaler også generateContent. Bruk oppdaterte offisielle eksempler, og test egen validering og feilhåndtering.
