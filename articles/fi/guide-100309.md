# Claude API aloittelijoille: käytännön aloitusopas

> Claude API:n aloitusopas, jossa käsitellään käyttöönottoa, ensimmäistä pyyntöä, mallin valintaa, keskeisiä ominaisuuksia ja tuotantokäytäntöjä.



Kaikki, mitä kehittäjä tarvitsee ensimmäiseen Claude API -kutsuun: avaimet, Messages API, mallin valinta ja tärkeimmät käsitteet matkalla ensimmäisestä pyynnöstä tuotantoon.

## Mikä Claude API on

Claude API on Anthropicin kehittäjäalusta. Se tarjoaa ohjelmallisen pääsyn Claude-malleihin Messages API:n kautta sekä järjestelmäkehotteet, työkalujen käytön, suoratoiston, näkökyvyn ja jäsennellyt tulosteet.

Messages API on tilaton HTTP-päätepiste. Lähetät luettelon käyttäjän ja avustajan viesteistä, mallin tunnisteen ja token-rajan; Claude palauttaa jäsennellyn vastauksen. Täydentäviä päätepisteitä ovat eräajot, tiedostot ja tokenien laskenta.

- **Tilaton:** API ei säilytä muistia. Lähetä keskusteluhistoria uudelleen jokaisella kutsulla.
- **Mallin valinta:** Mallin vaihtaminen tarkoittaa yleensä mallin tunnisteen vaihtamista.
- **SDK:t:** Viralliset Python- (anthropic) ja TypeScript-kirjastot (@anthropic-ai/sdk) käyttävät vastaavia pyyntömuotoja.

Arkkitehtuurin ymmärtäminen auttaa välttämään yleisen aloittelijan virheen: oletuksen, että API muistaisi aiemman pyynnön.

## Vaihe 1: Hanki avain ja määritä Console

Siirry osoitteeseen **console.anthropic.com**, luo tili tai organisaatio tiimillesi ja luo API-avain asetuksissa. Käsittele avainta kuin salasanaa: tallenna se ympäristömuuttujaan äläkä koskaan lisää sitä versionhallintaan.

Suorat HTTP-kutsut käyttävät **x-api-key**-otsaketta ja **anthropic-version**-otsaketta. SDK:t lukevat **ANTHROPIC_API_KEY**-arvon automaattisesti ympäristöstä, joten useimmissa koodiesimerkeissä avainta ei käsitellä suoraan.

- Luo erilliset avaimet kehitykseen, staging-ympäristöön ja tuotantoon.
- Eristä tiimin projektit ja kulut työtilojen avulla.
- Aseta Console-käyttörajat ennen kuin annat avaimet laajemman tiimin käyttöön.

## Vaihe 2: Tee ensimmäinen Messages API -kutsu

Asenna SDK komennolla **pip install anthropic**, vie avain ympäristöön ja suorita:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Pakollisia parametreja on kolme: **model**, **max_tokens** (tulosteen yläraja) ja **messages**. Vastaus sisältää luettelon sisältölohkoja. Tarkista jokaisen lohkon tyyppi sen sijaan, että olettaisit sen olevan tavallista tekstiä, sillä työkalujen käyttö ja ajattelu voivat lisätä muuntyyppisiä lohkoja. **usage**-olio ilmoittaa syöte- ja tulostetokenit, ja sitä voi käyttää kustannusten seurantaan.

## Vaihe 3: Valitse malli

Tässä ovat Anthropicin nykyiset Claude-mallit ja niiden API-tunnisteet.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — kuvataan nopeaksi ja edulliseksi malliksi luokitteluun ja suuriin määriin yksinkertaisia tehtäviä.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — kuvataan tasapainoiseksi vaihtoehdoksi tuotantokuormiin, myös koodaukseen.
- **Claude Opus 5.5** (**claude-opus-5-5**) — kuvataan vaativaan päättelyyn ja pitkäkestoisiin agenttitehtäviin.
- **Claude Fable 5.2** (**claude-fable-5-2**) — kuvataan vaativan päättelyn lippulaivamalliksi.

Aloita Opus 5.5 -mallilla. Kokeile Sonnet 5.5 -mallia, kun haluat tasapainottaa nopeuden ja laadun, Haiku 5.5 -mallia suureen määrään yksinkertaisia tehtäviä ja Fable 5.2 -mallia vaativaan päättelyyn. Tarkista ajantasaiset hinnat Anthropicin hinnastosivulta.

## Viisi seuraavaksi opittavaa käsitettä

Kun ensimmäinen pyyntö toimii, nämä ominaisuudet kattavat monia sovellustarpeita:

- **Järjestelmäkehotteet** — ylimmän tason **system**-parametri asettaa roolin, sävyn ja säännöt erillään käyttäjän viesteistä.
- **Usean vuoron keskustelut** — lisää jokainen avustajan vastaus messages-taulukkoon ja lähetä se uudelleen; ensimmäisen viestin on oltava käyttäjän vuoro.
- **Suoratoisto** — Server-Sent Events välittää tokenit niiden muodostuessa, mikä voi auttaa keskustelukäyttöliittymissä ja pitkissä tulosteissa.
- **Näkökyky** — välitä kuvat Base64- tai URL-sisältölohkoina tekstin kanssa.
- **Työkalujen käyttö** — määritä funktiot JSON-skeemojen avulla; Claude voi päättää, milloin niitä kutsutaan, ja koodisi suorittaa ne ja palauttaa tuloksen.

Harkitse **kehotteiden välimuistia** ja **eräajoa**, kun kustannuksilla on merkitystä, sekä **jäsenneltyjä tulosteita**, kun jatkokoodi tarvitsee vastauksen jäsenneltävässä muodossa.

## Oppaasta tuotantoon

Toimivan skriptin muuttaminen tuotantointegraatioksi vaatii teknistä kurinalaisuutta:

- **Virheenkäsittely:** käsittele nopeusrajoitusvirheet (429) ja palvelinvirheet eri tavoin. Lähteen mukaan SDK:t yrittävät näitä automaattisesti uudelleen kasvavalla viiveellä; tarkista nykyinen toiminta kyseisen SDK:n dokumentaatiosta.
- **Kustannusten näkyvyys:** kirjaa jokaisen vastauksen **usage**-arvo metriikkajärjestelmääsi.
- **Kehotteiden versiointi:** käsittele kehotteita kuten koodia: arvioi ja versioi ne sekä testaa pienellä arviointiaineistolla.
- **Mallin lukitseminen:** viittaa mallien tunnisteisiin kokoonpanosta, jotta päivitykset ovat harkittuja ja testattuja.

### Tärkeimmät asiat

- Messages API on tilaton; lähetä keskusteluhistoria uudelleen jokaisella kutsulla.
- Suora HTTP-todennus käyttää x-api-key-otsaketta; SDK:t voivat lukea ANTHROPIC_API_KEY-arvon ympäristöstä.
- Kolme pakollista pyyntöparametria ovat model, max_tokens ja messages.
- Aloita Opus 5.5 -mallilla ja vertaa vaihtoehtoja omalla aineistollasi.
- Järjestelmäkehotteet, suoratoisto, näkökyky, työkalujen käyttö ja usean vuoron historia tukevat monia sovellusmalleja.
- Kirjaa tokenien käyttö kustannusten ja kapasiteetin seurantaa varten.

## UKK

### Pitääkö minun tuntea koneoppimista, jotta voin käyttää Claude API:a?

Ei. Claude API on REST API, jolle on viralliset Python- ja TypeScript-SDK:t. Jos osaat kutsua HTTP-päätepistettä ja jäsentää JSONia, voit rakentaa Claudea hyödyntäviä ratkaisuja. Kehotesuunnittelu, virheenkäsittely ja kustannusten hallinta ovat hyödyllisiä teknisiä taitoja; ensimmäiseen API-kutsuun ei tarvita koneoppimisteoriaa.

### Millä Claude-mallilla aloittelijan kannattaa aloittaa?

Anthropic suosittelee Claude Opus 5.5 -mallia (API-tunniste `claude-opus-5-5`) useimpien työkuormien lähtökohdaksi. Kun kehotteet ovat vakiintuneet, vertaa muita malleja omalla aineistollasi.

### Muistaako Claude API aiemmat keskustelut?

Ei. Messages API on tilaton. Sovelluksesi tallentaa keskustelun ja lähettää koko viestihistorian uudelleen jokaisella pyynnöllä. Näin voit hallita kontekstia, lyhentää tai tiivistää vanhempia vuoroja ja yhdistää tämän kehotteiden välimuistiin.
