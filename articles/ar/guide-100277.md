# واجهة برمجة تطبيقات ChatGPT: كيفية الإعداد والتسعير وأمثلة برمجية (2026)

> دليل عملي لإعداد واجهة برمجة تطبيقات ChatGPT، ومقارنة النماذج والأسعار، وبناء تطبيقات باستخدام أمثلة برمجية.



تتيح واجهة برمجة تطبيقات ChatGPT للمطورين الوصول برمجيًا إلى نماذج OpenAI. يغطي هذا الدليل إعداد مفتاح API، واختيار النماذج، والأسعار، والأمثلة البرمجية، والممارسات اللازمة لبناء التطبيقات وإدارة التكاليف.

## ما واجهة برمجة تطبيقات ChatGPT؟

تتيح واجهة برمجة تطبيقات ChatGPT للمطورين دمج إمكانات الذكاء الاصطناعي في التطبيقات عبر طلبات HTTP. ترسل التطبيقات طلبات منظّمة إلى OpenAI وتتلقى استجابات JSON تتضمن مخرجات النموذج.

### كيف تعمل واجهة برمجة تطبيقات ChatGPT

تتبع العملية أربع خطوات:

**ترسل طلبًا.** يرسل تطبيقك طلب POST إلى OpenAI مع حمولة JSON تتضمن اسم النموذج والرسائل ومعلمات مثل درجة الحرارة وحدود الرموز.

**تعالج OpenAI الطلب.** ينشئ النموذج استجابة ويعيدها في كائن JSON. عند تفعيل البث، تصل الرموز تباعًا.

**يتلقى تطبيقك الاستجابة.** تتضمن الاستجابة المحتوى المُنشأ، واستخدام الرموز، ومعلومات النموذج، ومعرّف الطلب.

**تُحتسب الرسوم.** تعتمد الرسوم على الرموز التي جرت معالجتها. وقد تختلف أسعار رموز الإدخال والإخراج.

يؤثر طول المطالبة واختيار النموذج والتخزين المؤقت في الأداء والتكلفة.

## كيفية إعداد واجهة برمجة تطبيقات ChatGPT

تحتاج إلى مفتاح API لمصادقة الطلبات. تعامل معه كسرّ وخزّنه بأمان.

### كيفية الحصول على مفتاح OpenAI API

**الخطوة 1: الدخول إلى منصة OpenAI**

- انتقل إلى [platform.openai.com/api-keys](https://platform.openai.com/api-keys) وسجّل الدخول أو أنشئ حسابًا.

**الخطوة 2: إنشاء مفتاح API**

- افتح **مفاتيح API** في لوحة التحكم.
- اختر **إنشاء مفتاح سري جديد**، ويمكنك اختياريًا تسميته باسم خاص بالمشروع.
- انسخ المفتاح عند عرضه؛ فقد لا يظهر مرة أخرى.

**الخطوة 3: خزّنه بأمان**

- خزّن المفتاح في مدير كلمات مرور أو في متغير بيئة.
- لا تودع مفاتيح API مطلقًا في نظام التحكم بالإصدارات، ولا تكشفها في الشيفرة البرمجية من جهة العميل.
- إذا استخدمت ملف `.env`، فأضفه إلى `.gitignore` وأبقِ الملف خارج نظام التحكم بالإصدارات.

**ملاحظات أمنية:**

- قد يمنح المفتاح صلاحيات مرتبطة بحسابك وفوترك.
- إذا فقدت مفتاحًا، فأنشئ بديلًا.
- ألغِ المفاتيح التي يُحتمل أن تكون قد تعرضت للاختراق.
- استخدم مفاتيح منفصلة ومحددة النطاق على نحو مناسب لمشاريع مختلفة متى كان ذلك متاحًا.

## إعداد بيئة التطوير

يمكن استخدام API من أي لغة برمجة قادرة على إرسال طلبات HTTP. ومن الخيارات الشائعة Python وJavaScript وJava.

تجعل صياغة Python ونظام مكتباتها منها خيارًا شائعًا. ويمكن لحزمة Python من OpenAI تبسيط المصادقة وتنسيق الطلبات ومعالجة الأخطاء. كما يمكن لحزم مثل `python-dotenv` المساعدة في إدارة متغيرات البيئة.

تُستخدم Python أيضًا في تعلّم الآلة وعلوم البيانات وتطوير الويب والأتمتة، ما يجعلها مفيدة للمشاريع التي تجمع بين استدعاءات API ومعالجة البيانات.

### 2. JavaScript: مرونة لتطبيقات الويب

تصلح JavaScript لتطبيقات الخلفية باستخدام Node.js ولتطبيقات الويب التي تستخدم أطرًا مثل React أو Vue أو Next.js. وتدعم ميزاتها غير المتزامنة، بما فيها `async`/`await` وPromises، طلبات API غير الحاجبة.

### 3. Java: قابلية التوسع والأداء

تُستخدم Java عادةً في تطبيقات المؤسسات. ويمكن للكتابة ذات الأنواع الثابتة اكتشاف بعض الأخطاء وقت الترجمة، كما تساعد ميزات التزامن فيها التطبيقات على التعامل مع طلبات متعددة. وقد تناسب البرامج التي تتكامل مع أنظمة Java القائمة.

تستخدم الأمثلة أدناه Python. إذا كنت تستخدم JavaScript أو Java، فكيّف الصياغة لتناسب لغتك ومجموعة تطوير البرامج (SDK) التي تستخدمها.

### 2. استخدم المخرجات المنظّمة للحصول على بيانات موثوقة

لبيانات JSON أو غيرها من البيانات المنظّمة، استخدم ميزات المخرجات المنظّمة في API بدلًا من تحليل نص حرّ الصياغة. راجع الوثائق لمعرفة التنسيق والقيود المدعومة.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 5. عالج الأخطاء بسلاسة

قد تفشل الطلبات بسبب مشكلات الشبكة أو حدود المعدل أو مدخلات غير صالحة أو انقطاعات الخدمة. عالج الأخطاء وفقًا لوثائق SDK وAPI.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. استخدم استدعاء الدوال لدمج الأدوات

يتيح استدعاء الدوال للنموذج أن يطلب من تطبيقك استدعاء دالة أو أداة. يتولى تطبيقك تنفيذ الاستدعاء وإعادة النتائج حسب الاقتضاء.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```

## أفكار لتطبيقات يمكن بناؤها بواجهة برمجة تطبيقات ChatGPT

### 1. روبوتات محادثة لدعم العملاء

أنشئ مساعدين يجيبون عن الأسئلة الشائعة ويتتبعون الطلبات ويستكشفون المشكلات ويقدمون دعم العملاء. ويمكن لاستدعاء الدوال ربط التطبيق بأنظمة إدارة علاقات العملاء أو التذاكر أو إدارة الطلبات.

### 2. مساعدين افتراضيين للإنتاجية

أنشئ مساعدين يديرون الجداول الزمنية ويصيغون رسائل البريد الإلكتروني وينظمون المهام ويلخصون المستندات ويستخرجون بنود العمل من ملاحظات الاجتماعات باستخدام واجهات API للإنتاجية.

### 4. أدوات إنشاء المحتوى

### 5. تحليل البيانات والرؤى

دع المستخدمين يستعلمون عن قواعد البيانات بلغة طبيعية، وينشئون التقارير، ويحددون الاتجاهات، ويعدّون شروحات للبيانات. تحقّق من المخرجات بمقارنتها بالبيانات الأساسية.

### 6. إنشاء الشيفرة البرمجية وتصحيحها
