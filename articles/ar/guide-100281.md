# أسعار OpenAI Moderation API: مجانية، وحدود المعدل، والبدائل

> نماذج الإشراف على المحتوى من OpenAI مجانية. اطّلع على الأسعار وحدود المعدل حسب فئة الاستخدام وأمثلة Python والحالات التي يكون فيها البديل المتوافق مع OpenAI أنسب.




نقطة نهاية OpenAI Moderation مجانية لمستخدمي OpenAI API. لاختيار سير عمل لبيئة الإنتاج، تحقّق من المدخلات والفئات المدعومة، وحدود معدّل الطلبات في حسابك، ومدى ملاءمة نقطة النهاية لعملية المراجعة لديك.

يفصل هذا الدليل بين الإجابة الرسمية عن الأسعار والقرار الهندسي العملي.

## خلاصة سريعة

- **نقطة نهاية الإشراف من OpenAI مجانية لمستخدمي واجهة OpenAI API**، وفقًا لمركز مساعدة OpenAI.
- صُمم نموذج OpenAI `omni-moderation-latest` لاكتشاف المحتوى الضار، ويقبل النصوص والصور كمدخلات، وفقًا لصفحة النموذج الرسمية من OpenAI.
- لا تلغي الأسعار المجانية تكاليف سير العمل، مثل التسجيل، وقوائم انتظار المراجعة، ومواءمة السياسات، وإعادة المحاولة، والسلوك الاحتياطي، والقرارات الخاصة بالتطبيق.
- اختر نقطة نهاية OpenAI المجانية إذا كنت تستخدم OpenAI مباشرة بالفعل، وكان سير عمل الإشراف لديك يناسب فئاته وتنسيق استجابته.
- فكّر في استخدام EvoLink Moderation 1.0 إذا كنت تستخدم EvoLink بالفعل وتريد فحص أنواع متعددة من المدخلات، والحصول على ملخّص للمخاطر، والدفع مقابل كل استدعاء ضمن سير العمل نفسه.

## هل OpenAI Moderation API مجانية؟

نعم. يذكر مركز مساعدة OpenAI الرسمي أن نقطة نهاية الإشراف مجانية لمستخدمي واجهة OpenAI API، وأن استخدام الأداة لا يُحتسب ضمن حدود الاستخدام الشهرية.

المصدر: [مركز مساعدة OpenAI: هل استخدام نقطة نهاية الإشراف مجاني؟](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

هذه هي إجابة الأسعار. أما السؤال التالي فهو تشغيلي:

**هل تكفي نقطة نهاية إشراف مجانية لسير عمل الإنتاج لديك؟**

قد تكون كافية للنماذج الأولية والأدوات الداخلية والإشراف البسيط الذي يركّز على النصوص. أما التطبيقات التي تتعامل مع محتوى ينشئه المستخدمون أو تحميل الصور أو وكلاء الذكاء الاصطناعي أو قوائم انتظار المراجعة، فاستدعاء واجهة API ليس سوى جزء واحد من النظام.

## ما الذي يشمله إشراف OpenAI؟

توثّق OpenAI نموذج `omni-moderation-latest` بوصفه نموذج إشراف مصممًا لتحديد المحتوى الذي قد يكون ضارًا في النصوص والصور. وتصفه صفحة النموذج الرسمية بأنه أقوى نموذج إشراف لدى OpenAI، وتذكر دعمه لإدخال النصوص وإخراجها وإدخال الصور. المصدر: [صفحة نموذج OpenAI لـ omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) كما يشرح دليل الإشراف من OpenAI فئات تصنيف المحتوى، ويشير إلى أن بعض الفئات تقتصر على النصوص. إذا أرسلت صورًا فقط إلى `omni-moderation-latest`، فستُرجع الفئات التي لا تدعم مدخلات الصور درجة 0. المصدر: [دليل الإشراف من OpenAI](https://developers.openai.com/api/docs/guides/moderation)

وهذا يعني أن على الفرق قراءة جدول الفئات بعناية قبل افتراض أن كل فئة نصية تقابلها مباشرةً فئة للإشراف على الصور.

## التكلفة الحقيقية هي تكلفة سير العمل، لا أسعار واجهة API وحدها

قد تكون نقطة نهاية الإشراف مجانية، لكن نظام الإشراف الإنتاجي لا يزال يتطلب قرارات بشأن:

- موضع إجراء الفحوصات: قبل استدعاءات النموذج أو بعدها أو كليهما
- كيفية مواءمة الفئات مع قرارات السماح أو المراجعة أو الحظر
- كيفية تسجيل نتائج الإشراف دون تخزين محتوى حساس دون داعٍ
- كيفية التعامل مع النتائج الإيجابية الكاذبة والطعون
- كيفية الإشراف على تحميلات الصور بشكل منفصل عن المدخلات النصية
- كيفية مراقبة زمن الاستجابة والأخطاء وحدود المعدل
- كيفية الحفاظ على اتساق سلوك السياسات عبر واجهات المنتج

هذه تكاليف هندسية وتشغيلية. لا تظهر في صفحة الأسعار، لكنها تحدد ما إذا كانت طبقة الإشراف قابلة للصيانة فعليًا.

في سير العمل المعتاد، افحص المطالبات قبل إرسالها إلى النموذج والمخرجات قبل تسليمها. أحِل النتائج غير المؤكّدة إلى المراجعة، وسجّل الحد الأدنى من المعلومات عن القرارات، وخطّط لإعادة المحاولة والتعامل مع الطعون.

## متى تكون نقطة نهاية OpenAI المجانية مناسبة؟

غالبًا ما تكون نقطة نهاية الإشراف المجانية من OpenAI خيارًا أوليًا جيدًا عندما:

- تستخدم OpenAI مباشرة بالفعل
- يركّز تطبيقك في معظمه على النصوص
- لا تحتاج إلا إلى فئات الإشراف التي توثّقها OpenAI
- يمكنك إنشاء سير عمل المراجعة والتصعيد الخاص بك
- يرتاح فريقك إلى تولّي مسؤولية تحليل الاستجابات والعتبات والسجلات

في هذه الحالة، يصعب الاعتراض على نقطة النهاية المجانية. ابدأ بها، واختبرها على محتواك الفعلي، وقِس النتائج الإيجابية الكاذبة والحالات التي لم تُكتشف قبل توجيه حركة الإنتاج إليها.

## متى يكون البديل المتوافق مع OpenAI مناسبًا؟

EvoLink Moderation 1.0 بديل مدفوع يوفّر المسار `/v1/moderations` المتوافق مع OpenAI. يقبل EvoLink صورة واحدة كحد أقصى في كل طلب.

- فحوصات للنصوص فقط أو الصور فقط أو النصوص والصور معًا عبر نقطة نهاية واحدة
- 13 فئة ضرر مع درجات لكل فئة
- كائن `evolink_summary` يتضمّن الحقول `risk_level` و`flagged` و`violations` و`max_score` و`max_category`
- تسعير ثابت لكل استدعاء بدلًا من حسابات الرموز
- بنية استجابة أسهل في مواءمتها مع منطق السماح أو المراجعة أو الحظر

## كيفية استخدام OpenAI Moderation API في Python

إذا كنت تستخدم OpenAI SDK بالفعل، فسيبدو استدعاء أساسي للإشراف على النصوص هكذا:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

لاستخدام EvoLink، اضبط `EVOLINK_API_KEY` على مفتاح EvoLink الخاص بك، واضبط `EVOLINK_BASE_URL` على عنوان HTTPS الأساسي للواجهة الذي ينتهي بـ`/v1`، كما هو محدّد في إعدادات EvoLink API. تتضمّن الاستجابة أيضًا كائن `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## مقارنة التسعير وسير العمل بين OpenAI وEvoLink

| المعيار | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| الفوترة | مجاني لمستخدمي OpenAI API | سعر ثابت لكل استدعاء |
| شكل نقطة النهاية الرئيسية | `/v1/moderations` | `/v1/moderations` متوافق مع OpenAI |
| الإشراف على النصوص | مدعوم | مدعوم |
| الإشراف على الصور | مدعوم بواسطة `omni-moderation-latest`، مع دعم مدخلات يختلف حسب الفئة | مدعوم لطلبات الصور فقط وطلبات النصوص والصور معًا |
| حقول تُستخدم في اتخاذ القرارات وفق سياسة الإشراف | فسّر قيم `flagged` و`categories` و`category_scores` في `results` | استخدم `evolink_summary.risk_level` و`violations` إلى جانب درجات الفئات |
| الفِرَق التي يناسبها الخيار | الفِرَق التي تستدعي OpenAI مباشرةً بالفعل | الفِرَق التي تُدمج الإشراف في سير عمل قائم على EvoLink |

## توصية عملية

استخدم نقطة نهاية الإشراف المجانية من OpenAI إذا كان تطبيقك يعتمد OpenAI أصلًا، وكانت سياسة الإشراف لديك تتوافق بوضوح مع الفئات التي توثّقها.

إذا كان فريقك يستخدم EvoLink بالفعل، فقيّم تكلفة كل استدعاء واستخدم قيمة `evolink_summary.risk_level` كأحد المعطيات التي تستند إليها قواعد السماح أو المراجعة أو الحظر في تطبيقك.

استخدم نظام إشراف متعدد الطبقات إذا كان لتطبيقك متطلبات سياسات مخصصة تستلزم قواعد العلامة التجارية أو المراجعة البشرية أو الطعون أو إجراءات الامتثال التي تتجاوز قدرات أي واجهة إشراف واحدة.

## الأسئلة الشائعة

### هل OpenAI Moderation API مجانية؟

نعم. يذكر مركز مساعدة OpenAI أن نقطة نهاية الإشراف مجانية لمستخدمي واجهة OpenAI API، ولا تُحتسب ضمن حدود الاستخدام الشهرية.

### هل يدعم إشراف OpenAI الصور؟

نعم، يقبل `omni-moderation-latest` الصور كمدخلات وفقًا لصفحة النموذج الرسمية من OpenAI. لكن دليل الإشراف من OpenAI يشير إلى أن بعض الفئات تقتصر على النصوص، لذا ينبغي للفرق مراجعة دعم المدخلات على مستوى الفئات قبل الاعتماد على الإشراف على الصور فقط.

### هل EvoLink Moderation أقل تكلفة من OpenAI Moderation؟

نقطة نهاية OpenAI Moderation مجانية لمستخدمي OpenAI API. يفرض EvoLink سعرًا ثابتًا لكل استدعاء. قارن التكلفة الإجمالية لسير العمل، بما فيها المراجعة والصيانة.

### هل يمكنني استخدام EvoLink بديلًا لواجهة OpenAI Moderation API؟

نعم. استخدم مفتاح EvoLink API الخاص بك والنموذج `evolink-moderation-1.0` عبر مسار EvoLink المتوافق `/v1/moderations`. عدّل طريقة معالجة الاستجابة لتأخذ في الحسبان كائن `evolink_summary` المنفصل الذي يوفّره EvoLink.

### هل ينبغي أن أشرف على المطالبات أم المخرجات أم كليهما؟

في تطبيقات الذكاء الاصطناعي الإنتاجية، تشرف فرق كثيرة على المدخلات والمخرجات معًا. يمكن لإشراف المدخلات تقليل الطلبات غير الآمنة قبل وصولها إلى نموذج. ويمكن لإشراف المخرجات اكتشاف الاستجابات المولّدة غير الآمنة قبل وصولها إلى المستخدمين.

### ما هو omni-moderation-latest؟

هذا نموذج OpenAI للإشراف على النصوص والصور. اقرأ قيم الحقول `flagged` و`categories` و`category_scores` في `results` وطبّق سياسة الإشراف الخاصة بك.

### ما حد معدل OpenAI Moderation API؟

مجانية الاستخدام تخصّ الفوترة. تظلّ حدود الطلبات والرموز سارية. في [مرجع النموذج](https://developers.openai.com/api/docs/models/omni-moderation-latest)، يشير RPM إلى عدد الطلبات في الدقيقة، ويشير RPD عند وروده إلى عدد الطلبات في اليوم، ويشير TPM إلى عدد الرموز في الدقيقة.

تختلف حدود معدل OpenAI Moderation API حسب فئة الحساب، وقد تتغير بمرور الوقت. راجع [وثائق حدود المعدل من OpenAI](https://platform.openai.com/docs/guides/rate-limits) وصفحة [حدود الاستخدام لحسابك](https://platform.openai.com/settings/organization/limits) قبل التخطيط لمعدل الإنتاجية في بيئة الإنتاج.

### كيف أستخدم OpenAI Moderation API في Python؟

ثبّت حزمة `openai` واضبط `OPENAI_API_KEY` ثم استدعِ `client.moderations.create()` بالنموذج `omni-moderation-latest` والنصّ الذي تريد فحصه. للصور، مرّر `input` كمصفوفة من الكائنات. يتضمّن كل عنصر يمثّل صورةً `type: "image_url"` وكائن `image_url` يحتوي على `url`، كما هو موضّح في مرجع OpenAI API المرتبط أدناه.
