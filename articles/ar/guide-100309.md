# Claude API للمبتدئين: دليل عملي للبدء

> دليل للمبتدئين إلى Claude API يشمل الإعداد والطلب الأول واختيار النموذج والميزات الأساسية وممارسات بيئة الإنتاج.



كل ما يحتاجه المطوّر لإجراء أول استدعاء إلى Claude API: المفاتيح وMessages API واختيار النموذج والمفاهيم الأساسية للانتقال من أول طلب إلى بيئة الإنتاج.

## ما هي Claude API؟

Claude API هي منصة Anthropic للمطورين. تتيح وصولًا برمجيًا إلى نماذج Claude عبر Messages API، مع مطالبات النظام واستخدام الأدوات والبث والرؤية والمخرجات المنظّمة.

Messages API هي نقطة نهاية HTTP عديمة الحالة. ترسل قائمة برسائل المستخدم والمساعد ومعرّف النموذج وحدًا للرموز؛ فيعيد Claude استجابة منظّمة. تشمل نقاط النهاية المساندة الدُفعات والملفات وحساب الرموز.

- **عديمة الحالة:** لا تحتفظ API بذاكرة. أعد إرسال سجل المحادثة مع كل استدعاء.
- **اختيار النموذج:** عادةً ما يتطلب تغيير النموذج تغيير معرّف النموذج.
- **حِزم SDK:** تستخدم المكتبتان الرسميتان لـ Python (anthropic) وTypeScript (@anthropic-ai/sdk) صيغتي الطلب المقابلتين.

يساعد فهم هذه البنية على تجنّب خطأ شائع لدى المبتدئين: توقّع أن تتذكر API طلبًا سابقًا.

## الخطوة 1: احصل على مفتاح وأعد إعداد Console

انتقل إلى **console.anthropic.com**، وأنشئ حسابًا أو مؤسسة لفريقك، ثم أنشئ مفتاح API في الإعدادات. تعامل مع المفتاح ككلمة مرور: خزّنه في متغير بيئة ولا تضعه مطلقًا في مستودع الشفرة.

تستخدم طلبات HTTP المباشرة ترويسة **x-api-key** وترويسة **anthropic-version**. تقرأ حِزم SDK تلقائيًا **ANTHROPIC_API_KEY** من البيئة، لذا لا يتعامل معظم الشفرة مع المفتاح مباشرة.

- أنشئ مفاتيح منفصلة للتطوير والتجهيز والإنتاج.
- استخدم مساحات العمل لعزل مشاريع الفريق والإنفاق.
- اضبط حدود الاستخدام في Console قبل منح المفاتيح لفريق أوسع.

## الخطوة 2: أجرِ أول استدعاء إلى Messages API

ثبّت SDK باستخدام **pip install anthropic**، وصدّر مفتاحك، ثم شغّل:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

هناك ثلاثة معاملات مطلوبة: **model** و**max_tokens** (الحد الأعلى للمخرجات) و**messages**. تحتوي الاستجابة على قائمة من كتل المحتوى. تحقّق من نوع كل كتلة بدلًا من افتراض أنها نص عادي، لأن استخدام الأدوات والتفكير قد يضيفان أنواعًا أخرى من الكتل. يعرض كائن **usage** رموز الإدخال والإخراج، ويمكن استخدامه لمراقبة التكلفة.

## الخطوة 3: اختر نموذجًا

فيما يلي نماذج Claude الحالية من Anthropic ومعرّفاتها في واجهة API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — يوصف بأنه سريع ومنخفض التكلفة، ومناسب للتصنيف والمهام البسيطة عالية الحجم.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — يوصف بأنه خيار متوازن لأحمال الإنتاج، بما فيها البرمجة.
- **Claude Opus 5.5** (**claude-opus-5-5**) — يوصف بأنه مناسب للاستدلال الصعب والمهام الوكيلة طويلة الأمد.
- **Claude Fable 5.2** (**claude-fable-5-2**) — يوصف بأنه نموذج رائد للمهام الاستدلالية المتطلبة.

ابدأ باستخدام Opus 5.5. جرّب Sonnet 5.5 للموازنة بين السرعة والجودة، وHaiku 5.5 للمهام البسيطة كثيرة التكرار، وFable 5.2 للاستدلال المعقّد. راجع صفحة أسعار Anthropic للاطلاع على الأسعار الحالية.

## خمسة مفاهيم لتتعلمها لاحقًا

بعد نجاح الطلب الأول، تغطي هذه الميزات احتياجات كثير من التطبيقات:

- **مطالبات النظام** — معامل **system** من المستوى الأعلى يحدد الدور والنبرة والقواعد، منفصلًا عن رسائل المستخدم.
- **المحادثات متعددة الجولات** — أضف كل رد من المساعد إلى مصفوفة messages وأعد إرسالها؛ يجب أن تكون الرسالة الأولى من دور المستخدم.
- **البث** — ترسل الأحداث التي يبعثها الخادم الرموز أثناء توليدها، ما قد يفيد واجهات الدردشة والمخرجات الطويلة.
- **الرؤية** — مرّر الصور ككتل محتوى بترميز base64 أو كرابط URL إلى جانب النص.
- **استخدام الأدوات** — عرّف الدوال بمخططات JSON؛ ويمكن لـ Claude تحديد وقت استدعائها، بينما ينفّذها كودك ويعيد النتائج.

عندما تكون التكلفة مهمة، فكّر في **التخزين المؤقت للمطالبات** و**المعالجة على دفعات**، واستخدم **المخرجات المنظّمة** عندما تحتاج الشفرة اللاحقة إلى تحليل الاستجابة.

## من البرنامج التعليمي إلى الإنتاج

يتطلب الانتقال من سكربت يعمل إلى تكامل إنتاجي انضباطًا هندسيًا:

- **معالجة الأخطاء:** عالج أخطاء تحديد المعدل (429) وأخطاء الخادم كلًا على حدة. يذكر المصدر أن حِزم SDK تعيد المحاولة تلقائيًا مع التراجع التدريجي؛ تحقّق من وثائق SDK المعني لمعرفة السلوك الحالي.
- **وضوح التكلفة:** سجّل **usage** لكل استجابة في نظام المقاييس لديك.
- **إصدارات المطالبات:** تعامل مع المطالبات كالشفرة: راجعها وأصدر نسخًا منها واختبرها على مجموعة تقييم صغيرة.
- **تثبيت النموذج:** استدعِ معرّفات النماذج من الإعدادات كي تكون الترقيات مقصودة ومختبرة.

### الخلاصات الأساسية

- Messages API عديمة الحالة؛ أعد إرسال سجل المحادثة مع كل استدعاء.
- تستخدم مصادقة HTTP المباشرة ترويسة x-api-key؛ ويمكن لحِزم SDK قراءة ANTHROPIC_API_KEY من البيئة.
- معاملات الطلب الثلاثة المطلوبة هي model وmax_tokens وmessages.
- ابدأ باستخدام Opus 5.5 وقارن البدائل على بياناتك.
- تدعم مطالبات النظام والبث والرؤية واستخدام الأدوات وسجل المحادثة متعدد الجولات أنماطًا كثيرة من التطبيقات.
- سجّل استخدام الرموز لمراقبة التكلفة وتخطيط السعة.

## الأسئلة الشائعة

### هل أحتاج إلى معرفة تعلم الآلة لاستخدام Claude API؟

لا. Claude API هي واجهة REST ولها حِزم SDK رسمية لـ Python وTypeScript. إذا كنت تستطيع استدعاء نقطة نهاية HTTP وتحليل JSON، يمكنك التطوير باستخدام Claude. تصميم المطالبات ومعالجة الأخطاء وإدارة التكلفة مهارات هندسية مفيدة؛ أما نظرية تعلم الآلة فليست مطلوبة لإجراء أول استدعاء API.

### أي نموذج Claude يناسب المبتدئ؟

توصي Anthropic بالبدء بـ Claude Opus 5.5 (معرّف API ‏`claude-opus-5-5`) لمعظم أعباء العمل. بعد استقرار المطالبات، قارن النماذج الأخرى على بياناتك.

### هل تتذكر Claude API المحادثات السابقة؟

لا. Messages API عديمة الحالة. يخزّن تطبيقك المحادثة ويعيد إرسال سجل الرسائل كاملًا مع كل طلب. يمنحك ذلك التحكم في السياق، ويسمح بتقليص الأدوار الأقدم أو تلخيصها، ويمكن دمجه مع التخزين المؤقت للمطالبات.
