# Claude API cho người mới bắt đầu: hướng dẫn thực hành để khởi động

> Hướng dẫn Claude API cho người mới bắt đầu: thiết lập, yêu cầu đầu tiên, chọn mô hình, tính năng cốt lõi và thực tiễn production.



Những điều nhà phát triển cần biết để thực hiện lệnh gọi Claude API đầu tiên: khóa, Messages API, chọn mô hình và các khái niệm cốt lõi để chuyển từ yêu cầu đầu tiên sang môi trường production.

## Claude API là gì

Claude API là nền tảng dành cho nhà phát triển của Anthropic. Nền tảng này cung cấp quyền truy cập theo chương trình vào các mô hình Claude qua Messages API, với system prompt, sử dụng công cụ, streaming, thị giác và đầu ra có cấu trúc.

Messages API là một endpoint HTTP không trạng thái. Bạn gửi danh sách tin nhắn của người dùng và trợ lý, ID mô hình và giới hạn token; Claude trả về phản hồi có cấu trúc. Các endpoint hỗ trợ gồm xử lý theo lô, tệp và đếm token.

- **Không trạng thái:** API không lưu bộ nhớ. Gửi lại lịch sử hội thoại trong mỗi lần gọi.
- **Chọn mô hình:** Đổi mô hình thường đồng nghĩa với việc đổi ID mô hình.
- **SDK:** Thư viện Python (anthropic) và TypeScript (@anthropic-ai/sdk) chính thức sử dụng cấu trúc yêu cầu tương ứng.

Hiểu kiến trúc này giúp tránh một lỗi phổ biến của người mới: mong API ghi nhớ yêu cầu trước đó.

## Bước 1: Lấy khóa và thiết lập Console

Truy cập **console.anthropic.com**, tạo tài khoản hoặc tổ chức cho nhóm của bạn, rồi tạo API key trong phần cài đặt. Hãy coi khóa như mật khẩu: lưu trong biến môi trường và tuyệt đối không đưa vào hệ thống quản lý mã nguồn.

Các lệnh gọi HTTP trực tiếp dùng header **x-api-key** và header **anthropic-version**. SDK tự động đọc **ANTHROPIC_API_KEY** từ môi trường, nên phần lớn mã không xử lý khóa trực tiếp.

- Tạo khóa riêng cho môi trường phát triển, staging và production.
- Dùng workspace để tách biệt dự án và chi tiêu của nhóm.
- Đặt giới hạn sử dụng trong Console trước khi cấp khóa cho nhóm rộng hơn.

## Bước 2: Thực hiện lệnh gọi Messages API đầu tiên

Cài SDK bằng **pip install anthropic**, xuất khóa của bạn rồi chạy:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Có ba tham số bắt buộc: **model**, **max_tokens** (giới hạn trên của đầu ra) và **messages**. Phản hồi chứa danh sách các khối nội dung. Hãy kiểm tra loại của từng khối thay vì mặc định đó là văn bản thuần, vì việc dùng công cụ và suy nghĩ có thể tạo thêm các loại khối khác. Đối tượng **usage** báo cáo token đầu vào và đầu ra, có thể dùng làm dữ liệu theo dõi chi phí.

## Bước 3: Chọn mô hình

Dưới đây là các mô hình Claude hiện hành của Anthropic và ID API tương ứng.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — được mô tả là nhanh và chi phí thấp, phù hợp cho phân loại và các tác vụ đơn giản với khối lượng lớn.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — được mô tả là lựa chọn cân bằng cho khối lượng công việc production, bao gồm lập trình.
- **Claude Opus 5.5** (**claude-opus-5-5**) — được mô tả dành cho suy luận khó và công việc tác tử có thời hạn dài.
- **Claude Fable 5.2** (**claude-fable-5-2**) — được mô tả là mô hình chủ lực cho các tác vụ suy luận đòi hỏi cao.

Hãy bắt đầu với Opus 5.5. Thử Sonnet 5.5 để cân bằng tốc độ và chất lượng, Haiku 5.5 cho nhiều tác vụ đơn giản và Fable 5.2 cho các bài toán suy luận khó. Xem trang giá của Anthropic để biết mức giá hiện tại.

## Năm khái niệm tiếp theo cần tìm hiểu

Khi yêu cầu đầu tiên đã hoạt động, các tính năng sau đáp ứng nhiều nhu cầu ứng dụng:

- **System prompt** — tham số cấp cao nhất **system** đặt vai trò, giọng điệu và quy tắc, tách biệt với tin nhắn người dùng.
- **Hội thoại nhiều lượt** — nối từng phản hồi của trợ lý vào mảng messages và gửi lại; tin nhắn đầu tiên phải là lượt của người dùng.
- **Streaming** — sự kiện do máy chủ gửi sẽ truyền token ngay khi được tạo, hữu ích cho giao diện chat và đầu ra dài.
- **Thị giác** — truyền hình ảnh dưới dạng các khối nội dung base64 hoặc URL cùng với văn bản.
- **Dùng công cụ** — định nghĩa hàm bằng JSON schema; Claude có thể quyết định khi nào gọi hàm, còn mã của bạn thực thi và trả kết quả.

Khi chi phí là yếu tố quan trọng, hãy cân nhắc **bộ nhớ đệm prompt** và **xử lý theo lô**; khi mã phía sau cần phân tích phản hồi, hãy cân nhắc **đầu ra có cấu trúc**.

## Từ hướng dẫn thử nghiệm đến production

Chuyển từ một tập lệnh đang chạy sang tích hợp production đòi hỏi kỷ luật kỹ thuật:

- **Xử lý lỗi:** Xử lý riêng lỗi giới hạn tốc độ (429) và lỗi máy chủ. Nguồn cho biết SDK tự động thử lại các lỗi này với thời gian chờ tăng dần; hãy kiểm tra hành vi hiện tại trong tài liệu SDK tương ứng.
- **Theo dõi chi phí:** Ghi **usage** của mọi phản hồi vào hệ thống chỉ số.
- **Phiên bản prompt:** Coi prompt như mã: xem xét, gắn phiên bản và thử nghiệm với một bộ đánh giá nhỏ.
- **Ghim mô hình:** Tham chiếu ID mô hình từ cấu hình để việc nâng cấp được chủ động và có kiểm thử.

### Điểm chính cần nhớ

- Messages API không trạng thái; gửi lại lịch sử hội thoại trong mỗi lần gọi.
- Xác thực HTTP trực tiếp dùng header x-api-key; SDK có thể đọc ANTHROPIC_API_KEY từ môi trường.
- Ba tham số yêu cầu bắt buộc là model, max_tokens và messages.
- Bắt đầu với Opus 5.5 và so sánh các lựa chọn khác trên dữ liệu của bạn.
- System prompt, streaming, thị giác, dùng công cụ và lịch sử nhiều lượt hỗ trợ nhiều kiểu ứng dụng.
- Ghi mức dùng token để theo dõi chi phí và hoạch định năng lực.

## Câu hỏi thường gặp

### Tôi có cần biết về học máy để dùng Claude API không?

Không. Claude API là REST API có SDK chính thức cho Python và TypeScript. Nếu bạn biết gọi endpoint HTTP và phân tích JSON, bạn có thể xây dựng với Claude. Thiết kế prompt, xử lý lỗi và quản lý chi phí là các kỹ năng kỹ thuật hữu ích; không cần lý thuyết học máy để thực hiện lệnh gọi API đầu tiên.

### Người mới bắt đầu nên dùng mô hình Claude nào?

Anthropic khuyến nghị bắt đầu với Claude Opus 5.5 (ID API `claude-opus-5-5`) cho hầu hết khối lượng công việc. Khi lời nhắc đã ổn định, hãy so sánh các mô hình khác trên dữ liệu của bạn.

### Claude API có nhớ các cuộc trò chuyện trước không?

Không. Messages API không trạng thái. Ứng dụng của bạn lưu hội thoại và gửi lại toàn bộ lịch sử tin nhắn trong mỗi yêu cầu. Nhờ vậy, bạn kiểm soát được ngữ cảnh, có thể rút gọn hoặc tóm tắt các lượt cũ, đồng thời kết hợp với bộ nhớ đệm prompt.
