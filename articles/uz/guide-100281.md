## Haqiqiy xarajat API narxida emas, ish jarayonida

Moderation endpointi bepul bo‘lishi mumkin, ammo production moderatsiya tizimida quyidagilar bo‘yicha qarorlar baribir zarur:

- tekshiruvlarni qayerda o‘tkazish: model chaqiruvlaridan oldin, model javoblaridan keyin yoki har ikkala holatda
- kategoriyalarni ruxsat berish, tekshirish yoki bloklash qarorlariga qanday moslashtirish
- maxfiy kontentni keraksiz saqlamasdan moderatsiya natijalarini qanday qayd etish
- noto‘g‘ri ijobiy natijalar va apellyatsiyalarni qanday ko‘rib chiqish
- rasm yuklamalarini matnli kirishdan alohida qanday moderatsiya qilish
- kechikish, xatolar va so‘rovlar tezligi cheklovlarini qanday kuzatish
- mahsulotning turli interfeyslarida siyosat xatti-harakatini qanday izchil saqlash

Bular muhandislik va operatsion xarajatlardir. Ular narxlar sahifasida ko‘rinmaydi, ammo moderatsiya qatlamini amalda boshqarish mumkinligini aynan shular belgilaydi.

Odatdagi ish jarayonida promptlarni modelga jo‘natishdan oldin, chiqish ma’lumotlarini esa foydalanuvchiga yetkazishdan oldin tekshiring. Noaniq natijalarni qo‘shimcha tekshiruvga yo‘naltiring, qarorlar haqida faqat zarur ma’lumotlarni saqlang hamda qayta urinishlar va apellyatsiyalar uchun tartibni oldindan belgilang.

## OpenAI bilan mos muqobil qachon ma’qul

EvoLink Moderation 1.0 — OpenAI bilan mos keladigan `/v1/moderations` endpointini taqdim etuvchi pulli muqobil. EvoLink har bir so‘rovda ko‘pi bilan bitta rasmni qabul qiladi.

- bitta endpoint orqali faqat matn, faqat rasm va matn bilan rasmni birgalikda tekshirish
- har bir kategoriya uchun alohida ball beriladigan 13 ta zarar kategoriyasi
- `risk_level`, `flagged`, `violations`, `max_score` va `max_category` maydonlariga ega `evolink_summary` obyekti
- tokenlarni hisoblash o‘rniga har bir chaqiruv uchun belgilangan narx
- ruxsat berish, tekshirish yoki bloklash mantiqiga moslashtirish osonroq bo‘lgan javob tuzilishi

## OpenAI Moderation API’dan Python’da foydalanish

Agar OpenAI SDK’dan allaqachon foydalanayotgan bo‘lsangiz, matnni moderatsiya qilish uchun oddiy chaqiruv quyidagicha ko‘rinadi:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

EvoLink’dan foydalanish uchun `EVOLINK_API_KEY` qiymati sifatida EvoLink kalitingizni, `EVOLINK_BASE_URL` qiymati sifatida esa EvoLink API sozlamalarida ko‘rsatilgan va `/v1` bilan tugaydigan asosiy HTTPS manzilini kiriting. Javobda qo‘shimcha `evolink_summary` obyekti ham qaytariladi.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## FAQ

### OpenAI Moderation API bepulmi?

Ha. OpenAI Help Center ma’lumotiga ko‘ra, Moderation endpointi OpenAI API foydalanuvchilari uchun bepul va oylik foydalanish limitlariga kiritilmaydi.

### OpenAI moderatsiyasi rasmlarni qo‘llab-quvvatlaydimi?

Ha, OpenAI’ning rasmiy model sahifasiga ko‘ra, `omni-moderation-latest` rasmlarni kirish ma’lumoti sifatida qabul qiladi. Biroq, OpenAI moderatsiya qo‘llanmasida ayrim kategoriyalar faqat matn bilan ishlashi aytilgan. Shu sababli faqat rasm moderatsiyasiga tayanishdan oldin jamoalar har bir kategoriya uchun kirish ma’lumotlari qo‘llab-quvvatlanishini tekshirishi kerak.

### EvoLink Moderation OpenAI Moderation’dan arzonroqmi?

OpenAI Moderation endpointi OpenAI API foydalanuvchilari uchun bepul. EvoLink har bir chaqiruv uchun bir xil haq oladi. Tekshiruv va texnik xizmat xarajatlarini ham hisobga olib, butun ish jarayoni qancha turishini taqqoslang.

### OpenAI Moderation API’ga muqobil sifatida EvoLink’dan foydalansam bo‘ladimi?

Ha. EvoLink API kalitingizdan va `evolink-moderation-1.0` modelidan EvoLink’ning mos `/v1/moderations` endpointida foydalaning. Javobni qayta ishlash mantiqini EvoLink’ning alohida `evolink_summary` obyektini hisobga oladigan qilib moslang.

### Promptlarni, chiqishlarni yoki ikkalasini ham moderatsiya qilish kerakmi?

Production AI ilovalarida ko‘plab jamoalar ham kirish, ham chiqish ma’lumotlarini moderatsiya qiladi. Kirish ma’lumotlarini moderatsiya qilish xavfli so‘rovlarning modelga yetib borishidan oldin ularni kamaytirishi mumkin. Chiqish ma’lumotlarini moderatsiya qilish esa model yaratgan xavfli javoblarni foydalanuvchilarga yetib borishidan oldin aniqlashi mumkin.

### omni-moderation-latest nima?

Bu OpenAI’ning matn va rasmlarni moderatsiya qilish modeli. `results` ichidan `flagged`, `categories` va `category_scores` qiymatlarini o‘qing va o‘z moderatsiya siyosatingizni qo‘llang.

### OpenAI Moderation API so‘rovlar tezligi limiti qanday?

Bepul foydalanish to‘lovga taalluqli. So‘rovlar va tokenlar uchun limitlar amal qilishda davom etadi. [Model ma’lumotnomasida](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM bir daqiqadagi so‘rovlar sonini, RPD ko‘rsatilgan bo‘lsa, bir kundagi so‘rovlar sonini, TPM esa bir daqiqadagi tokenlar sonini anglatadi.

OpenAI Moderation API so‘rovlar tezligi limitlari akkaunt darajasiga qarab farq qiladi va vaqt o‘tishi bilan o‘zgarishi mumkin. Production unumdorligini rejalashtirishdan oldin [OpenAI’ning so‘rovlar tezligi cheklovlari hujjatlarini](https://platform.openai.com/docs/guides/rate-limits) va akkauntingizning [foydalanish limitlari sahifasini](https://platform.openai.com/settings/organization/limits) tekshiring.

### OpenAI Moderation API’dan Python’da qanday foydalanaman?

`openai` paketini o‘rnating, `OPENAI_API_KEY` qiymatini belgilang va `client.moderations.create()` usulini `omni-moderation-latest` modeli hamda matningiz bilan chaqiring. Rasmlar uchun `input` qiymatini obyektlar massivi shaklida uzating. Quyida havolasi berilgan OpenAI API ma’lumotnomasida ko‘rsatilganidek, har bir rasm elementi `type: "image_url"` va `image_url` obyektini o‘z ichiga oladi. Ushbu obyektning `url` maydoni bor.
