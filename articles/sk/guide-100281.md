# Ceny OpenAI Moderation API: bezplatné používanie, limity rýchlosti a alternatívy

> Modely OpenAI na moderovanie sú bezplatné. Pozrite si ceny, limity rýchlosti podľa úrovne používania, príklady v Pythone a kedy je vhodnejšia alternatíva kompatibilná s OpenAI.




Endpoint OpenAI Moderation je pre používateľov OpenAI API bezplatný. Pri výbere pracovného postupu pre produkčné prostredie si overte podporované vstupy a kategórie, limity frekvencie požiadaviek pre svoj účet aj to, ako endpoint zapadne do vášho procesu kontroly.

Táto príručka oddeľuje oficiálnu odpoveď o cenách od praktického technického rozhodnutia.

## Stručne

- **Endpoint OpenAI Moderation je pre používateľov OpenAI API bezplatný**, uvádza centrum pomoci OpenAI.
- Model OpenAI `omni-moderation-latest` je navrhnutý na rozpoznávanie škodlivého obsahu a ako vstup prijíma text aj obrázky, uvádza oficiálna stránka modelu OpenAI.
- Bezplatná cena neodstraňuje náklady na pracovný postup, ako sú zaznamenávanie, fronty na kontrolu, mapovanie zásad, opakované pokusy, záložné správanie a rozhodnutia špecifické pre aplikáciu.
- Bezplatný endpoint OpenAI si vyberte, ak už OpenAI používate priamo a váš pracovný postup moderovania zodpovedá jeho kategóriám a formátu odpovede.
- Ak už používate EvoLink a chcete v jednom pracovnom postupe kontrolovať rôzne typy vstupov, získať súhrn rizík a platiť za jednotlivé volania, zvážte EvoLink Moderation 1.0.

## Je OpenAI Moderation API bezplatné?

Áno. Oficiálne centrum pomoci OpenAI uvádza, že endpoint Moderation je pre používateľov OpenAI API bezplatný a jeho používanie sa nezapočítava do mesačných limitov používania.

Zdroj: [Centrum pomoci OpenAI: Je používanie endpointu Moderation bezplatné?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

To je odpoveď na otázku o cene. Ďalšia otázka je prevádzková:

**Stačí bezplatný endpoint na moderovanie pre váš produkčný pracovný postup?**

Pre prototypy, interné nástroje a jednoduché moderovanie zamerané predovšetkým na text možno áno. Pri aplikáciách, ktoré pracujú s obsahom vytvoreným používateľmi, nahrávaním obrázkov, AI agentmi alebo frontami na kontrolu, je volanie API iba jednou časťou systému.

## Čo pokrýva moderovanie OpenAI?

OpenAI opisuje `omni-moderation-latest` ako model na moderovanie navrhnutý na identifikáciu potenciálne škodlivého obsahu v texte a obrázkoch. Oficiálna stránka modelu ho označuje za najvýkonnejší model OpenAI na moderovanie a uvádza podporu textového vstupu a výstupu a obrazového vstupu. Zdroj: [Stránka modelu OpenAI pre omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Príručka OpenAI na moderovanie tiež vysvetľuje kategórie klasifikácie obsahu a uvádza, že niektoré kategórie podporujú iba text. Ak modelu `omni-moderation-latest` pošlete iba obrázky, kategórie, ktoré nepodporujú obrazový vstup, vrátia skóre 0. Zdroj: [Príručka OpenAI na moderovanie](https://developers.openai.com/api/docs/guides/moderation)

To znamená, že tímy by si mali pozorne prečítať tabuľku kategórií, skôr než predpokladajú, že každá textová kategória sa priamo vzťahuje aj na moderovanie obrázkov.

## Skutočné náklady sú v pracovnom postupe, nielen v cene API

Endpoint Moderation môže byť bezplatný, no produkčný systém moderovania si stále vyžaduje rozhodnutia o tom:

- kde vykonávať kontroly: pred volaniami modelu, po odpovediach modelu alebo oboje
- ako mapovať kategórie na rozhodnutia o povolení, kontrole alebo zablokovaní
- ako zaznamenávať výsledky moderovania bez zbytočného ukladania citlivého obsahu
- ako riešiť falošne pozitívne výsledky a odvolania
- ako moderovať nahrávané obrázky oddelene od textového vstupu
- ako monitorovať latenciu, chyby a limity rýchlosti
- ako zachovať konzistentné správanie zásad v rôznych častiach produktu

To sú náklady na vývoj a prevádzku. Na stránke s cenami sa neobjavia, no určujú, či sa vrstva moderovania dá skutočne udržiavať.

V bežnom pracovnom postupe kontrolujte prompty pred odoslaním do modelu a výstupy pred ich doručením používateľom. Nejednoznačné výsledky pošlite na kontrolu, o rozhodnutiach zaznamenávajte len nevyhnutné údaje a naplánujte postup pre opakované pokusy a odvolania.

## Kedy je bezplatný endpoint OpenAI vhodný

Bezplatný endpoint OpenAI Moderation je často dobrou prvou voľbou, keď:

- už používate OpenAI priamo
- vaša aplikácia je zameraná predovšetkým na text
- potrebujete iba zdokumentované kategórie moderovania OpenAI
- dokážete vytvoriť vlastný pracovný postup kontroly a eskalácie
- váš tím je pripravený spravovať spracovanie odpovedí, prahové hodnoty a záznamy

V takom prípade sa bezplatný endpoint obhajuje len ťažko. Začnite s ním, otestujte ho na svojom skutočnom obsahu a zmerajte falošne pozitívne výsledky aj nezachytené prípady skôr, než naň nasmerujete produkčnú prevádzku.

## Kedy má zmysel alternatíva kompatibilná s OpenAI

EvoLink Moderation 1.0 je platená alternatíva s endpointom `/v1/moderations` kompatibilným s OpenAI. EvoLink prijíma najviac jeden obrázok na požiadavku.

- kontroly iba textu, iba obrázkov aj textu spolu s obrázkami cez jeden endpoint
- 13 kategórií škodlivosti so skóre pre každú kategóriu
- objekt `evolink_summary` s poľami `risk_level`, `flagged`, `violations`, `max_score` a `max_category`
- jednotná cena za volanie namiesto výpočtov s tokenmi
- formát odpovede, ktorý sa jednoduchšie mapuje na logiku povolenia, kontroly alebo zablokovania

## Ako používať OpenAI Moderation API v Pythone

Ak už používate OpenAI SDK, základné volanie na moderovanie textu vyzerá takto:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Pri používaní EvoLink nastavte `EVOLINK_API_KEY` na svoj kľúč EvoLink a `EVOLINK_BASE_URL` na základnú HTTPS adresu API končiacu na `/v1`, ktorú nájdete v konfigurácii EvoLink API. Odpoveď obsahuje aj objekt `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Praktické odporúčanie

Použite bezplatný endpoint OpenAI Moderation, ak vaša aplikácia už funguje na OpenAI a vaše zásady moderovania sa dajú jednoducho namapovať na jeho zdokumentované kategórie.

Ak váš tím už používa EvoLink, posúďte cenu jedného volania a zohľadnite `evolink_summary.risk_level` ako jeden z podkladov pre pravidlá, podľa ktorých aplikácia obsah povolí, odošle na kontrolu alebo zablokuje.

Ak má vaša aplikácia vlastné požiadavky na zásady, ktoré vyžadujú pravidlá značky, ľudskú kontrolu, odvolania alebo pracovné postupy na zabezpečenie súladu nad rámec možností jediného API na moderovanie, použite viacvrstvový systém moderovania.

## Často kladené otázky

### Je OpenAI Moderation API bezplatné?

Áno. Centrum pomoci OpenAI uvádza, že endpoint Moderation je pre používateľov OpenAI API bezplatný a nezapočítava sa do mesačných limitov používania.

### Podporuje moderovanie OpenAI obrázky?

Áno, `omni-moderation-latest` prijíma obrázky ako vstup, uvádza oficiálna stránka modelu OpenAI. Príručka OpenAI na moderovanie však uvádza, že niektoré kategórie podporujú iba text, preto by si tímy mali pred spoliehaním sa na moderovanie iba obrázkov overiť podporu vstupu pre jednotlivé kategórie.

### Je služba EvoLink Moderation lacnejšia ako OpenAI Moderation?

Endpoint OpenAI Moderation je pre používateľov OpenAI API bezplatný. EvoLink účtuje pevnú cenu za každé volanie. Porovnajte náklady na celý pracovný postup vrátane kontroly a údržby.

### Dá sa EvoLink použiť ako alternatíva k OpenAI Moderation API?

Áno. Použite svoj kľúč EvoLink API a model `evolink-moderation-1.0` na kompatibilnom endpointe EvoLink `/v1/moderations`. Prispôsobte spracovanie odpovede tak, aby zohľadňovalo samostatný objekt `evolink_summary` od EvoLink.

### Mám moderovať prompty, výstupy alebo oboje?

Pri produkčných aplikáciách AI mnohé tímy moderujú vstupy aj výstupy. Moderovanie vstupu môže obmedziť nebezpečné požiadavky ešte predtým, ako sa dostanú k modelu. Moderovanie výstupu môže zachytiť nebezpečné vygenerované odpovede skôr, než sa dostanú k používateľom.

### Čo je omni-moderation-latest?

Je to model OpenAI na moderovanie textu a obrázkov. Z `results` načítajte hodnoty `flagged`, `categories` a `category_scores` a uplatnite vlastné zásady moderovania.

### Aký je limit rýchlosti pre OpenAI Moderation API?

Bezplatný prístup sa týka účtovania. Limity počtu požiadaviek a tokenov stále platia. V [referenčnej dokumentácii modelu](https://developers.openai.com/api/docs/models/omni-moderation-latest) označuje RPM počet požiadaviek za minútu, RPD počet požiadaviek za deň, ak je táto metrika uvedená, a TPM počet tokenov za minútu.

Limity rýchlosti OpenAI Moderation API sa líšia podľa úrovne účtu a môžu sa časom meniť. Pred plánovaním produkčnej priepustnosti si pozrite [dokumentáciu OpenAI o limitoch rýchlosti](https://platform.openai.com/docs/guides/rate-limits) a [stránku s limitmi používania](https://platform.openai.com/settings/organization/limits) svojho účtu.

### Ako používať OpenAI Moderation API v Pythone?

Nainštalujte balík `openai`, nastavte `OPENAI_API_KEY` a zavolajte `client.moderations.create()` s modelom `omni-moderation-latest` a svojím textom. Pri obrázkoch odovzdajte v `input` pole objektov. Každá položka s obrázkom má `type: "image_url"` a objekt `image_url` obsahujúci `url`, ako ukazuje nižšie uvedená referenčná dokumentácia OpenAI API.
