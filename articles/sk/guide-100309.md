# Claude API pre začiatočníkov: Praktický sprievodca prvými krokmi

> Praktický sprievodca Claude API pre začiatočníkov pokrýva nastavenie, prvú požiadavku, výber modelu, hlavné funkcie a postupy pre produkciu.



Všetko, čo vývojár potrebuje na prvé volanie Claude API: kľúče, Messages API, výber modelu a základné pojmy potrebné na prechod od prvej požiadavky do produkcie.

## Čo je Claude API

Claude API je vývojárska platforma spoločnosti Anthropic. Poskytuje programový prístup k modelom Claude prostredníctvom Messages API so systémovými promptmi, používaním nástrojov, streamovaním, spracovaním obrázkov a štruktúrovanými výstupmi.

Messages API je bezstavový HTTP endpoint. Odošlete zoznam používateľských a asistentských správ, ID modelu a limit tokenov; Claude vráti štruktúrovanú odpoveď. Medzi podporné endpointy patria dávky, súbory a počítanie tokenov.

- **Bezstavové:** API si nič nepamätá. Pri každom volaní znova odošlite históriu konverzácie.
- **Výber modelu:** Zmena modelu zvyčajne znamená zmenu jeho ID.
- **SDK:** Oficiálne knižnice pre Python (anthropic) a TypeScript (@anthropic-ai/sdk) používajú zodpovedajúce formáty požiadaviek.

Pochopenie tejto architektúry pomáha predísť bežnej chybe začiatočníkov: očakávaniu, že si API zapamätá predchádzajúcu požiadavku.

## Krok 1: Získajte kľúč a nastavte konzolu

Prejdite na **console.anthropic.com**, vytvorte účet alebo organizáciu pre svoj tím a v nastaveniach vygenerujte kľúč API. S kľúčom zaobchádzajte ako s heslom: uložte ho do environmentálnej premennej a nikdy ho nepridávajte do správy zdrojového kódu.

Priame HTTP volania používajú hlavičky **x-api-key** a **anthropic-version**. SDK automaticky načítajú **ANTHROPIC_API_KEY** z prostredia, takže väčšina kódu s kľúčom priamo nemanipuluje.

- Vytvorte samostatné kľúče pre vývoj, staging a produkciu.
- Pomocou pracovných priestorov oddeľte tímové projekty a výdavky.
- Pred sprístupnením kľúčov širšiemu tímu nastavte v konzole limity používania.

## Krok 2: Vykonajte prvé volanie Messages API

Nainštalujte SDK príkazom **pip install anthropic**, exportujte svoj kľúč a spustite:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Vyžadujú sa tri parametre: **model**, **max_tokens** (horný limit výstupu) a **messages**. Odpoveď obsahuje zoznam blokov obsahu. Skontrolujte typ každého bloku a nepredpokladajte, že ide o obyčajný text, pretože používanie nástrojov a premýšľanie môžu pridať aj iné typy blokov. Objekt **usage** uvádza počet vstupných a výstupných tokenov a môže slúžiť ako telemetria nákladov.

## Krok 3: Vyberte model

Tu sú aktuálne modely Claude od spoločnosti Anthropic a ich identifikátory API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — opisuje sa ako rýchly a lacný model na klasifikáciu a jednoduché úlohy vo veľkom objeme.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — opisuje sa ako vyvážená voľba pre produkčné úlohy vrátane programovania.
- **Claude Opus 5.5** (**claude-opus-5-5**) — opisuje sa ako vhodný na náročné uvažovanie a dlhodobú prácu agentov.
- **Claude Fable 5.2** (**claude-fable-5-2**) — opisuje sa ako vlajkový model na náročné úlohy uvažovania.

Začnite s modelom Opus 5.5. Vyskúšajte Sonnet 5.5, keď potrebujete vyvážiť rýchlosť a kvalitu, Haiku 5.5 na veľký objem jednoduchých úloh a Fable 5.2 na náročné uvažovanie. Aktuálne ceny nájdete na stránke Anthropic o cenách.

## Päť pojmov, ktoré sa oplatí naučiť ako ďalšie

Keď prvá požiadavka funguje, tieto funkcie pokrývajú mnohé potreby aplikácií:

- **Systémové prompty** — parameter najvyššej úrovne **system**, ktorý oddelene od používateľských správ nastavuje rolu, tón a pravidlá.
- **Viacotáčkové konverzácie** — každú odpoveď asistenta pridajte do poľa messages a odošlite ho znova; prvá správa musí byť od používateľa.
- **Streamovanie** — udalosti odosielané serverom poskytujú tokeny počas generovania, čo pomáha pri chatovacích rozhraniach a dlhých výstupoch.
- **Spracovanie obrazu** — popri texte odovzdávajte obrázky ako obsahové bloky vo formáte base64 alebo URL.
- **Používanie nástrojov** — definujte funkcie pomocou schém JSON; Claude môže rozhodnúť, kedy ich zavolať, pričom váš kód ich vykoná a vráti výsledky.

Ak záleží na nákladoch, zvážte **prompt caching** a **batch processing**; ak musí nadväzujúci kód spracovať odpoveď, zvážte **structured outputs**.

## Od tutoriálu k produkcii

Prechod od funkčného skriptu k produkčnej integrácii si vyžaduje technickú disciplínu:

- **Spracovanie chýb:** Odlišujte limity rýchlosti (429) od chýb servera. Zdroj uvádza, že SDK tieto chyby automaticky opakujú s postupným oneskorením; aktuálne správanie si overte v dokumentácii príslušného SDK.
- **Prehľad o nákladoch:** Zaznamenávajte **usage** každej odpovede do svojho systému metrík.
- **Verziovanie promptov:** S promptmi zaobchádzajte ako s kódom: kontrolujte ich, spravujte ich verzie a testujte ich na malej evaluačnej množine.
- **Pripnutie modelu:** Na ID modelov odkazujte z konfigurácie, aby boli aktualizácie plánované a otestované.

### Kľúčové poznatky

- Messages API je bezstavové; pri každom volaní znova odošlite históriu konverzácie.
- Priama HTTP autentifikácia používa hlavičku x-api-key; SDK môžu načítať ANTHROPIC_API_KEY z prostredia.
- Tri povinné parametre požiadavky sú model, max_tokens a messages.
- Začnite s modelom Opus 5.5 a porovnajte alternatívy na vlastných údajoch.
- Systémové prompty, streamovanie, spracovanie obrazu, používanie nástrojov a história viacerých ťahov podporujú mnoho vzorov aplikácií.
- Zaznamenávajte používanie tokenov kvôli prehľadu o nákladoch a plánovaniu kapacity.

## Časté otázky

### Musím poznať strojové učenie, aby som mohol používať Claude API?

Nie. Claude API je REST API s oficiálnymi SDK pre Python a TypeScript. Ak dokážete zavolať HTTP endpoint a spracovať JSON, môžete vytvárať aplikácie pomocou Claude. Návrh promptov, spracovanie chýb a riadenie nákladov sú užitočné technické zručnosti; na prvé volanie API nepotrebujete teóriu strojového učenia.

### S ktorým modelom Claude by mal začiatočník začať?

Anthropic pri väčšine úloh odporúča začať s modelom Claude Opus 5.5 (ID v API `claude-opus-5-5`). Keď sa prompty ustália, porovnajte ostatné modely na vlastných údajoch.

### Pamätá si Claude API predchádzajúce konverzácie?

Nie. Messages API je bezstavové. Vaša aplikácia konverzáciu uloží a pri každej požiadavke znova odošle celú históriu správ. Vďaka tomu máte kontext pod kontrolou, môžete staršie ťahy skrátiť alebo zhrnúť a môžete využiť prompt caching.
