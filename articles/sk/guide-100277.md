# ChatGPT API: nastavenie, ceny a príklady kódu (2026)

> Praktický sprievodca nastavením ChatGPT API, porovnaním modelov a cien a tvorbou aplikácií s príkladmi kódu.



ChatGPT API poskytuje vývojárom programový prístup k modelom OpenAI. Tento sprievodca sa venuje nastaveniu kľúča API, výberu modelu, cenám, príkladom kódu a postupom pri tvorbe aplikácií a správe nákladov.

## Čo je ChatGPT API?

ChatGPT API umožňuje vývojárom integrovať funkcie umelej inteligencie do aplikácií prostredníctvom požiadaviek HTTP. Aplikácie odosielajú OpenAI štruktúrované požiadavky a prijímajú odpovede JSON obsahujúce výstup modelu.

### Ako ChatGPT API funguje

Proces má štyri kroky:

**Odošlete požiadavku.** Vaša aplikácia odošle OpenAI požiadavku POST s dátami JSON obsahujúcimi názov modelu, správy a parametre, ako sú teplota a limity tokenov.

**OpenAI požiadavku spracuje.** Model vygeneruje odpoveď a vráti ju v objekte JSON. Keď je povolené streamovanie, tokeny prichádzajú postupne.

**Vaša aplikácia prijme odpoveď.** Odpoveď obsahuje vygenerovaný obsah, využitie tokenov, informácie o modeli a ID požiadavky.

**Prebehne fakturácia.** Poplatky závisia od spracovaných tokenov. Vstupné a výstupné tokeny môžu mať odlišné sadzby.

Dĺžka promptu, výber modelu a ukladanie do vyrovnávacej pamäte ovplyvňujú výkon a náklady.

Ceny sa zvyčajne odvíjajú od vstupných a výstupných tokenov, ktoré môžu mať odlišné sadzby.

## Ako nastaviť ChatGPT API

Na overovanie požiadaviek potrebujete kľúč API. Považujte ho za tajný údaj a bezpečne ho uložte.

**Bezpečnostné poznámky:**

- Kľúč môže poskytovať prístup spojený s vaším účtom a fakturáciou.
- Ak kľúč stratíte, vytvorte náhradný.

## Nastavenie vývojového prostredia

API možno používať z ľubovoľného programovacieho jazyka, ktorý dokáže odosielať požiadavky HTTP. Bežnou voľbou sú Python, JavaScript a Java.

### 1. Python: jednoduchosť a bohatý ekosystém

Vďaka svojej syntaxi a ekosystému knižníc je Python bežnou voľbou. Balík Python od OpenAI môže zjednodušiť overovanie, formátovanie požiadaviek a spracovanie chýb. Balíky ako `python-dotenv` môžu pomôcť so správou premenných prostredia.

Python sa používa aj v strojovom učení, dátovej vede, vývoji webových aplikácií a automatizácii, takže je užitočný pri projektoch, ktoré kombinujú volania API so spracovaním dát.

### 2. JavaScript: flexibilita pre webové aplikácie

JavaScript sa používa v backendových aplikáciách s Node.js aj vo webových aplikáciách využívajúcich frameworky, ako sú React, Vue alebo Next.js. Jeho asynchrónne funkcie vrátane `async`/`await` a Promises umožňujú neblokujúce požiadavky API.

### 3. Java: škálovateľnosť a výkon

Java sa bežne používa v podnikových aplikáciách. Statické typovanie môže zachytiť niektoré chyby už pri kompilácii a jej funkcie súbežného spracovania môžu aplikáciám pomôcť zvládať viacero požiadaviek. Môže byť vhodná pre softvér, ktorý sa integruje s existujúcimi systémami Java.

Nasledujúce príklady používajú Python. Ak používate JavaScript alebo Javu, prispôsobte syntax svojmu jazyku a SDK.

## Osvedčené postupy pri používaní ChatGPT API

### 1. Píšte jasné a konkrétne prompty

Jasné a konkrétne pokyny môžu zvýšiť užitočnosť odpovedí.

- Uveďte požadovaný formát, tón a dĺžku.
- V prípade potreby poskytnite príklady.
- Pokynmi pre vývojárov nastavte správanie a kontext.
- Zložité úlohy rozdeľte na menšie kroky.

Príklad:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.
vague = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)
print(vague.choices[0].message.content)

# Specify the audience, deliverable, and focus.
specific = client.chat.completions.create(
    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)
print(specific.choices[0].message.content)
```

### 2. Na spoľahlivé údaje používajte štruktúrované výstupy

Pri JSON alebo iných štruktúrovaných údajoch používajte funkcie API na štruktúrovaný výstup namiesto parsovania voľného textu. V dokumentácii si overte podporovaný formát a obmedzenia.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Používajte streamovanie na zlepšenie používateľského zážitku

Streamovanie môže zobrazovať obsah odpovede priebežne namiesto čakania na dokončenie celej odpovede.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Ošetrujte chyby vhodným spôsobom

Požiadavky môžu zlyhať pre problémy so sieťou, limity požiadaviek, neplatný vstup alebo výpadky služby. Chyby ošetrujte podľa dokumentácie SDK a API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Na integráciu nástrojov používajte volanie funkcií

Volanie funkcií umožňuje modelu požiadať vašu aplikáciu o zavolanie funkcie alebo nástroja. Aplikácia volanie spracuje a podľa potreby vráti výsledky.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```

## Často kladené otázky

**Má ChatGPT API?**

Áno. OpenAI poskytuje API na programový prístup k modelom. Aplikácie môžu odosielať požiadavky HTTP alebo používať oficiálne SDK; aktuálnu dostupnosť modelov a funkcií si overte v dokumentácii.

**Koľko stojí ChatGPT API?**

Cena závisí od modelu a využitia. Aktuálne sadzby a dostupné možnosti riadenia nákladov nájdete na [stránke cien OpenAI](https://openai.com/api/pricing/).

**Aký je rozdiel medzi ChatGPT a ChatGPT API?**

ChatGPT je konverzačný produkt. API umožňuje vývojárom programovo odosielať požiadavky a integrovať odpovede modelu do aplikácií. Dostupné ovládacie prvky závisia od API a zvoleného modelu.

**Aký je najnovší model dostupný v ChatGPT API?**

Dostupnosť modelov sa mení. Najnovšie modely a ich možnosti nájdete v aktuálnej [dokumentácii API](https://developers.openai.com/api/docs) spoločnosti OpenAI.

**Mám použiť Responses API alebo Chat Completions?**

API si vyberte podľa aplikácie a funkcií, ktoré potrebuje. Dokumentácia OpenAI opisuje aktuálne endpointy a pokyny na migráciu. Pri existujúcich aplikáciách postupujte podľa zdokumentovaných pokynov na podporu a migráciu príslušného endpointu.

**Môžem používať ChatGPT API zadarmo?**

Ailoot podporuje aj sémantické vyhľadávanie a štruktúrované rozhodovanie.

Ak váš projekt potrebuje [kľúč API Chat GPT](<https://ailoot.ai/>), vytvorte si kľúč priamo v Ailoote. Cez API Ailootu použijete GPT-6.2 Astra alebo GPT-6.2 Sol. Z rovnakého zostatku platíte aj za Claude, Gemini a multimediálne modely.

Majú vaše aplikácie používať samostatné kľúč API ChatGPT? V Ailoote vytvorte samostatný kľúč s vlastnými limitmi pre každý projekt, od prototypu „kľúče API ChatGPT“ až po služby s ďalšími modelmi. Prístupy tímu aj firemné výdavky spravujte v jednom pracovnom priestore Ailoot.

Na používanie nových vlajkových modelov môžete už od prvého dňa čerpať z toho istého zostatku v Ailoote. Jedno predplatné pokrýva celý katalóg. S predplatným a zľavovými kódmi môžete znížiť náklady na modely až o 50 % oproti oficiálnym cenám API poskytovateľov modelov. Prihláste sa do svojho účtu na [https://ailoot.ai/](<https://ailoot.ai/>) alebo požiadajte tím Ailoot o zľavový kód.
