The ChatGPT API gives developers programmatic access to OpenAI models. This guide covers API key setup, model selection, pricing, code examples, and practices for building applications and managing costs.

## What Is the ChatGPT API?

The ChatGPT API lets developers integrate AI capabilities into applications through HTTP requests. Applications send structured requests to OpenAI and receive JSON responses containing model output.

### How the ChatGPT API Works

The process follows four steps:

**You send a request.** Your application sends a POST request to OpenAI with a JSON payload containing a model name, messages, and parameters such as temperature and token limits.

**OpenAI processes the request.** The model generates a response and returns it in a JSON object. With streaming enabled, tokens arrive incrementally.

**Your application receives the response.** The response includes generated content, token usage, model information, and a request ID.

**Billing occurs.** Charges depend on processed tokens. Input and output tokens may have different rates.

Prompt length, model selection, and caching affect performance and cost.

## How to Set Up the ChatGPT API

You need an API key to authenticate requests. Treat it as a secret and store it securely.

### How to Obtain an OpenAI API Key

**Step 1: Access the OpenAI Platform**

- Visit [platform.openai.com/api-keys](https://platform.openai.com/api-keys) and sign in or create an account.

**Step 2: Create Your API Key**

- Open **API Keys** in the dashboard.
- Select **Create new secret key** and optionally give it a project-specific name.
- Copy the key when it is displayed; it may not be shown again.

**Step 3: Store It Securely**

- Store the key in a password manager or environment variable.
- Never commit API keys to version control or expose them in client-side code.
- If you use a `.env` file, add it to `.gitignore` and keep the file out of version control.

**Security notes:**

- A key can grant access associated with your account and billing.
- If a key is lost, create a replacement.
- Revoke keys that may have been compromised.
- Use separate, appropriately scoped keys for different projects when available.
