# תמחור OpenAI Moderation API: בחינם, מגבלות קצב וחלופות

> מודלי המודרציה של OpenAI הם בחינם. ראו מידע על תמחור, מגבלות קצב לפי דרגת שימוש, דוגמאות Python ומתי חלופה תואמת OpenAI מתאימה יותר.




נקודת הקצה Moderation של OpenAI זמינה בחינם למשתמשי OpenAI API. כשאתם בוחרים תהליך עבודה לסביבת ייצור, בדקו אילו סוגי קלט וקטגוריות נתמכים, מהן מגבלות הקצב בחשבונכם ואיך נקודת הקצה משתלבת בתהליך הבדיקה שלכם.

המדריך הזה מפריד בין התשובה הרשמית בנושא התמחור לבין ההחלטה ההנדסית המעשית.

## בקצרה

- **נקודת הקצה Moderation של OpenAI זמינה בחינם למשתמשי OpenAI API**, לפי מרכז העזרה של OpenAI.
- מודל `omni-moderation-latest` של OpenAI נועד לזהות תוכן מזיק ומקבל טקסט ותמונות כקלט, לפי עמוד המודל הרשמי של OpenAI.
- התמחור בחינם אינו מבטל עלויות תהליך עבודה כגון רישום, תורי בדיקה, מיפוי מדיניות, ניסיונות חוזרים, התנהגות בעת כשל והחלטות ייחודיות ליישום.
- בחרו בנקודת הקצה החינמית של OpenAI אם אתם כבר משתמשים ישירות ב־OpenAI ותהליך המודרציה שלכם מתאים לקטגוריות ולפורמט התגובה שלה.
- שקלו להשתמש ב־EvoLink Moderation 1.0 אם אתם כבר עובדים עם EvoLink ורוצים לבדוק סוגי קלט שונים, לקבל סיכום סיכונים ולשלם לפי קריאה באותו תהליך העבודה.

## האם OpenAI Moderation API בחינם?

כן. מרכז העזרה הרשמי של OpenAI מציין שנקודת הקצה Moderation זמינה בחינם למשתמשי OpenAI API, ושהשימוש בכלי אינו נכלל במגבלות השימוש החודשיות.

מקור: [מרכז העזרה של OpenAI: האם השימוש בנקודת הקצה Moderation הוא בחינם?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

זו התשובה בנושא התמחור. השאלה הבאה היא תפעולית:

**האם נקודת קצה חינמית למודרציה מספיקה לתהליך העבודה שלכם בסביבת ייצור?**

לאבות־טיפוס, לכלים פנימיים ולמודרציה פשוטה שמתחילה בטקסט, ייתכן שכן. עבור יישומים המטפלים בתוכן שנוצר בידי משתמשים, בהעלאות תמונות, בסוכני AI או בתורי בדיקה, קריאת ה־API היא רק חלק אחד מהמערכת.

## מה מכסה מודרציית OpenAI?

OpenAI מתעדת את `omni-moderation-latest` כמודל מודרציה שנועד לזהות תוכן שעלול להיות מזיק בטקסט ובתמונות. עמוד המודל הרשמי מתאר אותו כמודל המודרציה המתקדם ביותר של OpenAI ומציין תמיכה בקלט/פלט של טקסט ובקלט של תמונות. מקור: [עמוד המודל של OpenAI עבור omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) מדריך המודרציה של OpenAI מסביר גם את קטגוריות סיווג התוכן ומציין שחלק מהקטגוריות תומכות בטקסט בלבד. אם תשלחו רק תמונות אל `omni-moderation-latest`, הקטגוריות שאינן תומכות בקלט של תמונות יחזירו ציון 0. מקור: [מדריך המודרציה של OpenAI](https://developers.openai.com/api/docs/guides/moderation)

כלומר, צוותים צריכים לקרוא בעיון את טבלת הקטגוריות לפני שהם מניחים שכל קטגוריית טקסט ממופה ישירות למודרציה של תמונות.

## העלות האמיתית היא תהליך העבודה, לא רק תמחור ה־API

נקודת הקצה Moderation עשויה להיות בחינם, אבל מערכת מודרציה בסביבת ייצור עדיין מחייבת החלטות בנוגע ל:

- היכן להריץ בדיקות: לפני קריאות למודל, אחרי תגובות המודל או בשני המקרים
- כיצד למפות קטגוריות להחלטות של אישור, בדיקה או חסימה
- כיצד לתעד תוצאות מודרציה בלי לאחסן תוכן רגיש שלא לצורך
- כיצד לטפל בחיוביים שגויים ובערעורים
- כיצד לבצע מודרציה להעלאות תמונות בנפרד מקלט טקסט
- כיצד לנטר השהיה, שגיאות ומגבלות קצב
- כיצד לשמור על התנהגות מדיניות עקבית בכל ממשקי המוצר

אלה עלויות הנדסה ותפעול. הן אינן מופיעות בדף התמחור, אבל הן קובעות אם שכבת המודרציה באמת ניתנת לתחזוקה.

בתהליך טיפוסי, בדקו את הפרומפטים לפני שליחתם למודל ואת הפלט לפני מסירתו למשתמשים. העבירו תוצאות לא חד־משמעיות לבדיקה, תעדו רק את המידע הנחוץ על ההחלטות ותכננו מראש איך לטפל בניסיונות חוזרים ובערעורים.

## מתי נקודת הקצה החינמית של OpenAI מתאימה

נקודת הקצה Moderation החינמית של OpenAI היא לעיתים קרובות בחירה ראשונה טובה כאשר:

- אתם כבר משתמשים ישירות ב־OpenAI
- היישום שלכם מבוסס בעיקר על טקסט
- אתם זקוקים רק לקטגוריות המודרציה ש־OpenAI מתעדת
- אתם יכולים לבנות בעצמכם תהליך עבודה לבדיקה ולהסלמה
- נוח לצוות שלכם לנהל את פענוח התגובות, הספים והיומנים

במקרה כזה, קשה להתנגד לנקודת הקצה החינמית. התחילו בה, בדקו אותה מול התוכן האמיתי שלכם ומדדו חיוביים שגויים ומקרים שלא זוהו לפני שתנתבו אליה תעבורת ייצור.

## מתי חלופה תואמת OpenAI מתאימה

EvoLink Moderation 1.0 היא חלופה בתשלום עם נתיב `/v1/moderations` תואם OpenAI. ב־EvoLink אפשר לשלוח לכל היותר תמונה אחת בכל בקשה.

- בדיקות לטקסט בלבד, לתמונות בלבד ולשילוב של טקסט ותמונות באמצעות נקודת קצה אחת
- 13 קטגוריות נזק עם ציונים לכל קטגוריה
- אובייקט `evolink_summary` ובו השדות `risk_level`, `flagged`, `violations`, `max_score` ו־`max_category`
- תמחור אחיד לכל קריאה במקום חישוב לפי טוקנים
- מבנה תגובה שקל יותר למפות ללוגיקה של אישור, בדיקה או חסימה

## איך להשתמש ב־OpenAI Moderation API ב־Python

אם אתם כבר משתמשים ב־OpenAI SDK, קריאת מודרציה בסיסית של טקסט נראית כך:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

כדי להשתמש ב־EvoLink, הגדירו את `EVOLINK_API_KEY` למפתח EvoLink שלכם ואת `EVOLINK_BASE_URL` לכתובת הבסיס של ה־API ב־HTTPS שמסתיימת ב־`/v1`, לפי הגדרות ה־API של EvoLink. התגובה כוללת גם את האובייקט `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## השוואת OpenAI ו־EvoLink מבחינת תמחור ותהליך עבודה

| קריטריון | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| חיוב | בחינם למשתמשי OpenAI API | חיוב בתעריף קבוע לכל קריאה |
| מבנה נקודת הקצה הראשית | `/v1/moderations` | `/v1/moderations` תואם OpenAI |
| מודרציה של טקסט | נתמכת | נתמכת |
| מודרציה של תמונות | נתמכת על ידי `omni-moderation-latest`, עם תמיכה בקלט לפי קטגוריה | נתמכת בבקשות של תמונות בלבד ובבקשות המשלבות טקסט ותמונות |
| שדות לקבלת החלטות לפי מדיניות המודרציה | פרשו את הערכים של `flagged`, `categories` ו־`category_scores` תחת `results` | השתמשו ב־`evolink_summary.risk_level` וב־`violations` לצד ציוני הקטגוריות |
| למי מתאים | לצוותים שכבר מבצעים קריאות ישירות ל־OpenAI | לצוותים המשלבים מודרציה בתהליך עבודה קיים ב־EvoLink |

## המלצה מעשית

השתמשו בנקודת הקצה Moderation החינמית של OpenAI אם היישום שלכם כבר מבוסס על OpenAI ומדיניות המודרציה שלכם מתאימה לקטגוריות המתועדות שלה.

אם הצוות שלכם כבר משתמש ב־EvoLink, העריכו את העלות לכל קריאה והתייחסו לערך של `evolink_summary.risk_level` כאחד השיקולים בכללי האישור, הבדיקה או החסימה ביישום.

השתמשו במערכת מודרציה רב־שכבתית אם ליישום שלכם יש דרישות מדיניות מותאמות אישית שזקוקות לכללי מותג, לבדיקה אנושית, לערעורים או לתהליכי עבודה של תאימות מעבר למה שמציע כל API מודרציה יחיד.

## שאלות נפוצות

### האם OpenAI Moderation API בחינם?

כן. מרכז העזרה של OpenAI מציין שנקודת הקצה Moderation זמינה בחינם למשתמשי OpenAI API ואינה נכללת במגבלות השימוש החודשיות.

### האם מודרציית OpenAI תומכת בתמונות?

כן, `omni-moderation-latest` מקבל תמונות כקלט לפי עמוד המודל הרשמי של OpenAI. עם זאת, מדריך המודרציה של OpenAI מציין שחלק מהקטגוריות תומכות בטקסט בלבד, ולכן צוותים צריכים לבדוק את התמיכה בקלט עבור כל קטגוריה לפני שהם מסתמכים על מודרציה של תמונות בלבד.

### האם EvoLink Moderation זולה יותר מ־OpenAI Moderation?

נקודת הקצה Moderation של OpenAI זמינה בחינם למשתמשי OpenAI API. ב־EvoLink החיוב הוא בתעריף קבוע לכל קריאה. השוו את עלות תהליך העבודה כולו, כולל בדיקה ותחזוקה.

### האם אפשר להשתמש ב־EvoLink כחלופה ל־OpenAI Moderation API?

כן. השתמשו במפתח EvoLink API שלכם ובמודל `evolink-moderation-1.0` דרך הנתיב התואם `/v1/moderations` של EvoLink. התאימו את עיבוד התגובה לאובייקט הנפרד `evolink_summary` של EvoLink.

### האם כדאי לבצע מודרציה לפרומפטים, לפלטים או לשניהם?

ביישומי AI בסביבת ייצור, צוותים רבים מבצעים מודרציה הן לקלט והן לפלט. מודרציית קלט יכולה לצמצם בקשות לא בטוחות לפני שהן מגיעות למודל. מודרציית פלט יכולה לזהות תגובות שנוצרו ואינן בטוחות לפני שהן מגיעות למשתמשים.

### מהו omni-moderation-latest?

זהו מודל המודרציה של OpenAI לטקסט ולתמונות. קראו את הערכים של `flagged`, `categories` ו־`category_scores` תחת `results` והחילו את מדיניות המודרציה שלכם.

### מהי מגבלת הקצב של OpenAI Moderation API?

השימוש בחינם מתייחס לחיוב. המגבלות על מספר הבקשות והטוקנים עדיין חלות. לפי [תיעוד המודל](https://developers.openai.com/api/docs/models/omni-moderation-latest), RPM הוא מספר הבקשות בדקה, RPD הוא מספר הבקשות ביום כאשר המדד מופיע, ו־TPM הוא מספר הטוקנים בדקה.

מגבלות הקצב של OpenAI Moderation API משתנות לפי דרגת החשבון ועשויות להשתנות עם הזמן. בדקו את [התיעוד של OpenAI בנושא מגבלות קצב](https://platform.openai.com/docs/guides/rate-limits) ואת [עמוד מגבלות השימוש](https://platform.openai.com/settings/organization/limits) של החשבון שלכם לפני תכנון תפוקת ייצור.

### איך משתמשים ב־OpenAI Moderation API ב־Python?

התקינו את חבילת `openai`, הגדירו את `OPENAI_API_KEY` וקראו ל־`client.moderations.create()` עם המודל `omni-moderation-latest` והטקסט שלכם. לתמונות, העבירו את `input` כמערך של אובייקטים. כל פריט שמייצג תמונה כולל את `type: "image_url"` ואובייקט `image_url` המכיל את `url`, כפי שמופיע בתיעוד OpenAI API המקושר בהמשך.
