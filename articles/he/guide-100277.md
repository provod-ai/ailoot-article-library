# ChatGPT API: הגדרה, תמחור ודוגמאות קוד (2026)

> מדריך מעשי להגדרת ChatGPT API, להשוואת מודלים ותמחור ולבניית יישומים באמצעות דוגמאות קוד.



ChatGPT API מעניק למפתחים גישה תוכנתית למודלים של OpenAI. המדריך הזה עוסק בהגדרת מפתח API, בבחירת מודל, בתמחור, בדוגמאות קוד ובשיטות לבניית יישומים ולניהול עלויות.

## מהו ChatGPT API?

ChatGPT API מאפשר למפתחים לשלב יכולות AI ביישומים באמצעות בקשות HTTP. יישומים שולחים ל-OpenAI בקשות מובנות ומקבלים תגובות JSON המכילות פלט של מודל.

### איך ChatGPT API עובד

התהליך מורכב מארבעה שלבים:

**שולחים בקשה.** היישום שלכם שולח ל-OpenAI בקשת POST עם מטען JSON המכיל שם מודל, הודעות ופרמטרים כגון טמפרטורה ומגבלות טוקנים.

**OpenAI מעבדת את הבקשה.** המודל יוצר תגובה ומחזיר אותה באובייקט JSON. כשהזרמת נתונים מופעלת, הטוקנים מגיעים בהדרגה.

**היישום שלכם מקבל את התגובה.** התגובה כוללת את התוכן שנוצר, את השימוש בטוקנים, מידע על המודל ומזהה בקשה.

**החיוב מתבצע.** החיובים תלויים בטוקנים שעובדו. לתגובות ולבקשות עשויים להיות תעריפים שונים.

אורך ה-prompt, בחירת המודל ושמירת תוצאות במטמון משפיעים על הביצועים והעלות.

## איך להגדיר את ChatGPT API

כדי לאמת בקשות נדרש מפתח API. התייחסו אליו כאל סוד ושמרו אותו במקום מאובטח.

### איך להשיג מפתח API של OpenAI

**שלב 1: היכנסו לפלטפורמת OpenAI**

- בקרו ב-[platform.openai.com/api-keys](https://platform.openai.com/api-keys) והתחברו או צרו חשבון.

**שלב 2: צרו מפתח API**

- פתחו את **מפתחות API** בלוח הבקרה.
- בחרו **יצירת מפתח סודי חדש** ואפשר לתת לו שם ייחודי לפרויקט.
- העתיקו את המפתח כשהוא מוצג; ייתכן שהוא לא יוצג שוב.

**שלב 3: שמרו אותו באופן מאובטח**

- שמרו את המפתח במנהל סיסמאות או במשתנה סביבה.
- לעולם אל תכניסו מפתחות API למערכת בקרת גרסאות ואל תחשפו אותם בקוד צד-לקוח.
- אם אתם משתמשים בקובץ `.env`, הוסיפו אותו ל-`.gitignore` והשאירו אותו מחוץ למערכת בקרת הגרסאות.

**הערות אבטחה:**

- מפתח עשוי להעניק גישה המשויכת לחשבון ולחיוב שלכם.
- אם מפתח אבד, צרו מפתח חלופי.
- בטלו מפתחות שייתכן שנחשפו.
- כשאפשר, השתמשו במפתחות נפרדים בעלי הרשאות מתאימות לפרויקטים שונים.

### 2. השתמשו בפלט מובנה לקבלת נתונים מהימנים

עבור JSON או נתונים מובנים אחרים, השתמשו בתכונות הפלט המובנה של ה-API במקום לנתח טקסט חופשי. בדקו בתיעוד אילו פורמטים ומגבלות נתמכים.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. הטמיעו הזרמת נתונים לשיפור חוויית המשתמש

הזרמת נתונים יכולה להציג את תוכן התגובה עם הגעתו, במקום להמתין לקבלת התגובה המלאה.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. טפלו בשגיאות בצורה מסודרת

בקשות עלולות להיכשל בגלל בעיות רשת, מגבלות קצב, קלט לא תקין או תקלות בשירות. טפלו בשגיאות בהתאם לתיעוד של ה-SDK וה-API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. השתמשו בקריאה לפונקציות לשילוב כלים

קריאה לפונקציות מאפשרת למודל לבקש מהיישום שלכם להפעיל פונקציה או כלי. היישום שלכם מטפל בקריאה ומחזיר תוצאות לפי הצורך.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
