# Zapier jämfört med n8n: vad du får betala för egen drift

> Jämför Zapier och n8n när det gäller prissättning, integrationer, licensiering, krav för egen drift och utformning av arbetsflöden för att välja rätt automatiseringsverktyg för ditt team.



**Zapier är en driftad tjänst som räknar debiterbara åtgärder i uppgifter. [n8n](https://n8n.io/) tar betalt per arbetsflödeskörning i sina betalda abonnemang och erbjuder en utgåva för egen drift.**

Om ett arbetsflöde körs 1 000 gånger och slutför 12 debiterbara åtgärder per körning använder det 12 000 Zapier-uppgifter när varje åtgärd kostar en uppgift. Om samma körningar räknas in i kvoten för n8n-abonnemanget registrerar n8n 1 000 körningar.

Det du ger upp är också påtagligt. n8n kräver att du driver infrastruktur, eller accepterar ett mindre integrationsbibliotek, eller båda delarna.

- **Zapier**: brett apputbud, driftad tjänst, debitering efter antal uppgifter
- **n8n**: möjlighet till egen drift, betalda abonnemang baserade på antal körningar, källkod tillgänglig under Sustainable Use License
- **Den avgörande frågan**: är din begränsning apputbudet eller arbetsflödenas längd och var data lagras?

## Snabb jämförelse

|  | Zapier | n8n |
|----|----|----|
| Debiteringsenhet | Uppgifter för debiterbara åtgärder som lyckas, enligt gällande taxa | Körning – en hel körning av arbetsflödet |
| Kostnad för att lägga till ett steg | Ökar med varje debiterad åtgärd | Antalet körningar ändras inte |
| Egen drift | Inte tillgängligt | Ja, Community Edition |
| Licens | Proprietär SaaS | Sustainable Use License (källkod tillgänglig, inte öppen källkod enligt OSI) |
| Apputbud | Brett katalogutbud | Mindre integrationsbibliotek |
| Kodsteg | JavaScript och Python i en sandbox | JavaScript- och Python-noder samt npm-paket vid egen drift |
| Vem underhåller det | Zapier | Du, om du kör det på egen server |
| Passar bäst för | Brett apputbud, icke-tekniska ansvariga | Långa arbetsflöden, datakontroll, tekniska team |

## Debitering per steg jämfört med per körning – och varför det påverkar utformningen

Utlösare och regelbundna kontroller efter nya data förbrukar inga uppgifter. Inbyggda verktyg som Formatter och Filter förbrukar heller inga uppgifter. Vissa debiterbara åtgärder förbrukar mer än en uppgift, så kontrollera vad varje åtgärd kostar i uppgifter.

n8n:s modell räknar en körning som en enda körning av hela arbetsflödet – plattformens egen [prissida](https://n8n.io/pricing/) säger att antalet steg och mängden data som passerar genom arbetsflödet inte påverkar antalet körningar.

Följderna för utformningen går åt motsatta håll:

Använd Paths för förgreningar och Formatter för att ändra data där de passar. Uppskatta det totala antalet uppgifter utifrån vilka debiterbara åtgärder som körs och hur många uppgifter varje åtgärd kostar.

Varje arbetsflödeskörning som räknas in i kvoten för ett n8n-abonnemang förbrukar en körning, oavsett antal steg. Att bearbeta flera poster i samma körning kan minska antalet körningar som räknas in i kvoten.

Den här andra punkten kan överraska personer som migrerar från Zapier, där det är vanligt att köra en gång per post och kan vara billigt när antalet åtgärder är litet.

## Licensfrågan, korrekt beskriven

n8n beskrivs ofta som öppen källkod. Det är det inte, och n8n hävdar inte heller det. n8n distribueras under Sustainable Use License, en fair-code-licens. Källkoden finns på GitHub och får läsas, ändras och köras på egen server för internt bruk.

Licensen tillåter inte att n8n erbjuds till tredje part som en driftad tjänst. Eftersom Open Source Initiatives definition inte tillåter användningsbegränsningar undviker n8n beteckningen ”öppen källkod”.

För många team är skillnaden teoretisk: licensen tillåter egen drift internt utan gräns för antal arbetsflöden eller körningsfrekvens. Den spelar roll om du är en byrå som planerar att sälja vidare hanterade n8n-instanser; då behöver du ett kommersiellt avtal.

## Vad egen drift faktiskt kostar

Påståendet att ”n8n är gratis” bortser från kostnaderna du faktiskt betalar:

- **En server och någon som underhåller den.** Uppdateringar, säkerhetskopior, TLS-certifikat, övervakning och larmet klockan 02 när kön stannar
- **Arbete med skalning.** Övergång till köläge med workers när en enda instans inte längre hänger med
- Funktionerna varierar mellan abonnemangen. Business för egen drift innehåller SSO och LDAP. Enterprise innehåller även loggströmning och integration med externa lager för hemligheter.
- **Felsökning på egen hand.** Du kanske inte har någon support att kontakta när en nod beter sig fel

Om ingen i teamet ansvarar för infrastrukturen kan n8n på egen server bli en belastning snarare än en besparing. n8n Cloud erbjuder debitering per körning utan driftsansvaret och är ett relevant jämförelsealternativ till Zapier för många köpare.

## Där respektive verktyg är starkast

**Zapier är starkast när det gäller utbudet.** Appkatalogen är bredare än n8n:s integrationsbibliotek. Om din verktygsuppsättning innehåller något nischat är det större chans att Zapier redan har det. n8n:s HTTP Request-nod kan kommunicera med valfritt REST API, men ”valfritt API” innebär att du själv måste läsa dokumentationen och hantera autentiseringen.

**Zapier är starkast när den ansvariga inte är teknisk.** Personer som inte är ingenjörer kan underhålla Zaps. n8n förutsätter att du är bekväm med datastrukturer, uttryck och JSON – och n8n på egen server förutsätter dessutom att du är bekväm med servrar.

**n8n kan vara starkare för långa arbetsflöden.** Debitering per körning innebär ingen extra kostnad för varje ytterligare steg, vilket kan göra verktyget lämpligt för arbetsflöden med många steg.

**n8n kan vara starkare när det gäller datalagring och kontroll.** Reglerade branscher, eller verksamheter som inte kan låta kunddata passera genom en extern molntjänst, kan behöva egen drift. Zapier erbjuder inget alternativ för egen drift.

**n8n kan passa för AI-arbete.** LangChain-noderna och stödet för lokala modeller kan vara användbara för arbetsflöden utformade kring agenter.

## Så väljer du utan att ångra dig

Gå igenom frågorna i den här ordningen:

1. **Har du ett strikt krav på var data lagras?** Ja → n8n på egen server.
2. **Finns det någon som ansvarar för en server?** Nej → Zapier eller n8n Cloud.
3. **Hur långa är dina arbetsflöden?** Längre arbetsflöden kan göra n8n:s debiteringsmodell attraktiv.
4. **Hur nischad är din verktygsuppsättning?** Flera ovanliga verktyg kan göra Zapiers utbud värt kostnaden per steg.
5. **Allt annat** → börja med det verktyg som passar teamets kompetens och integrationer bäst. Det är lättare att migrera från en fungerande automatisering än att färdigställa en som aldrig kom igång.

Make ligger mellan dem i vissa avseenden: molnbaserat som Zapier, med en visuell arbetsyta som liknar n8n:s mer.

## Vanliga frågor

**Är n8n gratis?**

Community Edition är gratis att köra på egen server, utan gräns för antal arbetsflöden eller körningar. Du betalar för servern och underhållet. n8n Cloud är avgiftsbelagt, och Enterprise-funktioner för egen drift kräver en licensnyckel.

**Är n8n öppen källkod?**

Nej, och n8n hävdar inte att det är det. Källkoden är tillgänglig under Sustainable Use License, som tillåter intern användning och ändringar men förbjuder vidareförsäljning av n8n som en driftad tjänst. Användningsbegränsningar gör att en licens inte uppfyller OSI:s definition av öppen källkod.

**Blir n8n verkligen billigare än Zapier?**

n8n kan kosta mindre för långa arbetsflöden med många debiterbara Zapier-åtgärder. Jämför antalet arbetsflödeskörningar och hur många uppgifter varje debiterbar åtgärd förbrukar. Räkna med kostnader för infrastruktur och underhåll vid egen drift.

**Kan jag flytta mina Zaps till n8n automatiskt?**

Det kanske inte finns någon konverterare som stöds. Migreringen kan kräva att du bygger om dem, så det är klokt att prototypa dina tyngsta arbetsflöden i n8n innan du bestämmer dig.

**Behöver n8n en utvecklare?**

Vid egen drift måste någon ansvara för servern. n8n Cloud tar bort det ansvaret, men för att bygga i n8n behöver du fortfarande vara mer bekväm med datastrukturer och uttryck än med Zapier.

**Hur är det med Power Automate?**

Microsoft erbjuder abonnemang per användare och per process. Microsoft beskriver också användningsbaserad debitering per körning för flöden som uppfyller villkoren. Jämför prisalternativen för de flöden du använder.
