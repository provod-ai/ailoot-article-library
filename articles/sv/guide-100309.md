# Claude API för nybörjare: en praktisk startguide

> En introduktionsguide till Claude API med installation, första anropet, modellval, kärnfunktioner och arbetssätt för produktion.



Allt en utvecklare behöver för att göra sitt första Claude API-anrop: nycklar, Messages API, modellval och grundbegrepp för att gå från en första förfrågan till produktion.

## Vad Claude API är

Claude API är Anthropics utvecklarplattform. Den ger programmatisk åtkomst till Claude-modeller via Messages API, med systempromptar, verktygsanvändning, streaming, vision och strukturerade utdata.

Messages API är en tillståndslös HTTP-endpoint. Du skickar en lista med användar- och assistentmeddelanden, ett modell-ID och en tokengräns; Claude returnerar ett strukturerat svar. Kompletterande endpoints omfattar batcher, filer och tokenräkning.

- **Tillståndslös:** API:et har inget minne. Skicka med konversationshistoriken på nytt vid varje anrop.
- **Modellval:** Att byta modell innebär vanligtvis att modell-ID:t ändras.
- **SDK:er:** De officiella biblioteken för Python (anthropic) och TypeScript (@anthropic-ai/sdk) använder motsvarande begärandeformat.

Om du förstår arkitekturen undviker du ett vanligt nybörjarmisstag: att förvänta dig att API:et ska komma ihåg ett tidigare anrop.

## Steg 1: Skaffa en nyckel och konfigurera Console

Gå till **console.anthropic.com**, skapa ett konto eller en organisation för teamet och generera en API-nyckel i inställningarna. Behandla nyckeln som ett lösenord: lagra den i en miljövariabel och lägg aldrig in den i källkodshanteringen.

Direkta HTTP-anrop använder en **x-api-key**-header och en **anthropic-version**-header. SDK:erna läser automatiskt **ANTHROPIC_API_KEY** från miljön, så i de flesta kodexempel hanteras inte nyckeln direkt.

- Skapa separata nycklar för utveckling, staging och produktion.
- Använd arbetsytor för att isolera teamprojekt och kostnader.
- Ställ in användningsgränser i Console innan du ger ett större team tillgång till nycklarna.

## Steg 2: Gör ditt första anrop till Messages API

Installera SDK:et med **pip install anthropic**, exportera nyckeln och kör:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Tre parametrar krävs: **model**, **max_tokens** (utdatagränsen) och **messages**. Svaret innehåller en lista med innehållsblock. Kontrollera typen för varje block i stället för att anta att det är vanlig text, eftersom verktygsanvändning och tänkande kan ge andra blocktyper. Objektet **usage** rapporterar in- och utmatningstokens och kan användas för kostnadsuppföljning.

## Steg 3: Välj en modell

Här är Anthropics aktuella Claude-modeller och deras API-ID:n.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — beskrivs som snabb och billig, för klassificering och enkla uppgifter i hög volym.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — beskrivs som ett balanserat alternativ för produktionslaster, även kodning.
- **Claude Opus 5.5** (**claude-opus-5-5**) — beskrivs för avancerat resonemang och agentarbete över längre tid.
- **Claude Fable 5.2** (**claude-fable-5-2**) — beskrivs som en flaggskeppsmodell för krävande resonemangsuppgifter.

Börja med Opus 5.5. Prova Sonnet 5.5 för balans mellan hastighet och kvalitet, Haiku 5.5 för enkla uppgifter i hög volym och Fable 5.2 för avancerat resonemang. Se Anthropics prissida för aktuella priser.

## Fem begrepp att lära sig härnäst

När det första anropet fungerar täcker de här funktionerna många behov i applikationer:

- **Systempromptar** — en parameter på toppnivå, **system**, som anger roll, ton och regler separat från användarmeddelanden.
- **Konversationer med flera turer** — lägg till varje assistentsvar i messages-arrayen och skicka den igen; det första meddelandet måste komma från en användartur.
- **Streaming** — Server-Sent Events skickar tokens medan de genereras, vilket kan vara användbart i chattgränssnitt och för långa svar.
- **Vision** — skicka bilder som Base64- eller URL-innehållsblock tillsammans med text.
- **Verktygsanvändning** — definiera funktioner med JSON-scheman; Claude kan avgöra när de ska anropas, medan din kod kör dem och returnerar resultatet.

Överväg **promptcachning** och **batchbearbetning** när kostnaden spelar roll, och **strukturerade utdata** när efterföljande kod behöver tolka ett svar.

## Från handledning till produktion

Att gå från ett fungerande skript till en produktionsintegration kräver teknisk disciplin:

- **Felhantering:** hantera hastighetsbegränsningar (429) och serverfel på olika sätt. Källan säger att SDK:erna försöker om automatiskt med exponentiell väntetid; kontrollera aktuellt beteende i dokumentationen för det aktuella SDK:et.
- **Kostnadssynlighet:** logga **usage** från varje svar i ditt mätsystem.
- **Promptversionering:** behandla promptar som kod: granska dem, versionshantera dem och testa dem mot ett litet utvärderingsunderlag.
- **Låsning av modell:** hänvisa till modell-ID:n i konfigurationen så att uppgraderingar är avsiktliga och testade.

### Viktiga punkter

- Messages API är tillståndslöst; skicka om konversationshistoriken vid varje anrop.
- Direkt HTTP-autentisering använder x-api-key-headern; SDK:er kan läsa ANTHROPIC_API_KEY från miljön.
- De tre obligatoriska begärandeparametrarna är model, max_tokens och messages.
- Börja med Opus 5.5 och jämför alternativen på dina egna data.
- Systempromptar, streaming, vision, verktygsanvändning och historik över flera turer stöder många applikationsmönster.
- Logga tokenanvändning för att följa kostnader och kapacitet.

## FAQ

### Måste jag kunna maskininlärning för att använda Claude API?

Nej. Claude API är ett REST API med officiella SDK:er för Python och TypeScript. Om du kan anropa en HTTP-endpoint och tolka JSON kan du bygga med Claude. Promptdesign, felhantering och kostnadskontroll är användbara tekniska färdigheter; du behöver inte kunna maskininlärningsteori för att göra ett första API-anrop.

### Vilken Claude-modell bör en nybörjare börja med?

Anthropic rekommenderar att du börjar med Claude Opus 5.5 (API-ID `claude-opus-5-5`) för de flesta arbetsuppgifter. När dina promptar är stabila kan du jämföra de andra modellerna på dina egna data.

### Kommer Claude API ihåg tidigare konversationer?

Nej. Messages API är tillståndslöst. Din applikation lagrar konversationen och skickar hela meddelandehistoriken igen vid varje begäran. Då kan du styra kontexten, korta ned eller sammanfatta äldre turer och kombinera det med promptcachning.
