# Priser för OpenAI Moderation API: gratis, hastighetsbegränsningar och alternativ

> OpenAI:s modereringsmodeller är gratis. Se priser, hastighetsbegränsningar efter användningsnivå, Python-exempel och när ett OpenAI-kompatibelt alternativ passar bättre.




OpenAI:s Moderation-endpoint är kostnadsfri för användare av OpenAI API. När du väljer arbetsflöde för produktion bör du kontrollera vilka indata och kategorier som stöds, vilka hastighetsbegränsningar som gäller för ditt konto och hur endpointen passar in i din granskningsprocess.

Den här guiden skiljer det officiella prissvaret från det praktiska ingenjörsbeslutet.

## Kortfattat

- **OpenAI:s modereringsendpoint är gratis för användare av OpenAI API**, enligt OpenAI:s hjälpcenter.
- OpenAI:s modell `omni-moderation-latest` är utformad för att upptäcka skadligt innehåll och tar emot text och bilder som indata, enligt OpenAI:s officiella modellsida.
- Gratis prissättning eliminerar inte arbetsflödeskostnader som loggning, granskningsköer, policyanpassning, nya försök, reservbeteende och applikationsspecifika beslut.
- Välj OpenAI:s kostnadsfria endpoint om du redan använder OpenAI direkt och ditt modereringsflöde passar dess kategorier och svarsformat.
- Överväg EvoLink Moderation 1.0 om du redan använder EvoLink och vill samla multimodala kontroller, en risksammanfattning och debitering per anrop i samma arbetsflöde.

## Är OpenAI Moderation API gratis?

Ja. OpenAI:s officiella hjälpcenter anger att modereringsendpointen är gratis för användare av OpenAI API och att användningen av verktyget inte räknas mot månatliga användningsgränser.

Källa: [OpenAI:s hjälpcenter: Är modereringsendpointen gratis att använda?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Det är svaret om priset. Nästa fråga gäller driften:

**Räcker en kostnadsfri modereringsendpoint för ditt produktionsflöde?**

För prototyper, interna verktyg och enkel textbaserad moderering kan den göra det. För applikationer som hanterar användargenererat innehåll, bilduppladdningar, AI-agenter eller granskningsköer är API-anropet bara en del av systemet.

## Vad omfattar OpenAI:s moderering?

OpenAI dokumenterar `omni-moderation-latest` som en modereringsmodell utformad för att identifiera potentiellt skadligt innehåll i text och bilder. Den officiella modellsidan beskriver den som OpenAI:s mest kapabla modereringsmodell och anger stöd för text som indata och utdata samt bilder som indata. Källa: [OpenAI:s modellsida för omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) OpenAI:s modereringsguide förklarar också kategorierna för innehållsklassificering och noterar att vissa kategorier endast gäller text. Om du bara skickar bilder till `omni-moderation-latest` får kategorier som inte stöder bildindata poängen 0. Källa: [OpenAI:s modereringsguide](https://developers.openai.com/api/docs/guides/moderation)

Det innebär att team bör läsa kategoritabellen noggrant innan de antar att varje textkategori har en direkt motsvarighet inom bildmoderering.

## Den verkliga kostnaden ligger i arbetsflödet, inte bara i API-priset

Modereringsendpointen kan vara gratis, men ett produktionssystem för moderering kräver fortfarande beslut om:

- var kontrollerna ska köras: före modellanrop, efter modellsvar eller både och
- hur kategorier ska kopplas till beslut om att tillåta, granska eller blockera
- hur modereringsresultat ska loggas utan att lagra känsligt innehåll i onödan
- hur falska positiva resultat och överklaganden ska hanteras
- hur bilduppladdningar ska modereras separat från textindata
- hur latens, fel och hastighetsbegränsningar ska övervakas
- hur policybeteendet ska hållas konsekvent i produktens olika gränssnitt

Det här är kostnader för teknik och drift. De syns inte på en prissida, men avgör om modereringslagret faktiskt går att underhålla.

I ett vanligt arbetsflöde kontrollerar du prompter innan du skickar dem till modellen och utdata innan du skickar dem vidare. Skicka osäkra resultat till granskning, logga bara det nödvändigaste om besluten och planera för nya försök och överklaganden.

## När OpenAI:s kostnadsfria endpoint passar bra

OpenAI:s kostnadsfria modereringsendpoint är ofta ett bra förstahandsval när:

- du redan använder OpenAI direkt
- din app huvudsakligen är textbaserad
- du bara behöver OpenAI:s dokumenterade modereringskategorier
- du kan bygga ditt eget gransknings- och eskaleringsflöde
- ditt team är bekvämt med att själv hantera svarstolkning, tröskelvärden och loggar

I sådana fall är det svårt att argumentera emot den kostnadsfria endpointen. Börja där, testa den med ditt verkliga innehåll och mät falska positiva resultat och missade fall innan du skickar produktionstrafik dit.

## När ett OpenAI-kompatibelt alternativ är lämpligt

EvoLink Moderation 1.0 är ett betalalternativ med den OpenAI-kompatibla sökvägen `/v1/moderations`. EvoLink tar emot högst en bild per förfrågan.

- kontroller av enbart text, enbart bilder och text plus bilder via en endpoint
- 13 skade­kategorier med poäng per kategori
- ett `evolink_summary`-objekt med `risk_level`, `flagged`, `violations`, `max_score` och `max_category`
- fast pris per anrop i stället för tokenberäkningar
- ett svarsformat som är lättare att koppla till logik för att tillåta, granska eller blockera

## Så använder du OpenAI Moderation API i Python

Om du redan använder OpenAI SDK ser ett grundläggande modereringsanrop för text ut så här:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Ange din EvoLink-nyckel i `EVOLINK_API_KEY` och HTTPS-basadressen från din EvoLink-konfiguration i `EVOLINK_BASE_URL`. Basadressen slutar på `/v1`. Svaret innehåller även objektet `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Priser och arbetsflöden hos OpenAI och EvoLink

| Kriterium | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Debitering | Kostnadsfritt för användare av OpenAI API | Betalt, med ett fast pris per anrop |
| Huvudsakligt endpointformat | `/v1/moderations` | OpenAI-kompatibelt `/v1/moderations` |
| Textmoderering | Stöds | Stöds |
| Bildmoderering | Stöds av `omni-moderation-latest`, med kategorispecifikt stöd för indata | Stöds för förfrågningar med enbart bilder och med text plus bilder |
| Fält för att tillämpa modereringspolicyn | Tolka `flagged`, `categories` och `category_scores` i `results` | Använd `evolink_summary.risk_level` och `violations` tillsammans med poängen per kategori |
| Passar för | Team som redan anropar OpenAI direkt | Team som integrerar moderering i ett befintligt EvoLink-arbetsflöde |

## Praktisk rekommendation

Använd OpenAI:s kostnadsfria modereringsendpoint om din applikation redan är integrerad med OpenAI och din modereringspolicy passar tydligt med dess dokumenterade kategorier.

Om ditt team redan använder EvoLink, bedöm kostnaden per anrop och använd `evolink_summary.risk_level` som ett av kriterierna när din applikation ska tillåta, skicka vidare för granskning eller blockera innehåll.

Använd ett modereringssystem med flera lager om din applikation har anpassade policykrav som behöver varumärkesregler, mänsklig granskning, överklaganden eller efterlevnadsflöden utöver vad ett enskilt modererings-API erbjuder.

## Vanliga frågor

### Är OpenAI Moderation API gratis?

Ja. OpenAI:s hjälpcenter säger att modereringsendpointen är gratis för användare av OpenAI API och inte räknas mot månatliga användningsgränser.

### Stöder OpenAI:s moderering bilder?

Ja, `omni-moderation-latest` tar emot bilder som indata enligt OpenAI:s officiella modellsida. OpenAI:s modereringsguide noterar dock att vissa kategorier endast gäller text, så team bör granska indatastödet per kategori innan de förlitar sig på moderering av enbart bilder.

### Är EvoLink Moderation billigare än OpenAI Moderation?

OpenAI:s Moderation-endpoint är kostnadsfri för användare av OpenAI API. EvoLink tar ut ett fast pris per anrop. Jämför kostnaden för hela arbetsflödet, inklusive granskning och underhåll.

### Kan jag använda EvoLink som ett alternativ till OpenAI Moderation API?

Ja. Använd din EvoLink-API-nyckel och modellen `evolink-moderation-1.0` med EvoLinks kompatibla sökväg `/v1/moderations`. Anpassa svarshanteringen så att den tar hänsyn till EvoLinks separata `evolink_summary`-objekt.

### Bör jag moderera prompter, utdata eller både och?

För AI-applikationer i produktion modererar många team både indata och utdata. Indatamoderering kan minska osäkra förfrågningar innan de når en modell. Utdata­moderering kan fånga upp osäkra genererade svar innan de når användarna.

### Vad är omni-moderation-latest?

Det är OpenAI:s modereringsmodell för text och bilder. Läs `flagged`, `categories` och `category_scores` i `results` och tillämpa din egen modereringspolicy.

### Vilken hastighetsbegränsning gäller för OpenAI Moderation API?

Uppgiften om kostnadsfri tillgång gäller debiteringen. Gränser för förfrågningar och tokens gäller fortfarande. I [modellreferensen](https://developers.openai.com/api/docs/models/omni-moderation-latest) står RPM för förfrågningar per minut, RPD för förfrågningar per dag där det anges och TPM för tokens per minut.

OpenAI Moderation API:s hastighetsbegränsningar varierar beroende på kontonivå och kan ändras över tid. Kontrollera [OpenAI:s dokumentation om hastighetsbegränsningar](https://platform.openai.com/docs/guides/rate-limits) och ditt kontos [sida för användningsgränser](https://platform.openai.com/settings/organization/limits) innan du planerar produktionskapaciteten.

### Hur använder jag OpenAI Moderation API i Python?

Installera paketet `openai`, ange `OPENAI_API_KEY` och anropa `client.moderations.create()` med modellen `omni-moderation-latest` och din text. För bilder skickar du `input` som en array med objekt. Varje bildelement har `type: "image_url"` och ett `image_url`-objekt med fältet `url`, som i API-referensen från OpenAI som länkas nedan.
