# ChatGPT API: Så här konfigurerar du den, priser och kodexempel (2026)

> En praktisk guide till att konfigurera ChatGPT API, jämföra modeller och priser samt bygga applikationer med kodexempel.



ChatGPT API ger utvecklare programmatisk åtkomst till OpenAI-modeller. Den här guiden går igenom hur du konfigurerar en API-nyckel, väljer modell, priser, kodexempel och metoder för att bygga applikationer och hantera kostnader.

## Vad är ChatGPT API?

ChatGPT API gör det möjligt för utvecklare att integrera AI-funktioner i applikationer via HTTP-anrop. Applikationer skickar strukturerade anrop till OpenAI och får JSON-svar som innehåller modellens resultat.

### Så fungerar ChatGPT API

Processen består av fyra steg:

**Du skickar ett anrop.** Din applikation skickar ett POST-anrop till OpenAI med en JSON-payload som innehåller ett modellnamn, meddelanden och parametrar som temperatur och tokenbegränsningar.

**OpenAI behandlar anropet.** Modellen genererar ett svar och returnerar det i ett JSON-objekt. När strömning är aktiverad kommer tokenen stegvis.

**Din applikation tar emot svaret.** Svaret innehåller genererat innehåll, tokenanvändning, modellinformation och ett anrops-ID.

**Debitering sker.** Avgifterna beror på antalet behandlade token. In- och utgående token kan ha olika priser.

Promptens längd, modellval och cachelagring påverkar prestanda och kostnad.

## Så konfigurerar du ChatGPT API

Du behöver en API-nyckel för att autentisera anrop. Behandla den som en hemlighet och förvara den säkert.

### Så skaffar du en OpenAI API-nyckel

**Steg 1: Öppna OpenAI Platform**

- Besök [platform.openai.com/api-keys](https://platform.openai.com/api-keys) och logga in eller skapa ett konto.

**Steg 2: Skapa din API-nyckel**

- Öppna **API Keys** i kontrollpanelen.
- Välj **Create new secret key** och ge den eventuellt ett projektspecifikt namn.
- Kopiera nyckeln när den visas; den kanske inte visas igen.

**Steg 3: Förvara den säkert**

- Förvara nyckeln i en lösenordshanterare eller som en miljövariabel.
- Lägg aldrig in API-nycklar i versionshantering och exponera dem inte i kod på klientsidan.
- Om du använder en `.env`-fil ska du lägga till den i `.gitignore` och hålla filen utanför versionshanteringen.

**Säkerhetsanvisningar:**

- En nyckel kan ge åtkomst som är kopplad till ditt konto och din fakturering.
- Om du tappar bort en nyckel ska du skapa en ersättningsnyckel.
- Återkalla nycklar som kan ha röjts.
- Använd separata nycklar med lämpliga behörigheter för olika projekt när det är möjligt.

### 1. Skriv tydliga och specifika prompter

Tydliga, specifika instruktioner kan göra svaren mer användbara.

- Ange önskat format, ton och längd.
- Ge exempel när det är användbart.
- Använd utvecklarinstruktioner för att ange beteende och sammanhang.
- Dela upp komplexa uppgifter i mindre steg.

Exempel:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.
vague = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)
print(vague.choices[0].message.content)

# Specify the audience, deliverable, and focus.
specific = client.chat.completions.create(
    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)
print(specific.choices[0].message.content)
```

### 2. Använd strukturerade utdata för tillförlitliga data

För JSON eller andra strukturerade data använder du API:ts funktioner för strukturerade utdata i stället för att tolka fritext. Kontrollera dokumentationen för vilka format och begränsningar som stöds.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Implementera strömning för en bättre användarupplevelse

Strömning kan visa svarsinnehållet efter hand i stället för att vänta tills hela svaret är klart.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Hantera fel på ett bra sätt

Anrop kan misslyckas på grund av nätverksproblem, hastighetsbegränsningar, ogiltiga indata eller driftavbrott. Hantera fel enligt dokumentationen för SDK:t och API:t.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Använd funktionsanrop för verktygsintegrering

Funktionsanrop gör det möjligt för en modell att be din applikation anropa en funktion eller ett verktyg. Applikationen hanterar anropet och returnerar resultat efter behov.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
