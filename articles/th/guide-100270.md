# 5 โมเดลภาษาขนาดเล็กชั้นนำสำหรับใช้งานจริง (คู่มือเชิงปฏิบัติ)

> คู่มือเชิงปฏิบัติสำหรับโมเดลภาษาขนาดเล็ก 5 รุ่นสำหรับใช้งานจริง พร้อมเกณฑ์การเลือก ข้อแลกเปลี่ยนในการติดตั้งใช้งาน หมายเหตุเกี่ยวกับการปรับแต่ง และข้อพิจารณาด้านการปฏิบัติงาน



ในที่นี้ โมเดลภาษาขนาดเล็กหมายถึงโมเดลที่มีพารามิเตอร์ประมาณ 7 พันล้านตัวหรือน้อยกว่า ซึ่งทีมสามารถรันได้ด้วยต้นทุนที่สมเหตุสมผลผ่านการอนุมานบน GPU หรือบน CPU เมื่อใช้การควอนไทซ์ เป้าหมายคือให้โมเดลทำงานได้อย่างน่าเชื่อถือและคาดการณ์ได้ในการใช้งานจริง ได้แก่ มีเวลาแฝงต่ำ ใช้หน่วยความจำน้อย และทำตามคำสั่งได้อย่างมีประโยชน์ รายชื่อคัดสรรนี้มุ่งเน้นโมเดลที่ติดตั้งใช้งานได้ไม่ยุ่งยาก มีระบบนิเวศที่คึกคักสำหรับการควอนไทซ์ รันไทม์ และการปรับแต่งแบบละเอียด และรองรับการสร้างเนื้อหาเสริมด้วยการดึงข้อมูล ผู้ช่วยแชต และเอเจนต์ขนาดเล็ก

## เกณฑ์การเลือก

- **ประสิทธิภาพการอนุมาน:** การใช้หน่วยความจำและเวลาแฝงสำหรับแบตช์ขนาด 1–8 โทเค็นบน GPU ทั่วไป
- **คุณภาพการทำตามคำสั่ง:** ความสามารถในการทำตามคำสั่งได้ทันที หรือมีน้ำหนักโมเดลที่ปรับแต่งมาเพื่อทำตามคำสั่งให้ใช้งาน
- **ระบบนิเวศสำหรับการติดตั้งใช้งาน:** รองรับ ggml, ONNX, TensorRT หรือไลบรารียอดนิยม เช่น Transformers และ llama.cpp
- **ข้อแลกเปลี่ยนในทางปฏิบัติ:** รูปแบบความล้มเหลว การปรับแต่งด้านความปลอดภัย และค่าบำรุงรักษา เลือกโดยพิจารณาจากเป้าหมายเวลาแฝง ขนาดการใช้งาน และข้อจำกัดด้านลิขสิทธิ์

## 1. Llama 2 7B

Llama 2 7B เป็นจุดเริ่มต้นที่ใช้งานได้จริงสำหรับทีมที่ต้องการโมเดลอเนกประสงค์ซึ่งมีระบบนิเวศรองรับอย่างกว้างขวาง สามารถรันบน GPU สำหรับผู้ใช้ทั่วไปเพียงตัวเดียว และมีรุ่นที่ปรับแต่งมาเพื่อทำตามคำสั่ง รวมถึงรุ่นที่ชุมชนปรับแต่งเพิ่มเติม พร้อมเครื่องมือสำหรับการควอนไทซ์และการอนุมานที่มีเวลาแฝงต่ำ โมเดลมีข้อจำกัดด้านการให้เหตุผลที่ซับซ้อน ดังนั้นการติดตั้งใช้งานจริงควรมีมาตรการป้องกันการหลอนข้อมูล

**สรุป:** โมเดลพื้นฐานอเนกประสงค์สำหรับทีมที่ต้องการรุ่นที่มีระบบรองรับอย่างแพร่หลาย

## 2. Mistral 7B Instruct

Mistral 7B Instruct เป็นตัวเลือกสำหรับงานทำตามคำสั่งที่ให้ความสำคัญกับประสิทธิภาพการอนุมาน ควรพิจารณาว่าโมเดลจัดการกับการให้เหตุผลแบบยาวและหลายขั้นตอนได้อย่างไรในเวิร์กโหลดของคุณเอง เพราะโมเดลที่มีขนาดใหญ่อาจทำงานในลักษณะดังกล่าวได้ดีกว่า

**สรุป:** พิจารณาเมื่อคุณให้ความสำคัญกับคุณภาพการทำตามคำสั่งเมื่อเทียบกับทรัพยากรประมวลผล

## 3. Falcon 7B

Falcon 7B เป็นตัวเลือกสำหรับบริการที่ให้ความสำคัญกับปริมาณงานและความเร็วในการสร้างโทเค็น รูปแบบ prompt อาจส่งผลต่อผลลัพธ์ ดังนั้นเทมเพลต prompt และตัวอย่าง few-shot อาจช่วยเพิ่มความสม่ำเสมอได้

**สรุป:** พิจารณาสำหรับบริการที่ต้องการปริมาณงานสูงและเวลาแฝงที่สม่ำเสมอ

## 4. MPT-7B-Instruct

MPT-7B-Instruct เป็นตัวเลือกสำหรับเวิร์กโฟลว์ที่ต้องใช้บริบทที่ยาวขึ้นหรือการสตรีม สามารถนำไปผสานเข้ากับเวิร์กโฟลว์เอกสารยาวและการจัดการบริบทแบบกำหนดเองได้ ประเมินความสามารถในการทำตามคำสั่งและการทำงานแบบสตรีมเทียบกับข้อกำหนดของคุณเอง

**สรุป:** พิจารณาสำหรับกรณีใช้งานที่เน้นเอกสารและ API สำหรับการสตรีม

## 5. StableLM / StableLM-Tuned-Alpha 7B

StableLM 7B และรุ่นที่ผ่านการปรับแต่งเป็นตัวเลือกสำหรับทีมที่ต้องการใช้ระบบแบบโฮสต์เองแทนเอนด์พอยต์เชิงพาณิชย์ ประเมินประสิทธิภาพในการจัดประเภท การสรุปความ และการเสริมข้อมูลด้วยการดึงข้อมูล รวมถึงพิจารณาว่าจำเป็นต้องปรับแต่งเพิ่มเติมสำหรับกรณีใช้งานของคุณหรือไม่

**สรุป:** พิจารณาเมื่อการควบคุมโมเดลและระบบติดตั้งใช้งานเป็นสิ่งสำคัญ

## ข้อแลกเปลี่ยนในทางปฏิบัติและหมายเหตุเกี่ยวกับการปรับแต่ง

- **การควอนไทซ์และการอนุมาน:** โมเดลเหล่านี้อาจได้ประโยชน์จากการควอนไทซ์แบบ 4-bit หรือ 8-bit สำหรับการติดตั้งใช้งานบน CPU หรือ GPU ที่มีหน่วยความจำน้อย การควอนไทซ์อย่างเข้มข้นอาจทำให้คุณภาพลดลง ควรประเมินด้วยอินพุตที่เป็นตัวแทนของการใช้งานจริง
- **การปรับแต่งเพื่อทำตามคำสั่ง:** รุ่นที่ปรับแต่งมาเพื่อทำตามคำสั่งอาจช่วยลดภาระด้านวิศวกรรม prompt หากใช้โมเดลพื้นฐาน ให้พิจารณาจัดเตรียมชุดข้อมูลขนาดเล็กที่คัดสรรมาอย่างดีสำหรับการปรับแต่งเพื่อทำตามคำสั่ง เพื่อเพิ่มความน่าเชื่อถือก่อนใช้งานจริง
- **ความปลอดภัยและการหลอนข้อมูล:** โมเดลขนาดเล็กอาจให้คำตอบที่ไม่ถูกต้อง สำหรับงานที่ต้องอาศัยข้อเท็จจริง ให้เพิ่มการยึดโยงคำตอบด้วยการดึงข้อมูล กฎการงดตอบ และตัวกรองหลังการสร้างผลลัพธ์
- **เวลาแฝงเทียบกับคุณภาพ:** หากเวลาแฝงต่อโทเค็นต่ำกว่า 50 ms เป็นข้อกำหนดที่ต้องทำให้ได้ ให้เลือกโมเดลที่มีการรองรับรันไทม์และการควอนไทซ์ที่เหมาะสม หากคุณภาพสำคัญกว่าเวลาแฝง ให้พิจารณาโมเดลที่ใหญ่ขึ้นหรือ API ภายนอกสำหรับคำถามที่ท้าทาย
- **ลิขสิทธิ์และการปฏิบัติตามข้อกำหนด:** เงื่อนไขของแต่ละโมเดลแตกต่างกันและอาจเปลี่ยนแปลงได้ ก่อนติดตั้งใช้งาน ให้ตรวจสอบสิทธิ์การใช้เชิงพาณิชย์ ข้อกำหนดเกี่ยวกับการใช้ข้อมูล และข้อควบคุมการส่งออกของโมเดลที่เลือก

## สรุป

โมเดลขนาดเล็กอาจให้ต้นทุนและเวลาแฝงที่น่าสนใจสำหรับงานใช้งานจริง แต่ก็มีข้อจำกัดด้านการให้เหตุผลและความถูกต้องของข้อเท็จจริง Llama 2 7B, Mistral 7B Instruct, Falcon 7B, MPT-7B-Instruct และ StableLM ต่างมีข้อควรพิจารณาในการติดตั้งใช้งานที่แตกต่างกัน ตัวเลือกที่เหมาะสมขึ้นอยู่กับเป้าหมายเวลาแฝง ข้อกำหนดด้านความปลอดภัย เวิร์กโหลด และข้อจำกัดด้านลิขสิทธิ์

## สิ่งที่ควรพิจารณา

- วัดเวลาแฝงต่อโทเค็นและการใช้หน่วยความจำด้วย prompt ที่เป็นตัวแทนของการใช้งานจริงก่อนเลือกโมเดล
- ทดสอบตั้งแต่ต้นจนจบด้วยไปป์ไลน์การดึงข้อมูลและความปลอดภัยของคุณ ไม่ใช่ทดสอบเฉพาะบนเบนช์มาร์กแบบแยกส่วน
- จัดสรรงบประมาณสำหรับวิศวกรรม prompt การตรวจติดตาม และการปรับแต่งเป็นระยะ เพราะค่าใช้จ่ายในการปฏิบัติงานอาจสูงกว่าค่าใช้จ่ายของโมเดล
