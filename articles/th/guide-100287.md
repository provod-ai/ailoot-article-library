# เราเตอร์ LLM คืออะไร?

> เรียนรู้ว่าเราเตอร์ LLM เลือกโมเดลตามต้นทุน เวลาแฝง การรักษาความลับ และคุณภาพอย่างไร รวมถึงความสัมพันธ์ระหว่างการกำหนดเส้นทางกับเกตเวย์และการสลับไปใช้ระบบสำรอง



> **คำจำกัดความ:** เราเตอร์ LLM คือเลเยอร์ควบคุมที่อยู่ระหว่างแอปพลิเคชันของคุณกับโมเดล AI หลายโมเดล โดยส่งคำขอแต่ละรายการไปยังโมเดลที่เหมาะสมที่สุดตามต้นทุน เวลาแฝง คุณภาพ และการรักษาความลับ ช่วยลดค่าใช้จ่าย ลดการพึ่งพาผู้ให้บริการรายเดียว และเพิ่มการสลับระบบเมื่อเกิดข้อขัดข้องโดยอัตโนมัติ

เราเตอร์ LLM (เรียกอีกอย่างว่า *เกตเวย์ AI*, *เราเตอร์โมเดล* หรือ *โบรกเกอร์ LLM*) คือเลเยอร์ที่อยู่ระหว่างแอปพลิเคชันของคุณกับโมเดลจำนวนมาก แทนที่จะเขียนโค้ดเรียก API ของผู้ให้บริการรายเดียว แอปพลิเคชันของคุณจะเรียกเราเตอร์ ซึ่งจะเลือกโมเดลที่ดีที่สุดสำหรับแต่ละคำขอและนำเสนออินเทอร์เฟซแบบรวมศูนย์เพียงชุดเดียว

- วิเคราะห์คำขอแต่ละรายการ (ประเภทงาน ความซับซ้อน ความอ่อนไหว)
- เลือกโมเดลที่เหมาะสมที่สุด (โมเดลราคาประหยัดสำหรับงานง่าย โมเดลแนวหน้าสำหรับงานยาก)
- จัดการการกระจายโหลดและการสลับระบบเมื่อเกิดข้อขัดข้องระหว่างผู้ให้บริการ
- การเลือกเส้นทางช่วยลดต้นทุนได้เมื่อโมเดลที่เลือกตรงตามเกณฑ์คุณภาพของคุณ

## เราเตอร์ LLM กับเกตเวย์ AI: ต่างกันอย่างไร?

ทั้งสองมีความสามารถทับซ้อนกัน **เราเตอร์** เน้นการเลือกโมเดลสำหรับแต่ละคำขอ ส่วน **เกตเวย์ AI** เพิ่มการยืนยันตัวตน การกำกับดูแล และการตรวจสอบ **โบรกเกอร์** เน้นการเป็นตัวกลางที่ไม่ขึ้นกับผู้ให้บริการรายใดรายหนึ่งระหว่างผู้ให้บริการหลายราย โซลูชันที่แข็งแกร่งทำได้ครบทั้งสามอย่าง

## การกำหนดเส้นทาง LLM ทำงานอย่างไร?

เราเตอร์ให้คะแนนคำขอแต่ละรายการตามเกณฑ์สี่ข้อ:

- **ต้นทุน** — ส่งงานง่ายไปยังโมเดลราคาประหยัด และใช้โมเดลราคาแพงเมื่อจำเป็นเท่านั้น
- **เวลาแฝง** — ส่งคำขอที่ต้องคำนึงถึงเวลาไปยังโมเดลขนาดเล็กที่รวดเร็ว
- **การรักษาความลับ / ระดับการคุ้มครอง** — ส่งคำขอที่มีข้อมูลละเอียดอ่อนไปยังบริการและสถานที่ที่ได้รับอนุมัติเท่านั้น
- **คุณภาพ** — ส่งงานที่ซับซ้อนไปยังโมเดลแนวหน้า

การกำหนดเส้นทางอาจเป็นแบบ **คงที่** (กฎ), **ไดนามิก** (การให้คะแนน/อิงโมเดล), **ไฮบริด** หรือ **เรียนรู้จากข้อมูล (RL)**

## การกำหนดเส้นทาง LLM ช่วยประหยัดได้เท่าไร? (หลักฐาน)

- **RouteLLM** (UC Berkeley/LMSYS, arXiv 2406.18665): ผู้เขียนรายงานว่าในการทดสอบ MT Bench ต้นทุนต่ำลงประมาณ 85% และได้คะแนนประมาณ 95% ของ GPT-4 เมื่อเทียบกับการใช้ GPT-4 สำหรับทุกคำขอ \[R1\]
- **AWS Bedrock Intelligent Prompt Routing:** AWS ประเมินว่าการส่งคำขอไปยังโมเดลต่าง ๆ ภายในตระกูลเดียวกันอาจลดต้นทุนได้สูงสุด 30% [\[R2\]](https://aws.amazon.com/bedrock/intelligent-prompt-routing/)
- **ส่วนต่างของต้นทุน:** ราคาแตกต่างกันตามโมเดลและผู้ให้บริการ เมื่อเลือกโมเดล ให้เปรียบเทียบอัตราค่าบริการปัจจุบันของโทเคนขาเข้าและขาออก


## การกำหนดเส้นทางที่ไม่ขึ้นกับผู้ให้บริการ: วิธีเลิกผูกติดกับผู้ให้บริการรายเดียว

เราเตอร์ของผู้ให้บริการจะผูกคุณไว้กับผู้ให้บริการในอีกระดับหนึ่ง โบรกเกอร์ที่ **ไม่ขึ้นกับผู้ให้บริการ** จะครอบคลุมผู้ให้บริการหลายราย (OpenAI, Anthropic, Google, Mistral, โมเดลแบบเปิดที่เปิดเผยน้ำหนัก) ทำให้เปลี่ยนโมเดลได้ด้วยการปรับการตั้งค่า ไม่ใช่แก้โค้ด นี่คือวิธีแก้ปัญหาการผูกติดกับผู้ให้บริการ AI โดยตรง

## การกำหนดเส้นทาง LLM ที่อยู่ภายใต้อธิปไตยของ EU และติดตั้งภายในองค์กร

เราเตอร์สามารถจำกัดคำขอที่มีข้อมูลละเอียดอ่อนให้ประมวลผลเฉพาะบนโมเดลที่ได้รับอนุมัติและโฮสต์ในสหภาพยุโรปหรือบนโครงสร้างพื้นฐานขององค์กรเอง และส่งคำขอที่ใช้ข้อมูลสาธารณะไปยังโมเดลคลาวด์ต้นทุนต่ำกว่าเมื่อได้รับอนุญาต ตรวจสอบวิธีที่แต่ละบริการประมวลผลและจัดเก็บข้อมูลให้สอดคล้องกับข้อกำหนดที่เกี่ยวข้อง

## สร้างหรือซื้อ

ต้นทุนรวมในการเป็นเจ้าของ — และข้อกำหนดว่าต้องมีระดับการคุ้มครองและอธิปไตยของ EU ในตัวหรือไม่ — เป็นตัวตัดสิน

## คำถามที่พบบ่อย

**เราเตอร์ LLM คืออะไร?**

เราเตอร์ LLM คือเลเยอร์ซอฟต์แวร์ระหว่างแอปพลิเคชันของคุณกับโมเดล AI หลายโมเดล ซึ่งกำหนดเส้นทางคำขอแต่ละรายการไปยังโมเดลที่เหมาะสมที่สุดตามต้นทุน เวลาแฝง คุณภาพ และการรักษาความลับ พร้อมให้บริการ API แบบรวมศูนย์เพียงชุดเดียว

**การกำหนดเส้นทาง LLM ทำงานอย่างไร?**

เราเตอร์ให้คะแนนคำขอแต่ละรายการและเลือกโมเดลโดยใช้กฎแบบคงที่ การให้คะแนนแบบไดนามิก หรือนโยบายที่เรียนรู้จากข้อมูล โดยส่งงานง่ายไปยังโมเดลราคาประหยัด และส่งงานยากไปยังโมเดลแนวหน้า

**เราเตอร์ LLM เหมือนกับเกตเวย์ AI หรือไม่?**

ไม่ทั้งหมด เราเตอร์เน้นการเลือกโมเดลสำหรับแต่ละคำขอ ส่วนเกตเวย์เพิ่มการยืนยันตัวตน การกำกับดูแล และการตรวจสอบ แพลตฟอร์มที่แข็งแกร่งจะรวมทั้งสองอย่างเข้าด้วยกัน พร้อมกับการเป็นตัวกลางที่ไม่ขึ้นกับผู้ให้บริการ

**เราเตอร์ LLM ช่วยประหยัดได้เท่าไร?**

ผู้เขียน RouteLLM รายงานว่าในการทดสอบ MT Bench ต้นทุนต่ำลงประมาณ 85% และได้คะแนนประมาณ 95% ของ GPT-4 เมื่อเทียบกับการใช้ GPT-4 สำหรับทุกคำขอ AWS ประเมินว่าการส่งคำขอไปยังโมเดลต่าง ๆ ภายในตระกูลเดียวกันอาจลดต้นทุนได้สูงสุด 30% ผลประหยัดจริงขึ้นอยู่กับลักษณะงาน

**การกำหนดเส้นทางทำให้คุณภาพคำตอบลดลงหรือไม่?**

คุณภาพขึ้นอยู่กับงาน โมเดล และกฎการเลือกเส้นทาง ทดสอบกฎเหล่านี้กับคำขอที่เป็นตัวแทนของงานจริง

**ฉันสามารถเรียกใช้เราเตอร์ LLM ภายในองค์กร / ใน EU ได้หรือไม่?**

ทำได้ หากเราเตอร์และโมเดลรองรับรูปแบบการติดตั้งนั้น ระบุว่าบริการใดจัดการคำขอที่มีข้อมูลละเอียดอ่อนได้ และตรวจสอบข้อกำหนดการประมวลผลข้อมูลที่เกี่ยวข้อง
