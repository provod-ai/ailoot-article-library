# ราคา OpenAI Moderation API: ฟรี ขีดจำกัดอัตรา และทางเลือกอื่น

> โมเดล moderation ของ OpenAI ใช้งานได้ฟรี ดูราคา ขีดจำกัดอัตราตามระดับการใช้งาน ตัวอย่าง Python และกรณีที่ทางเลือกที่เข้ากันได้กับ OpenAI อาจเหมาะกว่า




OpenAI Moderation endpoint ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API ก่อนเลือกเวิร์กโฟลว์สำหรับ production ให้ตรวจสอบประเภทอินพุตและหมวดหมู่ที่รองรับ ขีดจำกัดอัตราของบัญชี และวิธีนำ endpoint นี้ไปใช้ในขั้นตอนการตรวจสอบของคุณ

คู่มือนี้แยกคำตอบอย่างเป็นทางการเรื่องราคาออกจากการตัดสินใจด้านวิศวกรรมในทางปฏิบัติ

## สรุปสั้น ๆ

- **OpenAI Moderation endpoint ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API** ตามข้อมูลจากศูนย์ช่วยเหลือ OpenAI
- โมเดล `omni-moderation-latest` ของ OpenAI ออกแบบมาเพื่อตรวจจับเนื้อหาที่เป็นอันตราย และรับข้อความกับรูปภาพเป็นอินพุต ตามหน้าโมเดลอย่างเป็นทางการของ OpenAI
- การใช้งานฟรีไม่ได้ขจัดต้นทุนเวิร์กโฟลว์ เช่น การบันทึกข้อมูล คิวตรวจสอบ การแมปนโยบาย การลองใหม่ พฤติกรรมสำรองเมื่อเกิดข้อผิดพลาด และการตัดสินใจเฉพาะแอปพลิเคชัน
- เลือก endpoint ฟรีของ OpenAI หากคุณใช้งาน OpenAI โดยตรงอยู่แล้ว และเวิร์กโฟลว์ moderation ของคุณเหมาะกับหมวดหมู่และรูปแบบการตอบกลับของ endpoint นี้
- หากคุณใช้งาน EvoLink อยู่แล้วและต้องการตรวจสอบอินพุตหลายรูปแบบ รับสรุปความเสี่ยง และจ่ายตามจำนวนครั้งที่เรียก API ในเวิร์กโฟลว์เดียวกัน ให้พิจารณา EvoLink Moderation 1.0

## OpenAI Moderation API ใช้งานฟรีหรือไม่?

ใช่ ศูนย์ช่วยเหลืออย่างเป็นทางการของ OpenAI ระบุว่า Moderation endpoint ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API และการใช้งานเครื่องมือนี้ไม่นับรวมในขีดจำกัดการใช้งานรายเดือน

แหล่งข้อมูล: [ศูนย์ช่วยเหลือ OpenAI: Moderation endpoint ใช้งานฟรีหรือไม่?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

นั่นคือคำตอบเรื่องราคา คำถามถัดไปเป็นเรื่องการปฏิบัติงาน:

**Moderation endpoint ฟรีเพียงพอสำหรับเวิร์กโฟลว์ production ของคุณหรือไม่?**

สำหรับต้นแบบ เครื่องมือภายใน และ moderation แบบง่ายที่เน้นข้อความเป็นหลัก ก็อาจเพียงพอ แต่สำหรับแอปพลิเคชันที่จัดการเนื้อหาที่ผู้ใช้สร้าง การอัปโหลดรูปภาพ AI agent หรือคิวตรวจสอบ การเรียก API เป็นเพียงส่วนหนึ่งของระบบเท่านั้น

## OpenAI moderation ครอบคลุมอะไรบ้าง?

OpenAI ระบุว่า `omni-moderation-latest` เป็นโมเดล moderation ที่ออกแบบมาเพื่อระบุเนื้อหาที่อาจเป็นอันตรายในข้อความและรูปภาพ หน้าโมเดลอย่างเป็นทางการอธิบายว่าเป็นโมเดล moderation ที่มีความสามารถสูงที่สุดของ OpenAI และระบุว่ารองรับอินพุต/เอาต์พุตข้อความและอินพุตรูปภาพ แหล่งข้อมูล: [หน้าโมเดล OpenAI สำหรับ omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) คู่มือ moderation ของ OpenAI ยังอธิบายหมวดหมู่การจัดประเภทเนื้อหา และระบุว่าบางหมวดหมู่รองรับเฉพาะข้อความ หากคุณส่งเฉพาะรูปภาพไปยัง `omni-moderation-latest` หมวดหมู่ที่ไม่รองรับอินพุตรูปภาพจะส่งคะแนน 0 กลับมา แหล่งข้อมูล: [คู่มือ Moderation ของ OpenAI](https://developers.openai.com/api/docs/guides/moderation)

นั่นหมายความว่าทีมควรอ่านตารางหมวดหมู่อย่างละเอียดก่อนจะสรุปว่าหมวดหมู่ข้อความทุกหมวดจับคู่กับ moderation ของรูปภาพได้โดยตรง

## ต้นทุนที่แท้จริงอยู่ที่เวิร์กโฟลว์ ไม่ใช่แค่ราคา API

Moderation endpoint อาจใช้งานได้ฟรี แต่ระบบ moderation สำหรับ production ยังต้องมีการตัดสินใจเกี่ยวกับเรื่องต่อไปนี้:

- จะตรวจสอบที่ใด: ก่อนเรียกโมเดล หลังได้รับคำตอบจากโมเดล หรือทั้งสองจุด
- จะแมปหมวดหมู่ให้เป็นการอนุญาต ตรวจสอบ หรือบล็อกอย่างไร
- จะบันทึกผล moderation อย่างไรโดยไม่จัดเก็บเนื้อหาที่ละเอียดอ่อนเกินความจำเป็น
- จะจัดการผลบวกลวงและการอุทธรณ์อย่างไร
- จะแยก moderation การอัปโหลดรูปภาพออกจากอินพุตข้อความอย่างไร
- จะตรวจสอบ latency ข้อผิดพลาด และขีดจำกัดอัตราอย่างไร
- จะทำให้การใช้นโยบายสอดคล้องกันในส่วนต่าง ๆ ของผลิตภัณฑ์อย่างไร

สิ่งเหล่านี้เป็นต้นทุนด้านวิศวกรรมและการปฏิบัติงาน ซึ่งไม่ปรากฏในหน้าราคา แต่เป็นตัวกำหนดว่าชั้น moderation จะดูแลรักษาได้จริงหรือไม่

ในเวิร์กโฟลว์ทั่วไป ให้ตรวจสอบพรอมต์ก่อนส่งให้โมเดลและตรวจสอบเอาต์พุตก่อนส่งให้ผู้ใช้ ส่งผลที่ยังตัดสินไม่ได้ไปตรวจสอบเพิ่มเติม บันทึกการตัดสินใจเท่าที่จำเป็น และวางแผนรับมือการลองใหม่และการอุทธรณ์

## กรณีที่ endpoint ฟรีของ OpenAI เหมาะสม

OpenAI Moderation endpoint ฟรีมักเป็นตัวเลือกแรกที่ดีเมื่อ:

- คุณใช้งาน OpenAI โดยตรงอยู่แล้ว
- แอปของคุณเน้นข้อความเป็นหลัก
- คุณต้องการเพียงหมวดหมู่ moderation ที่ OpenAI ระบุไว้ในเอกสาร
- คุณสร้างเวิร์กโฟลว์ตรวจสอบและยกระดับปัญหาเองได้
- ทีมของคุณพร้อมดูแลการแยกวิเคราะห์คำตอบ เกณฑ์ และบันทึกข้อมูล

ในกรณีนั้น ยากที่จะโต้แย้งกับการเลือก endpoint ฟรี เริ่มจากตรงนั้น ทดสอบกับเนื้อหาจริงของคุณ และวัดผลบวกลวงกับกรณีที่ตรวจไม่พบก่อนกำหนดเส้นทางทราฟฟิก production

## กรณีที่ทางเลือกอื่นซึ่งเข้ากันได้กับ OpenAI เหมาะสม

EvoLink Moderation 1.0 เป็นทางเลือกแบบเสียค่าใช้จ่ายที่มีเส้นทาง `/v1/moderations` ซึ่งเข้ากันได้กับ OpenAI โดย EvoLink รับรูปภาพได้สูงสุดหนึ่งรูปต่อคำขอ

- ตรวจสอบข้อความอย่างเดียว รูปภาพอย่างเดียว และข้อความพร้อมรูปภาพผ่าน endpoint เดียว
- หมวดหมู่อันตราย 13 หมวด พร้อมคะแนนแยกตามหมวดหมู่
- ออบเจ็กต์ `evolink_summary` ที่มีฟิลด์ `risk_level`, `flagged`, `violations`, `max_score` และ `max_category`
- คิดราคาแบบคงที่ต่อการเรียก แทนการคำนวณตามจำนวน token
- รูปแบบคำตอบที่แมปเข้ากับตรรกะอนุญาต ตรวจสอบ หรือบล็อกได้ง่ายกว่า

## วิธีใช้ OpenAI Moderation API ใน Python

หากคุณใช้ OpenAI SDK อยู่แล้ว การเรียก moderation ข้อความแบบพื้นฐานจะมีลักษณะดังนี้:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

สำหรับ EvoLink ให้ตั้ง `EVOLINK_API_KEY` เป็นคีย์ EvoLink ของคุณ และตั้ง `EVOLINK_BASE_URL` เป็น URL พื้นฐานของ API แบบ HTTPS ที่ลงท้ายด้วย `/v1` ตามการตั้งค่า EvoLink API การตอบกลับจะมีออบเจ็กต์ `evolink_summary` เพิ่มเติม

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## เปรียบเทียบราคาและเวิร์กโฟลว์ของ OpenAI กับ EvoLink

| เกณฑ์ | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| การคิดค่าบริการ | ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API | คิดค่าบริการในอัตราคงที่ต่อการเรียก API |
| รูปแบบ endpoint หลัก | `/v1/moderations` | `/v1/moderations` ที่เข้ากันได้กับ OpenAI |
| การ moderation ข้อความ | รองรับ | รองรับ |
| การ moderation รูปภาพ | รองรับโดย `omni-moderation-latest` โดยการรองรับอินพุตขึ้นอยู่กับหมวดหมู่ | รองรับคำขอที่มีเฉพาะรูปภาพและคำขอที่มีทั้งข้อความและรูปภาพ |
| ฟิลด์สำหรับตัดสินใจตามนโยบาย | ตีความค่า `flagged`, `categories` และ `category_scores` ใน `results` | ใช้ `evolink_summary.risk_level` และ `violations` ประกอบกับคะแนนของแต่ละหมวดหมู่ |
| ทีมที่เหมาะกับบริการ | ทีมที่เรียกใช้ OpenAI โดยตรงอยู่แล้ว | ทีมที่ผสาน moderation เข้ากับเวิร์กโฟลว์ EvoLink ที่ใช้อยู่ |

## คำแนะนำในทางปฏิบัติ

ใช้ OpenAI Moderation endpoint ฟรีหากแอปพลิเคชันของคุณใช้ OpenAI อยู่แล้ว และนโยบาย moderation ของคุณสอดคล้องกับหมวดหมู่ที่ระบุไว้ในเอกสาร

หากทีมของคุณใช้งาน EvoLink อยู่แล้ว ให้ประเมินค่าใช้จ่ายต่อการเรียก API และใช้ `evolink_summary.risk_level` เป็นข้อมูลประกอบข้อหนึ่งสำหรับกฎของแอปพลิเคชันที่ตัดสินว่าจะอนุญาต ส่งตรวจสอบ หรือบล็อก

ใช้ระบบ moderation หลายชั้นหากแอปพลิเคชันของคุณมีข้อกำหนดด้านนโยบายเฉพาะที่ต้องใช้กฎของแบรนด์ การตรวจสอบโดยมนุษย์ การอุทธรณ์ หรือเวิร์กโฟลว์ด้านการปฏิบัติตามข้อกำหนด ซึ่งเกินขอบเขตของ moderation API ใด API หนึ่ง

## คำถามที่พบบ่อย

### OpenAI Moderation API ใช้งานฟรีหรือไม่?

ใช่ ศูนย์ช่วยเหลือของ OpenAI ระบุว่า Moderation endpoint ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API และไม่นับรวมในขีดจำกัดการใช้งานรายเดือน

### OpenAI moderation รองรับรูปภาพหรือไม่?

รองรับ โดย `omni-moderation-latest` รับรูปภาพเป็นอินพุตตามหน้าโมเดลอย่างเป็นทางการของ OpenAI อย่างไรก็ตาม คู่มือ moderation ของ OpenAI ระบุว่าบางหมวดหมู่รองรับเฉพาะข้อความ ดังนั้นทีมควรตรวจสอบการรองรับอินพุตในระดับหมวดหมู่ก่อนพึ่งพา moderation ที่ใช้เฉพาะรูปภาพ

### EvoLink Moderation มีค่าใช้จ่ายต่ำกว่า OpenAI Moderation หรือไม่?

OpenAI Moderation endpoint ใช้งานได้ฟรีสำหรับผู้ใช้ OpenAI API ส่วน EvoLink คิดค่าบริการในอัตราคงที่ต่อการเรียก API ให้เปรียบเทียบต้นทุนของทั้งเวิร์กโฟลว์ รวมถึงการตรวจสอบและการบำรุงรักษา

### ฉันใช้ EvoLink แทน OpenAI Moderation API ได้หรือไม่?

ได้ ใช้คีย์ API ของ EvoLink และโมเดล `evolink-moderation-1.0` ผ่านเส้นทาง `/v1/moderations` ของ EvoLink ที่เข้ากันได้กับ OpenAI ปรับการจัดการคำตอบให้รองรับออบเจ็กต์ `evolink_summary` เพิ่มเติมในคำตอบของ EvoLink

### ฉันควรทำ moderation กับ prompt, output หรือทั้งสองอย่าง?

สำหรับแอปพลิเคชัน AI ใน production หลายทีมทำ moderation ทั้งอินพุตและเอาต์พุต การทำ moderation อินพุตช่วยลดคำขอที่ไม่ปลอดภัยก่อนส่งถึงโมเดล ส่วนการทำ moderation เอาต์พุตช่วยตรวจจับคำตอบที่สร้างขึ้นและไม่ปลอดภัยก่อนส่งถึงผู้ใช้

### omni-moderation-latest คืออะไร?

เป็นโมเดล moderation ของ OpenAI สำหรับข้อความและรูปภาพ อ่านค่า `flagged`, `categories` และ `category_scores` ใน `results` แล้วใช้นโยบาย moderation ของคุณเอง

### ขีดจำกัดอัตราของ OpenAI Moderation API คือเท่าใด?

การใช้งานฟรีหมายถึงไม่มีค่าบริการ ขีดจำกัดจำนวนคำขอและโทเค็นยังคงมีผล ใน[เอกสารอ้างอิงของโมเดล](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM คือจำนวนคำขอต่อนาที RPD (หากระบุไว้) คือจำนวนคำขอต่อวัน และ TPM คือจำนวนโทเค็นต่อนาที

ขีดจำกัดอัตราของ OpenAI Moderation API แตกต่างกันตามระดับบัญชีและอาจเปลี่ยนแปลงได้ตามเวลา ตรวจสอบ[เอกสารขีดจำกัดอัตราของ OpenAI](https://platform.openai.com/docs/guides/rate-limits) และ[หน้าขีดจำกัดการใช้งาน](https://platform.openai.com/settings/organization/limits) ของบัญชีคุณก่อนวางแผน throughput สำหรับ production

### ฉันจะใช้ OpenAI Moderation API ใน Python ได้อย่างไร?

ติดตั้งแพ็กเกจ `openai` ตั้งค่า `OPENAI_API_KEY` แล้วเรียก `client.moderations.create()` โดยระบุโมเดล `omni-moderation-latest` พร้อมข้อความที่ต้องการตรวจสอบ สำหรับรูปภาพ ให้ส่งอาร์เรย์ของออบเจ็กต์ใน `input` แต่ละรายการที่เป็นรูปภาพต้องมี `type: "image_url"` และออบเจ็กต์ `image_url` ที่มี `url` ตามตัวอย่างในเอกสารอ้างอิง OpenAI API ที่ลิงก์ไว้ด้านล่าง
