## Was die einzelnen Tools eigentlich sind

### Zapier

Ein Zap beginnt mit einem Trigger und führt eine oder mehrere Aktionen aus. Eine erfolgreich ausgeführte abrechenbare Standardaktion verbraucht eine Aufgabe aus dem Tarifkontingent. Ein Trigger kann einen Zap starten, ohne eine Aufgabe zu verbrauchen.

### n8n

n8n wurde 2019 in Berlin gestartet. Es ist eine quelloffene, knotenbasierte Workflow-Engine. Sie können die verwaltete Cloud-Version nutzen oder die Community Edition auf Ihrer eigenen Infrastruktur selbst hosten. Die Oberfläche ist eine visuelle Arbeitsfläche, auf der Sie Nodes verbinden, die jeweils eine Operation ausführen – Daten abrufen, umwandeln, verzweigen, eine API aufrufen oder in eine Datenbank schreiben.

Der strukturelle Unterschied: n8n legt das zugrunde liegende Datenmodell offen. Jeder Node empfängt und gibt Arrays von Elementen aus. Sie können JavaScript oder Python direkt einfügen. Sie können Workflow-JSON in Git ablegen. Sie können den Workflow auf einer Infrastruktur ausführen, die Sie selbst verwalten. Das Tool richtet sich an technische Betreiber, nicht an technisch unerfahrene Einsteiger – auch wenn der visuelle Builder den Einstieg erleichtert.

## Preise: Hier ist der Unterschied am größten

**Zapier rechnet nach Aufgaben ab.** In einem Classic Zap zählt eine erfolgreich ausgeführte abrechenbare Standardaktion als eine Aufgabe. Trigger, Filter, Paths und der Schritt Looping verbrauchen keine Aufgaben. Abrechenbare Aktionen innerhalb einer Schleife zählen bei jeder erfolgreichen Ausführung. Für AI by Zapier und Code-Schritte mit verlängerter Laufzeit gelten eigene Abrechnungssätze. Ob nach Verbrauch des Kontingents Zusatzkosten anfallen oder Läufe zurückgehalten werden, hängt vom Tarif und seinen Abrechnungseinstellungen ab.

**n8n rechnet in kostenpflichtigen Tarifen nach Workflow-Ausführungen ab.** Zählen Sie die Ausführungen des gesamten Workflows. Ein zusätzlicher Node in einem bestehenden Lauf verursacht für sich genommen keine weitere Ausführung. Prüfen Sie die Tarifregeln für Wiederholungsversuche, Fehler und Unter-Workflows.

Nutzen Sie den tatsächlichen Aufgabenverbrauch bei Zapier und die Zahl der Ausführungen bei n8n aus einem repräsentativen Lauf. Berücksichtigen Sie beim Vergleich mit Selbsthosting neben möglichen Abo- oder Lizenzgebühren auch Infrastruktur und Wartung.

## Integrationen

Wenn Sie auf eine spezialisierte SaaS-App angewiesen sind, prüfen Sie, ob das Zapier-Verzeichnis genau den benötigten Trigger und die passende Aktion enthält. Beginnen Sie bei n8n mit den integrierten oder von der Community bereitgestellten Nodes. Mit HTTP Request können Sie auch direkt eine API aufrufen. Prüfen Sie, ob die API den benötigten Vorgang unterstützt und von Ihrer Installation aus erreichbar ist.

## Benutzerdefinierter Code

Hier wird der Unterschied deutlich.

**Zapier** führt JavaScript oder Python in Code by Zapier aus. Kostenpflichtige Code-Aktionen unterstützen kompatible öffentliche Pakete aus npm oder PyPI. Die Laufzeitlimits richten sich nach dem Tarif. Bei verlängerter Laufzeit werden Aufgaben nach einem anderen Satz berechnet.

**n8n** unterstützt JavaScript und Python im Code-Node. In n8n Cloud lassen sich keine Python-Bibliotheken importieren, auch keine Module aus der Standardbibliothek. Beim Selbsthosting geben Sie die Bibliotheken im Task Runner frei und installieren dort auch die zusätzlich benötigten Abhängigkeiten. Beim Selbsthosting können Sie außerdem eigene Nodes bereitstellen.

Testen Sie die tatsächlich benötigten Bibliotheken und Endpunkte, bevor Sie entscheiden, ob ein gehosteter Code-Schritt ausreicht.

## Verzweigungen, Logik und komplexe Workflows

Beide Tools kommen mit linearen Abläufen gut zurecht. Sobald die Logik komplex wird, zeigen sich schnell die Unterschiede.

**Zapier Paths** unterstützt in einem Classic Zap bis zu 10 Zweige pro Gruppe und bis zu drei Ebenen von Pfadgruppen. Die Zweige, deren Bedingungen erfüllt sind, werden der Reihe nach ausgeführt. Um Aktionen in mehreren Zweigen zu verwenden, nutzen Sie einen Sub-Zap oder wiederholen die Schritte in jedem Zweig. Looping ist ein eigener Schritt.

**n8n** verwendet IF und Switch zum Weiterleiten von Elementen, Merge zum Zusammenführen von Datenströmen, Loop Over Items zur stapelweisen Verarbeitung und Execute Sub-workflow zur Wiederverwendung eines Workflows. Bilden Sie einen echten Fall mit Verzweigung und Zusammenführung nach, bevor Sie entscheiden, welche Lösung leichter zu warten ist.

## Fehlerbehandlung

**Zapier** erlaubt in kostenpflichtigen Classic Zaps eine benutzerdefinierte Fehlerbehandlung für unterstützte Schritte. Wenn Sie einen Zap mit einer solchen Fehlerbehandlung veröffentlichen, deaktiviert Zapier Autoreplay für genau diesen Zap. Der vollständige Lauf lässt sich weiterhin manuell wiederholen.

**n8n** bietet in den Einstellungen unter On Error die Wahl, den Lauf fortzusetzen oder Elemente an einen Fehlerausgang zu senden. Ein separater Fehler-Workflow kann Error Trigger nutzen, um auf fehlgeschlagene Produktionsläufe zu reagieren und zum Beispiel ein Team zu benachrichtigen. Welche Details bei der Fehlersuche verfügbar sind, hängt von den Einstellungen für Ausführungsprotokollierung und Aufbewahrung ab.

## Skalierbarkeit und Zuverlässigkeit

**Zapier** verwaltet die Infrastruktur. Wählen Sie ein Aufgabenkontingent, das die erwarteten Aktionen abdeckt, und prüfen Sie die Limits für Ihre Trigger und Apps zu Spitzenzeiten.

**n8n Cloud** hat tarifabhängige Limits für Ausführungen und Parallelität. Berücksichtigen Sie bei selbst gehostetem n8n die maximale Zahl gleichzeitiger Ausführungen, die Infrastruktur und die laufende Wartung. Die Zahl abrechenbarer Aktionen pro Ereignis und die Betriebskosten der Infrastruktur können beeinflussen, welche Option günstiger ist.

## KI-Funktionen

Beide Plattformen können Modellaufrufe in eine Automatisierung integrieren. Vergleichen Sie, welche Daten und Werkzeuge Ihr Workflow benötigt.

**Zapier** bietet AI by Zapier in kostenpflichtigen Tarifen. Die Funktion unterstützt mehrere Modellanbieter und kann App-Aktionen und Wissensquellen als Werkzeuge verwenden. Zapier MCP stellt unterstützte App-Aktionen einem externen MCP-Client zur Verfügung.

**n8n** bietet Modell-Nodes und LangChain-Komponenten für Embeddings, Speicher und Vektorspeicher wie Qdrant. Der Node AI Agent kann einen Workflow als Werkzeug aufrufen. Prüfen Sie, welche Modellendpunkte Ihre gewählte Installation erreichen kann.

Testen Sie bei Agenten oder Retrieval-Augmented Generation die Berechtigungen, den Weg Ihrer Daten und die Möglichkeiten zur Untersuchung von Fehlern.

## Versionskontrolle und Team-Workflows

**Zapier** bietet in kostenpflichtigen Classic-Tarifen einen Versionsverlauf in der App und die Möglichkeit, aus einer älteren Version einen Entwurf zu erstellen. Die Aufbewahrungsdauer richtet sich nach dem Tarif.

**n8n**-Workflows lassen sich als JSON exportieren und manuell in Git verwalten. Native Git-basierte Quellcodeverwaltung und Umgebungen sind in Business und Enterprise verfügbar. Business läuft auf Ihrer eigenen Infrastruktur. Wenn Sie n8n Cloud nutzen und diese Funktionen benötigen, prüfen Sie Enterprise.

Für Einzelpersonen spielt das keine Rolle. Für Teams, die Workflows entwickeln, sind Versionskontrolle und die Übernahme in andere Umgebungen wichtig.

## Lernkurve

**Zapier** ist für technisch unerfahrene Nutzer konzipiert und bietet einen schrittweisen Builder.

**n8n** hat eine steilere Lernkurve. Wenn Sie bereits Zapier oder Make verwendet haben, werden Sie innerhalb eines Tages produktiv sein. Wenn Sie noch nie eine Workflow-Automatisierung erstellt haben, sollten Sie eine Woche praktischer Arbeit einplanen, bis das Datenmodell klar wird. Die Ausdruckssprache und das Datenmodell pro Element sind die beiden Konzepte, deren Verinnerlichung am längsten dauert.

## Wann Zapier am besten passt

Wählen Sie Zapier, wenn Ihre Apps bereits die benötigten Trigger und Aktionen bieten, Ihr Team den Zap im Editor selbst betreuen kann und ein verwalteter Dienst Ihre Anforderungen erfüllt. So können Sie etwa bei jeder neuen Formularantwort eine Slack-Benachrichtigung senden.

## Wann n8n am besten passt

Wählen Sie n8n, wenn ein Workflow Daten aus mehreren Zweigen wieder zusammenführen, andere Workflows wiederverwenden oder von einer selbst gehosteten Instanz auf Dienste in Ihrem eigenen Netz zugreifen muss. Sie können etwa eine Bestellung um mehrere interne Datensätze ergänzen und nur Ausnahmefälle zur Prüfung weiterleiten.

## Wann Sie von Zapier zu n8n wechseln sollten

Klare Anzeichen dafür, dass Sie bereit sind:

- Sie stoßen an Aufgabenlimits, und ein Upgrade fühlt sich wie eine zusätzliche Steuer an
- Sie haben Workflows nach dem Muster „wenn A und B, dann C; andernfalls, wenn D, dann E oder F“ – sie lassen sich nicht sauber in Zapier Paths abbilden
- Sie müssen Daten verarbeiten, die Ihr Rechtsteam nicht an einen SaaS-Drittanbieter senden möchte
- Sie entwickeln KI-Funktionen, die über ein einfaches ChatGPT in einem Zap hinausgehen
- Sie verfügen über genügend Engineering-Kapazität, um selbst gehostete Infrastruktur zu warten (oder wechseln zu n8n Cloud)

## So treffen Sie Ihre Entscheidung

Ein einfacher Entscheidungsbaum:

1. **Ist das die erste Automatisierung Ihres Teams?** Beginnen Sie mit Zapier, wenn die benötigten App-Aktionen bereits vorhanden sind und das Team einen verwalteten Editor möchte.
2. **Ist das Volumen niedrig?** Bei 60 Läufen pro Monat mit je einer abrechenbaren Standardaktion verbraucht Zapier 60 Aufgaben. Ein Zap mit zwei Schritten bleibt bei diesem Volumen innerhalb des Free-Kontingents.
3. **Ist das Volumen hoch und löst jedes Ereignis mehrere Aktionen aus?** Bei 4.000 Läufen pro Monat mit je fünf solchen Aktionen stehen 20.000 Aufgaben bei Zapier 4.000 Ausführungen bei n8n gegenüber. Prüfen Sie die Spitzenlast und die Betriebskosten einer eigenen Instanz, bevor Sie sich zwischen Cloud und Selbsthosting entscheiden.
4. **Liegt Ihr Volumen dazwischen?** Planen Sie bei 600 Läufen pro Monat mit je drei solchen Aktionen 1.800 Zapier-Aufgaben oder 600 n8n-Ausführungen ein. Vergleichen Sie die Preise der Tarifstufen, die dieses Volumen abdecken, in derselben Währung. Rechnen Sie beim Selbsthosting Wartung und Backups ein.
