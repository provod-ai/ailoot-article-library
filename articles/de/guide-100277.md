> Ein praktischer Leitfaden zur Einrichtung der ChatGPT-API, zum Vergleich von Modellen und Preisen sowie zur Entwicklung von Anwendungen mit Codebeispielen.



Die ChatGPT-API ermöglicht Entwicklern den programmgesteuerten Zugriff auf OpenAI-Modelle. Dieser Leitfaden behandelt die Einrichtung eines API-Schlüssels, die Modellauswahl, Preise, Codebeispiele sowie Verfahren zur Entwicklung von Anwendungen und zur Kostenverwaltung.

## Was ist die ChatGPT-API?

Mit der ChatGPT-API können Entwickler KI-Funktionen über HTTP-Anfragen in Anwendungen integrieren. Anwendungen senden strukturierte Anfragen an OpenAI und erhalten JSON-Antworten mit der Modellausgabe.

### So funktioniert die ChatGPT-API

Der Ablauf umfasst vier Schritte:

**Du sendest eine Anfrage.** Deine Anwendung sendet eine POST-Anfrage mit einer JSON-Nutzlast an OpenAI, die einen Modellnamen, Nachrichten und Parameter wie Temperatur und Tokenlimits enthält.

**OpenAI verarbeitet die Anfrage.** Das Modell generiert eine Antwort und gibt sie in einem JSON-Objekt zurück. Bei aktiviertem Streaming treffen die Tokens schrittweise ein.

**Deine Anwendung empfängt die Antwort.** Die Antwort enthält generierte Inhalte, Informationen zur Token-Nutzung, Modellinformationen und eine Anfrage-ID.

**Die Abrechnung erfolgt.** Die Gebühren hängen von den verarbeiteten Tokens ab. Für Eingabe- und Ausgabetokens können unterschiedliche Tarife gelten.

Promptlänge, Modellauswahl und Caching wirken sich auf Leistung und Kosten aus.

## So richtest du die ChatGPT-API ein

Für die Authentifizierung von Anfragen benötigst du einen API-Schlüssel. Behandle ihn als Geheimnis und bewahre ihn sicher auf.

### So erhältst du einen OpenAI-API-Schlüssel

**Schritt 1: Öffne die OpenAI-Plattform**

- Besuche [platform.openai.com/api-keys](https://platform.openai.com/api-keys) und melde dich an oder erstelle ein Konto.

**Schritt 2: Erstelle deinen API-Schlüssel**

- Öffne im Dashboard **API Keys**.
- Wähle **Create new secret key** und gib ihm optional einen projektspezifischen Namen.
- Kopiere den Schlüssel, sobald er angezeigt wird; möglicherweise wird er später nicht erneut angezeigt.

**Schritt 3: Bewahre ihn sicher auf**

- Speichere den Schlüssel in einem Passwortmanager oder einer Umgebungsvariablen.
- Übernimm API-Schlüssel niemals in die Versionsverwaltung und lege sie nicht im clientseitigen Code offen.
- Wenn du eine `.env`-Datei verwendest, füge sie zu `.gitignore` hinzu und halte sie aus der Versionsverwaltung heraus.

**Sicherheitshinweise:**

- Ein Schlüssel kann Zugriff gewähren, der mit deinem Konto und der Abrechnung verknüpft ist.
- Wenn ein Schlüssel verloren geht, erstelle einen Ersatz.
- Widerrufe Schlüssel, die möglicherweise kompromittiert wurden.
- Verwende, sofern verfügbar, separate Schlüssel mit passenden Berechtigungen für verschiedene Projekte.

## Einrichten deiner Entwicklungsumgebung

Die API lässt sich mit jeder Programmiersprache verwenden, die HTTP-Anfragen senden kann. Python, JavaScript und Java sind gängige Optionen.

### 1. Python: einfach und mit einem umfangreichen Ökosystem

Dank seiner Syntax und seines Bibliotheksökosystems ist Python eine gängige Wahl. Das Python-Paket von OpenAI kann die Authentifizierung, das Formatieren von Anfragen und die Fehlerbehandlung vereinfachen. Pakete wie `python-dotenv` können bei der Verwaltung von Umgebungsvariablen helfen.

Python kommt außerdem in den Bereichen maschinelles Lernen, Data Science, Webentwicklung und Automatisierung zum Einsatz. Dadurch eignet es sich für Projekte, die API-Aufrufe mit Datenverarbeitung verbinden.

### 2. JavaScript: flexibel für Webanwendungen

JavaScript eignet sich für Backend-Anwendungen mit Node.js sowie für Webanwendungen mit Frameworks wie React, Vue oder Next.js. Asynchrone Funktionen, darunter `async`/`await` und Promises, unterstützen nicht blockierende API-Anfragen.

### 3. Java: Skalierbarkeit und Leistung

Java wird häufig für Unternehmensanwendungen verwendet. Statische Typisierung kann manche Fehler bereits zur Kompilierzeit erkennen, und die Nebenläufigkeitsfunktionen können Anwendungen dabei helfen, mehrere Anfragen zu verarbeiten. Java eignet sich für Software, die in bestehende Java-Systeme integriert wird.

Die folgenden Beispiele verwenden Python. Wenn du JavaScript oder Java nutzt, passe die Syntax an deine Sprache und dein SDK an.

## Best Practices für die Verwendung der ChatGPT-API

### 1. Schreibe klare und konkrete Prompts

Klare, konkrete Anweisungen können die Nützlichkeit der Antworten verbessern.

- Gib das gewünschte Format, den Ton und die Länge an.
- Stelle bei Bedarf Beispiele bereit.
- Verwende Entwickleranweisungen, um Verhalten und Kontext festzulegen.
- Teile komplexe Aufgaben in kleinere Schritte auf.

### 3. Implementiere Streaming für ein besseres Nutzererlebnis

Streaming kann Antwortinhalte schon während des Eintreffens anzeigen, statt bis zur vollständigen Antwort zu warten.

### 4. Verwalte Kontext- und Tokenlimits

Das Kontextfenster eines Modells begrenzt die für Eingabe und Ausgabe verfügbaren Tokens. Überwache die Nutzung, um Kürzungen und unerwartete Kosten zu vermeiden.

- Halte den Gesprächsverlauf kurz; fasse ältere Nachrichten zusammen oder kürze sie.
- Verwende das vom Modell und der API unterstützte passende Ausgabelimit.
- Prüfe die Nutzungsinformationen in der Antwort.
- Ziehe bei langen Dokumenten eine Aufteilung in Abschnitte oder eine Zusammenfassung in Betracht.


### 7. Setze Ratenbegrenzungen um

Je nach Konto und Dienstbedingungen können Ratenbegrenzungen für Anfragen und Tokens über einen bestimmten Zeitraum gelten. Eine 429-Antwort weist auf eine Ratenbegrenzung hin.

- Verwende bei Bedarf Backoff.
- Überwache die Anfrageraten und drossele sie gegebenenfalls.
- Prüfe die aktuellen Limits deines Kontos und ob Änderungen möglich sind.
- Ziehe für geeignete Arbeitslasten die Stapelverarbeitung in Betracht.

## Häufig gestellte Fragen

**Hat ChatGPT eine API?**

Ja. OpenAI bietet eine API für den programmgesteuerten Zugriff auf Modelle. Anwendungen können HTTP-Anfragen senden oder offizielle SDKs verwenden; aktuelle Modelle und Funktionen findest du in der Dokumentation.

**Wie viel kostet die ChatGPT-API?**

Die Preise hängen vom Modell und der Nutzung ab. Aktuelle Tarife und verfügbare Optionen zur Kostenverwaltung findest du auf der [OpenAI-Preisseite](https://openai.com/api/pricing/).

**Was ist der Unterschied zwischen ChatGPT und der ChatGPT-API?**

ChatGPT ist ein dialogorientiertes Produkt. Über die API können Entwickler Anfragen programmatisch senden und Modellantworten in Anwendungen integrieren. Die verfügbaren Steuerungsmöglichkeiten richten sich nach der API und dem gewählten Modell.

**Welches ist das neueste Modell, das in der ChatGPT-API verfügbar ist?**

Die Modellverfügbarkeit ändert sich. Die neuesten Modelle und Fähigkeiten findest du in der aktuellen [API-Dokumentation](https://developers.openai.com/api/docs) von OpenAI.

Wähle eine API anhand deiner Anwendung und der benötigten Funktionen aus. Die Dokumentation von OpenAI beschreibt die aktuellen Endpunkte und Migrationshinweise. Bestehende Anwendungen sollten den dokumentierten Support- und Migrationsanweisungen für ihren Endpunkt folgen.
