# Preise der OpenAI Moderation API: kostenlos, Ratenlimits und Alternativen

> Die Moderationsmodelle von OpenAI sind kostenlos. Erfahren Sie mehr über Preise, Ratenlimits nach Nutzungsstufe, Python-Beispiele und wann eine OpenAI-kompatible Alternative besser passt.




Der Moderationsendpunkt von OpenAI ist für Nutzer der OpenAI API kostenlos. Prüfen Sie für den Produktivbetrieb, welche Eingaben und Kategorien der Endpunkt unterstützt, welche Ratenlimits für Ihr Konto gelten und wie er sich in Ihren Prüfablauf einfügt.

Dieser Leitfaden trennt die offizielle Preisauskunft von der praktischen technischen Entscheidung.

## Kurz gesagt

- **Der Moderation-Endpunkt von OpenAI ist für Nutzer der OpenAI API kostenlos**, laut OpenAIs Help Center.
- OpenAIs Modell `omni-moderation-latest` wurde dafür entwickelt, schädliche Inhalte zu erkennen, und akzeptiert laut der offiziellen OpenAI-Modellseite Text und Bilder als Eingabe.
- Kostenlose Nutzung beseitigt keine Workflow-Kosten wie Protokollierung, Prüfwarteschlangen, Richtlinienzuordnung, Wiederholungsversuche, Fallback-Verhalten und anwendungsspezifische Entscheidungen.
- Wählen Sie OpenAIs kostenlosen Endpunkt, wenn Sie OpenAI bereits direkt nutzen und Ihr Moderations-Workflow zu den Kategorien und dem Antwortformat passt.
- Ziehen Sie EvoLink Moderation 1.0 in Betracht, wenn Sie EvoLink bereits nutzen und multimodale Prüfungen, eine Risikoübersicht und die Abrechnung pro Aufruf im selben Workflow zusammenführen möchten.

## Ist die OpenAI Moderation API kostenlos?

Ja. Im offiziellen Help Center von OpenAI steht, dass der Moderation-Endpunkt für Nutzer der OpenAI API kostenlos ist und seine Nutzung nicht auf die monatlichen Nutzungslimits angerechnet wird.

Quelle: [OpenAI Help Center: Is the Moderation endpoint free to use?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Das ist die Antwort zur Preisgestaltung. Die nächste Frage betrifft den Betrieb:

**Reicht ein kostenloser Moderationsendpunkt für Ihren Produktions-Workflow aus?**

Bei Prototypen, internen Tools und einfacher, textorientierter Moderation kann das der Fall sein. Bei Anwendungen, die nutzergenerierte Inhalte, Bild-Uploads, KI-Agenten oder Prüfwarteschlangen verarbeiten, ist der API-Aufruf nur ein Teil des Systems.

## Was deckt die Moderation von OpenAI ab?

OpenAI beschreibt `omni-moderation-latest` als Moderationsmodell, das potenziell schädliche Inhalte in Texten und Bildern erkennen soll. Auf der offiziellen Modellseite wird es als leistungsfähigstes Moderationsmodell von OpenAI bezeichnet; dort ist Unterstützung für Text als Ein- und Ausgabe sowie für Bilder als Eingabe aufgeführt. Quelle: [OpenAI model page for omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Der Moderationsleitfaden von OpenAI erläutert außerdem die Kategorien zur Inhaltsklassifizierung und weist darauf hin, dass einige Kategorien nur für Text gelten. Wenn Sie ausschließlich Bilder an `omni-moderation-latest` senden, erhalten Kategorien ohne Unterstützung für Bildeingaben den Wert 0. Quelle: [OpenAI Moderation guide](https://developers.openai.com/api/docs/guides/moderation)

Das bedeutet, dass Teams die Kategorientabelle sorgfältig lesen sollten, bevor sie annehmen, dass jede Textkategorie direkt auf die Bildmoderation übertragbar ist.

## Die tatsächlichen Kosten entstehen im Workflow, nicht nur bei der API-Preisgestaltung

Der Moderation-Endpunkt ist möglicherweise kostenlos, aber für ein Moderationssystem im Produktivbetrieb müssen weiterhin Entscheidungen getroffen werden zu:

- dem Zeitpunkt der Prüfungen: vor Modellaufrufen, nach Modellantworten oder beides
- der Zuordnung von Kategorien zu Entscheidungen über Freigabe, Prüfung oder Blockierung
- der Protokollierung von Moderationsergebnissen, ohne unnötig sensible Inhalte zu speichern
- dem Umgang mit falsch positiven Ergebnissen und Einsprüchen
- der getrennten Moderation von Bild-Uploads und Texteingaben
- der Überwachung von Latenz, Fehlern und Ratenlimits
- der einheitlichen Umsetzung von Richtlinien auf allen Produktoberflächen

Das sind Entwicklungs- und Betriebskosten. Sie erscheinen auf keiner Preisseite, entscheiden aber darüber, ob sich die Moderationsschicht tatsächlich warten lässt.

In einem typischen Workflow prüfen Sie Prompts vor dem Modellaufruf und Ausgaben vor der Auslieferung. Leiten Sie unklare Ergebnisse zur Prüfung weiter, protokollieren Sie nur die nötigen Angaben zu Entscheidungen und planen Sie Wiederholungsversuche und Einsprüche ein.

## Wann OpenAIs kostenloser Endpunkt gut passt

OpenAIs kostenloser Moderation-Endpunkt ist oft eine gute erste Wahl, wenn:

- Sie OpenAI bereits direkt nutzen
- Ihre App überwiegend textorientiert ist
- Sie nur die dokumentierten Moderationskategorien von OpenAI benötigen
- Sie Ihren eigenen Prüf- und Eskalations-Workflow aufbauen können
- Ihr Team die Auswertung von Antworten, Schwellenwerte und Protokolle selbst verwalten kann

In diesem Fall lässt sich der kostenlose Endpunkt kaum ablehnen. Beginnen Sie damit, testen Sie ihn mit Ihren tatsächlichen Inhalten und messen Sie falsch positive Ergebnisse sowie übersehene Fälle, bevor Sie Produktionsverkehr darüber leiten.

## Wann eine OpenAI-kompatible Alternative sinnvoll ist

EvoLink Moderation 1.0 ist eine kostenpflichtige Alternative mit dem OpenAI-kompatiblen Endpunkt `/v1/moderations`. EvoLink akzeptiert höchstens ein Bild pro Anfrage.

- Prüfungen nur für Text, nur für Bilder sowie für Text und Bilder über einen Endpunkt
- 13 Schadenskategorien mit Werten für jede Kategorie
- ein `evolink_summary`-Objekt mit `risk_level`, `flagged`, `violations`, `max_score` und `max_category`
- ein Festpreis pro Aufruf statt Tokenberechnung
- ein Antwortformat, das sich leichter der Freigabe-, Prüf- oder Blockierungslogik zuordnen lässt

## So verwenden Sie die OpenAI Moderation API in Python

Wenn Sie bereits das OpenAI SDK verwenden, sieht ein einfacher Aufruf zur Textmoderation so aus:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Setzen Sie für EvoLink `EVOLINK_API_KEY` auf Ihren EvoLink-Schlüssel und `EVOLINK_BASE_URL` auf die HTTPS-Basis-URL aus Ihrer EvoLink-API-Konfiguration. Diese URL endet auf `/v1`. Die Antwort enthält zusätzlich das Objekt `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Preise und Workflows bei OpenAI und EvoLink

| Kriterium | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Abrechnung | Kostenlos für Nutzer der OpenAI API | Kostenpflichtig zum Festpreis pro Aufruf |
| Aufbau des Hauptendpunkts | `/v1/moderations` | OpenAI-kompatibles `/v1/moderations` |
| Textmoderation | Unterstützt | Unterstützt |
| Bildmoderation | Von `omni-moderation-latest` unterstützt, mit kategoriespezifischer Unterstützung für Eingaben | Für Anfragen nur mit Bildern sowie mit Text und Bildern unterstützt |
| Felder für Entscheidungen nach Moderationsrichtlinie | Werten Sie `flagged`, `categories` und `category_scores` in `results` aus | Nutzen Sie `evolink_summary.risk_level` und `violations` zusammen mit den Werten pro Kategorie |
| Geeignet für | Teams, die die OpenAI API bereits direkt nutzen | Teams, die Moderation in einen bestehenden EvoLink-Workflow integrieren |

## Praktische Empfehlung

Verwenden Sie OpenAIs kostenlosen Moderation-Endpunkt, wenn Ihre Anwendung bereits auf OpenAI basiert und sich Ihre Moderierungsrichtlinie klar den dokumentierten Kategorien zuordnen lässt.

Wenn Ihr Team schon EvoLink nutzt, prüfen Sie die Kosten pro Aufruf und ziehen Sie `evolink_summary.risk_level` als eines der Kriterien heran, nach denen Ihre Anwendung Inhalte freigibt, zur Prüfung weiterleitet oder blockiert.

Verwenden Sie ein mehrschichtiges Moderationssystem, wenn Ihre Anwendung eigene Richtlinien benötigt, etwa Markenregeln, menschliche Prüfung, Einsprüche oder Compliance-Workflows, die über die Möglichkeiten einer einzelnen Moderations-API hinausgehen.

## Häufig gestellte Fragen

### Ist die OpenAI Moderation API kostenlos?

Ja. Laut OpenAIs Help Center ist der Moderation-Endpunkt für Nutzer der OpenAI API kostenlos und wird nicht auf die monatlichen Nutzungslimits angerechnet.

### Unterstützt die Moderation von OpenAI Bilder?

Ja, `omni-moderation-latest` akzeptiert laut der offiziellen OpenAI-Modellseite Bilder als Eingabe. Der Moderationsleitfaden von OpenAI weist jedoch darauf hin, dass einige Kategorien nur für Text gelten. Teams sollten daher die Unterstützung für Eingaben auf Kategorieebene prüfen, bevor sie sich auf die Moderation ausschließlich von Bildern verlassen.

### Ist EvoLink Moderation günstiger als OpenAI Moderation?

Der Moderationsendpunkt von OpenAI ist für Nutzer der OpenAI API kostenlos. EvoLink berechnet einen Festpreis pro Aufruf. Vergleichen Sie die Kosten des gesamten Workflows einschließlich Prüfung und Wartung.

### Kann ich EvoLink als Alternative zur OpenAI Moderation API verwenden?

Ja. Verwenden Sie Ihren EvoLink-API-Schlüssel und das Modell `evolink-moderation-1.0` am kompatiblen Endpunkt `/v1/moderations` von EvoLink. Passen Sie die Verarbeitung der Antwort an, damit sie das separate Objekt `evolink_summary` von EvoLink berücksichtigt.

### Sollte ich Prompts, Ausgaben oder beides moderieren?

Bei KI-Anwendungen im Produktivbetrieb moderieren viele Teams sowohl Eingaben als auch Ausgaben. Die Moderation von Eingaben kann unsichere Anfragen aussortieren, bevor sie ein Modell erreichen. Die Moderation von Ausgaben kann unsichere generierte Antworten erkennen, bevor sie Nutzer erreichen.

### Was ist omni-moderation-latest?

Das ist das Moderationsmodell von OpenAI für Text und Bilder. Lesen Sie `flagged`, `categories` und `category_scores` in `results` aus und wenden Sie Ihre eigene Moderationsrichtlinie an.

### Wie hoch ist das Ratenlimit der OpenAI Moderation API?

Die kostenlose Nutzung bezieht sich auf die Abrechnung. Die Limits für Anfragen und Tokens gelten weiterhin. In der [Modellreferenz](https://developers.openai.com/api/docs/models/omni-moderation-latest) steht RPM für Anfragen pro Minute, RPD, sofern angegeben, für Anfragen pro Tag und TPM für Tokens pro Minute.

Die Ratenlimits der OpenAI Moderation API hängen von der Kontostufe ab und können sich im Laufe der Zeit ändern. Prüfen Sie die [Dokumentation zu den Ratenlimits von OpenAI](https://platform.openai.com/docs/guides/rate-limits) und die [Seite mit den Nutzungslimits Ihres Kontos](https://platform.openai.com/settings/organization/limits), bevor Sie den Produktionsdurchsatz planen.

### Wie verwende ich die OpenAI Moderation API in Python?

Installieren Sie das Paket `openai`, setzen Sie `OPENAI_API_KEY` und rufen Sie `client.moderations.create()` mit dem Modell `omni-moderation-latest` und Ihrem Text auf. Bei Bildern übergeben Sie `input` als Array von Objekten. Jeder Bildeintrag hat `type: "image_url"` und ein Objekt `image_url`, das `url` enthält, wie in der unten verlinkten API-Referenz von OpenAI gezeigt.
