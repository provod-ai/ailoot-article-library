# Claude API za začetnike: praktični vodnik za prvi korak

> Praktični vodnik za začetnike po Claude API zajema nastavitev, prvo zahtevo, izbiro modela, ključne funkcije in uporabo v produkciji.



Vse, kar razvijalec potrebuje za prvi klic API-ja Claude: ključe, Messages API, izbiro modela in osnovne koncepte za prehod od prve zahteve do produkcije.

## Kaj je Claude API

Claude API je razvojna platforma podjetja Anthropic. Omogoča programski dostop do modelov Claude prek Messages API, s sistemskimi pozivi, uporabo orodij, pretočnim prenosom, vidom in strukturiranimi izhodi.

Messages API je HTTP-končna točka brez stanja. Pošljete seznam uporabniških in asistenčnih sporočil, ID modela ter omejitev števila žetonov; Claude vrne strukturiran odgovor. Med podpornimi končnimi točkami so paketna obdelava, datoteke in štetje žetonov.

- **Brez stanja:** API ne ohranja spomina. Zgodovino pogovora pošljite znova ob vsakem klicu.
- **Izbira modela:** Pri zamenjavi modela je običajno treba spremeniti ID modela.
- **SDK-ji:** Uradni knjižnici za Python (anthropic) in TypeScript (@anthropic-ai/sdk) uporabljata ustrezno obliko zahtev.

Razumevanje te arhitekture pomaga preprečiti pogosto začetniško napako: pričakovanje, da si bo API zapomnil prejšnjo zahtevo.

## 1. korak: Pridobite ključ in nastavite konzolo

Odprite **console.anthropic.com**, ustvarite račun ali organizacijo za svojo ekipo in v nastavitvah ustvarite ključ API. S ključem ravnajte kot z geslom: shranite ga v okoljsko spremenljivko in ga nikoli ne dodajte v nadzor različic.

Neposredne zahteve HTTP uporabljajo glavi **x-api-key** in **anthropic-version**. SDK-ji samodejno preberejo **ANTHROPIC_API_KEY** iz okolja, zato v večini kode ključa ni treba obravnavati neposredno.

- Ustvarite ločene ključe za razvoj, staging in produkcijo.
- Za ločevanje ekipnih projektov in porabe uporabite delovne prostore.
- Preden ključe omogočite širšemu krogu ekipe, v konzoli nastavite omejitve uporabe.

## 2. korak: Izvedite prvi klic Messages API

Namestite SDK z ukazom **pip install anthropic**, izvozite svoj ključ in zaženite:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Obvezni so trije parametri: **model**, **max_tokens** (zgornja meja izhoda) in **messages**. Odgovor vsebuje seznam vsebinskih blokov. Preverite vrsto vsakega bloka in ne predpostavljajte, da gre zgolj za navadno besedilo, saj lahko uporaba orodij in razmišljanje dodata druge vrste blokov. Objekt **usage** poroča o vhodnih in izhodnih žetonih, kar lahko uporabite kot telemetrijo stroškov.

## 3. korak: Izberite model

Spodaj so trenutni modeli Claude podjetja Anthropic in njihovi identifikatorji API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — opisan kot hiter in cenovno ugoden model za klasifikacijo in preproste naloge z velikim obsegom.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — opisan kot uravnotežena izbira za produkcijske obremenitve, tudi za programiranje.
- **Claude Opus 5.5** (**claude-opus-5-5**) — opisan za zahtevno sklepanje in dolgotrajno agentsko delo.
- **Claude Fable 5.2** (**claude-fable-5-2**) — opisan kot vodilni model za zahtevne naloge sklepanja.

Začnite z modelom Opus 5.5. Preizkusite Sonnet 5.5 za ravnovesje med hitrostjo in kakovostjo, Haiku 5.5 za veliko preprostih nalog in Fable 5.2 za zahtevno sklepanje. Za aktualne cene preverite Anthropicov cenik.

## Pet konceptov, ki jih velja spoznati naslednje

Ko prvo zahtevo uspešno izvedete, te funkcije pokrivajo številne potrebe aplikacij:

- **Sistemski pozivi** — vrhnji parameter **system**, ki ločeno od uporabniških sporočil določa vlogo, ton in pravila.
- **Večzaporedni pogovori** — vsako asistentovo sporočilo dodajte v polje messages in ga znova pošljite; prvo sporočilo mora biti uporabniško.
- **Pretakanje** — dogodki, ki jih pošlje strežnik, posredujejo žetone med ustvarjanjem, kar je uporabno pri klepetalnih vmesnikih in dolgih izhodih.
- **Vid** — slike pošljite kot vsebinske bloke base64 ali URL skupaj z besedilom.
- **Uporaba orodij** — določite funkcije s shemami JSON; Claude se lahko odloči, kdaj jih bo poklical, vaša koda pa jih izvede in vrne rezultate.

Ko so stroški pomembni, razmislite o **prompt caching** in **batch processing**; če mora nadaljnja koda razčleniti odgovor, pa o **structured outputs**.

## Od vadnice do produkcije

Prehod od delujočega skripta do produkcijske integracije zahteva inženirsko disciplino:

- **Obravnava napak:** Napake zaradi omejitve hitrosti (429) in strežniške napake obravnavajte ločeno. Vir navaja, da jih SDK-ji samodejno poskusijo znova z naraščajočimi zamiki; za trenutno vedenje preverite dokumentacijo ustreznega SDK-ja.
- **Preglednost stroškov:** V sistem za metrike beležite **usage** iz vsakega odgovora.
- **Različice pozivov:** S pozivi ravnajte kot s kodo: preglejte jih, različice upravljajte in jih preizkusite na majhnem naboru za evalvacijo.
- **Pripenjanje modela:** Na ID-je modelov se sklicujte prek konfiguracije, da bodo nadgradnje načrtovane in preizkušene.

### Ključne ugotovitve

- Messages API je brez stanja; ob vsakem klicu znova pošljite zgodovino pogovora.
- Neposredna avtentikacija HTTP uporablja glavo x-api-key; SDK-ji lahko iz okolja preberejo ANTHROPIC_API_KEY.
- Trije obvezni parametri zahteve so model, max_tokens in messages.
- Začnite z modelom Opus 5.5 in primerjajte druge možnosti na svojih podatkih.
- Sistemski pozivi, pretakanje, vid, uporaba orodij in večzaporedna zgodovina podpirajo številne vzorce uporabe v aplikacijah.
- Za preglednost stroškov in načrtovanje zmogljivosti beležite porabo žetonov.

## Pogosta vprašanja

### Ali moram za uporabo Claude API poznati strojno učenje?

Ne. Claude API je REST API z uradnima SDK-jema za Python in TypeScript. Če znate poklicati končno točko HTTP in razčleniti JSON, lahko razvijate s Claudeom. Oblikovanje pozivov, obravnava napak in upravljanje stroškov so koristne inženirske veščine; za prvi klic API-ja teorija strojnega učenja ni potrebna.

### S katerim modelom Claude naj začne začetnik?

Anthropic za večino opravil priporoča, da začnete z modelom Claude Opus 5.5 (identifikator API `claude-opus-5-5`). Ko se pozivi ustalijo, primerjajte še preostale modele na svojih podatkih.

### Ali si Claude API zapomni prejšnje pogovore?

Ne. Messages API je brez stanja. Vaša aplikacija shrani pogovor in ob vsaki zahtevi znova pošlje celotno zgodovino sporočil. Tako ohranite nadzor nad kontekstom, lahko skrajšate ali povzamete starejše izmenjave in uporabite predpomnjenje pozivov.
