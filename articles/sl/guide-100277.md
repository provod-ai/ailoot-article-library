# ChatGPT API: kako jo nastaviti, cene in primeri kode (2026)

> Praktični vodnik za nastavitev API-ja ChatGPT, primerjavo modelov in cen ter izdelavo aplikacij s primeri kode.



API ChatGPT razvijalcem omogoča programski dostop do modelov OpenAI. Ta vodnik obravnava nastavitev ključa API, izbiro modela, cene, primere kode ter prakse za izdelavo aplikacij in upravljanje stroškov.

## Kaj je API ChatGPT?

API ChatGPT razvijalcem omogoča vključevanje zmogljivosti umetne inteligence v aplikacije prek zahtev HTTP. Aplikacije pošiljajo strukturirane zahteve OpenAI in prejmejo odgovore JSON, ki vsebujejo izhod modela.

### Kako deluje API ChatGPT

Postopek poteka v štirih korakih:

**Pošljete zahtevo.** Vaša aplikacija OpenAI pošlje zahtevo POST s koristnim tovorom JSON, ki vsebuje ime modela, sporočila in parametre, kot sta temperatura in omejitev števila žetonov.

**OpenAI obdela zahtevo.** Model ustvari odgovor in ga vrne v objektu JSON. Ko je omogočeno pretakanje, žetoni prihajajo postopoma.

**Vaša aplikacija prejme odgovor.** Odgovor vključuje ustvarjeno vsebino, porabo žetonov, podatke o modelu in ID zahteve.

**Izvede se obračun.** Stroški so odvisni od obdelanih žetonov. Vhodni in izhodni žetoni imajo lahko različne tarife.

Dolžina poziva, izbira modela in predpomnjenje vplivajo na zmogljivost in stroške.

### 2. Za zanesljive podatke uporabite strukturirane izhode

Za JSON ali druge strukturirane podatke uporabite funkcije API-ja za strukturirani izhod, namesto da razčlenjujete prosto besedilo. V dokumentaciji preverite podprto obliko in omejitve.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Za boljšo uporabniško izkušnjo omogočite pretakanje

Pretakanje lahko prikaže vsebino odgovora, ko ta prihaja, namesto da bi čakali na celoten odgovor.

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)

### 5. Napake obravnavajte elegantno

Zahteve lahko spodletijo zaradi težav z omrežjem, omejitev hitrosti, neveljavnega vhoda ali izpadov storitve. Napake obravnavajte skladno z dokumentacijo SDK-ja in API-ja.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Za integracijo orodij uporabite klicanje funkcij

Klicanje funkcij modelu omogoča, da zahteva, naj vaša aplikacija pokliče funkcijo ali orodje. Aplikacija izvede klic in po potrebi vrne rezultate.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```

Prijavite se v svoj račun na [https://ailoot.ai/](<https://ailoot.ai/>) ali prosite ekipo Ailoot za promocijsko kodo.
