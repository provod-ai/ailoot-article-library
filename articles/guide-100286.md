# Zapier vs n8n: What You Trade for Self-Hosting

> Compare Zapier and n8n pricing, integrations, licensing, self-hosting requirements, and workflow design to choose the right automation tool for your team.



**Zapier is a hosted service that meters billable actions in tasks. [n8n](https://n8n.io/) charges by workflow execution on its paid plans and offers a self-hosted edition.**

If a workflow runs 1,000 times and completes 12 billable actions per run, it uses 12,000 Zapier tasks when each action costs one task. If those runs count toward the n8n plan’s quota, n8n records 1,000 executions.

What you give up is real too. n8n asks you to run infrastructure, or to accept a smaller integration library, or both.

- **Zapier**: broad app coverage, hosted service, task-based billing
- **n8n**: self-hosting available, execution-based paid plans, source available under the Sustainable Use License
- **The dividing question**: is your constraint app coverage, or is it workflow length and data residency?

## Quick comparison

|  | Zapier | n8n |
|----|----|----|
| Billing unit | Tasks for successful billable actions, at the applicable rate | Execution—one whole workflow run |
| Cost of adding a step | Increases with each billed action | No change to execution count |
| Self-hosting | Not available | Yes, Community Edition |
| Licence | Proprietary SaaS | Sustainable Use License (source-available, not OSI open source) |
| App coverage | Broad directory | Smaller integration library |
| Code steps | JavaScript and Python, sandboxed | JavaScript and Python nodes, plus npm packages when self-hosted |
| Who maintains it | Zapier | You, if self-hosted |
| Best fit | Breadth of apps, non-technical owners | Long workflows, data control, technical teams |

## Per-step vs per-execution, and why it changes design

Triggers and polling for new data do not use tasks. Built-in tools such as Formatter and Filter are task-free. Some billable actions consume more than one task, so check the rate for each action.

n8n's model counts an execution as a single run of the entire workflow—the platform's own [pricing page](https://n8n.io/pricing/) says that the number of steps and the amount of data passing through the workflow do not change the execution count.

The design consequences run in opposite directions:

Use Paths for branching and Formatter for data changes where they fit. Estimate the task total from the billable actions that run and the rate of each action.

Each workflow run that counts toward an n8n plan’s quota uses one execution regardless of the number of steps. Processing several records in one run can reduce the number of counted executions.

That second point can catch people migrating from Zapier, where per-record firing is common and may be inexpensive when actions are few.

## The licence question, stated accurately

n8n is frequently described as open source. It is not, and n8n does not claim to be. n8n is distributed under the Sustainable Use License, a fair-code licence. The source is on GitHub and can be read, modified, and self-hosted for internal use.

The licence does not permit offering n8n to third parties as a hosted service. Because the Open Source Initiative's definition does not permit use restrictions, n8n avoids the "open source" label.

For many teams this distinction is academic: internal self-hosting is what the licence permits, with no cap on workflows or run frequency. It matters if you're an agency planning to resell managed n8n instances, where you need a commercial arrangement.

## What self-hosting actually costs

The "n8n is free" framing skips the bill you do pay:

- **A server, and someone who maintains it.** Updates, backups, TLS certificates, monitoring, and the 2am page when the queue stalls
- **Scaling work.** Moving to queue mode with workers once a single instance stops keeping up
- Features vary by plan. Self-hosted Business includes SSO and LDAP. Enterprise also includes log streaming and integration with external secret stores.
- **Debugging on your own.** You may have no support ticket to file when a node misbehaves

If nobody on your team owns infrastructure, self-hosted n8n may be a liability rather than a saving. n8n Cloud offers execution-based billing without the operations burden, and is a relevant comparison point against Zapier for many buyers.

## Where each one wins

**Zapier wins on coverage.** Its app directory is broader than n8n's integration library. If your stack includes something niche, Zapier may be more likely to have it already. n8n's HTTP Request node can talk to any REST API, but "any API" means reading docs and handling auth yourself.

**Zapier wins when the owner isn't technical.** Non-engineers can maintain Zaps. n8n expects comfort with data shapes, expressions, and JSON—and self-hosted n8n expects comfort with a server.

**n8n can win on long workflows.** Per-execution billing does not add a charge for each additional step, which can make it suitable for workflows with many steps.

**n8n can win on data residency and control.** Regulated industries, or anyone who can't route customer data through a third-party cloud, may need self-hosting. Zapier does not offer a self-hosting option.

**n8n can suit AI work.** Its LangChain nodes and support for local models can be useful for agent-shaped workflows.

## Choosing without regret

Work through it in this order:

1. **Do you have a hard data-residency requirement?** Yes → n8n self-hosted.
2. **Is there someone who will own a server?** No → Zapier or n8n Cloud.
3. **How long are your workflows?** Longer workflows may make n8n's billing model attractive.
4. **How niche is your stack?** Several obscure tools may make Zapier's coverage worth the per-step cost.
5. **Everything else** → start with the tool that best fits your team's skills and integrations. It's easier to migrate away from a working automation than to finish one you never got running.

Make sits between them in some respects: cloud-hosted like Zapier, with a visual canvas closer to n8n's.

## FAQ

**Is n8n free?**

The Community Edition is free to self-host, with no limit on workflows or executions. You pay for the server and the maintenance. n8n Cloud is paid, and self-hosted Enterprise features require a licence key.

**Is n8n open source?**

No, and n8n doesn't claim it is. The source is available under the Sustainable Use License, which permits internal use and modification but forbids reselling n8n as a hosted service. Use restrictions disqualify a licence from the OSI definition of open source.

**Will n8n really be cheaper than Zapier?**

n8n can be less expensive for long workflows with many billable Zapier actions. Compare the number of workflow runs and how many tasks each billable action uses. For self-hosting, include infrastructure and maintenance costs.

**Can I move my Zaps to n8n automatically?**

There may be no supported converter. Migration can require a rebuild, so it's worth prototyping your heaviest workflows on n8n before committing.

**Does n8n need a developer?**

Self-hosted, someone has to own the server. n8n Cloud removes that, but building in n8n still assumes more comfort with data structures and expressions than Zapier does.

**What about Power Automate?**

Microsoft offers user and process subscriptions. It also documents pay-as-you-go billing per run for eligible flows. Compare the pricing options for the flows you use.
