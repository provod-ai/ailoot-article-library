# Zapier vs n8n: wat je inruilt voor zelfhosting

> Vergelijk de prijzen, integraties, licenties, vereisten voor zelfhosting en workflowontwerp van Zapier en n8n om de juiste automatiseringstool voor je team te kiezen.



**Zapier is een gehoste dienst die factureerbare acties in taken telt. [n8n](https://n8n.io/) rekent bij betaalde abonnementen af per workflowuitvoering en biedt een editie om zelf te hosten.**

Als een workflow 1.000 keer draait en per uitvoering 12 factureerbare acties voltooit, gebruikt die 12.000 Zapier-taken wanneer elke actie één taak kost. Als diezelfde runs meetellen voor het quotum van het n8n-abonnement, registreert n8n 1.000 uitvoeringen.

Wat je ervoor opgeeft, is ook reëel. Bij n8n moet je zelf de infrastructuur beheren, genoegen nemen met een kleinere integratiebibliotheek, of allebei.

- **Zapier**: brede appdekking, gehoste dienst, facturering op basis van taken
- **n8n**: zelfhosting mogelijk, betaalde abonnementen op basis van uitvoeringen, broncode beschikbaar onder de Sustainable Use License
- **De onderscheidende vraag**: is app-ondersteuning je beperking, of gaat het om de lengte van workflows en de locatie van je gegevens?

## Korte vergelijking

|  | Zapier | n8n |
|----|----|----|
| Factureringseenheid | Taken voor succesvol uitgevoerde factureerbare acties, tegen het toepasselijke tarief | Uitvoering — één volledige workflowrun |
| Kosten van een stap toevoegen | Stijgen met elke gefactureerde actie | Het aantal uitvoeringen verandert niet |
| Zelf hosten | Niet mogelijk | Ja, Community Edition |
| Licentie | Eigen SaaS | Sustainable Use License (broncode beschikbaar, geen open source volgens de OSI-definitie) |
| App-ondersteuning | Uitgebreide catalogus | Kleinere integratiebibliotheek |
| Codestappen | JavaScript en Python in een sandbox | JavaScript- en Python-nodes, plus npm-pakketten bij zelfhosting |
| Wie onderhoudt het? | Zapier | Jij, als je het zelf host |
| Meest geschikt voor | Brede appkeuze, niet-technische beheerders | Lange workflows, gegevensbeheer, technische teams |

## Betaling per stap versus per uitvoering, en waarom dat het ontwerp verandert

Triggers en periodieke controles op nieuwe gegevens gebruiken geen taken. Ingebouwde tools zoals Formatter en Filter gebruiken ook geen taken. Sommige factureerbare acties gebruiken meer dan één taak, dus controleer het tarief per actie.

Het model van n8n telt één uitvoering voor een volledige run van de workflow. Op de eigen [prijzenpagina](https://n8n.io/pricing/) staat dat het aantal stappen en de hoeveelheid gegevens die door de workflow gaan, het aantal uitvoeringen niet veranderen.

De gevolgen voor het ontwerp zijn tegengesteld:

Gebruik Paths voor vertakkingen en Formatter voor gegevensaanpassingen wanneer ze bij de workflow passen. Schat het totale aantal taken op basis van de factureerbare acties die worden uitgevoerd en het tarief per actie.

Elke workflowrun die meetelt voor het quotum van een n8n-abonnement, telt als één uitvoering, ongeacht het aantal stappen. Als je meerdere records in één run verwerkt, kan dat het aantal meegetelde uitvoeringen verlagen.

Dat tweede punt kan mensen verrassen die van Zapier overstappen, waar het gebruikelijk is om voor elk record een run te starten en dat bij weinig acties voordelig kan zijn.

## De licentiekwestie nauwkeurig uitgelegd

n8n wordt vaak als open source omschreven. Dat klopt niet, en n8n beweert dat zelf ook niet. n8n wordt verspreid onder de Sustainable Use License, een fair-code-licentie. De broncode staat op GitHub en mag worden gelezen, aangepast en voor intern gebruik zelf gehost.

De licentie staat niet toe dat je n8n als gehoste dienst aan derden aanbiedt. De definitie van het Open Source Initiative staat gebruiksbeperkingen niet toe; daarom vermijdt n8n de term ‘open source’.

Voor veel teams is dit onderscheid theoretisch: de licentie staat zelfhosting voor intern gebruik toe, zonder limiet op het aantal workflows of de uitvoeringsfrequentie. Het is wel van belang als je een bureau bent dat beheerde n8n-instanties wil doorverkopen; daarvoor heb je een commerciële overeenkomst nodig.

## Wat zelfhosting werkelijk kost

De uitspraak ‘n8n is gratis’ laat de rekening die je wel betaalt buiten beschouwing:

- **Een server en iemand die deze onderhoudt.** Updates, back-ups, TLS-certificaten, monitoring en het bericht om twee uur ’s nachts wanneer de wachtrij vastloopt.
- **Schaalwerk.** Overstappen op de wachtrijmodus met workers zodra één instantie het niet meer aankan.
- Functies verschillen per abonnement. Het zelfgehoste Business-abonnement omvat SSO en LDAP. Enterprise biedt daarnaast streaming van logboeken en integratie met externe opslag voor geheimen.
- **Zelf debuggen.** Misschien kun je geen supportticket indienen wanneer een node zich niet goed gedraagt.

Als niemand in je team verantwoordelijk is voor de infrastructuur, kan zelfgehoste n8n eerder een risico dan een besparing zijn. n8n Cloud biedt facturering op basis van uitvoeringen zonder de operationele last. Voor veel kopers is het daarom een relevant alternatief voor Zapier.

## Waar elk van beide in uitblinkt

**Zapier blinkt uit in brede ondersteuning.** De appcatalogus is uitgebreider dan de integratiebibliotheek van n8n. Als je stack iets niche bevat, is de kans groter dat Zapier het al ondersteunt. Met de HTTP Request-node van n8n kun je elke REST API aanspreken, maar ‘elke API’ betekent wel dat je zelf de documentatie moet lezen en de authenticatie moet regelen.

**Zapier blinkt uit wanneer de beheerder niet technisch is.** Niet-technische medewerkers kunnen Zaps onderhouden. Voor n8n moet je vertrouwd zijn met gegevensstructuren, expressies en JSON. Bij zelfgehoste n8n moet je bovendien met een server overweg kunnen.

**n8n kan voordelig zijn voor lange workflows.** Bij facturering per uitvoering komen er geen kosten bij voor extra stappen, waardoor n8n geschikt kan zijn voor workflows met veel stappen.

**n8n kan voordelig zijn voor gegevenslocatie en controle.** Gereguleerde sectoren en organisaties die klantgegevens niet via de cloud van een derde partij mogen routeren, hebben mogelijk zelfhosting nodig. Zapier biedt geen optie voor zelfhosting.

**n8n kan geschikt zijn voor AI-toepassingen.** De LangChain-nodes en ondersteuning voor lokale modellen kunnen nuttig zijn voor workflows met agents.

## Kiezen zonder spijt

Doorloop de volgende stappen in deze volgorde:

1. **Heb je een harde eis voor de locatie van gegevens?** Ja → n8n zelfgehost.
2. **Is er iemand die verantwoordelijk is voor een server?** Nee → Zapier of n8n Cloud.
3. **Hoe lang zijn je workflows?** Bij langere workflows kan het prijsmodel van n8n aantrekkelijk zijn.
4. **Hoe niche is je stack?** Als je meerdere obscure tools gebruikt, kan de brede ondersteuning van Zapier de kosten per stap waard zijn.
5. **Alle overige gevallen** → begin met de tool die het beste past bij de vaardigheden en integraties van je team. Overstappen vanaf een werkende automatisering is eenvoudiger dan een automatisering afmaken die je nooit aan de praat kreeg.

Make zit in sommige opzichten tussen beide in: het wordt net als Zapier in de cloud gehost, maar heeft een visueel canvas dat meer lijkt op dat van n8n.

## Veelgestelde vragen

**Is n8n gratis?**

De Community Edition is gratis zelf te hosten, zonder limiet op workflows of uitvoeringen. Je betaalt voor de server en het onderhoud. n8n Cloud is betaald en voor zelfgehoste Enterprise-functies heb je een licentiesleutel nodig.

**Is n8n open source?**

Nee, en n8n beweert dat ook niet. De broncode is beschikbaar onder de Sustainable Use License. Die staat intern gebruik en aanpassingen toe, maar verbiedt het doorverkopen van n8n als gehoste dienst. Gebruiksbeperkingen zorgen ervoor dat een licentie niet voldoet aan de OSI-definitie van open source.

**Is n8n echt goedkoper dan Zapier?**

n8n kan goedkoper zijn voor lange workflows met veel factureerbare Zapier-acties. Vergelijk het aantal workflowuitvoeringen en hoeveel taken elke factureerbare actie gebruikt. Neem bij zelfhosting de kosten van infrastructuur en onderhoud mee.

**Kan ik mijn Zaps automatisch naar n8n verplaatsen?**

Er is mogelijk geen ondersteunde converter. Migratie kan betekenen dat je de workflows opnieuw moet opbouwen. Daarom is het verstandig om je zwaarste workflows eerst als prototype in n8n te testen voordat je definitief kiest.

**Heb je een ontwikkelaar nodig voor n8n?**

Bij zelfhosting moet iemand verantwoordelijk zijn voor de server. n8n Cloud neemt dat uit handen, maar bij het bouwen in n8n moet je nog steeds meer vertrouwd zijn met gegevensstructuren en expressies dan bij Zapier.

**En Power Automate?**

Microsoft biedt abonnementen per gebruiker en per proces. Microsoft documenteert ook facturering naar gebruik per uitvoering voor flows die aan de voorwaarden voldoen. Vergelijk de prijsopties voor de flows die je gebruikt.
