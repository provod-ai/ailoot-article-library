# Claude API voor beginners: een praktische startgids

> Een beginnersgids voor de Claude API over configuratie, je eerste verzoek, modelkeuze, kernfuncties en werkwijzen voor productie.



Alles wat een ontwikkelaar nodig heeft voor de eerste aanroep van de Claude API: sleutels, de Messages API, modelkeuze en de basisconcepten om van een eerste verzoek naar productie te gaan.

## Wat is de Claude API?

De Claude API is het ontwikkelaarsplatform van Anthropic. Het biedt programmatische toegang tot Claude-modellen via de Messages API, met systeemprompts, toolgebruik, streaming, vision en gestructureerde uitvoer.

De Messages API is een stateless HTTP-endpoint. Je verstuurt een lijst met gebruikers- en assistentberichten, een model-ID en een tokenlimiet; Claude retourneert een gestructureerd antwoord. Aanvullende endpoints zijn onder meer batches, bestanden en het tellen van tokens.

- **Stateless:** De API bewaart geen geheugen. Verstuur de gespreksgeschiedenis bij elke aanroep opnieuw.
- **Modelkeuze:** Van model wisselen betekent doorgaans dat je het model-ID wijzigt.
- **SDK's:** De officiële Python- (anthropic) en TypeScript-bibliotheken (@anthropic-ai/sdk) gebruiken overeenkomstige verzoekvormen.

Inzicht in deze architectuur helpt een veelgemaakte beginnersfout te voorkomen: verwachten dat de API een eerder verzoek onthoudt.

## Stap 1: Maak een sleutel aan en stel de Console in

Ga naar **console.anthropic.com**, maak een account of organisatie voor je team en genereer een API-sleutel in de instellingen. Behandel de sleutel als een wachtwoord: bewaar hem in een omgevingsvariabele en zet hem nooit in versiebeheer.

Rechtstreekse HTTP-aanroepen gebruiken de headers **x-api-key** en **anthropic-version**. De SDK's lezen **ANTHROPIC_API_KEY** automatisch uit de omgeving, dus de meeste code verwerkt de sleutel niet rechtstreeks.

- Maak aparte sleutels voor ontwikkeling, staging en productie.
- Gebruik workspaces om teamprojecten en uitgaven te scheiden.
- Stel gebruikslimieten in de Console in voordat je sleutels met een groter team deelt.

## Stap 2: Doe je eerste aanroep naar de Messages API

Installeer de SDK met **pip install anthropic**, exporteer je sleutel en voer dit uit:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Drie parameters zijn verplicht: **model**, **max_tokens** (de bovengrens voor de uitvoer) en **messages**. Het antwoord bevat een lijst met inhoudsblokken. Controleer het type van elk blok in plaats van aan te nemen dat het gewone tekst is; toolgebruik en denkprocessen kunnen ook andere bloktypen opleveren. Het object **usage** rapporteert de invoer- en uitvoertokens en kan dienen als kostentelemetrie.

## Stap 3: Kies een model

Dit zijn de huidige Claude-modellen van Anthropic en hun API-ID’s.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — beschreven als snel en goedkoop, voor classificatie en eenvoudige taken met een hoog volume.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — beschreven als een gebalanceerde keuze voor productiebelasting, waaronder programmeren.
- **Claude Opus 5.5** (**claude-opus-5-5**) — beschreven voor moeilijke redeneringen en langdurig agentwerk.
- **Claude Fable 5.2** (**claude-fable-5-2**) — beschreven als een topmodel voor veeleisende redeneertaken.

Begin met Opus 5.5. Probeer Sonnet 5.5 voor een balans tussen snelheid en kwaliteit, Haiku 5.5 voor grote aantallen eenvoudige taken en Fable 5.2 voor complexe redeneertaken. Bekijk de actuele tarieven op de prijspagina van Anthropic.

## De vijf concepten om hierna te leren

Als het eerste verzoek werkt, dekken deze functies veel toepassingsbehoeften:

- **Systeemprompts** — een parameter **system** op het hoogste niveau die rol, toon en regels instelt, los van gebruikersberichten.
- **Gesprekken met meerdere beurten** — voeg elk antwoord van de assistent toe aan de messages-array en verstuur die opnieuw; het eerste bericht moet van de gebruiker komen.
- **Streaming** — server-sent events leveren tokens terwijl ze worden gegenereerd; dat is handig voor chatinterfaces en lange antwoorden.
- **Vision** — stuur afbeeldingen samen met tekst als base64- of URL-inhoudsblokken.
- **Toolgebruik** — definieer functies met JSON-schema's; Claude kan bepalen wanneer het ze aanroept, terwijl jouw code ze uitvoert en het resultaat terugstuurt.

Overweeg **prompt caching** en **batch processing** als kosten ertoe doen, en **structured outputs** als vervolgcode een antwoord moet verwerken.

## Van tutorial naar productie

De stap van een werkend script naar een productie-integratie vraagt om technische discipline:

- **Foutafhandeling:** Behandel rate-limitfouten (429) en serverfouten afzonderlijk. Volgens de bron proberen de SDK's deze automatisch opnieuw met backoff; controleer het actuele gedrag in de documentatie van de betreffende SDK.
- **Kosteninzicht:** Log **usage** van elk antwoord in je metricsysteem.
- **Promptversies:** Behandel prompts als code: beoordeel en versioneer ze en test ze met een kleine evaluatieset.
- **Model vastzetten:** Verwijs vanuit de configuratie naar model-ID's, zodat upgrades bewust en getest gebeuren.

### Belangrijkste punten

- De Messages API is stateless; verstuur de gespreksgeschiedenis bij elke aanroep opnieuw.
- Rechtstreekse HTTP-authenticatie gebruikt een x-api-key-header; SDK's kunnen ANTHROPIC_API_KEY uit de omgeving lezen.
- De drie verplichte verzoekparameters zijn model, max_tokens en messages.
- Begin met Opus 5.5 en vergelijk de alternatieven met je eigen gegevens.
- Systeemprompts, streaming, vision, toolgebruik en gespreksgeschiedenis ondersteunen veel toepassingspatronen.
- Registreer token usage voor kosteninzicht en capaciteitsplanning.

## FAQ

### Moet ik machine learning kennen om de Claude API te gebruiken?

Nee. De Claude API is een REST API met officiële Python- en TypeScript-SDK's. Als je een HTTP-endpoint kunt aanroepen en JSON kunt verwerken, kun je met Claude bouwen. Promptontwerp, foutafhandeling en kostenbeheer zijn nuttige technische vaardigheden; machinelearningtheorie is niet nodig om je eerste API-aanroep te doen.

### Met welk Claude-model kan een beginner het beste beginnen?

Anthropic raadt Claude Opus 5.5 (API-ID `claude-opus-5-5`) aan als startpunt voor de meeste workloads. Zodra je prompts stabiel zijn, vergelijk je de andere modellen met je eigen gegevens.

### Onthoudt de Claude API eerdere gesprekken?

Nee. De Messages API is stateless. Je applicatie bewaart het gesprek en verstuurt de volledige berichtgeschiedenis opnieuw bij elk verzoek. Zo houd je controle over de context, kun je oudere beurten inkorten of samenvatten en kun je prompt caching toepassen.
