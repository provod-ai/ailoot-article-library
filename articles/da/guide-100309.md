# Claude API for begyndere: En praktisk introduktionsguide

> En introduktion til Claude API med opsætning, det første kald, valg af model, kernefunktioner og praksis til produktion.



Alt, hvad en udvikler skal bruge til sit første kald til Claude API: nøgler, Messages API, valg af model og de vigtigste begreber til at gå fra den første anmodning til produktion.

## Hvad Claude API er

Claude API er Anthropics udviklerplatform. Den giver programmatisk adgang til Claude-modeller via Messages API med systemprompts, værktøjsbrug, streaming, vision og strukturerede outputs.

Messages API er et tilstandsløst HTTP-endpoint. Du sender en liste med bruger- og assistentbeskeder, et model-id og en token-grænse; Claude returnerer et struktureret svar. Supplerende endpoints omfatter batches, filer og optælling af tokens.

- **Tilstandsløs:** API'et gemmer ingen hukommelse. Send samtalehistorikken igen ved hvert kald.
- **Valg af model:** Et skift af model betyder typisk, at model-id'et ændres.
- **SDK'er:** De officielle Python- (anthropic) og TypeScript-biblioteker (@anthropic-ai/sdk) bruger de tilsvarende anmodningsformater.

Forståelse af denne arkitektur hjælper med at undgå en almindelig begynderfejl: at forvente, at API'et husker en tidligere anmodning.

## Trin 1: Få en nøgle, og opsæt Console

Gå til **console.anthropic.com**, opret en konto eller en organisation til dit team, og generér en API-nøgle i indstillingerne. Behandl nøglen som en adgangskode: gem den i en miljøvariabel, og læg den aldrig i versionsstyring.

Direkte HTTP-kald bruger en **x-api-key**-header og en **anthropic-version**-header. SDK'erne læser automatisk **ANTHROPIC_API_KEY** fra miljøet, så de fleste kodeeksempler håndterer ikke nøglen direkte.

- Opret separate nøgler til udvikling, staging og produktion.
- Brug arbejdsområder til at adskille teamprojekter og udgifter.
- Sæt forbrugsgrænser i Console, før du giver et større team adgang til nøglerne.

## Trin 2: Foretag dit første kald til Messages API

Installér SDK'et med **pip install anthropic**, eksportér din nøgle, og kør:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Tre parametre er påkrævet: **model**, **max_tokens** (maksimum for output) og **messages**. Svaret indeholder en liste med indholdsblokke. Kontrollér typen for hver blok i stedet for at antage, at det er almindelig tekst, for værktøjsbrug og tænkning kan tilføje andre bloktyper. Objektet **usage** viser input- og outputtokens og kan bruges til omkostningsmåling.

## Trin 3: Vælg en model

Her er Anthropics aktuelle Claude-modeller og deres API-id'er.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — beskrives som hurtig og billig til klassificering og enkle opgaver i stort omfang.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — beskrives som et balanceret valg til produktionsarbejde, herunder kodning.
- **Claude Opus 5.5** (**claude-opus-5-5**) — beskrives til krævende ræsonnement og længerevarende agentopgaver.
- **Claude Fable 5.2** (**claude-fable-5-2**) — beskrives som flagskib til krævende ræsonnementsopgaver.

Begynd med Opus 5.5. Afprøv Sonnet 5.5, når hastighed og kvalitet skal balanceres, Haiku 5.5 til enkle opgaver i stort omfang og Fable 5.2 til krævende ræsonnement. Se Anthropics prisside for aktuelle priser.

## De fem begreber, du bør lære som det næste

Når det første kald fungerer, dækker disse funktioner mange behov i applikationer:

- **Systemprompts** — en parameter på øverste niveau kaldet **system**, som fastlægger rolle, tone og regler adskilt fra brugerbeskeder.
- **Samtaler med flere ture** — føj hvert assistentsvar til messages-arrayet, og send det igen; den første besked skal være fra brugeren.
- **Streaming** — Server-Sent Events leverer tokens, mens de genereres, hvilket kan hjælpe i chatgrænseflader og ved lange outputs.
- **Vision** — send billeder som Base64- eller URL-indholdsblokke sammen med tekst.
- **Værktøjsbrug** — definér funktioner med JSON-skemaer; Claude kan vælge, hvornår de skal kaldes, mens din kode udfører dem og returnerer resultatet.

Overvej **prompt-caching** og **batchbehandling**, når omkostningerne betyder noget, og **strukturerede outputs**, når efterfølgende kode skal fortolke et svar.

## Fra vejledning til produktion

Overgangen fra et fungerende script til en produktionsintegration kræver teknisk disciplin:

- **Fejlhåndtering:** Behandl hastighedsbegrænsninger (429) og serverfejl forskelligt. Kilden siger, at SDK'erne automatisk gentager disse fejl med gradvist længere ventetid; kontrollér den aktuelle adfærd i dokumentationen for det relevante SDK.
- **Omkostningsoverblik:** Log **usage** fra hvert svar i dit metricsystem.
- **Prompt-versionering:** Behandl prompts som kode: gennemgå og versionsstyr dem, og test dem mod et lille evalueringssæt.
- **Fastlåsning af model:** Henvis til model-id'er fra konfigurationen, så opgraderinger sker bevidst og er testet.

### Vigtigste pointer

- Messages API er tilstandsløs; send samtalehistorikken igen ved hvert kald.
- Direkte HTTP-godkendelse bruger x-api-key-headeren; SDK'er kan læse ANTHROPIC_API_KEY fra miljøet.
- De tre påkrævede anmodningsparametre er model, max_tokens og messages.
- Begynd med Opus 5.5, og sammenlign alternativerne på dine egne data.
- Systemprompts, streaming, vision, værktøjsbrug og historik over flere ture understøtter mange anvendelsesmønstre.
- Log tokenforbrug for at holde styr på omkostninger og kapacitet.

## FAQ

### Skal jeg kende til maskinlæring for at bruge Claude API?

Nej. Claude API er et REST API med officielle SDK'er til Python og TypeScript. Hvis du kan kalde et HTTP-endpoint og fortolke JSON, kan du bygge med Claude. Promptdesign, fejlhåndtering og omkostningsstyring er nyttige tekniske færdigheder; teori om maskinlæring er ikke nødvendig for at foretage et første API-kald.

### Hvilken Claude-model bør en nybegynder starte med?

Anthropic anbefaler at begynde med Claude Opus 5.5 (API-id `claude-opus-5-5`) til de fleste opgaver. Når dine prompts er stabile, kan du sammenligne de øvrige modeller på dine egne data.

### Husker Claude API tidligere samtaler?

Nej. Messages API er tilstandsløs. Din applikation gemmer samtalen og sender hele beskedhistorikken igen ved hver anmodning. Det giver dig kontrol over konteksten, mulighed for at forkorte eller opsummere ældre ture og mulighed for at kombinere det med prompt-caching.
