# ChatGPT API: Sådan konfigurerer du den, priser og kodeeksempler (2026)

> En praktisk vejledning til opsætning af ChatGPT API, sammenligning af modeller og priser samt udvikling af applikationer med kodeeksempler.



ChatGPT API giver udviklere programmatisk adgang til OpenAI-modeller. Denne vejledning gennemgår opsætning af API-nøgler, valg af modeller, priser, kodeeksempler og metoder til at bygge applikationer og styre omkostninger.

## Hvad er ChatGPT API?

ChatGPT API gør det muligt for udviklere at integrere AI-funktioner i applikationer via HTTP-anmodninger. Applikationer sender strukturerede anmodninger til OpenAI og modtager JSON-svar med modellens output.

### Sådan fungerer ChatGPT API

Processen følger fire trin:

**Du sender en anmodning.** Din applikation sender en POST-anmodning til OpenAI med en JSON-payload, der indeholder et modelnavn, meddelelser og parametre som temperatur og tokenbegrænsninger.

**OpenAI behandler anmodningen.** Modellen genererer et svar og returnerer det i et JSON-objekt. Når streaming er aktiveret, ankommer tokens løbende.

**Din applikation modtager svaret.** Svaret indeholder genereret indhold, tokenforbrug, modeloplysninger og et anmodnings-ID.

**Der opkræves betaling.** Gebyrerne afhænger af de behandlede tokens. Input- og outputtokens kan have forskellige priser.

Promptens længde, modelvalg og caching påvirker ydeevne og omkostninger.

## Sådan konfigurerer du ChatGPT API

Du skal bruge en API-nøgle til at godkende anmodninger. Behandl den som en hemmelighed, og opbevar den sikkert.

### Sådan får du en OpenAI API-nøgle

**Trin 1: Åbn OpenAI Platform**

- Gå til [platform.openai.com/api-keys](https://platform.openai.com/api-keys), og log ind eller opret en konto.

**Trin 2: Opret din API-nøgle**

- Åbn **API Keys** i kontrolpanelet.
- Vælg **Create new secret key**, og giv den eventuelt et projektspecifikt navn.
- Kopiér nøglen, når den vises; den vises muligvis ikke igen.

**Trin 3: Opbevar den sikkert**

- Opbevar nøglen i en adgangskodeadministrator eller som en miljøvariabel.
- Læg aldrig API-nøgler i versionsstyring, og eksponér dem ikke i kode på klientsiden.
- Hvis du bruger en `.env`-fil, skal du føje den til `.gitignore` og holde filen ude af versionsstyring.

**Sikkerhedsbemærkninger:**

- En nøgle kan give adgang, der er knyttet til din konto og fakturering.
- Opret en erstatningsnøgle, hvis du mister en nøgle.
- Tilbagekald nøgler, der kan være kompromitteret.
- Brug separate nøgler med passende begrænsede rettigheder til forskellige projekter, når det er muligt.

## Opsætning af dit udviklingsmiljø

API'et kan bruges fra ethvert programmeringssprog, der kan sende HTTP-anmodninger. Python, JavaScript og Java er almindelige valg.

### 1. Python: enkelt og med et rigt økosystem

Pythons syntaks og biblioteksøkosystem gør sproget til et almindeligt valg. OpenAI's Python-pakke kan forenkle godkendelse, formatering af anmodninger og fejlhåndtering. Pakker som `python-dotenv` kan hjælpe med at håndtere miljøvariabler.

Python bruges også inden for maskinlæring, datalogi, webudvikling og automatisering, hvilket gør det nyttigt til projekter, der kombinerer API-kald med databehandling.

### 2. JavaScript: fleksibilitet til webapplikationer

JavaScript fungerer til backend-applikationer med Node.js og til webapplikationer, der bruger frameworks som React, Vue eller Next.js. De asynkrone funktioner, herunder `async`/`await` og Promises, understøtter ikke-blokerende API-anmodninger.

### 3. Java: skalerbarhed og ydeevne

Java bruges ofte til virksomhedsapplikationer. Statisk typning kan fange nogle fejl ved kompilering, og sprogets funktioner til samtidighed kan hjælpe applikationer med at håndtere flere anmodninger. Det kan egne sig til software, der integreres med eksisterende Java-systemer.

Eksemplerne nedenfor bruger Python. Hvis du bruger JavaScript eller Java, skal du tilpasse syntaksen til dit sprog og SDK.
