# Harga API Moderation OpenAI: Percuma, Had Kadar dan Alternatif

> Model moderasi OpenAI adalah percuma. Lihat harga, had kadar mengikut peringkat penggunaan, contoh Python dan bila alternatif yang serasi dengan OpenAI lebih sesuai.




Endpoint Moderation OpenAI percuma untuk pengguna API OpenAI. Untuk memilih aliran kerja produksi, semak jenis input dan kategori yang disokong, had kadar akaun anda serta cara endpoint ini boleh digunakan dalam proses semakan anda.

Panduan ini memisahkan jawapan rasmi tentang harga daripada keputusan kejuruteraan praktikal.

## Ringkasan

- **Endpoint Moderation OpenAI adalah percuma untuk pengguna API OpenAI**, menurut Pusat Bantuan OpenAI.
- Model OpenAI `omni-moderation-latest` direka untuk mengesan kandungan berbahaya dan menerima teks serta imej sebagai input, menurut halaman model rasmi OpenAI.
- Harga percuma tidak menghapuskan kos aliran kerja seperti pengelogan, baris gilir semakan, pemetaan dasar, percubaan semula, tingkah laku sandaran dan keputusan khusus aplikasi.
- Pilih endpoint percuma OpenAI jika anda sudah menggunakan OpenAI secara langsung dan aliran kerja moderasi anda sesuai dengan kategorinya serta format responsnya.
- Pertimbangkan EvoLink Moderation 1.0 jika anda sudah menggunakan EvoLink dan mahukan semakan multimodal, ringkasan risiko serta pengebilan mengikut panggilan dalam satu aliran kerja.

## Adakah API Moderation OpenAI percuma?

Ya. Pusat Bantuan rasmi OpenAI menyatakan bahawa endpoint Moderation adalah percuma untuk pengguna API OpenAI dan penggunaan alat tersebut tidak dikira dalam had penggunaan bulanan.

Sumber: [Pusat Bantuan OpenAI: Adakah endpoint Moderation percuma untuk digunakan?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Itulah jawapan tentang harga. Soalan seterusnya bersifat operasi:

**Adakah endpoint moderasi percuma mencukupi untuk aliran kerja produksi anda?**

Untuk prototaip, alat dalaman dan moderasi ringkas yang mengutamakan teks, mungkin ya. Bagi aplikasi yang mengendalikan kandungan dijana pengguna, muat naik imej, ejen AI atau baris gilir semakan, panggilan API hanyalah satu bahagian daripada sistem.

## Apakah yang diliputi oleh moderasi OpenAI?

OpenAI mendokumenkan `omni-moderation-latest` sebagai model moderasi yang direka untuk mengenal pasti kandungan yang berpotensi berbahaya dalam teks dan imej. Halaman model rasmi menerangkannya sebagai model moderasi OpenAI yang paling berkebolehan dan menyenaraikan sokongan untuk input/output teks serta input imej. Sumber: [Halaman model OpenAI untuk omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Panduan moderasi OpenAI juga menerangkan kategori pengelasan kandungan dan menyatakan bahawa sesetengah kategori hanya menyokong teks. Jika anda menghantar imej sahaja kepada `omni-moderation-latest`, kategori yang tidak menyokong input imej akan mengembalikan skor 0. Sumber: [Panduan Moderation OpenAI](https://developers.openai.com/api/docs/guides/moderation)

Ini bermakna pasukan perlu membaca jadual kategori dengan teliti sebelum menganggap setiap kategori teks dipadankan secara langsung dengan moderasi imej.

## Kos sebenar ialah aliran kerja, bukan harga API semata-mata

Endpoint Moderation mungkin percuma, tetapi sistem moderasi produksi masih memerlukan keputusan tentang:

- tempat untuk menjalankan semakan: sebelum panggilan model, selepas respons model atau kedua-duanya
- cara memetakan kategori kepada keputusan benarkan, semak atau sekat
- cara mengelog hasil moderasi tanpa menyimpan kandungan sensitif secara tidak perlu
- cara mengendalikan positif palsu dan rayuan
- cara memoderasi muat naik imej secara berasingan daripada input teks
- cara memantau kependaman, ralat dan had kadar
- cara memastikan tingkah laku dasar konsisten merentas permukaan produk

Semua itu ialah kos kejuruteraan dan operasi. Kos tersebut tidak tertera pada halaman harga, tetapi menentukan sama ada lapisan moderasi benar-benar mudah diselenggara.

Dalam aliran kerja biasa, semak prompt sebelum dihantar kepada model dan semak output sebelum disampaikan kepada pengguna. Hantar hasil yang belum dapat diputuskan untuk semakan, simpan rekod keputusan setakat yang diperlukan dan sediakan prosedur untuk percubaan semula serta rayuan.

## Bila endpoint percuma OpenAI sesuai digunakan

Endpoint Moderation percuma OpenAI selalunya menjadi pilihan pertama yang baik apabila:

- anda sudah menggunakan OpenAI secara langsung
- aplikasi anda kebanyakannya mengutamakan teks
- anda hanya memerlukan kategori moderasi yang didokumenkan oleh OpenAI
- anda boleh membina aliran kerja semakan dan eskalasi sendiri
- pasukan anda selesa mengurus penghuraian respons, ambang dan log

Dalam keadaan itu, sukar untuk menolak endpoint percuma. Mulakan di situ, uji dengan kandungan sebenar anda dan ukur positif palsu serta kes yang terlepas sebelum menghalakan trafik produksi.

## Bila alternatif yang serasi dengan OpenAI sesuai

EvoLink Moderation 1.0 ialah alternatif berbayar dengan laluan `/v1/moderations` yang serasi dengan OpenAI. EvoLink menerima paling banyak satu imej bagi setiap permintaan.

- semakan teks sahaja, imej sahaja dan teks bersama imej melalui satu endpoint
- 13 kategori mudarat dengan skor bagi setiap kategori
- objek `evolink_summary` yang mengandungi `risk_level`, `flagged`, `violations`, `max_score` dan `max_category`
- harga rata bagi setiap panggilan, bukan pengiraan token
- bentuk respons yang lebih mudah dipetakan kepada logik benarkan, semak atau sekat

## Cara menggunakan API Moderation OpenAI dalam Python

Jika anda sudah menggunakan SDK OpenAI, panggilan moderasi teks asas kelihatan seperti ini:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Untuk EvoLink, tetapkan `EVOLINK_API_KEY` kepada kunci API EvoLink anda dan `EVOLINK_BASE_URL` kepada URL asas API HTTPS yang berakhir dengan `/v1`, seperti yang tertera dalam konfigurasi API EvoLink anda. Responsnya mengandungi objek tambahan `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Perbandingan harga dan aliran kerja OpenAI dengan EvoLink

| Kriteria | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Pengebilan | Percuma untuk pengguna API OpenAI | Caj pada kadar tetap bagi setiap panggilan |
| Bentuk endpoint utama | `/v1/moderations` | `/v1/moderations` yang serasi dengan OpenAI |
| Moderasi teks | Disokong | Disokong |
| Moderasi imej | Disokong oleh `omni-moderation-latest`, dengan sokongan input khusus mengikut kategori | Disokong untuk permintaan imej sahaja serta teks bersama imej |
| Medan untuk membuat keputusan mengikut dasar | Tafsir nilai `flagged`, `categories` dan `category_scores` dalam `results` | Gunakan `evolink_summary.risk_level` dan `violations` bersama skor setiap kategori |
| Pasukan yang paling sesuai | Pasukan yang sudah membuat panggilan terus ke OpenAI | Pasukan yang menyepadukan moderasi ke dalam aliran kerja EvoLink sedia ada |

## Saranan praktikal

Gunakan endpoint Moderation percuma OpenAI jika aplikasi anda sudah berasaskan OpenAI dan dasar moderasi anda sepadan dengan kategori yang didokumenkannya.

Jika pasukan anda sudah menggunakan EvoLink, nilai kos bagi setiap panggilan dan gunakan `evolink_summary.risk_level` sebagai salah satu input bagi peraturan aplikasi anda untuk membenarkan, menyemak atau menyekat kandungan.

Gunakan sistem moderasi berbilang lapisan jika aplikasi anda mempunyai keperluan dasar tersuai yang memerlukan peraturan jenama, semakan manusia, rayuan atau aliran kerja pematuhan di luar kemampuan mana-mana satu API moderasi.

## Soalan lazim

### Adakah API Moderation OpenAI percuma?

Ya. Pusat Bantuan OpenAI menyatakan bahawa endpoint Moderation adalah percuma untuk pengguna API OpenAI dan tidak dikira dalam had penggunaan bulanan.

### Adakah moderasi OpenAI menyokong imej?

Ya, `omni-moderation-latest` menerima imej sebagai input menurut halaman model rasmi OpenAI. Walau bagaimanapun, panduan moderasi OpenAI menyatakan bahawa sesetengah kategori hanya menyokong teks, jadi pasukan perlu menyemak sokongan input pada peringkat kategori sebelum bergantung pada moderasi imej sahaja.

### Adakah EvoLink Moderation lebih murah daripada OpenAI Moderation?

Endpoint Moderation OpenAI percuma untuk pengguna API OpenAI. EvoLink mengenakan caj pada kadar tetap bagi setiap panggilan. Bandingkan kos keseluruhan aliran kerja, termasuk semakan dan penyelenggaraan.

### Bolehkah saya menggunakan EvoLink sebagai alternatif kepada API Moderation OpenAI?

Ya. Gunakan kunci API EvoLink anda dan model `evolink-moderation-1.0` pada laluan `/v1/moderations` EvoLink yang serasi dengan OpenAI. Kemas kini cara anda memproses respons untuk mengendalikan objek tambahan `evolink_summary` dalam respons EvoLink.

### Patutkah saya memoderasi prompt, output atau kedua-duanya?

Bagi aplikasi AI produksi, banyak pasukan memoderasi input dan output. Moderasi input boleh mengurangkan permintaan tidak selamat sebelum sampai kepada model. Moderasi output boleh mengesan respons terjana yang tidak selamat sebelum sampai kepada pengguna.

### Apakah itu omni-moderation-latest?

Ini ialah model moderasi OpenAI untuk teks dan imej. Baca `flagged`, `categories` dan `category_scores` dalam `results`, kemudian laksanakan dasar moderasi anda sendiri.

### Apakah had kadar API Moderation OpenAI?

Akses percuma merujuk kepada pengebilan. Had bilangan permintaan dan token masih terpakai. Dalam [rujukan model](https://developers.openai.com/api/docs/models/omni-moderation-latest), RPM bermaksud bilangan permintaan seminit, RPD bermaksud bilangan permintaan sehari jika disenaraikan, dan TPM bermaksud bilangan token seminit.

Had kadar API Moderation OpenAI berbeza mengikut peringkat akaun dan boleh berubah dari semasa ke semasa. Semak [dokumentasi had kadar OpenAI](https://platform.openai.com/docs/guides/rate-limits) dan [halaman had penggunaan](https://platform.openai.com/settings/organization/limits) akaun anda sebelum merancang daya pemprosesan produksi.

### Bagaimanakah cara menggunakan API Moderation OpenAI dalam Python?

Pasang pakej `openai`, tetapkan `OPENAI_API_KEY`, kemudian panggil `client.moderations.create()` dengan model `omni-moderation-latest` dan teks yang hendak disemak. Untuk imej, hantar tatasusunan objek sebagai nilai `input`. Setiap item imej mempunyai `type: "image_url"` dan objek `image_url` yang mengandungi `url`, seperti yang ditunjukkan dalam rujukan API OpenAI yang dipautkan di bawah.
