# ChatGPT API: Cara Menyediakan, Harga dan Contoh Kod (2026)

> Panduan praktikal untuk menyediakan ChatGPT API, membandingkan model dan harga, serta membina aplikasi dengan contoh kod.



ChatGPT API memberikan pembangun akses programatik kepada model OpenAI. Panduan ini merangkumi penyediaan kunci API, pemilihan model, harga, contoh kod serta amalan untuk membina aplikasi dan mengurus kos.

## Apakah ChatGPT API?

ChatGPT API membolehkan pembangun mengintegrasikan keupayaan AI ke dalam aplikasi melalui permintaan HTTP. Aplikasi menghantar permintaan berstruktur kepada OpenAI dan menerima respons JSON yang mengandungi output model.

### Cara ChatGPT API Berfungsi

Proses ini mengikuti empat langkah:

**Anda menghantar permintaan.** Aplikasi anda menghantar permintaan POST kepada OpenAI dengan muatan JSON yang mengandungi nama model, mesej dan parameter seperti suhu serta had token.

**OpenAI memproses permintaan.** Model menjana respons dan mengembalikannya dalam objek JSON. Dengan penstriman diaktifkan, token tiba secara berperingkat.

**Aplikasi anda menerima respons.** Respons itu merangkumi kandungan yang dijana, penggunaan token, maklumat model dan ID permintaan.

**Pengebilan berlaku.** Caj bergantung pada token yang diproses. Token input dan output mungkin mempunyai kadar yang berbeza.

Panjang prompt, pemilihan model dan caching mempengaruhi prestasi dan kos.

## Model dan Harga ChatGPT API (2026)

Ketersediaan model, ciri dan harga boleh berubah. Semak [harga API](https://openai.com/api/pricing/) dan [dokumentasi pembangun](https://developers.openai.com/api/docs) OpenAI untuk butiran terkini. Harga biasanya berdasarkan token input dan output, yang mungkin mempunyai kadar yang berbeza.

### Model dan Keupayaan

Sumber ini menyenaraikan GPT-5.4, GPT-5.4 mini, GPT-5.4 nano, GPT-5.4 pro, GPT-5.2, GPT-5 mini, GPT-5 nano, GPT-4.1, GPT-4.1 mini, GPT-4.1 nano, o3, o4-mini dan o3-mini. Dakwaan khususnya tentang tarikh pelancaran, harga, tetingkap konteks, ketersediaan model dan keupayaan adalah sensitif terhadap masa dan hendaklah disemak dengan dokumentasi rasmi terkini sebelum digunakan.

### Cara Memilih Model

Pilih model berdasarkan tugas, keperluan kualiti, kependaman dan bajet anda. Uji calon model dengan beban kerja yang mewakili penggunaan sebenar dan bandingkan kualiti output serta kos.

- Sokongan pelanggan, soal jawab dan penjanaan kandungan: bandingkan model menggunakan permintaan yang mewakili penggunaan sebenar.
- Penjanaan kod, analisis dan aliran kerja ejen: nilai kualiti berdasarkan tugas anda sendiri.
- Pemahaman imej dan aplikasi multimodal: pastikan input yang disokong oleh model.
- Matematik dan penaakulan berbilang langkah: uji model penaakulan berbanding keperluan anda.
- Pengelasan dan pengekstrakan: pertimbangkan kadar pemprosesan dan kos bersama-sama ketepatan.

### 1. Tulis Prompt yang Jelas dan Khusus

Arahan yang jelas dan khusus boleh meningkatkan kegunaan respons.

- Nyatakan format, nada dan panjang yang dikehendaki.
- Berikan contoh apabila berguna.
- Gunakan arahan pembangun untuk menetapkan tingkah laku dan konteks.
- Bahagikan tugas yang rumit kepada langkah yang lebih kecil.

Contoh:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.
vague = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)
print(vague.choices[0].message.content)

# Specify the audience, deliverable, and focus.
specific = client.chat.completions.create(
    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)
print(specific.choices[0].message.content)
```

### 2. Gunakan Output Berstruktur untuk Data yang Boleh Dipercayai

Untuk JSON atau data berstruktur lain, gunakan ciri output berstruktur API dan bukannya menghuraikan teks bebas. Semak dokumentasi untuk format dan kekangan yang disokong.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Laksanakan Penstriman untuk Pengalaman Pengguna yang Lebih Baik

Penstriman boleh memaparkan kandungan respons sebaik sahaja ia tiba, tanpa menunggu respons lengkap.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Kendalikan Ralat dengan Baik

Permintaan mungkin gagal disebabkan masalah rangkaian, had kadar, input tidak sah atau gangguan perkhidmatan. Kendalikan ralat mengikut dokumentasi SDK dan API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 7. Laksanakan Had Kadar

### 8. Gunakan Panggilan Fungsi untuk Integrasi Alat

Panggilan fungsi membolehkan model meminta aplikasi anda memanggil fungsi atau alat. Aplikasi anda mengendalikan panggilan tersebut dan memulangkan hasil yang sesuai.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
