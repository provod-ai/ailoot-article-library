# Claude API untuk Pemula: Panduan Praktikal untuk Bermula

> Panduan Claude API untuk pemula: persediaan, permintaan pertama, pemilihan model, ciri utama dan amalan produksi.



Semua yang diperlukan oleh pembangun untuk membuat panggilan Claude API yang pertama: kunci, Messages API, pemilihan model dan konsep asas untuk beralih daripada permintaan pertama kepada penggunaan produksi.

## Apakah Claude API

Claude API ialah platform pembangun Anthropic. Platform ini menyediakan akses programatik kepada model Claude melalui Messages API, termasuk prompt sistem, penggunaan alat, penstriman, visi dan output berstruktur.

Messages API ialah endpoint HTTP tanpa keadaan. Anda menghantar senarai mesej pengguna dan pembantu, ID model dan had token; Claude memulangkan respons berstruktur. Endpoint sokongan termasuk kelompok, fail dan pengiraan token.

- **Tanpa keadaan:** API tidak menyimpan memori. Hantar semula sejarah perbualan dalam setiap panggilan.
- **Pemilihan model:** Menukar model biasanya bermaksud menukar ID model.
- **SDK:** Pustaka rasmi Python (anthropic) dan TypeScript (@anthropic-ai/sdk) menggunakan bentuk permintaan yang sepadan.

Memahami seni bina ini membantu mengelakkan kesilapan lazim pemula: menyangka API akan mengingati permintaan terdahulu.

## Langkah 1: Dapatkan kunci dan sediakan konsol

Pergi ke **console.anthropic.com**, cipta akaun atau organisasi untuk pasukan anda, kemudian jana kunci API di bahagian tetapan. Anggap kunci itu seperti kata laluan: simpan dalam pemboleh ubah persekitaran dan jangan sekali-kali memasukkannya ke dalam kawalan sumber.

Panggilan HTTP mentah menggunakan pengepala **x-api-key** dan pengepala **anthropic-version**. SDK membaca **ANTHROPIC_API_KEY** daripada persekitaran secara automatik, jadi kebanyakan kod tidak mengendalikan kunci itu secara langsung.

- Cipta kunci berasingan untuk pembangunan, staging dan produksi.
- Gunakan ruang kerja untuk mengasingkan projek dan perbelanjaan pasukan.
- Tetapkan had penggunaan dalam Konsol sebelum memberikan kunci kepada pasukan yang lebih besar.

## Langkah 2: Buat panggilan Messages API yang pertama

Pasang SDK dengan **pip install anthropic**, eksport kunci anda dan jalankan:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Tiga parameter diperlukan: **model**, **max_tokens** (siling output) dan **messages**. Respons mengandungi senarai blok kandungan. Semak jenis setiap blok dan jangan menganggapnya teks biasa, kerana penggunaan alat dan proses berfikir boleh menambah jenis blok lain. Objek **usage** melaporkan token input dan output, yang boleh digunakan sebagai telemetri kos.

## Langkah 3: Pilih model

Berikut ialah model Claude semasa daripada Anthropic dan ID API masing-masing.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — diterangkan sebagai pantas dan berkos rendah, untuk pengelasan dan tugasan mudah berjumlah besar.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — diterangkan sebagai pilihan yang seimbang untuk beban kerja produksi, termasuk pengekodan.
- **Claude Opus 5.5** (**claude-opus-5-5**) — diterangkan untuk penaakulan sukar dan kerja ejen jangka panjang.
- **Claude Fable 5.2** (**claude-fable-5-2**) — diterangkan sebagai model utama untuk tugasan penaakulan yang mencabar.

Mulakan dengan Opus 5.5. Cuba Sonnet 5.5 untuk mengimbangi kelajuan dan kualiti, Haiku 5.5 untuk tugasan mudah dalam jumlah besar dan Fable 5.2 untuk penaakulan yang rumit. Rujuk halaman harga Anthropic untuk kadar semasa.

## Lima konsep seterusnya untuk dipelajari

Selepas permintaan pertama berjaya, ciri-ciri ini memenuhi banyak keperluan aplikasi:

- **Prompt sistem** — parameter **system** peringkat atas yang menetapkan peranan, nada dan peraturan, berasingan daripada mesej pengguna.
- **Perbualan berbilang giliran** — tambahkan setiap balasan pembantu pada tatasusunan messages dan hantar semula; mesej pertama mestilah giliran pengguna.
- **Penstriman** — peristiwa dihantar oleh pelayan untuk menyampaikan token semasa dijana, yang boleh membantu antara muka sembang dan output panjang.
- **Visi** — hantar imej sebagai blok kandungan base64 atau URL bersama teks.
- **Penggunaan alat** — takrifkan fungsi dengan skema JSON; Claude boleh menentukan bila hendak memanggilnya, manakala kod anda melaksanakan fungsi itu dan memulangkan hasilnya.

Pertimbangkan **cache prompt** dan **pemprosesan kelompok** apabila kos penting, serta **output berstruktur** apabila kod hiliran perlu menghuraikan respons.

## Daripada tutorial kepada produksi

Peralihan daripada skrip yang berfungsi kepada integrasi produksi memerlukan disiplin kejuruteraan:

- **Pengendalian ralat:** Kendalikan ralat had kadar (429) dan ralat pelayan secara berasingan. Sumber menyatakan SDK mencuba semula ralat ini secara automatik dengan sela masa; semak tingkah laku semasa dalam dokumentasi SDK berkenaan.
- **Keterlihatan kos:** Log **usage** daripada setiap respons ke dalam sistem metrik anda.
- **Pemversian prompt:** Anggap prompt seperti kod: semak dan versikannya, kemudian uji menggunakan set penilaian kecil.
- **Penetapan model:** Rujuk ID model daripada konfigurasi supaya penaiktarafan dilakukan secara sengaja dan diuji.

### Perkara utama

- Messages API tidak menyimpan keadaan; hantar semula sejarah perbualan dalam setiap panggilan.
- Pengesahan HTTP mentah menggunakan pengepala x-api-key; SDK boleh membaca ANTHROPIC_API_KEY daripada persekitaran.
- Tiga parameter permintaan yang diperlukan ialah model, max_tokens dan messages.
- Mulakan dengan Opus 5.5 dan bandingkan pilihan lain menggunakan data anda sendiri.
- Prompt sistem, penstriman, visi, penggunaan alat dan sejarah berbilang giliran menyokong banyak corak aplikasi.
- Log penggunaan token untuk keterlihatan kos dan perancangan kapasiti.

## Soalan Lazim

### Perlukah saya tahu pembelajaran mesin untuk menggunakan Claude API?

Tidak. Claude API ialah REST API dengan SDK rasmi untuk Python dan TypeScript. Jika anda boleh memanggil endpoint HTTP dan menghuraikan JSON, anda boleh membina aplikasi dengan Claude. Reka bentuk prompt, pengendalian ralat dan pengurusan kos ialah kemahiran kejuruteraan yang berguna; teori pembelajaran mesin tidak diperlukan untuk membuat panggilan API pertama.

### Model Claude yang manakah patut digunakan oleh pemula?

Anthropic mengesyorkan bermula dengan Claude Opus 5.5 (ID API `claude-opus-5-5`) untuk kebanyakan beban kerja. Selepas prompt anda stabil, bandingkan model lain menggunakan data anda sendiri.

### Adakah Claude API mengingati perbualan terdahulu?

Tidak. Messages API tidak menyimpan keadaan. Aplikasi anda menyimpan perbualan dan menghantar semula keseluruhan sejarah mesej dalam setiap permintaan. Ini memberi anda kawalan terhadap konteks, membolehkan giliran lama dipendekkan atau diringkaskan, dan boleh digabungkan dengan cache prompt.
