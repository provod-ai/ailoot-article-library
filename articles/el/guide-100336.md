# Παρουσιάζουμε τους Managed Agents στο Gemini API

> Πρακτικός οδηγός για τους διαχειριζόμενους agents του Gemini API: επιλογή εργασιών, έλεγχος αποτελεσμάτων και σχεδιασμός για κόστος, ιδιωτικότητα και αποτυχίες.



Ένα αίτημα σε γλωσσικό μοντέλο συνήθως παράγει μια απάντηση· ένας agent μπορεί επίσης να εκτελέσει ενδιάμεσα βήματα προς ένα αποτέλεσμα. Για παράδειγμα, μπορεί να εξετάσει δεδομένα, να γράψει και να εκτελέσει κώδικα και να επιστρέψει αναφορά. Οι διαχειριζόμενοι agents της Google παρέχουν φιλοξενούμενο χώρο εργασίας για τέτοιες εργασίες μέσω του Gemini API. Η λειτουργία βρίσκεται σε προεπισκόπηση, οπότε ελέγξτε την τρέχουσα τεκμηρίωση και διαθεσιμότητα πριν την εντάξετε σε παραγωγική διαδικασία.

Ο οδηγός εξηγεί πώς να επιλέξετε μια πρώτη εργασία, να αξιολογήσετε το αποτέλεσμα και να σχεδιάσετε τη λειτουργική υποστήριξη ενός διαχειριζόμενου agent. Η [τεκμηρίωση Gemini API της Google](https://ai.google.dev/gemini-api/docs) παρέχει τα τρέχοντα παραδείγματα αιτημάτων και τα υποστηριζόμενα αναγνωριστικά agents.

## Τι διαχειρίζεται ο πάροχος;

Στην προσέγγιση διαχειριζόμενου agent, ο πάροχος εκτελεί το περιβάλλον και διαθέτει εργαλεία που μπορεί να χρησιμοποιήσει ο agent. Η Google περιγράφει ένα απομακρυσμένο sandbox όπου ο agent Antigravity μπορεί να χειρίζεται αρχεία, να εκτελεί κώδικα και να χρησιμοποιεί τον ιστό. Η εφαρμογή σας εξακολουθεί να πρέπει να ορίσει τον στόχο, να δώσει κατάλληλα δεδομένα εισόδου και να αποφασίσει αν το αποτέλεσμα είναι αποδεκτό.

Ένα φιλοξενούμενο περιβάλλον είναι χρήσιμο όταν η εργασία απαιτεί πολλά βήματα και ενδιάμεσο χώρο εργασίας. Δεν υποκαθιστά τις αποφάσεις της εφαρμογής για εξουσιοδότηση, έλεγχο ή χειρισμό δεδομένων. Ελέγξτε ποια εργαλεία και ρυθμίσεις περιβάλλοντος είναι διαθέσιμα για το έργο και την έκδοσή σας πριν βασιστείτε σε αυτά.

## Επιλέξτε μια πρώτη εργασία με σαφή όρια

Ξεκινήστε με εργασία της οποίας το αποτέλεσμα ελέγχεται χωρίς να εμπιστευτείτε την εξήγηση του agent. Ένα μικρό σύνολο CSV για σύνοψη είναι καλό παράδειγμα: δώστε μη ευαίσθητο δείγμα, ζητήστε πίνακα συνόλων και ορίστε τη μορφή εξόδου. Υπολογίστε ανεξάρτητα μερικά σύνολα και συγκρίνετέ τα με το αποτέλεσμα.

Μια χρήσιμη περιγραφή εργασίας περιλαμβάνει:

- Την είσοδο και τη σημασία κάθε πεδίου.
- Την επιθυμητή έξοδο, όπως σύνοψη και αρχείο CSV.
- Κανόνες για ελλείπουσες ή μη έγκυρες τιμές.
- Όρια στα δεδομένα και στα εργαλεία που επιτρέπεται να χρησιμοποιήσει ο agent.
- Ελέγχους που μπορεί να εκτελέσει ο παραλήπτης πριν χρησιμοποιήσει το αποτέλεσμα.

Για παράδειγμα: «Σύνοψισε αυτό το δείγμα πωλήσεων CSV ανά μήνα και νόμισμα. Μην συνδυάσεις νομίσματα. Κατάγραψε χωριστά τις γραμμές χωρίς ημερομηνία και δώσε τους υπολογισμούς για κάθε σύνολο». Στην αρχική δοκιμή αποφύγετε να ζητήσετε αποστολή μηνυμάτων, αλλαγή δεδομένων παραγωγής ή άλλες εξωτερικές ενέργειες.

## Εκτελέστε και εξετάστε μια αλληλεπίδραση

Χρησιμοποιήστε τον [οδηγό έναρξης της Google](https://ai.google.dev/gemini-api/docs/get-started) για να ρυθμίσετε το SDK και τα διαπιστευτήρια και ακολουθήστε το παράδειγμα διαχειριζόμενου agent. Το παράδειγμα παρέχει αναγνωριστικό agent, είσοδο και απομακρυσμένο περιβάλλον. Χρησιμοποιήστε το αναγνωριστικό που τεκμηριώνει τώρα η Google, χωρίς να θεωρείτε ότι ένα παλιό αναγνωριστικό προεπισκόπησης παραμένει διαθέσιμο.

Εξετάστε περισσότερα από την τελική παράγραφο. Ελέγξτε την επιστρεφόμενη κατάσταση, την έξοδο και τα αρχεία που σκοπεύετε να χρησιμοποιήσετε. Σε εργασία δεδομένων συγκρίνετε τους αριθμούς με την πηγή· για παραγόμενο script, εξετάστε και δοκιμάστε το σε ελεγχόμενο περιβάλλον. Αν η εργασία βασίζεται σε πληροφορίες από τον ιστό, ανοίξτε τις πηγές που παρατίθενται και ελέγξτε αν υποστηρίζουν τους ισχυρισμούς. Ένα καλοδιατυπωμένο αποτέλεσμα μπορεί να περιέχει λάθος.

Αν συνεχίζετε την εργασία σε πολλαπλές αλληλεπιδράσεις, ακολουθήστε τον τεκμηριωμένο από την Google κύκλο ζωής περιβάλλοντος και αλληλεπίδρασης. Διατηρήστε τα σχετικά αναγνωριστικά στην εγγραφή της εργασίας της εφαρμογής και χειριστείτε ρητά τη λήξη ή την αποτυχία· μην υποθέτετε ότι ένας χώρος εργασίας θα διατηρείται επ’ αόριστον.

## Δώστε σαφείς οδηγίες σε έναν προσαρμοσμένο agent

Η Google τεκμηριώνει επίσης τρόπους παροχής προσαρμοσμένων οδηγιών, skills και δεδομένων σε διαχειριζόμενους agents. Χρησιμοποιήστε τις δυνατότητες αυτές για να περιγράψετε την εργασία και τις απαιτήσεις εξόδου, όχι για να ενσωματώσετε μυστικά σε έγγραφο. Σε εργασία αναφοράς, οι οδηγίες μπορούν να ορίζουν την ομαδοποίηση δεδομένων, τη σήμανση της αβεβαιότητας και τις ενέργειες όταν ένας υπολογισμός δεν ολοκληρώνεται.

Διατηρήστε τα αρχεία οδηγιών σε έλεγχο εκδόσεων και εξετάζετε τις αλλαγές όπως στον κώδικα της εφαρμογής. Δοκιμάστε μια νέα έκδοση με μικρό σύνολο αντιπροσωπευτικών εισόδων, όπως κενά αρχεία, απρόσμενες τιμές και αίτημα εκτός προβλεπόμενου πεδίου. Καταγράψτε την έκδοση και την είσοδο κάθε αξιολόγησης, ώστε να μπορείτε να διερευνήσετε αλλαγές στην έξοδο.

## Σχεδιάστε για κόστος, ιδιωτικότητα και αποτυχία

Ένας agent πολλών βημάτων μπορεί να κάνει αρκετές κλήσεις μοντέλου ή να χρησιμοποιήσει εργαλεία πριν επιστρέψει αποτέλεσμα. Δείτε τη [σελίδα τιμών της Google](https://ai.google.dev/gemini-api/docs/pricing) και τα όρια του έργου σας πριν από δοκιμή· οι χρεώσεις και οι όροι προεπισκόπησης μπορεί να αλλάξουν. Μετρήστε τη χρήση σε αντιπροσωπευτικές εργασίες και ορίστε προϋπολογισμό σε επίπεδο εφαρμογής κατάλληλο για τον φόρτο σας.

Στείλτε μόνο δεδομένα που επιτρέπεται να επεξεργαστεί η διαδικασία. Αντιμετωπίστε τις ανακτημένες σελίδες και τα μεταφορτωμένα αρχεία ως μη έμπιστη είσοδο και εξετάστε τον παραγόμενο κώδικα πριν τον εκτελέσετε εκτός sandbox. Ορίστε τι συμβαίνει αν λήξει ο χρόνος μιας εργασίας, αποτύχει ένα εργαλείο ή ο agent επιστρέψει ελλιπές αποτέλεσμα. Η επανάληψη εργασίας με παρενέργειες μπορεί να τις προκαλέσει ξανά, γι’ αυτό ελέγξτε την αρχική ενέργεια πριν επαναλάβετε.

## Πότε να χρησιμοποιήσετε διαχειριζόμενο agent;

Αξίζει να αξιολογήσετε έναν διαχειριζόμενο agent για οριοθετημένη έρευνα, ανάλυση ή παραγωγή αρχείων, όπου βοηθούν πολλά βήματα με εργαλεία και το αποτέλεσμα μπορεί να ελεγχθεί από άνθρωπο ή αυτόματο έλεγχο. Ένα άμεσο αίτημα μοντέλου ή συνηθισμένος κώδικας εφαρμογής μπορεί να είναι ευκολότερος στη λειτουργία για έναν μεμονωμένο προβλέψιμο μετασχηματισμό. Συγκρίνετε τις προσεγγίσεις ως προς ποιότητα, καθυστέρηση, κόστος και απαιτούμενο έλεγχο.

Η παραπάνω διαδικασία διαχειριζόμενου agent χρησιμοποιεί το Gemini API της Google. Η Ailoot προσφέρει το δικό της API για πρόσβαση σε μοντέλα AI.
