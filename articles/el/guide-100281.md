# Τιμολόγηση OpenAI Moderation API: δωρεάν χρήση, όρια ρυθμού και εναλλακτικές

> Τα μοντέλα εποπτείας περιεχομένου της OpenAI είναι δωρεάν. Δείτε τις τιμές, τα όρια ρυθμού ανά επίπεδο χρήσης, παραδείγματα Python και πότε ταιριάζει καλύτερα μια εναλλακτική συμβατή με το OpenAI.




Το endpoint Moderation της OpenAI είναι δωρεάν για τους χρήστες του OpenAI API. Για να επιλέξετε ροή εργασίας για χρήση στην παραγωγή, ελέγξτε τις υποστηριζόμενες εισόδους και κατηγορίες, τα όρια ρυθμού του λογαριασμού σας και πώς εντάσσεται το endpoint στη διαδικασία ελέγχου σας.

Αυτός ο οδηγός διαχωρίζει την επίσημη απάντηση για την τιμολόγηση από την πρακτική απόφαση μηχανικής.

## Με λίγα λόγια

- **Το endpoint Moderation της OpenAI είναι δωρεάν για τους χρήστες του OpenAI API**, σύμφωνα με το Κέντρο βοήθειας της OpenAI.
- Το μοντέλο `omni-moderation-latest` της OpenAI έχει σχεδιαστεί για τον εντοπισμό επιβλαβούς περιεχομένου και δέχεται κείμενο και εικόνες ως είσοδο, σύμφωνα με την επίσημη σελίδα μοντέλων της OpenAI.
- Η δωρεάν τιμολόγηση δεν καταργεί τα λειτουργικά έξοδα της ροής εργασίας, όπως η καταγραφή, οι ουρές ελέγχου, η αντιστοίχιση πολιτικών, οι επαναλήψεις, η εφεδρική συμπεριφορά και οι αποφάσεις που αφορούν συγκεκριμένες εφαρμογές.
- Επιλέξτε το δωρεάν endpoint της OpenAI, αν χρησιμοποιείτε ήδη απευθείας την OpenAI και η ροή εποπτείας περιεχομένου σας ταιριάζει στις κατηγορίες και τη μορφή απόκρισής της.
- Εξετάστε το EvoLink Moderation 1.0 αν χρησιμοποιείτε ήδη την EvoLink και θέλετε πολυτροπικούς ελέγχους, σύνοψη κινδύνου και χρέωση ανά κλήση στην ίδια ροή εργασίας.

## Είναι δωρεάν το OpenAI Moderation API;

Ναι. Το επίσημο Κέντρο βοήθειας της OpenAI αναφέρει ότι το endpoint Moderation είναι δωρεάν για τους χρήστες του OpenAI API και ότι η χρήση του εργαλείου δεν προσμετράται στα μηνιαία όρια χρήσης.

Πηγή: [Κέντρο βοήθειας OpenAI: Είναι δωρεάν η χρήση του endpoint Moderation;](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Αυτή είναι η απάντηση για την τιμολόγηση. Το επόμενο ερώτημα είναι λειτουργικό:

**Αρκεί ένα δωρεάν endpoint εποπτείας περιεχομένου για τη ροή εργασίας παραγωγής σας;**

Για πρωτότυπα, εσωτερικά εργαλεία και απλή εποπτεία περιεχομένου με έμφαση στο κείμενο, μπορεί να αρκεί. Για εφαρμογές που διαχειρίζονται περιεχόμενο που δημιουργούν οι χρήστες, μεταφορτώσεις εικόνων, πράκτορες AI ή ουρές ελέγχου, η κλήση API είναι μόνο ένα μέρος του συστήματος.

## Τι καλύπτει η εποπτεία περιεχομένου της OpenAI;

Η OpenAI περιγράφει το `omni-moderation-latest` ως μοντέλο εποπτείας περιεχομένου σχεδιασμένο για τον εντοπισμό δυνητικά επιβλαβούς περιεχομένου σε κείμενο και εικόνες. Η επίσημη σελίδα μοντέλων το περιγράφει ως το πιο προηγμένο μοντέλο εποπτείας περιεχομένου της OpenAI και αναφέρει υποστήριξη για είσοδο και έξοδο κειμένου, καθώς και είσοδο εικόνας. Πηγή: [Σελίδα μοντέλου της OpenAI για το omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Ο οδηγός εποπτείας περιεχομένου της OpenAI εξηγεί επίσης τις κατηγορίες ταξινόμησης περιεχομένου και σημειώνει ότι ορισμένες κατηγορίες υποστηρίζουν μόνο κείμενο. Αν στείλετε μόνο εικόνες στο `omni-moderation-latest`, οι κατηγορίες που δεν υποστηρίζουν είσοδο εικόνας επιστρέφουν βαθμολογία 0. Πηγή: [Οδηγός εποπτείας περιεχομένου της OpenAI](https://developers.openai.com/api/docs/guides/moderation)

Αυτό σημαίνει ότι οι ομάδες πρέπει να μελετήσουν προσεκτικά τον πίνακα κατηγοριών πριν υποθέσουν ότι κάθε κατηγορία κειμένου αντιστοιχεί άμεσα σε εποπτεία εικόνων.

## Το πραγματικό κόστος αφορά τη ροή εργασίας, όχι μόνο την τιμολόγηση του API

Το endpoint Moderation μπορεί να είναι δωρεάν, αλλά ένα σύστημα εποπτείας περιεχομένου παραγωγής εξακολουθεί να απαιτεί αποφάσεις σχετικά με τα εξής:

- πού θα εκτελούνται οι έλεγχοι: πριν από τις κλήσεις μοντέλων, μετά τις αποκρίσεις μοντέλων ή και στα δύο σημεία
- πώς θα αντιστοιχίζονται οι κατηγορίες σε αποφάσεις για αποδοχή, έλεγχο ή αποκλεισμό
- πώς θα καταγράφονται τα αποτελέσματα εποπτείας περιεχομένου χωρίς περιττή αποθήκευση ευαίσθητου περιεχομένου
- πώς θα αντιμετωπίζονται τα ψευδώς θετικά και οι ενστάσεις
- πώς θα εποπτεύονται χωριστά οι μεταφορτώσεις εικόνων από την είσοδο κειμένου
- πώς θα παρακολουθούνται οι καθυστερήσεις, τα σφάλματα και τα όρια ρυθμού
- πώς θα διατηρείται συνεπής η εφαρμογή πολιτικών σε διαφορετικές επιφάνειες του προϊόντος

Αυτά είναι κόστη μηχανικής και λειτουργίας. Δεν εμφανίζονται σε μια σελίδα τιμολόγησης, αλλά καθορίζουν αν το επίπεδο εποπτείας περιεχομένου είναι πράγματι συντηρήσιμο.

Σε μια τυπική ροή εργασίας, ελέγχετε τα prompts πριν τα στείλετε στο μοντέλο και τα αποτελέσματα πριν τα παραδώσετε. Παραπέμπετε τις αβέβαιες περιπτώσεις για έλεγχο, τηρείτε μόνο τα αναγκαία στοιχεία για τις αποφάσεις και προβλέπετε διαδικασίες για επαναλήψεις αιτημάτων και ενστάσεις.

## Πότε ταιριάζει το δωρεάν endpoint της OpenAI

Το δωρεάν endpoint Moderation της OpenAI είναι συχνά μια καλή αρχική επιλογή όταν:

- χρησιμοποιείτε ήδη απευθείας την OpenAI
- η εφαρμογή σας βασίζεται κυρίως στο κείμενο
- χρειάζεστε μόνο τις τεκμηριωμένες κατηγορίες εποπτείας περιεχομένου της OpenAI
- μπορείτε να δημιουργήσετε τη δική σας ροή ελέγχου και κλιμάκωσης
- η ομάδα σας είναι διατεθειμένη να αναλάβει την ανάλυση των αποκρίσεων, τα κατώφλια και τα αρχεία καταγραφής

Σε αυτή την περίπτωση, είναι δύσκολο να αμφισβητήσει κανείς την επιλογή του δωρεάν endpoint. Ξεκινήστε από αυτό, δοκιμάστε το με το πραγματικό σας περιεχόμενο και μετρήστε τα ψευδώς θετικά και τις περιπτώσεις που δεν εντοπίστηκαν πριν δρομολογήσετε σε αυτό την κίνηση παραγωγής.

## Πότε έχει νόημα μια εναλλακτική συμβατή με το OpenAI

Το EvoLink Moderation 1.0 είναι μια επί πληρωμή εναλλακτική με διαδρομή `/v1/moderations` συμβατή με την OpenAI. Η EvoLink δέχεται το πολύ μία εικόνα ανά αίτημα.

- έλεγχοι μόνο κειμένου, μόνο εικόνων και κειμένου μαζί με εικόνες μέσω ενός endpoint
- 13 κατηγορίες βλάβης με βαθμολογίες ανά κατηγορία
- ένα αντικείμενο `evolink_summary` με τα πεδία `risk_level`, `flagged`, `violations`, `max_score` και `max_category`
- σταθερή χρέωση ανά κλήση αντί για υπολογισμό με βάση τα token
- μορφή απόκρισης που αντιστοιχίζεται ευκολότερα στη λογική αποδοχής, ελέγχου ή αποκλεισμού

## Πώς να χρησιμοποιήσετε το OpenAI Moderation API σε Python

Αν χρησιμοποιείτε ήδη το OpenAI SDK, μια βασική κλήση εποπτείας κειμένου μοιάζει ως εξής:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Ως `EVOLINK_API_KEY` ορίστε το κλειδί σας στην EvoLink και ως `EVOLINK_BASE_URL` τη βασική διεύθυνση HTTPS του API από τις ρυθμίσεις της EvoLink. Η διεύθυνση πρέπει να τελειώνει σε `/v1`. Η απόκριση περιλαμβάνει επιπλέον το αντικείμενο `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Σύγκριση OpenAI και EvoLink ως προς τη χρέωση και τη ροή εργασίας

| Κριτήριο | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Χρέωση | Δωρεάν για τους χρήστες του OpenAI API | Σταθερή χρέωση ανά κλήση |
| Μορφή κύριου endpoint | `/v1/moderations` | OpenAI-compatible `/v1/moderations` |
| Εποπτεία κειμένου | Υποστηρίζεται | Υποστηρίζεται |
| Εποπτεία εικόνων | Υποστηρίζεται από το `omni-moderation-latest`, με υποστήριξη εισόδου ανά κατηγορία | Υποστηρίζεται για αιτήματα μόνο με εικόνες και για αιτήματα με κείμενο και εικόνες |
| Πεδία για αποφάσεις βάσει πολιτικής | Ερμηνεύστε τα `flagged`, `categories` και `category_scores` στο `results` | Χρησιμοποιήστε τα `evolink_summary.risk_level` και `violations` μαζί με τις βαθμολογίες ανά κατηγορία |
| Κατάλληλο για | Ομάδες που πραγματοποιούν ήδη απευθείας κλήσεις στην OpenAI | Ομάδες που εντάσσουν την εποπτεία περιεχομένου στην υπάρχουσα ροή εργασίας τους με την EvoLink |

## Συχνές ερωτήσεις

### Είναι δωρεάν το OpenAI Moderation API;

Ναι. Το Κέντρο βοήθειας της OpenAI αναφέρει ότι το endpoint Moderation είναι δωρεάν για τους χρήστες του OpenAI API και δεν προσμετράται στα μηνιαία όρια χρήσης.

### Υποστηρίζει εικόνες η εποπτεία περιεχομένου της OpenAI;

Ναι, το `omni-moderation-latest` δέχεται εικόνες ως είσοδο, σύμφωνα με την επίσημη σελίδα μοντέλων της OpenAI. Ωστόσο, ο οδηγός εποπτείας περιεχομένου της OpenAI σημειώνει ότι ορισμένες κατηγορίες υποστηρίζουν μόνο κείμενο, οπότε οι ομάδες πρέπει να ελέγχουν την υποστήριξη εισόδου ανά κατηγορία πριν βασιστούν στην εποπτεία περιεχομένου μόνο μέσω εικόνων.

### Είναι το EvoLink Moderation φθηνότερο από το OpenAI Moderation;

Το endpoint Moderation της OpenAI είναι δωρεάν για τους χρήστες του OpenAI API. Η EvoLink εφαρμόζει σταθερή χρέωση ανά κλήση. Συγκρίνετε το κόστος ολόκληρης της ροής εργασίας, μαζί με τον έλεγχο και τη συντήρηση.

### Μπορώ να χρησιμοποιήσω την EvoLink ως εναλλακτική λύση στο OpenAI Moderation API;

Ναι. Χρησιμοποιήστε το κλειδί σας για το EvoLink API και το μοντέλο `evolink-moderation-1.0` στη συμβατή διαδρομή `/v1/moderations` της EvoLink. Προσαρμόστε την επεξεργασία της απόκρισης ώστε να χειρίζεται το ξεχωριστό αντικείμενο `evolink_summary`.

### Πρέπει να εποπτεύω τα prompts, τις εξόδους ή και τα δύο;

Για εφαρμογές AI παραγωγής, πολλές ομάδες εποπτεύουν τόσο τις εισόδους όσο και τις εξόδους. Η εποπτεία εισόδου μπορεί να μειώσει τα μη ασφαλή αιτήματα πριν φτάσουν σε ένα μοντέλο. Η εποπτεία εξόδου μπορεί να εντοπίσει μη ασφαλείς παραγόμενες αποκρίσεις πριν φτάσουν στους χρήστες.

### Τι είναι το omni-moderation-latest;

Είναι το μοντέλο της OpenAI για την εποπτεία κειμένου και εικόνων. Διαβάστε τα `flagged`, `categories` και `category_scores` στο `results` και εφαρμόστε τη δική σας πολιτική εποπτείας περιεχομένου.

### Ποιο είναι το όριο ρυθμού για το OpenAI Moderation API;

Η δωρεάν πρόσβαση αφορά τη χρέωση. Τα όρια για τα αιτήματα και τα token εξακολουθούν να ισχύουν. Στην [τεκμηρίωση του μοντέλου](https://developers.openai.com/api/docs/models/omni-moderation-latest), το RPM σημαίνει αιτήματα ανά λεπτό, το RPD αιτήματα ανά ημέρα όπου αναφέρεται αυτό το όριο και το TPM token ανά λεπτό.

Τα όρια ρυθμού του OpenAI Moderation API διαφέρουν ανάλογα με το επίπεδο λογαριασμού και μπορεί να αλλάξουν με την πάροδο του χρόνου. Ελέγξτε την [τεκμηρίωση ορίων ρυθμού της OpenAI](https://platform.openai.com/docs/guides/rate-limits) και τη [σελίδα ορίων χρήσης](https://platform.openai.com/settings/organization/limits) του λογαριασμού σας πριν σχεδιάσετε τη διεκπεραιωτική ικανότητα παραγωγής.

### Πώς χρησιμοποιώ το OpenAI Moderation API σε Python;

Εγκαταστήστε το πακέτο `openai`, ορίστε το `OPENAI_API_KEY` και καλέστε τη μέθοδο `client.moderations.create()` με το μοντέλο `omni-moderation-latest` και το κείμενό σας. Για εικόνες, περάστε το `input` ως πίνακα αντικειμένων. Κάθε στοιχείο εικόνας έχει `type: "image_url"` και ένα αντικείμενο `image_url` που περιέχει το `url`, όπως δείχνει η τεκμηρίωση του OpenAI API στον σύνδεσμο παρακάτω.
