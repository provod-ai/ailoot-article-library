# LLM ως κριτής: Χρήση τεχνητής νοημοσύνης για την αξιολόγηση τεχνητής νοημοσύνης (με αξιοπιστία)

> Πώς να χρησιμοποιείτε γλωσσικά μοντέλα για την αξιολόγηση αποτελεσμάτων τεχνητής νοημοσύνης, να συνυπολογίζετε τη μεροληψία του κριτή, να σχεδιάζετε ρουμπρίκες και να βαθμονομείτε αυτοματοποιημένες βαθμολογίες με βάση ανθρώπινες κρίσεις.



Ένα γλωσσικό μοντέλο ως κριτής εφαρμόζει γραπτά κριτήρια σε μια απάντηση άλλου μοντέλου. Μπορεί να βοηθήσει τις ομάδες να εξετάσουν μεγάλα σύνολα απαντήσεων, όμως οι κρίσεις του πρέπει να ελέγχονται σε σύγκριση με παραδείγματα που έχουν αξιολογήσει άνθρωποι.

## Ξεκινήστε με μια εργασία και κριτήρια αξιολόγησης

Επιλέξτε μία εργασία, όπως η απάντηση σε ερωτήσεις υποστήριξης βάσει μιας παρεχόμενης πολιτικής. Περιγράψτε την αναμενόμενη συμπεριφορά με παρατηρήσιμους όρους. Για παράδειγμα, ελέγξτε αν η απάντηση ακολουθεί την πολιτική, απαντά στην ερώτηση και αποφεύγει ατεκμηρίωτους ισχυρισμούς. Τα κριτήρια πρέπει επίσης να ορίζουν τι γίνεται όταν λείπουν στοιχεία.

Χρησιμοποιήστε χωριστά κριτήρια πριν καταλήξετε σε συνολικό αποτέλεσμα. Μια απάντηση μπορεί να είναι σύντομη αλλά ανακριβής· μία μόνο βαθμολογία μπορεί να κρύψει αυτή τη διαφορά. Διατηρήστε τα κριτήρια και την έκδοση του μοντέλου κριτή μαζί με τα αποτελέσματα, ώστε οι μεταγενέστερες συγκρίσεις να έχουν το κατάλληλο πλαίσιο.

## Επιλέξτε τρόπο σύγκρισης

Για έλεγχο επιτυχίας ή αποτυχίας, δώστε στον κριτή την ερώτηση, τα διαθέσιμα στοιχεία και μία απάντηση. Ζητήστε απόφαση για κάθε κριτήριο και σύντομη αιτιολόγηση που βασίζεται στο παρεχόμενο υλικό. Η μέθοδος λειτουργεί καλύτερα όταν τα κριτήρια είναι αρκετά συγκεκριμένα ώστε οι αξιολογητές να τα εφαρμόζουν με συνέπεια.

Για σύγκριση, δώστε στον κριτή δύο απαντήσεις στην ίδια ερώτηση και ζητήστε ποια ανταποκρίνεται καλύτερα στα κριτήρια, επιτρέποντας ισοπαλία. Επαναλάβετε με αντίστροφη σειρά. Αν αλλάξει ο νικητής, σημειώστε την περίπτωση για έλεγχο αντί να θεωρήσετε κάποιο αποτέλεσμα οριστικό. Αφαιρέστε περιττές ετικέτες που αποκαλύπτουν ποιο σύστημα παρήγαγε την απάντηση.

Μια απάντηση αναφοράς μπορεί να βοηθήσει όταν η σωστή απάντηση είναι γνωστή. Σε ανοικτές εργασίες, αντιμετωπίστε την ως παράδειγμα αποδεκτής ποιότητας και όχι ως τη μόνη έγκυρη διατύπωση.

## Κάντε τα αποτελέσματα αξιοποιήσιμα

Ζητήστε δομημένο αποτέλεσμα με απόφαση και σύντομη αιτία για κάθε κριτήριο. Για παράδειγμα:

```json
{"policy_supported":{"result":"pass","reason":"Η απάντηση παραπέμπει στον παρεχόμενο κανόνα ακύρωσης."},"addresses_question":{"result":"fail","reason":"Δεν εξηγεί πώς γίνεται η ακύρωση."}}
```

Αυτό είναι παράδειγμα πιθανής απάντησης, όχι απόδειξη ότι ένας κριτής εξέτασε πραγματική περίπτωση. Ελέγξτε την εγκυρότητα του αποτελέσματος πριν το χρησιμοποιήσετε σε αναφορά· επαναλάβετε ή στείλτε τα κακοσχηματισμένα αποτελέσματα για έλεγχο σύμφωνα με τη διαδικασία σας. Η εξήγηση του μοντέλου είναι και η ίδια αποτέλεσμα προς έλεγχο, όχι απόδειξη ορθής κρίσης.

## Βαθμονομήστε με ανθρώπους

Δημιουργήστε αντιπροσωπευτικό δείγμα με απλές περιπτώσεις, οριακές περιπτώσεις και γνωστές αποτυχίες. Ζητήστε από αξιολογητές να εφαρμόσουν ανεξάρτητα τα ίδια κριτήρια σε κοινό υποσύνολο, να συζητήσουν τις διαφωνίες και να καταγράψουν τις αποφάσεις. Έπειτα συγκρίνετε τα αποτελέσματα του κριτή με τις ανθρώπινες αξιολογήσεις, εξετάστε τις διαφωνίες και αναθεωρήστε τα κριτήρια ή τη διαδικασία πριν βασιστείτε στη μέτρηση.

Προσέξτε ιδιαίτερα τη σειρά, το μήκος και το ύφος. Μια καλοδιατυπωμένη ή μεγαλύτερη απάντηση δεν είναι απαραίτητα ακριβέστερη. Συμπεριλάβετε σύντομες σωστές και πειστικές λανθασμένες απαντήσεις. Στις συγκρίσεις ανά ζεύγη, μετρήστε πόσο συχνά αλλάζει η απόφαση όταν αντιστρέφεται η σειρά.

## Χρησιμοποιήστε τον κριτή ως ένα επίπεδο ελέγχου

Εκτελέστε πρώτα ντετερμινιστικούς ελέγχους όπου ταιριάζουν, όπως έλεγχο JSON ή απαιτούμενου πεδίου. Χρησιμοποιήστε τον κριτή για κριτήρια που απαιτούν ερμηνεία και διατηρήστε τον ανθρώπινο έλεγχο για αβέβαιες ή σημαντικές περιπτώσεις. Παρακολουθήστε συγκεντρωτικά αποτελέσματα σε σταθερό σύνολο δεδομένων, αλλά εξετάστε και τις μεμονωμένες αποτυχίες.

Ελέγξτε ξανά τη βαθμονόμηση όταν αλλάζει το μοντέλο, τα κριτήρια, η εργασία ή η κατανομή εισόδου. Μια υψηλότερη βαθμολογία από μόνη της δεν αποδεικνύει βελτίωση: εξετάστε τις απαντήσεις και κρατήστε χωριστό σύνολο αξιολόγησης όταν η ίδια αυτοματοποιημένη μέτρηση χρησιμοποιείται για τη βελτιστοποίηση του συστήματος.

## Πρακτική λίστα ελέγχου

1. Ορίστε την εργασία, τα διαθέσιμα στοιχεία και τα κριτήρια.
2. Συλλέξτε παραδείγματα και συμφωνήστε στις ανθρώπινες αξιολογήσεις.
3. Επιλέξτε αξιολόγηση μίας απάντησης ή σύγκριση ανά ζεύγη και ορίστε αποτέλεσμα ισοπαλίας ή αβεβαιότητας.
4. Ελέγξτε τα δομημένα αποτελέσματα και εξετάστε τις διαφωνίες.
5. Παρακολουθήστε τις εκδόσεις και βαθμονομήστε ξανά μετά από ουσιαστικές αλλαγές.

Για περισσότερες πληροφορίες, δείτε τις [συστάσεις της OpenAI για την αξιολόγηση](https://platform.openai.com/docs/guides/evaluation-best-practices).
