Πώς αλληλεπιδρούν οι πύλες, η δρομολόγηση, η προσωρινή αποθήκευση και η εξυπηρέτηση μοντέλων, και πώς το πλαίσιο ενός αιτήματος μπορεί να μεταφέρεται σε αυτά τα επίπεδα.

Το πλαίσιο ενός αιτήματος μπορεί να περάσει μέσω μιας πύλης και ενός δρομολογητή και να φτάσει στην εξυπηρέτηση μοντέλων. Αυτό το πλαίσιο συνδέει την επιλογή μοντέλου, την επαναχρησιμοποίηση της cache και την εκτέλεση με την ταυτότητα του καλούντος και το κόστος κάθε προσπάθειας. Ένας δρομολογητής που αγνοεί την κατάσταση της cache μπορεί να εξανεμίσει την εξοικονόμηση που πέτυχε το γειτονικό επίπεδο.

Η κοινή χρήση του πλαισίου απαιτεί δουλειά ενσωμάτωσης, ενώ ένας δρομολογητής που διαβάζει την κατάσταση της cache είναι δυσκολότερο να αντικατασταθεί. Η αποστολή του πλαισίου μαζί με το αίτημα, ενώ τα προϊόντα παραμένουν ξεχωριστά, επιτρέπει σε μια ομάδα να χρησιμοποιεί πύλη και δρομολογητή στο περιβάλλον εκτέλεσης άλλου παρόχου. Στη συνέχεια, ο δρομολογητής λαμβάνει αποφάσεις με βάση τις πληροφορίες που εκθέτει αυτός ο πάροχος.

## Μια φθηνότερη διαδρομή μπορεί να κοστίσει περισσότερο

Ας εξετάσουμε μια ενδεικτική υπηρεσία εξαγωγής πληροφοριών από έγγραφα, με μακροσκελείς σταθερές οδηγίες και ένα σύντομο έγγραφο σε κάθε αίτημα. Η cache προθεμάτων και η δρομολόγηση φαίνονται ελκυστικές, αλλά η καθεμία μπορεί να υπονομεύσει την άλλη. Ένα αποθηκευμένο πρόθεμα είναι κατάσταση κλειδιού-τιμής που υπολογίστηκε από ένα μοντέλο, επομένως ένα αίτημα που δρομολογείται σε άλλο μοντέλο επεξεργάζεται τις οδηγίες από την αρχή.

Η δημοσιευμένη τιμολόγηση της Anthropic για cache πέντε λεπτών είναι 1,25 φορές τη βασική τιμή εισόδου για εγγραφή και 0,1 φορές για ανάγνωση, με εξαιρέσεις ανά μοντέλο ([ανακοίνωση](https://www.anthropic.com/news/prompt-caching), [τεκμηρίωση](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)). Σε σύγκριση με αυτή τη θερμή cache, μια εναλλακτική χωρίς cache πρέπει να χρεώνει λιγότερο από το ένα δέκατο της τιμής εισόδου του υφιστάμενου μοντέλου για να συμφέρει στο κοινό πρόθεμα. Μία εγγραφή και μία επιτυχής ανάγνωση κοστίζουν 1,35 περάσματα εισόδου στο τμήμα που βρίσκεται στην cache, έναντι δύο χωρίς cache. Μια εγγραφή που δεν θα διαβαστεί από κανένα μεταγενέστερο αίτημα κοστίζει 1,25.

Ένας δρομολογητής που συγκρίνει τιμές καταλόγου μπορεί να εντοπίσει ένα μοντέλο με τη μισή τιμή εισόδου και να αλλάξει σε αυτό, πληρώνοντας τουλάχιστον πέντε φορές περισσότερο για το πρόθεμα. Οι δηλωμένοι κανόνες δρομολόγησης ορίζουν ποια μοντέλα μπορούν να υποκαταστήσουν το ένα το άλλο· το κοινό πλαίσιο δείχνει το κόστος κάθε τέτοιας υποκατάστασης.

Μια cache απαντήσεων επιστρέφει αποθηκευμένο αποτέλεσμα· μια σημασιολογική cache αποφασίζει επίσης πότε δύο διαφορετικά αιτήματα δικαιολογούν την ίδια απάντηση. Η [GPTCache](https://github.com/zilliztech/GPTCache) εντοπίζει επιτυχείς ανακτήσεις με βάση την ομοιότητα των embeddings, και το README της προειδοποιεί για «false positives during cache hits».

Στην εξαγωγή πληροφοριών, ένα false positive θα μπορούσε να επιστρέψει λανθασμένο αριθμό λογαριασμού: δύο τιμολόγια του ίδιου προμηθευτή, βασισμένα στο ίδιο πρότυπο, μπορεί να βρίσκονται κοντά στον χώρο των embeddings, και η cache μπορεί να επιστρέψει στο δεύτερο τιμολόγιο τον αριθμό λογαριασμού του πρώτου. Μια σημασιολογική cache χωρίς ταυτότητα εφαρμογής μπορεί να προκαλέσει σφάλμα ορθότητας, ενώ ο πίνακας ελέγχου του ποσοστού επιτυχημένων ανακτήσεων μετρά κάθε λανθασμένη απάντηση ως εξοικονόμηση.

Η Anthropic απομονώνει τις cache προτροπών μεταξύ οργανισμών και, στο δικό της API, ανά workspace, παρότι μια cache προθεμάτων δεν επιστρέφει αποθηκευμένη απάντηση. Μια cache απαντήσεων χρειάζεται τουλάχιστον το ίδιο όριο. Μια εφαρμογή μπορεί να δηλώσει αν μια εργασία επιτρέπει επαναχρησιμοποίηση μεταξύ παρόμοιων εισόδων, ενώ το κλειδί επαναχρησιμοποίησης μπορεί να βασίζεται στον καλούντα, στα δεδομένα που επιτρέπεται να διαβάζει και στην έκδοση της εργασίας.

Η εξαγωγή πληροφοριών μπορεί να χρησιμοποιεί επαναχρησιμοποίηση μόνο για ακριβή αντιστοίχιση ή να μην χρησιμοποιεί καθόλου cache, με ένα άγνωστο κλειδί να ενεργοποιεί νέο υπολογισμό. Αυτός ο κανόνας μειώνει τα ποσοστά επιτυχημένων ανακτήσεων και επιβάλλει κόστος για εργασία που μια πιο χαλαρή cache θα παρέλειπε. Η προεπιλογή μπορεί να είναι υπερβολικά αυστηρή: σε μια μεγάλη δημόσια ενότητα συχνών ερωτήσεων, ο επανυπολογισμός για άγνωστα κλειδιά μπορεί να κοστίζει περισσότερο από τη σπάνια λανθασμένη απάντηση που αποτρέπει.

## Εντοπίστε την αστοχία πριν επιλέξετε τη λύση

Ας υποθέσουμε ότι ένα φθηνότερο μοντέλο επιστρέφει μη έγκυρα πεδία και ένα μεγαλύτερο μοντέλο τα διορθώνει, αυξάνοντας τον λογαριασμό και την καθυστέρηση για εκείνο το έγγραφο. Το κόστος μπορεί να υπολογιστεί ανά σωστή εξαγωγή πληροφοριών στον απαιτούμενο χρόνο απόκρισης· η τιμή των tokens της πρώτης κλήσης είναι μόνο ένα στοιχείο.

Η ανάλυση των σύνθετων συστημάτων τεχνητής νοημοσύνης του Berkeley υποστηρίζει τη συνολική βελτιστοποίηση των αλληλεπιδρώντων στοιχείων. Ένα trace πρέπει να ξεχωρίζει μια αστοχία μοντέλου από την παρωχημένη επαναχρησιμοποίηση, ένα αργό εργαλείο ή μια κακή διαδρομή, καθώς καθένα υποδεικνύει λύση σε διαφορετικό επίπεδο. Ο έλεγχος της εκτέλεσης μπορεί να βοηθήσει στον εντοπισμό της προέλευσης του κόστους, ενώ ένα ταχύτερο περιβάλλον εκτέλεσης μπορεί να μετατοπίσει τη σπατάλη στις αποφάσεις γύρω από αυτό. Η σύνδεση των traces με την αξιολόγηση της κίνησης παραγωγής μπορεί να ελέγξει αν μια αλλαγή βελτιώνει την εργασία, συμπεριλαμβανομένης της διαδρομής ανάκαμψης.

Ένας χειριστής μπορεί να χρησιμοποιήσει αυτό το trace για να αλλάξει το επίπεδο όπου συνέβη η αστοχία. Αν το ιστορικό αιτημάτων, οι περιπτώσεις αξιολόγησης και η επιλογή ανάπτυξης παραμένουν στην εφαρμογή του πελάτη, οι βελτιώσεις μπορούν να βασίζονται στην εμπειρία της ίδιας της εφαρμογής.
