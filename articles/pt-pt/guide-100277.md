# API do ChatGPT: configuração, preços e exemplos de código (2026)

> Um guia prático para configurar a API do ChatGPT, comparar modelos e preços e criar aplicações com exemplos de código.



A API do ChatGPT dá aos programadores acesso programático aos modelos da OpenAI. Este guia aborda a configuração da chave da API, a escolha de modelos, os preços, exemplos de código e práticas para criar aplicações e gerir custos.

## O que é a API do ChatGPT?

A API do ChatGPT permite aos programadores integrar capacidades de IA em aplicações através de pedidos HTTP. As aplicações enviam pedidos estruturados à OpenAI e recebem respostas JSON com resultados do modelo.

### Como funciona a API do ChatGPT

O processo decorre em quatro passos:

**Envia um pedido.** A tua aplicação envia um pedido POST à OpenAI com um payload JSON que contém o nome do modelo, as mensagens e parâmetros como a temperatura e os limites de tokens.

**A OpenAI processa o pedido.** O modelo gera uma resposta e devolve-a num objeto JSON. Com a transmissão em fluxo ativada, os tokens chegam de forma incremental.

**A tua aplicação recebe a resposta.** A resposta inclui o conteúdo gerado, informações sobre a utilização de tokens, informações sobre o modelo e um ID do pedido.

**Ocorre a faturação.** Os encargos dependem dos tokens processados. As tarifas dos tokens de entrada e de saída podem ser diferentes.

A extensão do prompt, a escolha do modelo e a colocação em cache afetam o desempenho e os custos.

## Como configurar a API do ChatGPT

Precisas de uma chave da API para autenticar os pedidos. Trata-a como um segredo e guarda-a em segurança.

### Como obter uma chave da API da OpenAI

**Passo 1: Acede à plataforma da OpenAI**

- Visita [platform.openai.com/api-keys](https://platform.openai.com/api-keys) e inicia sessão ou cria uma conta.

**Passo 2: Cria a tua chave da API**

- Abre **API Keys** no painel de controlo.
- Seleciona **Create new secret key** e, opcionalmente, atribui-lhe um nome específico do projeto.
- Copia a chave quando for apresentada; poderá não voltar a ser mostrada.

**Passo 3: Guarda-a em segurança**

- Guarda a chave num gestor de palavras-passe ou numa variável de ambiente.
- Nunca comites chaves da API no controlo de versões nem as exponhas em código do lado do cliente.
- Se utilizares um ficheiro `.env`, adiciona-o ao `.gitignore` e mantém-no fora do controlo de versões.

**Notas de segurança:**

- Uma chave pode conceder acesso associado à tua conta e faturação.
- Se perderes uma chave, cria uma substituta.
- Revoga as chaves que possam ter sido comprometidas.
- Sempre que possível, utiliza chaves separadas e com o âmbito adequado para projetos diferentes.
