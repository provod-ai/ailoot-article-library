# O que é um router de LLM?

> Saiba como os routers de LLM selecionam modelos com base no custo, na latência, na confidencialidade e na qualidade, e como o encaminhamento se relaciona com gateways e mecanismos de contingência.



> **Definição:** Um router de LLM é uma camada do plano de controlo entre a sua aplicação e vários modelos de IA que encaminha cada pedido para o modelo mais adequado com base no custo, na latência, na qualidade e na confidencialidade. Reduz os gastos, elimina a dependência de um único fornecedor e acrescenta comutação automática em caso de falha.

Um router de LLM (também chamado *gateway de IA*, *router de modelos* ou *broker de LLM*) é uma camada entre a sua aplicação e vários modelos. Em vez de programar a aplicação para a API de um único fornecedor, a aplicação chama o router, que escolhe o melhor modelo para cada pedido e disponibiliza uma interface unificada.

- Analisa cada pedido (tipo de tarefa, complexidade, sensibilidade)
- Seleciona o modelo ideal (modelo económico para tarefas simples, modelo de ponta para tarefas difíceis)
- Gere o balanceamento de carga e a comutação em caso de falha entre fornecedores
- O encaminhamento pode reduzir os custos quando os modelos escolhidos satisfazem os seus requisitos de qualidade

## Router de LLM vs. gateway de IA: qual é a diferença?

As funções sobrepõem-se. Um **router** dá prioridade à seleção do modelo para cada pedido; um **gateway de IA** acrescenta autenticação, governação e observabilidade; um **broker** dá prioridade à mediação independente de fornecedores entre vários fornecedores. Uma solução robusta faz as três coisas.

## Como funciona o encaminhamento de LLM?

O router avalia cada pedido segundo quatro critérios:

- **Custo** — encaminha tarefas simples para modelos económicos e só recorre a modelos dispendiosos quando necessário.
- **Latência** — encaminha pedidos urgentes para modelos pequenos e rápidos.
- **Confidencialidade / classe de proteção** — Envie pedidos sensíveis apenas para serviços aprovados em localizações autorizadas.
- **Qualidade** — encaminha tarefas complexas para modelos de ponta.

O encaminhamento pode ser **estático** (regras), **dinâmico** (pontuação ou baseado em modelos), **híbrido** ou **aprendido (RL)**.

## Quanto se poupa com o encaminhamento de LLM? (as evidências)

- **RouteLLM** (UC Berkeley/LMSYS, arXiv 2406.18665): No teste MT Bench, os autores indicaram que o custo foi cerca de 85% inferior ao de usar o GPT-4 para cada pedido. A pontuação ficou em cerca de 95% da obtida com o GPT-4 \[R1\].
- **AWS Bedrock Intelligent Prompt Routing:** A AWS estima que é possível poupar até 30% nos custos ao encaminhar pedidos entre modelos da mesma família [\[R2\]](https://aws.amazon.com/bedrock/intelligent-prompt-routing/).
- **Diferença de custos:** Os preços variam consoante o modelo e o fornecedor. Ao escolher modelos, compare as tarifas em vigor para tokens de entrada e de saída.


## Encaminhamento independente de fornecedores: como acaba com a dependência de um fornecedor

O router do próprio fornecedor prende-o um nível acima. Um broker **independente de fornecedores** abstrai as diferenças entre fornecedores (OpenAI, Anthropic, Google, Mistral, modelos de pesos abertos), pelo que mudar de modelo exige alterar a configuração, não o código. Esta é a solução direta para a dependência de um fornecedor de IA.

## Encaminhamento de LLM com soberania da UE e execução local

Um router pode limitar o tratamento de pedidos sensíveis a modelos aprovados alojados na UE ou executados nas suas instalações e encaminhar pedidos públicos para modelos de cloud mais económicos, quando permitido. Verifique como cada serviço trata e armazena os dados à luz dos requisitos aplicáveis.

## Desenvolver ou comprar

A decisão depende do custo total de propriedade e de ser necessário integrar as classes de proteção e a soberania da UE.

## FAQ

**O que é um router de LLM?**

Um router de LLM é uma camada de software entre a sua aplicação e vários modelos de IA que encaminha cada pedido para o modelo mais adequado em termos de custo, latência, qualidade e confidencialidade, disponibilizando uma API unificada.

**Como funciona o encaminhamento de LLM?**

Avalia cada pedido e seleciona um modelo com regras estáticas, pontuação dinâmica ou políticas aprendidas — encaminhando tarefas simples para modelos económicos e tarefas difíceis para modelos de ponta.

**Um router de LLM é o mesmo que um gateway de IA?**

Não exatamente. Um router dá prioridade à seleção do modelo para cada pedido; um gateway acrescenta autenticação, governação e observabilidade. As plataformas robustas combinam ambos, além da intermediação independente de fornecedores.

**Quanto se poupa com um router de LLM?**

No teste MT Bench, os autores do RouteLLM indicaram que o custo foi cerca de 85% inferior ao de usar o GPT-4 para cada pedido. A pontuação ficou em cerca de 95% da obtida com o GPT-4. A AWS estima que os custos podem baixar até 30% dentro de uma família de modelos. As poupanças reais variam consoante a carga de trabalho.

**O encaminhamento prejudica a qualidade das respostas?**

A qualidade depende das tarefas, dos modelos e das regras de encaminhamento. Teste as regras com pedidos representativos da sua carga de trabalho.

**Posso executar um router de LLM localmente / na UE?**

Sim, se o router e os modelos suportarem este tipo de implementação. Defina quais os serviços que podem tratar pedidos sensíveis e verifique os requisitos aplicáveis ao tratamento de dados.
