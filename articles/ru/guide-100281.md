# Цены на OpenAI Moderation API: бесплатно, лимиты скорости и альтернативы

> Модели модерации OpenAI бесплатны. Узнайте о ценах, лимитах скорости в зависимости от уровня использования, примерах на Python и о том, когда лучше выбрать совместимую с OpenAI альтернативу.




Пользователи OpenAI API могут вызывать эндпоинт модерации бесплатно. Чтобы выбрать схему для продакшена, уточните поддерживаемые типы входных данных, категории модерации и лимиты аккаунта. Затем проверьте, как вызов API впишется в ваш процесс проверки контента.

В этом руководстве официальный ответ о ценах отделён от практического инженерного решения.

## Кратко

- **Эндпоинт OpenAI Moderation бесплатен для пользователей API OpenAI**, согласно справочному центру OpenAI.
- Модель OpenAI `omni-moderation-latest` предназначена для выявления вредоносного контента и принимает на вход текст и изображения, согласно официальной странице модели OpenAI.
- Бесплатная цена не устраняет затраты на рабочий процесс, такие как ведение журналов, очереди на проверку, сопоставление с политиками, повторные попытки, резервное поведение и решения, специфичные для приложения.
- Выбирайте бесплатный эндпоинт OpenAI, если уже используете OpenAI напрямую и ваш рабочий процесс модерации соответствует его категориям и формату ответа.
- Если вы уже пользуетесь EvoLink, рассмотрите EvoLink Moderation 1.0. Сервис позволяет проверять текст и изображения, получать сводку рисков и оплачивать вызовы в рамках той же платформы.

## Бесплатен ли OpenAI Moderation API?

Да. В официальном справочном центре OpenAI указано, что эндпоинт Moderation бесплатен для пользователей API OpenAI, а его использование не учитывается в месячных лимитах использования.

Источник: [Справочный центр OpenAI: бесплатно ли использовать эндпоинт Moderation?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Таков ответ о цене. Следующий вопрос — операционный:

**Достаточно ли бесплатного эндпоинта модерации для вашего рабочего процесса в production?**

Для прототипов, внутренних инструментов и простой модерации, ориентированной прежде всего на текст, его может быть достаточно. Для приложений, работающих с контентом пользователей, загрузкой изображений, ИИ-агентами или очередями на проверку, вызов API — лишь одна часть системы.

## Что охватывает модерация OpenAI?

OpenAI описывает `omni-moderation-latest` как модель модерации, предназначенную для выявления потенциально вредоносного контента в тексте и изображениях. На официальной странице модели она названа самой мощной моделью модерации OpenAI и указана поддержка текстового ввода и вывода, а также ввода изображений. Источник: [Страница модели OpenAI для omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) В руководстве OpenAI по модерации также описаны категории классификации контента и отмечено, что некоторые категории работают только с текстом. Если отправить в `omni-moderation-latest` только изображения, категории, не поддерживающие изображения на входе, вернут оценку 0. Источник: [Руководство OpenAI по модерации](https://developers.openai.com/api/docs/guides/moderation)

Это означает, что командам следует внимательно изучить таблицу категорий, прежде чем считать, что каждая текстовая категория напрямую применима к модерации изображений.

## Реальные затраты — это рабочий процесс, а не только цена API

Эндпоинт Moderation может быть бесплатным, но для производственной системы модерации всё равно нужно принять решения о следующем:

- где запускать проверки: до вызовов модели, после ответов модели или в обоих случаях
- как сопоставлять категории с решениями «разрешить», «проверить» или «заблокировать»
- как журналировать результаты модерации, не сохраняя без необходимости конфиденциальный контент
- как обрабатывать ложные срабатывания и апелляции
- как отдельно модерировать загрузки изображений и текстовый ввод
- как отслеживать задержки, ошибки и лимиты скорости
- как поддерживать единообразие политики на разных поверхностях продукта

Это затраты на разработку и эксплуатацию. Они не указаны на странице с ценами, но именно от них зависит, можно ли поддерживать слой модерации в рабочем состоянии.

Проверяйте запросы перед отправкой в модель, а ответы — перед показом пользователю. Спорные случаи направляйте на проверку, сохраняйте минимум данных о решениях и предусмотрите повторные попытки и апелляции.

## Когда бесплатный эндпоинт OpenAI подходит

Бесплатный эндпоинт OpenAI Moderation часто становится хорошим первым выбором, если:

- вы уже используете OpenAI напрямую
- ваше приложение в основном работает с текстом
- вам нужны только документированные категории модерации OpenAI
- вы можете создать собственный процесс проверки и эскалации
- ваша команда готова отвечать за разбор ответов, пороговые значения и журналы

В таком случае бесплатный эндпоинт сложно не рекомендовать. Начните с него, проверьте его на реальном контенте и измерьте число ложных срабатываний и пропущенных случаев, прежде чем направлять на него производственный трафик.

## Когда имеет смысл совместимая с OpenAI альтернатива

EvoLink Moderation 1.0 — платная альтернатива с совместимым с OpenAI маршрутом `/v1/moderations`. EvoLink принимает не более одного изображения на запрос.

- проверки только текста, только изображений и текста вместе с изображениями через один эндпоинт
- 13 категорий вредоносного контента с оценками для каждой категории
- объект `evolink_summary` с полями `risk_level`, `flagged`, `violations`, `max_score` и `max_category`
- фиксированная цена за вызов вместо расчётов по токенам
- формат ответа, который проще сопоставить с логикой «разрешить», «проверить» или «заблокировать»

## Как использовать OpenAI Moderation API в Python

Если вы уже используете SDK OpenAI, базовый вызов модерации текста выглядит так:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Для EvoLink укажите свой ключ в `EVOLINK_API_KEY`, а в `EVOLINK_BASE_URL` — базовый HTTPS-адрес API из конфигурации EvoLink, который заканчивается на `/v1`. В ответе появится дополнительный объект `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Сравнение OpenAI и EvoLink по цене и процессу модерации

| Критерий | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Оплата | Бесплатно для пользователей OpenAI API | Фиксированная плата за вызов |
| Основная форма эндпоинта | `/v1/moderations` | Совместимый с OpenAI `/v1/moderations` |
| Модерация текста | Поддерживается | Поддерживается |
| Модерация изображений | Поддерживается моделью `omni-moderation-latest` с учётом поддержки входных данных для каждой категории | Поддерживаются запросы только с изображениями и с текстом вместе с изображениями |
| Поля для принятия решений | Используйте `flagged`, `categories` и `category_scores` из `results` | Используйте `evolink_summary.risk_level` и `violations` вместе с оценками категорий |
| Кому подходит | Командам, которые уже вызывают API OpenAI напрямую | Командам, которые встраивают модерацию в действующий процесс на EvoLink |

## Практическая рекомендация

Используйте бесплатный эндпоинт OpenAI Moderation, если ваше приложение уже построено на OpenAI и ваша политика модерации хорошо соответствует документированным категориям.

Если ваша команда уже пользуется EvoLink, оцените стоимость вызовов и учитывайте `evolink_summary.risk_level` в правилах приложения, которые разрешают, направляют на проверку или блокируют контент.

Используйте многоуровневую систему модерации, если приложению нужны особые требования к политике, такие как правила бренда, проверка человеком, апелляции или процессы соответствия требованиям, выходящие за рамки любого отдельного API модерации.

## Часто задаваемые вопросы

### Бесплатен ли OpenAI Moderation API?

Да. В справочном центре OpenAI сказано, что эндпоинт Moderation бесплатен для пользователей API OpenAI и не учитывается в месячных лимитах использования.

### Поддерживает ли модерация OpenAI изображения?

Да, `omni-moderation-latest` принимает изображения на вход, согласно официальной странице модели OpenAI. Однако в руководстве OpenAI по модерации отмечено, что некоторые категории работают только с текстом, поэтому перед использованием модерации только изображений командам следует проверить поддержку входных данных для каждой категории.

### EvoLink Moderation дешевле OpenAI Moderation?

Пользователи OpenAI API могут вызывать эндпоинт модерации бесплатно. EvoLink берёт фиксированную плату за вызов. При сравнении учитывайте стоимость всей схемы, включая ручную проверку и поддержку.

### Подходит ли EvoLink в качестве альтернативы OpenAI Moderation API?

Да. Используйте ключ EvoLink и модель `evolink-moderation-1.0` по совместимому маршруту EvoLink `/v1/moderations`. При обработке ответа учитывайте отдельный объект `evolink_summary`.

### Нужно модерировать запросы, ответы или и то и другое?

В производственных приложениях с ИИ многие команды модерируют и входные, и выходные данные. Модерация входных данных может отсеять небезопасные запросы до того, как они достигнут модели. Модерация выходных данных может обнаружить небезопасные ответы, сгенерированные моделью, прежде чем они попадут к пользователям.

### Что такое omni-moderation-latest?

Это модель OpenAI для модерации текста и изображений. Читайте `flagged`, `categories` и `category_scores` в `results` и применяйте собственные правила модерации.

### Каков лимит скорости OpenAI Moderation API?

Бесплатность касается оплаты. Ограничения на запросы и токены продолжают действовать. В [справочнике модели](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM — число запросов в минуту, RPD — число запросов в день, если указан этот лимит, а TPM — число токенов в минуту.

Лимиты скорости OpenAI Moderation API зависят от уровня аккаунта и могут меняться со временем. Прежде чем планировать производительную пропускную способность, проверьте [документацию OpenAI по лимитам скорости](https://platform.openai.com/docs/guides/rate-limits) и страницу [лимитов использования вашего аккаунта](https://platform.openai.com/settings/organization/limits).

### Как использовать OpenAI Moderation API в Python?

Установите пакет `openai`, задайте `OPENAI_API_KEY` и вызовите `client.moderations.create()` с моделью `omni-moderation-latest` и своим текстом. Для изображений передайте `input` как массив объектов. Для каждого изображения укажите `type: "image_url"` и объект `image_url` с полем `url`, как в справочнике OpenAI API по ссылке ниже.
