# Claude API для начинающих: практическое руководство для старта

> Руководство для начинающих по Claude API: настройка, первый запрос, выбор модели, основные функции и практика для production.



Всё необходимое разработчику для первого вызова Claude API: ключи, Messages API, выбор модели и основные понятия, которые помогут перейти от первого запроса к production.

## Что такое Claude API

Claude API — платформа Anthropic для разработчиков. Она предоставляет программный доступ к моделям Claude через Messages API, включая системные промпты, использование инструментов, потоковую передачу, анализ изображений и структурированные выходные данные.

Messages API — это stateless HTTP endpoint. Вы отправляете список сообщений пользователя и ассистента, ID модели и лимит токенов; Claude возвращает структурированный ответ. Дополнительные endpoints включают пакетную обработку, файлы и подсчёт токенов.

- **Без сохранения состояния:** API не хранит память. Передавайте историю диалога с каждым вызовом.
- **Выбор модели:** обычно при смене модели меняется её ID.
- **SDK:** официальные библиотеки Python (anthropic) и TypeScript (@anthropic-ai/sdk) используют соответствующие форматы запросов.

Понимание этой архитектуры помогает избежать распространённой ошибки новичков: ожидания, что API запомнит предыдущий запрос.

## Шаг 1. Получите ключ и настройте Console

Перейдите на **console.anthropic.com**, создайте аккаунт или организацию для команды и выпустите API-ключ в настройках. Считайте ключ паролем: храните его в переменной окружения и никогда не добавляйте в систему контроля версий.

В HTTP-запросах напрямую используются заголовки **x-api-key** и **anthropic-version**. SDK автоматически считывают из окружения **ANTHROPIC_API_KEY**, поэтому в большинстве случаев код не работает с ключом напрямую.

- Создайте отдельные ключи для разработки, staging и production.
- Используйте рабочие пространства для разделения проектов команды и расходов.
- Настройте лимиты использования в Console, прежде чем передавать ключи широкой команде.

## Шаг 2. Выполните первый запрос к Messages API

Установите SDK командой **pip install anthropic**, экспортируйте ключ и запустите:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Обязательны три параметра: **model**, **max_tokens** (верхний предел вывода) и **messages**. Ответ содержит список блоков содержимого. Проверяйте тип каждого блока, а не считайте, что там всегда обычный текст: использование инструментов и режим размышления могут добавлять другие типы блоков. Объект **usage** сообщает количество входных и выходных токенов и может использоваться для учёта стоимости.

## Шаг 3. Выберите модель

Ниже приведены актуальные модели Claude от Anthropic и их идентификаторы в API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — описана как быстрая и недорогая модель для классификации и простых задач большого объёма.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — описана как сбалансированный вариант для production-нагрузок, включая программирование.
- **Claude Opus 5.5** (**claude-opus-5-5**) — описана для сложных рассуждений и долгих агентных задач.
- **Claude Fable 5.2** (**claude-fable-5-2**) — описана как флагман для требовательных задач на рассуждение.

Начните с Opus 5.5. Для баланса скорости и качества попробуйте Sonnet 5.5, для простых массовых задач — Haiku 5.5, для сложных рассуждений — Fable 5.2. Актуальные расценки смотрите на странице цен Anthropic.

## Пять понятий, которые стоит освоить дальше

После первого успешного запроса эти функции покрывают многие потребности приложений:

- **Системные промпты** — параметр верхнего уровня **system**, задающий роль, тон и правила отдельно от сообщений пользователя.
- **Многошаговые диалоги** — добавляйте каждый ответ ассистента в массив сообщений и отправляйте его снова; первым сообщением должен быть запрос пользователя.
- **Потоковая передача** — server-sent events передают токены по мере генерации, что удобно для чат-интерфейсов и долгих ответов.
- **Vision** — передавайте изображения как блоки содержимого с base64 или URL вместе с текстом.
- **Использование инструментов** — задавайте функции схемами JSON; Claude может выбрать, когда вызвать их, а ваш код выполняет функцию и возвращает результат.

Если важна стоимость, рассмотрите **prompt caching** и **batch processing**; если последующему коду нужно разобрать ответ, используйте **structured outputs**.

## От учебного примера к production

Переход от работающего скрипта к production-интеграции требует инженерной дисциплины:

- **Обработка ошибок:** отдельно обрабатывайте rate limit (429) и ошибки сервера. Источник утверждает, что SDK повторяют такие запросы автоматически с задержкой; проверьте актуальное поведение в документации нужного SDK.
- **Контроль стоимости:** записывайте **usage** каждого ответа в систему метрик.
- **Версионирование промптов:** относитесь к промптам как к коду: проверяйте изменения, версионируйте их и тестируйте на небольшом наборе оценок.
- **Фиксация модели:** задавайте ID моделей в конфигурации, чтобы обновления были осознанными и проверенными.

### Главное

- Messages API не хранит состояние; отправляйте историю диалога при каждом вызове.
- Для прямых HTTP-запросов используется заголовок x-api-key; SDK могут читать ANTHROPIC_API_KEY из окружения.
- Три обязательных параметра запроса: model, max_tokens и messages.
- Начните с Opus 5.5 и сравните альтернативы на собственных данных.
- Системные промпты, потоковая передача, vision, инструменты и история диалога покрывают множество сценариев.
- Записывайте usage токенов для контроля расходов и планирования ёмкости.

## FAQ

### Нужно ли знать машинное обучение, чтобы пользоваться Claude API?

Нет. Claude API — это REST API с официальными SDK для Python и TypeScript. Если вы умеете отправить запрос HTTP endpoint и разобрать JSON, вы можете создавать приложения с Claude. Для первого вызова не нужна теория машинного обучения; полезны навыки проектирования промптов, обработки ошибок и управления стоимостью.

### С какой модели Claude начать новичку?

Anthropic рекомендует начинать с Claude Opus 5.5 (ID в API `claude-opus-5-5`) для большинства задач. Когда промпты стабилизируются, сравните остальные модели на собственных данных.

### Claude API помнит предыдущие разговоры?

Нет. Messages API не хранит состояние. Приложение сохраняет диалог и отправляет полную историю сообщений с каждым запросом. Это даёт контроль над контекстом, позволяет сокращать или обобщать старые реплики и сочетать их с prompt caching.
