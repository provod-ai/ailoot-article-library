## Что такое ChatGPT API?

ChatGPT API позволяет разработчикам интегрировать возможности ИИ в приложения с помощью HTTP-запросов. Приложения отправляют структурированные запросы в OpenAI и получают ответы в формате JSON, содержащие вывод модели.

### Как работает ChatGPT API

Процесс состоит из четырёх шагов:

**Вы отправляете запрос.** Ваше приложение отправляет POST-запрос в OpenAI с полезной нагрузкой JSON, содержащей название модели, сообщения и такие параметры, как temperature и ограничения на количество токенов.

**OpenAI обрабатывает запрос.** Модель генерирует ответ и возвращает его в объекте JSON. При включённой потоковой передаче токены поступают постепенно.

**Ваше приложение получает ответ.** Ответ содержит сгенерированный контент, сведения об использовании токенов, информацию о модели и идентификатор запроса.

**Происходит оплата.** Сумма зависит от обработанных токенов. Для входных и выходных токенов могут действовать разные тарифы.

Длина промпта, выбор модели и кэширование влияют на производительность и стоимость.

## Как настроить ChatGPT API

Для аутентификации запросов нужен API-ключ. Считайте его секретом и храните в безопасном месте.

### Как получить API-ключ OpenAI

**Шаг 1: Откройте платформу OpenAI**

- Перейдите на страницу [platform.openai.com/api-keys](https://platform.openai.com/api-keys) и войдите в систему или создайте аккаунт.

**Шаг 2: Создайте API-ключ**

- Откройте в панели управления раздел **API Keys**.
- Нажмите **Create new secret key** и при желании укажите название, связанное с проектом.
- Скопируйте ключ после его отображения: повторно он может не показываться.

**Шаг 3: Надёжно сохраните ключ**

- Храните ключ в менеджере паролей или переменной среды.
- Никогда не добавляйте API-ключи в систему контроля версий и не раскрывайте их в клиентском коде.
- Если используете файл `.env`, добавьте его в `.gitignore` и не включайте в систему контроля версий.

**Примечания по безопасности:**

- Ключ может предоставлять доступ к ресурсам, связанным с вашим аккаунтом и оплатой.
- Если ключ утерян, создайте замену.
- Отзовите ключи, которые могли быть скомпрометированы.
- По возможности используйте отдельные ключи с подходящими ограничениями для разных проектов.

### 3. Реализуйте потоковую передачу для удобства пользователей

Потоковая передача позволяет показывать ответ по мере поступления содержимого, не дожидаясь его полной генерации.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Корректно обрабатывайте ошибки

Запросы могут завершаться с ошибкой из-за проблем с сетью, ограничений частоты запросов, некорректных входных данных или сбоев сервиса. Обрабатывайте ошибки согласно документации SDK и API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Используйте вызов функций для интеграции инструментов

Вызов функций позволяет модели запросить, чтобы ваше приложение вызвало функцию или инструмент. Приложение обрабатывает вызов и при необходимости возвращает результаты.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
