## Что такое ChatGPT API?

ChatGPT API позволяет разработчикам интегрировать возможности ИИ в приложения с помощью HTTP-запросов. Приложения отправляют структурированные запросы в OpenAI и получают ответы в формате JSON, содержащие вывод модели.

### Как работает ChatGPT API

Процесс состоит из четырёх шагов:

**Вы отправляете запрос.** Ваше приложение отправляет POST-запрос в OpenAI с полезной нагрузкой JSON, содержащей название модели, сообщения и такие параметры, как temperature и ограничения на количество токенов.

**OpenAI обрабатывает запрос.** Модель генерирует ответ и возвращает его в объекте JSON. При включённой потоковой передаче токены поступают постепенно.

**Ваше приложение получает ответ.** Ответ содержит сгенерированный контент, сведения об использовании токенов, информацию о модели и идентификатор запроса.

**Происходит оплата.** Сумма зависит от обработанных токенов. Для входных и выходных токенов могут действовать разные тарифы.

Длина промпта, выбор модели и кэширование влияют на производительность и стоимость.

## Как настроить ChatGPT API

Для аутентификации запросов нужен API-ключ. Считайте его секретом и храните в безопасном месте.

### Как получить API-ключ OpenAI

**Шаг 1: Откройте платформу OpenAI**

- Перейдите на страницу [platform.openai.com/api-keys](https://platform.openai.com/api-keys) и войдите в систему или создайте аккаунт.

**Шаг 2: Создайте API-ключ**

- Откройте в панели управления раздел **API Keys**.
- Нажмите **Create new secret key** и при желании укажите название, связанное с проектом.
- Скопируйте ключ после его отображения: повторно он может не показываться.

**Шаг 3: Надёжно сохраните ключ**

- Храните ключ в менеджере паролей или переменной среды.
- Никогда не добавляйте API-ключи в систему контроля версий и не раскрывайте их в клиентском коде.
- Если используете файл `.env`, добавьте его в `.gitignore` и не включайте в систему контроля версий.

**Примечания по безопасности:**

- Ключ может предоставлять доступ к ресурсам, связанным с вашим аккаунтом и оплатой.
- Если ключ утерян, создайте замену.
- Отзовите ключи, которые могли быть скомпрометированы.
- По возможности используйте отдельные ключи с подходящими ограничениями для разных проектов.

## Часто задаваемые вопросы

**Есть ли у ChatGPT API?**

Да. OpenAI предоставляет API для программного доступа к моделям. Приложения могут отправлять HTTP-запросы или использовать официальные SDK; актуальную информацию о моделях и функциях см. в текущей документации.

**В чём разница между ChatGPT и ChatGPT API?**

ChatGPT — это диалоговый продукт. API позволяет разработчикам программно отправлять запросы и интегрировать ответы моделей в приложения; доступные средства управления зависят от API и выбранной модели.

**Какая самая новая модель доступна в ChatGPT API?**

Доступность моделей меняется. Актуальный список моделей и их возможностей см. в текущей [документации API](https://developers.openai.com/api/docs) OpenAI.

**Что выбрать: Responses API или Chat Completions?**

Выбирайте API с учётом приложения и нужных ему функций. В документации OpenAI описаны актуальные конечные точки и инструкции по миграции. Для существующих приложений следуйте опубликованным инструкциям по поддержке и миграции используемой конечной точки.

**Можно ли пользоваться ChatGPT API бесплатно?**

Стоимость и наличие кредитов зависят от актуальных условий аккаунта и объёма использования. Перед планированием бюджета проверьте информацию о ценах OpenAI.
