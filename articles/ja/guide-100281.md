# OpenAI Moderation APIの料金：無料、レート制限、代替サービス

> OpenAIのモデレーションモデルは無料です。料金、利用階層ごとのレート制限、Pythonの例、OpenAI互換の代替サービスがより適している場合を紹介します。




OpenAIのModerationエンドポイントは、OpenAI APIユーザーが無料で利用できます。本番ワークフローを決める際は、対応する入力とカテゴリ、アカウントのレート制限、レビュー手順にこのエンドポイントをどう組み込めるかを確認してください。

このガイドでは、公式の料金に関する回答と、実務上のエンジニアリング判断を分けて説明します。

## 要点

- OpenAIのヘルプセンターによると、**OpenAI ModerationエンドポイントはOpenAI APIユーザー向けに無料**です。
- OpenAIの`omni-moderation-latest`モデルは有害なコンテンツを検出するよう設計されており、公式のOpenAIモデルページによると、テキストと画像を入力として受け付けます。
- 料金が無料でも、ログ記録、レビューキュー、ポリシーの対応付け、再試行、フォールバック動作、アプリケーション固有の判断といったワークフローコストはなくなりません。
- すでにOpenAIを直接利用していて、モデレーションワークフローがそのカテゴリと応答形式に適合する場合は、OpenAIの無料エンドポイントを選びましょう。
- すでにEvoLinkを利用しており、マルチモーダルなチェック、リスクの要約、呼び出しごとの課金を同じワークフローにまとめたい場合は、EvoLink Moderation 1.0を検討してください。

## OpenAI Moderation APIは無料ですか？

はい。OpenAIの公式ヘルプセンターによると、ModerationエンドポイントはOpenAI APIユーザー向けに無料であり、このツールの利用は月間利用上限にカウントされません。

出典：[OpenAIヘルプセンター：Moderationエンドポイントは無料で利用できますか？](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

これが料金についての回答です。次に考えるべきなのは運用面です。

**無料のモデレーションエンドポイントで、本番ワークフローに十分対応できますか？**

プロトタイプ、社内ツール、テキスト中心のシンプルなモデレーションであれば、十分な場合があります。ユーザー生成コンテンツ、画像アップロード、AIエージェント、レビューキューを扱うアプリケーションでは、API呼び出しはシステムの一部にすぎません。

## OpenAIのモデレーションで対応できること

OpenAIは`omni-moderation-latest`を、テキストや画像に含まれる潜在的に有害なコンテンツを識別するためのモデレーションモデルとして公開しています。公式モデルページでは、これをOpenAIで最も高性能なモデレーションモデルと説明し、テキストの入力と出力、および画像入力への対応を記載しています。出典：[OpenAIのomni-moderation-latestモデルページ](https://platform.openai.com/docs/models/omni-moderation-latest) OpenAIのモデレーションガイドでは、コンテンツ分類のカテゴリについても説明しており、一部のカテゴリはテキストのみを対象としています。`omni-moderation-latest`に画像だけを送信した場合、画像入力に対応していないカテゴリのスコアは0になります。出典：[OpenAIモデレーションガイド](https://developers.openai.com/api/docs/guides/moderation)

つまり、各テキストカテゴリが画像モデレーションにもそのまま対応すると考える前に、カテゴリ表を注意深く確認する必要があります。

## 本当のコストはAPI料金だけでなく、ワークフローにある

Moderationエンドポイントは無料でも、本番用のモデレーションシステムには次のような判断が必要です。

- チェックを実行するタイミング：モデル呼び出しの前、応答の後、または両方
- カテゴリを許可、レビュー、ブロックの判断にどう対応付けるか
- 不要に機微なコンテンツを保存せずに、モデレーション結果をどう記録するか
- 誤検知や異議申し立てにどう対応するか
- 画像アップロードをテキスト入力とは別にどうモデレーションするか
- レイテンシ、エラー、レート制限をどう監視するか
- 製品内の各画面でポリシーの動作をどう一貫させるか

これらはエンジニアリングと運用にかかるコストです。料金ページには表示されませんが、モデレーションレイヤーを実際に保守できるかどうかを左右します。

典型的なワークフローでは、モデルに送る前にプロンプトを、ユーザーに届ける前に出力をチェックします。判断が難しい結果はレビューに回し、判断の記録は必要最小限にとどめ、再試行と異議申し立ての手順を用意しておきます。

## OpenAIの無料エンドポイントが適している場合

次のような場合、OpenAIの無料Moderationエンドポイントは最初の選択肢として適していることがよくあります。

- すでにOpenAIを直接利用している
- アプリが主にテキストを扱う
- OpenAIが公開しているモデレーションカテゴリだけが必要
- 独自のレビューワークフローとエスカレーションワークフローを構築できる
- 応答の解析、しきい値、ログの管理をチームで担える

この場合、無料エンドポイントを選ばない理由はあまりありません。まず使い始め、実際のコンテンツでテストし、本番トラフィックを流す前に誤検知と見逃しを測定しましょう。

## OpenAI互換の代替サービスが適している場合

EvoLink Moderation 1.0は、OpenAI互換の`/v1/moderations`を提供する有料の代替サービスです。EvoLinkが一度のリクエストで受け付ける画像は一枚までです。

- 1つのエンドポイントで、テキストのみ、画像のみ、テキストと画像の組み合わせをチェックできる
- 13の有害カテゴリについて、カテゴリごとのスコアが得られる
- `risk_level`、`flagged`、`violations`、`max_score`、`max_category`を含む`evolink_summary`オブジェクト
- トークン数に基づく計算ではなく、呼び出しごとの固定料金
- 許可、レビュー、ブロックのロジックに対応付けやすい応答形式

## PythonでOpenAI Moderation APIを使う方法

すでにOpenAI SDKを使用している場合、基本的なテキストモデレーションの呼び出しは次のようになります。

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

EvoLinkを使う場合は、`EVOLINK_API_KEY`にEvoLinkのAPIキーを設定します。`EVOLINK_BASE_URL`には、EvoLinkのAPI設定にある`/v1`で終わるHTTPSのAPIベースURLを設定します。応答には追加の`evolink_summary`オブジェクトが含まれます。

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## OpenAIとEvoLinkの料金とワークフローを比較

| 比較項目 | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| 料金 | OpenAI APIユーザーは無料 | 呼び出しごとに固定料金が発生 |
| 主なエンドポイントの形式 | `/v1/moderations` | OpenAI互換の`/v1/moderations` |
| テキストモデレーション | 対応 | 対応 |
| 画像モデレーション | `omni-moderation-latest`で対応。ただし入力への対応はカテゴリごとに異なる | 画像のみのリクエストと、テキストと画像を組み合わせたリクエストに対応 |
| ポリシーに基づく判断に使うフィールド | `results`内の`flagged`、`categories`、`category_scores`の値を解釈する | `evolink_summary.risk_level`と`violations`をカテゴリ別スコアと併せて使う |
| 適しているチーム | すでにOpenAIを直接呼び出しているチーム | 既存のEvoLinkワークフローにモデレーションを組み込むチーム |

## 実践的なおすすめ

アプリケーションがすでにOpenAIを中心に構築されており、モデレーションポリシーをOpenAIが公開しているカテゴリに無理なく対応付けられる場合は、OpenAIの無料Moderationエンドポイントを使いましょう。

すでにEvoLinkを利用しているチームは、呼び出しごとの費用を評価してください。アプリケーションの許可、レビュー、ブロックのルールでは、判断材料の一つとして`evolink_summary.risk_level`を使います。

ブランドルール、人によるレビュー、異議申し立て、コンプライアンスのワークフローなど、単一のモデレーションAPIでは対応できない独自のポリシー要件がある場合は、多層型のモデレーションシステムを使いましょう。

## よくある質問

### OpenAI Moderation APIは無料ですか？

はい。OpenAIのヘルプセンターによると、ModerationエンドポイントはOpenAI APIユーザー向けに無料で、月間利用上限にはカウントされません。

### OpenAIのモデレーションは画像に対応していますか？

はい。OpenAIの公式モデルページによると、`omni-moderation-latest`は画像を入力として受け付けます。ただし、OpenAIのモデレーションガイドでは一部のカテゴリはテキストのみを対象としているため、画像のみのモデレーションに依存する前に、カテゴリごとの入力対応状況を確認してください。

### EvoLink ModerationはOpenAI Moderationより安いですか？

OpenAIのModerationエンドポイントはOpenAI APIユーザー向けに無料です。EvoLinkは呼び出しごとに固定料金を課します。レビューや保守を含め、ワークフロー全体の費用を比較してください。

### OpenAI Moderation APIの代わりにEvoLinkを使えますか？

はい。EvoLinkのAPIキーと`evolink-moderation-1.0`モデルを使い、EvoLinkの互換ルート`/v1/moderations`にリクエストを送ります。EvoLinkが返す別個の`evolink_summary`オブジェクトを処理できるように、応答の処理を更新してください。

### プロンプト、出力、それとも両方をモデレーションすべきですか？

本番用AIアプリケーションでは、入力と出力の両方をモデレーションするチームが多くあります。入力モデレーションは、安全でないリクエストがモデルに届く前に減らすのに役立ちます。出力モデレーションは、安全でない生成応答がユーザーに届く前に検出できます。

### omni-moderation-latestとは何ですか？

テキストと画像を対象とするOpenAIのモデレーションモデルです。`results`内の`flagged`、`categories`、`category_scores`を読み取り、独自のモデレーションポリシーを適用してください。

### OpenAI Moderation APIのレート制限はどのくらいですか？

無料で使えるというのは料金の話です。リクエスト数とトークン数には制限が適用されます。[モデルのリファレンス](https://developers.openai.com/api/docs/models/omni-moderation-latest)では、RPMは一分あたりのリクエスト数、RPD（記載がある場合）は一日あたりのリクエスト数、TPMは一分あたりのトークン数を表します。

OpenAI Moderation APIのレート制限はアカウントの階層によって異なり、時間の経過とともに変更される場合があります。本番環境のスループットを計画する前に、[OpenAIのレート制限に関するドキュメント](https://platform.openai.com/docs/guides/rate-limits)と、アカウントの[利用上限ページ](https://platform.openai.com/settings/organization/limits)を確認してください。

### PythonでOpenAI Moderation APIを使うにはどうすればよいですか？

`openai`パッケージをインストールし、`OPENAI_API_KEY`を設定します。`client.moderations.create()`を呼び出す際に、モデルとして`omni-moderation-latest`、入力としてチェックするテキストを指定します。画像の場合は、下記のOpenAI APIリファレンスに示されているように、`input`にオブジェクトの配列を渡します。画像を表す各要素には`type: "image_url"`を指定し、`image_url`オブジェクトに`url`を含めます。
