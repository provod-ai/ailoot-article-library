# Claude API入門：はじめての実装ガイド

> Claude APIの初心者向けガイドです。セットアップ、最初のリクエスト、モデル選択、主な機能、本番環境での実践方法を解説します。



開発者がClaude APIを初めて呼び出すために必要な内容をまとめました。キー、Messages API、モデル選択から、最初のリクエストを本番環境に移すための基本概念まで解説します。

## Claude APIとは

Claude APIはAnthropicの開発者向けプラットフォームです。Messages APIを通じてClaudeモデルにプログラムからアクセスでき、システムプロンプト、ツール利用、ストリーミング、画像入力、構造化出力に対応します。

Messages APIはステートレスなHTTPエンドポイントです。ユーザーとアシスタントのメッセージ一覧、モデルID、トークン上限を送ると、Claudeが構造化された応答を返します。補助エンドポイントには、バッチ、ファイル、トークン数のカウントがあります。

- **ステートレス:** APIは記憶を保持しません。呼び出しごとに会話履歴を再送します。
- **モデル選択:** モデルを変更するときは、通常モデルIDを変更します。
- **SDK:** 公式のPython（anthropic）とTypeScript（@anthropic-ai/sdk）ライブラリは、それぞれ対応するリクエスト形式を使います。

この仕組みを理解すると、APIが以前のリクエストを覚えていると思い込む、初心者によくある間違いを避けられます。

## ステップ1：キーを取得してConsoleを設定する

**console.anthropic.com** にアクセスし、アカウントまたはチーム用の組織を作成して、設定画面でAPIキーを発行します。キーはパスワードのように扱い、環境変数に保存してください。ソースコード管理に含めてはいけません。

直接HTTPリクエストを送る場合は、**x-api-key** ヘッダーと **anthropic-version** ヘッダーを使います。SDKは環境変数から **ANTHROPIC_API_KEY** を自動的に読み取るため、ほとんどのコードでキーを直接扱う必要はありません。

- 開発、ステージング、本番用に別々のキーを作成します。
- ワークスペースを使い、チームのプロジェクトと支出を分離します。
- チームのより多くのメンバーにキーを配布する前に、Consoleで利用上限を設定します。

## ステップ2：最初のMessages API呼び出しを行う

**pip install anthropic** でSDKをインストールし、キーを環境変数に設定して、次を実行します。

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

必須パラメーターは3つです。**model**、出力上限の **max_tokens**、そして **messages** です。応答にはコンテンツブロックの一覧が含まれます。ツール利用や思考によって別のブロック型が加わることがあるため、通常のテキストだと決めつけず、各ブロックの型を確認してください。**usage** オブジェクトは入力・出力トークン数を報告し、コスト計測に使えます。

## ステップ3：モデルを選ぶ

Anthropicが掲載している現行のClaudeモデルとAPI IDは以下のとおりです。

- **Claude Haiku 5.5**（**claude-haiku-5-5**）— 高速で低コストとされ、分類や大量の単純なタスク向けです。
- **Claude Sonnet 5.5**（**claude-sonnet-5-5**）— コーディングを含む本番ワークロード向けの、バランスの取れた選択肢とされています。
- **Claude Opus 5.5**（**claude-opus-5-5**）— 難しい推論や長期的なエージェント作業向けとされています。
- **Claude Fable 5.2**（**claude-fable-5-2**）— 高度な推論タスク向けのフラッグシップとされています。

まずOpus 5.5から始めます。速度と品質のバランスを重視するならSonnet 5.5、大量の単純作業にはHaiku 5.5、難しい推論にはFable 5.2を試します。現在の料金はAnthropicの料金ページで確認してください。

## 次に学ぶ5つの概念

最初のリクエストが動いたら、次の機能が多くのアプリケーション要件に役立ちます。

- **システムプロンプト** — ユーザーメッセージとは別に、役割、口調、ルールを設定するトップレベルの **system** パラメーターです。
- **複数ターンの会話** — アシスタントの返答をmessages配列に追加して再送します。最初のメッセージはユーザーのターンである必要があります。
- **ストリーミング** — サーバー送信イベントで生成中のトークンを受け取れるため、チャット画面や長い出力に役立ちます。
- **画像入力** — 画像をbase64またはURLのコンテンツブロックとしてテキストと一緒に渡します。
- **ツール利用** — JSONスキーマで関数を定義します。Claudeが呼び出すタイミングを判断し、コードが関数を実行して結果を返します。

コストが重要な場合は **プロンプトのキャッシュ** と **バッチ処理** を検討し、後続コードが応答を解析する必要がある場合は **構造化出力** を使います。

## チュートリアルから本番環境へ

動作するスクリプトを本番環境に統合するには、エンジニアリング上の規律が必要です。

- **エラー処理:** レート制限（429）とサーバーエラーを区別して処理します。ソースによると、SDKはバックオフ付きで自動的に再試行します。現在の動作は該当SDKのドキュメントで確認してください。
- **コストの可視化:** すべての応答の **usage** をメトリクスシステムに記録します。
- **プロンプトのバージョン管理:** プロンプトをコードと同じようにレビューしてバージョン管理し、小規模な評価セットでテストします。
- **モデルの固定:** 設定からモデルIDを参照し、アップグレードを計画的にテストします。

### 要点

- Messages APIはステートレスです。呼び出しごとに会話履歴を再送します。
- 直接HTTPで認証する場合はx-api-keyヘッダーを使い、SDKは環境変数からANTHROPIC_API_KEYを読み取れます。
- 必須リクエストパラメーターはmodel、max_tokens、messagesの3つです。
- Opus 5.5から始め、他の候補と自分のデータで比較します。
- システムプロンプト、ストリーミング、画像入力、ツール利用、複数ターンの履歴で多くのアプリケーション構成に対応できます。
- コストの把握と容量計画のため、トークン使用量を記録します。

## よくある質問

### Claude APIを使うのに機械学習の知識は必要ですか？

いいえ。Claude APIは公式Python・TypeScript SDKを備えたREST APIです。HTTPエンドポイントを呼び出してJSONを解析できれば、Claudeを使った開発ができます。プロンプト設計、エラー処理、コスト管理は役立つエンジニアリングスキルですが、最初のAPI呼び出しに機械学習理論は必要ありません。

### 初心者はどのClaudeモデルから始めるべきですか？

Anthropicは、大半のワークロードでClaude Opus 5.5（API ID `claude-opus-5-5`）から始めることを勧めています。プロンプトが安定したら、他のモデルも自分のデータで比較してください。

### Claude APIは以前の会話を覚えていますか？

いいえ。Messages APIはステートレスです。アプリケーションが会話を保存し、各リクエストでメッセージ履歴全体を再送します。これによりコンテキストを管理し、古いターンを短縮または要約でき、プロンプトのキャッシュと組み合わせることもできます。
