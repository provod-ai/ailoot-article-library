# OpenAI Moderation API бағасы: тегін пайдалану, сұрау жиілігінің шектеулері және баламалар

> OpenAI модерация модельдері тегін. Бағасын, пайдалану деңгейіне қарай қойылатын сұрау жиілігі шектеулерін, Python мысалдарын және OpenAI-мен үйлесімді балама қай кезде тиімдірек болатынын қараңыз.




OpenAI Moderation endpoint-і OpenAI API пайдаланушылары үшін тегін. Өндірістік ортаға лайық жұмыс процесін таңдау үшін қолдау көрсетілетін кіріс деректері мен санаттарды, аккаунтыңыздағы сұрау жиілігінің шектеулерін және endpoint-тің тексеру процесіңізге қаншалықты сай келетінін бағалаңыз.

Бұл нұсқаулықта ресми баға туралы жауап практикалық инженерлік шешімнен бөлек қарастырылады.

## Қысқаша

- **OpenAI анықтама орталығының мәліметі бойынша, OpenAI Moderation endpoint-і OpenAI API пайдаланушылары үшін тегін.**
- OpenAI-дің `omni-moderation-latest` моделі зиянды мазмұнды анықтауға арналған және кіріс дерегі ретінде мәтін мен суреттерді қабылдайды; бұл туралы OpenAI-дің ресми модель бетінен білуге болады.
- Тегін баға журнал жүргізу, тексеру кезектері, саясатты сәйкестендіру, қайталап көру, балама әрекет және қолданбаға тән шешімдер сияқты жұмыс процесіне кететін шығындарды жоймайды.
- Егер OpenAI-ді тікелей қолданып жүрсеңіз және модерация процесіңіз оның санаттары мен жауап пішіміне сай келсе, OpenAI-дің тегін endpoint-ін таңдаңыз.
- EvoLink-ті пайдаланып жүрсеңіз әрі бір жұмыс процесінде әртүрлі кіріс деректерін тексергіңіз, тәуекел туралы қысқаша мәлімет алғыңыз және әр шақыру үшін төлегіңіз келсе, EvoLink Moderation 1.0 нұсқасын қарастырыңыз.

## OpenAI Moderation API тегін бе?

Иә. OpenAI анықтама орталығында Moderation endpoint-і OpenAI API пайдаланушылары үшін тегін екені және бұл құралды пайдалану ай сайынғы пайдалану шектеулеріне есептелмейтіні айтылған.

Дереккөз: [OpenAI анықтама орталығы: Moderation endpoint-ін пайдалану тегін бе?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Баға туралы жауап осындай. Келесі сұрақ — операциялық мәселе:

**Тегін модерация endpoint-і өндірістік жұмыс процесіңізге жеткілікті ме?**

Прототиптерге, ішкі құралдарға және негізінен мәтінді өңдейтін қарапайым модерацияға ол жеткілікті болуы мүмкін. Пайдаланушы жасаған мазмұнды, жүктелген суреттерді, AI агенттерін немесе тексеру кезектерін басқаратын қолданбаларда API шақыруы бүкіл жүйенің бір бөлігі ғана.

## OpenAI модерациясы нені қамтиды?

OpenAI `omni-moderation-latest` моделін мәтін мен суреттердегі ықтимал зиянды мазмұнды анықтауға арналған модерация моделі ретінде сипаттайды. Ресми модель бетінде ол OpenAI-дің ең қабілетті модерация моделі деп көрсетілген және мәтіндік кіріс пен шығысты, сондай-ақ сурет кірісін қолдайтыны жазылған. Дереккөз: [OpenAI-дің omni-moderation-latest моделі туралы беті](https://platform.openai.com/docs/models/omni-moderation-latest) OpenAI модерация нұсқаулығында мазмұнды жіктеу санаттары да түсіндіріліп, кейбір санаттар тек мәтінмен жұмыс істейтіні атап өтілген. `omni-moderation-latest` моделіне тек суреттер жіберсеңіз, сурет кірісін қолдамайтын санаттардың бағасы 0 болады. Дереккөз: [OpenAI модерация нұсқаулығы](https://developers.openai.com/api/docs/guides/moderation)

Сондықтан топтар әрбір мәтін санаты суреттерді модерациялауға тікелей сәйкес келеді деп ойламас бұрын, санаттар кестесін мұқият оқуы керек.

## Нақты шығындар API бағасына ғана емес, жұмыс процесіне байланысты

Moderation endpoint-і тегін болуы мүмкін, бірақ өндірістік модерация жүйесінде әлі де мына мәселелер бойынша шешім қабылдау қажет:

- тексерулерді қашан жүргізу керек: модель шақыруларына дейін, модель жауаптарынан кейін немесе екі жағдайда да
- санаттарды рұқсат ету, тексеру немесе бұғаттау шешімдерімен қалай сәйкестендіру керек
- сезімтал мазмұнды қажетсіз сақтамай, модерация нәтижелерін қалай тіркеу керек
- жалған позитивтер мен шағымдарды қалай өңдеу керек
- сурет жүктелімдерін мәтіндік кірістен бөлек қалай модерациялау керек
- кідірісті, қателерді және сұрау жиілігінің шектеулерін қалай бақылау керек
- саясаттың өнімнің барлық интерфейстерінде бірізді қолданылуын қалай қамтамасыз ету керек

Бұл — инженерлік және операциялық шығындар. Олар баға парағында көрсетілмейді, бірақ модерация қабатын іс жүзінде қолдауға болатынын анықтайды.

Әдеттегі жұмыс процесінде сұрауларды модельге жібермей тұрып, ал модельдің жауаптарын пайдаланушыға бермей тұрып тексеріңіз. Күмәнді нәтижелерді қосымша тексеруге жіберіңіз, шешімдер туралы ең қажетті деректерді ғана тіркеңіз және қайталап көру мен шағымдарды қарау тәртібін алдын ала белгілеңіз.

## OpenAI-дің тегін endpoint-і қай кезде қолайлы?

OpenAI-дің тегін Moderation endpoint-і мына жағдайларда көбіне жақсы бастапқы таңдау болады:

- OpenAI-ді тікелей қолданып жүрсеңіз
- қолданбаңыз негізінен мәтінмен жұмыс істесе
- OpenAI құжаттаған модерация санаттары ғана қажет болса
- тексеру және эскалация жұмыс процесін өзіңіз құра алсаңыз
- тобыңыз жауаптарды талдауға, шекті мәндер мен журналдарға жауап беруге дайын болса

Мұндай жағдайда тегін endpoint-ке қарсы уәж айту қиын. Одан бастаңыз, оны нақты мазмұныңызбен сынаңыз және өндірістік трафикті бағыттамас бұрын жалған позитивтер мен өткізіп алған жағдайларды өлшеңіз.

## OpenAI-мен үйлесімді балама қай кезде орынды?

EvoLink Moderation 1.0 — OpenAI-мен үйлесімді `/v1/moderations` жолын ұсынатын ақылы балама. EvoLink бір сұрауда ең көбі бір сурет қабылдайды.

- мәтінді ғана, суретті ғана және мәтін мен суретті бірге бір endpoint арқылы тексеру
- әр санат бойынша жеке бағалары бар 13 зиян санаты
- `risk_level`, `flagged`, `violations`, `max_score` және `max_category` өрістері бар `evolink_summary` объектісі
- токенмен есептеудің орнына әр шақыруға тұрақты баға
- рұқсат ету, тексеру немесе бұғаттау логикасымен сәйкестендіруге ыңғайлырақ жауап пішімі

## OpenAI Moderation API-ді Python тілінде қалай пайдалануға болады?

OpenAI SDK қолданып жүрсеңіз, мәтінді модерациялауға арналған қарапайым шақыру мынадай болады:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

EvoLink үшін `EVOLINK_API_KEY` айнымалысына EvoLink кілтіңізді, ал `EVOLINK_BASE_URL` айнымалысына EvoLink API баптауларында көрсетілген, `/v1` жолымен аяқталатын негізгі HTTPS мекенжайын қойыңыз. Жауапта қосымша `evolink_summary` объектісі болады.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## OpenAI мен EvoLink-ті баға және жұмыс процесі бойынша салыстыру

| Өлшем | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|
| Төлем | OpenAI API пайдаланушылары үшін тегін | Әр шақыру үшін тұрақты ақы алынады |
| Негізгі endpoint пішімі | `/v1/moderations` | OpenAI-мен үйлесімді `/v1/moderations` |
| Мәтінді модерациялау | Қолдау көрсетіледі | Қолдау көрсетіледі |
| Суреттерді модерациялау | `omni-moderation-latest` моделінде, санатқа қарай кірісті қолдау ерекшеліктерімен қолдау көрсетіледі | Тек сурет және мәтін мен сурет бірге берілетін сұрауларға қолдау көрсетіледі |
| Модерация шешімдеріне қажет өрістер | `results` ішіндегі `flagged`, `categories` және `category_scores` мәндерін талдаңыз | Санат бағаларымен қатар `evolink_summary.risk_level` және `violations` мәндерін пайдаланыңыз |
| Кімге қолайлы | OpenAI-ге қазірдің өзінде тікелей сұрау жіберетін топтарға | Модерацияны бұрыннан бар EvoLink жұмыс процесіне қосатын топтарға |

## Практикалық ұсыныс

Қолданбаңыз OpenAI ортасына негізделген болса және модерация саясатыңыз құжатталған санаттарға нақты сәйкес келсе, OpenAI-дің тегін Moderation endpoint-ін пайдаланыңыз.

Тобыңыз EvoLink-ті пайдаланып жүрсе, әр шақырудың құнын бағалаңыз және `evolink_summary.risk_level` мәнін қолданбаның рұқсат ету, тексеруге жіберу немесе бұғаттау ережелерінде ескерілетін деректердің бірі ретінде қолданыңыз.

Қолданбаңызға бренд ережелері, адамның тексеруі, шағымдар немесе бір ғана модерация API-інен тыс сәйкестік процестері қажет болатын жеке саясат талаптары болса, көп қабатты модерация жүйесін пайдаланыңыз.

## Жиі қойылатын сұрақтар

### OpenAI Moderation API тегін бе?

Иә. OpenAI анықтама орталығының мәліметі бойынша, Moderation endpoint-і OpenAI API пайдаланушылары үшін тегін және ай сайынғы пайдалану шектеулеріне есептелмейді.

### OpenAI модерациясы суреттерді қолдай ма?

Иә, OpenAI-дің ресми модель бетіне сәйкес, `omni-moderation-latest` кіріс ретінде суреттерді қабылдайды. Алайда OpenAI модерация нұсқаулығында кейбір санаттар тек мәтінмен жұмыс істейтіні айтылған. Сондықтан топтар тек суреттерді модерациялауға сенбес бұрын, әр санат бойынша кіріс деректерінің қолдауын тексеруі керек.

### EvoLink Moderation қызметі OpenAI Moderation қызметінен арзан ба?

OpenAI Moderation endpoint-і OpenAI API пайдаланушылары үшін тегін. EvoLink әр шақыру үшін тұрақты ақы алады. Тексеру мен жүйені күтіп ұстауға кететін шығындарды ескеріп, бүкіл жұмыс процесінің құнын салыстырыңыз.

### EvoLink-ті OpenAI Moderation API-ге балама ретінде пайдалана аламын ба?

Иә. EvoLink API кілтіңізді және `evolink-moderation-1.0` моделін EvoLink-тің үйлесімді `/v1/moderations` жолында пайдаланыңыз. Жауапты өңдеу логикасын EvoLink-тің бөлек `evolink_summary` объектісін ескеретіндей бейімдеңіз.

### Сұрауларды, жауаптарды немесе екеуін де модерациялау керек пе?

Өндірістік AI қолданбаларында көптеген топтар кіріс пен шығыстың екеуін де модерациялайды. Кірісті модерациялау қауіпті сұраулардың модельге жетуіне дейін олардың санын азайта алады. Шығысты модерациялау қауіпті жасалған жауаптарды пайдаланушыларға жетпей тұрып анықтай алады.

### omni-moderation-latest дегеніміз не?

Бұл — OpenAI-дің мәтін мен суреттерді модерациялау моделі. `results` ішінен `flagged`, `categories` және `category_scores` мәндерін оқып, өз модерация саясатыңызды қолданыңыз.

### OpenAI Moderation API сұрау жиілігінің шектеуі қандай?

Тегін қолжетімділік төлемге қатысты. Сұраулар мен токендерге қойылған шектеулер күшінде қалады. [Модель анықтамасында](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM — минутына келетін сұраулар саны, RPD — анықтамада көрсетілсе, тәулігіне келетін сұраулар саны, ал TPM — минутына қолданылатын токендер саны.

OpenAI Moderation API сұрау жиілігінің шектеулері аккаунт деңгейіне қарай өзгереді және уақыт өте өзгеруі мүмкін. Өндірістік өткізу қабілетін жоспарламас бұрын, [OpenAI сұрау жиілігінің шектеулері туралы құжаттаманы](https://platform.openai.com/docs/guides/rate-limits) және аккаунтыңыздың [пайдалану шектеулері бетін](https://platform.openai.com/settings/organization/limits) тексеріңіз.

### OpenAI Moderation API-ді Python тілінде қалай пайдалануға болады?

`openai` пакетін орнатыңыз, `OPENAI_API_KEY` айнымалысын баптаңыз және `client.moderations.create()` әдісін `omni-moderation-latest` моделімен және тексерілетін мәтінмен шақырыңыз. Суреттер үшін `input` мәнін объектілер массиві ретінде жіберіңіз. Төменде берілген OpenAI API анықтамасында көрсетілгендей, әр сурет элементінде `type: "image_url"` және `image_url` объектісі болады, ал сол объектіде `url` өрісі беріледі.
