# Gemini: қолданба мен API арасында таңдау

> Gemini қолданбасы мен API арасында таңдау, модельдерді бағалау және пайдалану құнын есептеу бойынша практикалық нұсқаулық.



Gemini-ді Google-дың тұтынушыларға арналған қолданбасында пайдалануға немесе API арқылы бағдарламалық жасақтамаға біріктіруге болады. Дұрыс бастау жолы тапсырманы өзіңіз орындағыңыз келе ме, әлде басқалар үшін қайталанатын жұмыс тәртібін құрғыңыз келе ме — соған байланысты.

## Тапсырмадан бастаңыз

Хабарлама жобасын жазу немесе идеяны зерттеу сияқты бір реттік тапсырмада интерактивті қолданба сұрақ қойып, жауапты нақтылауға мүмкіндік береді. Нәтижеге сүйенбес бұрын оны тексеріңіз: жатық жауапта да қате, жетіспейтін мәнмәтін немесе қате көрсетілген дереккөз болуы мүмкін.

Қолданба жұмыс тәртібінің бір бөлігі ретінде кіріс жіберіп, шығысты өңдеуі керек болғанда API пайдалы. Мысалы, қолдау қолданбасы адам тексерушіге өтінімнің қысқаша мазмұнын дайындай алады. Әзірлеуші нұсқауларды, деректерге қол жеткізуді, қателерді және нәтижелердің көрсетілуі не сақталуын басқаруы тиіс.

Қолданба мен API — бөлек өнімдер. Біреуіндегі мүмкіндік, шектеу, жазылым немесе дерек параметрі екіншісінде автоматты түрде қолжетімді деп ойламаңыз. Нақты қолданатын өнім мен есептік жазбаның құжаттамасын және параметрлерін тексеріңіз.

## Тапсырмаға сай модель таңдаңыз

Модельді тек атауына қарап таңдаудың орнына, бірнеше өкілдік мысалдан бастаңыз. Қысқаша мазмұндау үшін қысқа хабарламаны, ұзын хабарламаны және ақпараты жетіспейтін жағдайды қосыңыз. Жақсы жауап нені сақтауы, нені ойдан шығармауы және қаншалықты ұзын болуы керегін анықтаңыз.

Тапсырмада сурет, аудио немесе басқа кіріс болса, нақты модель мен endpoint қажетті пішімді қолдайтынын тексеріңіз. Қолдау көрсетілетін модальділіктер, контекст шектері және қолжетімділік модельге қарай әртүрлі болып, өзгеруі мүмкін. Ағымдағы нұсқалар мен сұрау пішімдерін Google-дың [Gemini API құжаттамасынан](https://ai.google.dev/gemini-api/docs) тексеріңіз.

## Шынайы үлгімен құнды бағалаңыз

API жұмыс тәртібі үшін шағын өкілдік сұраулар жиынында пайдаланылған кіріс пен шығыс көлемін тіркеңіз. Қолданылатын кіріс пен шығыстың әр түрін ескеріп, өлшенген пайдалануды тиісті жария бағаларға көбейтіңіз. Содан кейін жұмыс тәртібінің орындалу жиілігін болжап, қайта әрекеттер мен жауап ұзындығының өзгеруіне қор қалдырыңыз.

Нәтижені кепілді шот емес, болжам ретінде қарастырыңыз. Есептік жазбаңыздың ағымдағы [Gemini API бағаларын](https://ai.google.dev/gemini-api/docs/pricing), квоталарын және төлем параметрлерін тексеріңіз. Қолданба жазылымы мен API пайдалануының шарттары әртүрлі болуы мүмкін.

## Ауқымды ұлғайтпас бұрын бағалаңыз

Нәтижелерді адамдар тексерген мысалдармен салыстырыңыз. Әр жауапта фактілерді кіріспен, сұралған пішіммен және тапсырмаға тән ережелермен салыстырып тексеріңіз. Күрделі жағдайларды және модель бас тартуы немесе адамға жіберуі тиіс жағдайларды қосыңыз. Жарамды көрінетін жауап міндетті түрде дұрыс емес.

Қателерді бақылап, бір уақытта жұмыс тәртібінің бір бөлігін өзгертіңіз: нұсқауларды, кірісті дайындауды, модельді немесе шығысты тексеруді. Өзгерістен кейін сол сынақ жиынын қайталаңыз. Модель немесе кіріс деректерінің түрі өзгерсе, алдыңғы бағалау әлі жарамды деп ойламай, нәтижені қайта бағалаңыз.

## Деректер мен қателерді жоспарлы өңдеңіз

Тек тапсырмаға қажетті деректерді жіберіп, сезімтал ақпаратты қолданбас бұрын тиісті өнімнің деректерді өңдеу параметрлерін қараңыз. Қолданба нәтижеге сүйеніп әрекет етпес бұрын шығысты тексеріңіз. Сұрау жиілігінің шектеулерін, күту уақытының аяқталуын және толық емес нәтижелерді ескеріңіз; сәтсіздікті үнсіз аяқталған жұмыс деп қабылдамай, нақты әрекет жасауға болатын қате көрсетіңіз немесе жағдайды тексеруге жіберіңіз.

Сыртқы әрекеттерді іске қосуы мүмкін сұраулар үшін операцияны тіркеп, қайта әрекеттен бұрын оның күйін тексеріңіз. Жеткізу кезінде жауаптың жоғалуы әрекеттің сәтсіз болғанын дәлелдемейді.
