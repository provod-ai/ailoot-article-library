# Precios de la API de moderación de OpenAI: gratuita, límites de velocidad y alternativas

> Los modelos de moderación de OpenAI son gratuitos. Consulta los precios, los límites de velocidad por nivel de uso, ejemplos en Python y cuándo puede encajar mejor una alternativa compatible con OpenAI.




El endpoint de moderación de OpenAI es gratuito para los usuarios de la API de OpenAI. Para elegir un flujo de trabajo para producción, comprueba qué entradas y categorías admite, qué límites de velocidad tiene tu cuenta y cómo encaja el endpoint en tu proceso de revisión.

Esta guía distingue la respuesta oficial sobre precios de la decisión práctica de ingeniería.

## En resumen

- **El endpoint de moderación de OpenAI es gratuito para los usuarios de la API de OpenAI**, según el Centro de ayuda de OpenAI.
- El modelo `omni-moderation-latest` de OpenAI está diseñado para detectar contenido dañino y acepta texto e imágenes como entrada, según la página oficial del modelo de OpenAI.
- Que el precio sea gratuito no elimina los costes del flujo de trabajo, como el registro, las colas de revisión, la asignación de políticas, los reintentos, el comportamiento alternativo y las decisiones específicas de la aplicación.
- Elige el endpoint gratuito de OpenAI si ya utilizas OpenAI directamente y tu flujo de moderación se ajusta a sus categorías y formato de respuesta.
- Considera EvoLink Moderation 1.0 si ya usas EvoLink y quieres reunir en un mismo flujo las comprobaciones multimodales, un resumen de riesgos y la facturación por llamada.

## ¿La API de moderación de OpenAI es gratuita?

Sí. El Centro de ayuda oficial de OpenAI afirma que el endpoint de moderación es gratuito para los usuarios de la API de OpenAI y que el uso de la herramienta no cuenta para los límites de uso mensuales.

Fuente: [Centro de ayuda de OpenAI: ¿El endpoint de moderación es gratuito?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

Esa es la respuesta sobre precios. La siguiente pregunta es operativa:

**¿Es suficiente un endpoint de moderación gratuito para tu flujo de trabajo de producción?**

Para prototipos, herramientas internas y moderación sencilla centrada primero en texto, puede serlo. En aplicaciones que gestionan contenido generado por usuarios, cargas de imágenes, agentes de IA o colas de revisión, la llamada a la API es solo una parte del sistema.

## ¿Qué cubre la moderación de OpenAI?

OpenAI documenta `omni-moderation-latest` como un modelo de moderación diseñado para identificar contenido potencialmente dañino en texto e imágenes. La página oficial del modelo lo describe como el modelo de moderación más capaz de OpenAI y enumera compatibilidad con entrada y salida de texto y entrada de imágenes. Fuente: [Página del modelo omni-moderation-latest de OpenAI](https://platform.openai.com/docs/models/omni-moderation-latest) La guía de moderación de OpenAI también explica las categorías de clasificación de contenido y señala que algunas categorías solo admiten texto. Si envías solo imágenes a `omni-moderation-latest`, las categorías que no admiten entradas de imagen devuelven una puntuación de 0. Fuente: [Guía de moderación de OpenAI](https://developers.openai.com/api/docs/guides/moderation)

Eso significa que los equipos deben leer atentamente la tabla de categorías antes de suponer que todas las categorías de texto se corresponden directamente con la moderación de imágenes.

## El coste real está en el flujo de trabajo, no solo en el precio de la API

El endpoint de moderación puede ser gratuito, pero un sistema de moderación de producción aún requiere decidir:

- dónde realizar las comprobaciones: antes de las llamadas al modelo, después de sus respuestas o en ambos momentos
- cómo asignar las categorías a decisiones de permitir, revisar o bloquear
- cómo registrar los resultados de moderación sin almacenar innecesariamente contenido sensible
- cómo gestionar los falsos positivos y las apelaciones
- cómo moderar las cargas de imágenes por separado de las entradas de texto
- cómo supervisar la latencia, los errores y los límites de velocidad
- cómo mantener un comportamiento coherente de las políticas en las distintas interfaces del producto

Esos son costes de ingeniería y operaciones. No aparecen en una página de precios, pero determinan si la capa de moderación es realmente fácil de mantener.

En un flujo habitual, comprueba las instrucciones antes de enviarlas al modelo y las respuestas antes de entregarlas. Envía los resultados dudosos a revisión, conserva un registro mínimo de las decisiones y prevé reintentos y apelaciones.

## Cuándo encaja bien el endpoint gratuito de OpenAI

El endpoint gratuito de moderación de OpenAI suele ser una buena primera opción cuando:

- ya utilizas OpenAI directamente
- tu aplicación se centra principalmente en texto
- solo necesitas las categorías de moderación documentadas por OpenAI
- puedes crear tu propio flujo de revisión y escalado
- tu equipo está dispuesto a hacerse cargo del análisis de respuestas, los umbrales y los registros

En ese caso, es difícil encontrar argumentos en contra del endpoint gratuito. Empieza por ahí, pruébalo con tu contenido real y mide los falsos positivos y los casos no detectados antes de dirigirle tráfico de producción.

## Cuándo tiene sentido una alternativa compatible con OpenAI

EvoLink Moderation 1.0 es una alternativa de pago con una ruta `/v1/moderations` compatible con OpenAI. EvoLink admite como máximo una imagen por solicitud.

- comprobaciones de solo texto, solo imágenes y texto más imágenes a través de un único endpoint
- 13 categorías de daño con puntuaciones por categoría
- un objeto `evolink_summary` con `risk_level`, `flagged`, `violations`, `max_score` y `max_category`
- precio fijo por llamada en lugar de cálculos basados en tokens
- una estructura de respuesta más fácil de asignar a la lógica de permitir, revisar o bloquear

## Cómo usar la API de moderación de OpenAI en Python

Si ya utilizas el SDK de OpenAI, una llamada básica de moderación de texto es así:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Para usar EvoLink, configura `EVOLINK_API_KEY` con tu clave de EvoLink y `EVOLINK_BASE_URL` con la URL base HTTPS de la API que figura en tu configuración de EvoLink y termina en `/v1`. La respuesta también incluye el objeto `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

## Recomendación práctica

Usa el endpoint gratuito de moderación de OpenAI si tu aplicación ya está integrada de forma nativa con OpenAI y tu política de moderación se corresponde claramente con sus categorías documentadas.

Si tu equipo ya usa EvoLink, evalúa el coste por llamada y usa `evolink_summary.risk_level` como uno de los criterios con los que tu aplicación decide si permite, remite a revisión o bloquea un contenido.

Usa un sistema de moderación de varias capas si tu aplicación tiene requisitos de políticas personalizados que necesitan reglas de marca, revisión humana, apelaciones o flujos de cumplimiento que vayan más allá de cualquier API de moderación individual.

## Preguntas frecuentes

### ¿La API de moderación de OpenAI es gratuita?

Sí. El Centro de ayuda de OpenAI indica que el endpoint de moderación es gratuito para los usuarios de la API de OpenAI y que no cuenta para los límites de uso mensuales.

### ¿La moderación de OpenAI admite imágenes?

Sí, `omni-moderation-latest` acepta imágenes como entrada según la página oficial del modelo de OpenAI. Sin embargo, la guía de moderación de OpenAI señala que algunas categorías solo admiten texto, por lo que los equipos deben revisar la compatibilidad de entrada de cada categoría antes de depender de la moderación de imágenes sin texto.

### ¿Es EvoLink Moderation más barato que OpenAI Moderation?

El endpoint de moderación de OpenAI es gratuito para los usuarios de la API de OpenAI. EvoLink cobra una tarifa fija por llamada. Compara el coste de todo el flujo de trabajo, incluida la revisión y el mantenimiento.

### ¿Puedo usar EvoLink como alternativa a la API de moderación de OpenAI?

Sí. Usa tu clave de la API de EvoLink y el modelo `evolink-moderation-1.0` en la ruta compatible `/v1/moderations` de EvoLink. Adapta el procesamiento de la respuesta para tener en cuenta el objeto separado `evolink_summary` de EvoLink.

### ¿Debo moderar las instrucciones, las respuestas o ambas?

En las aplicaciones de IA de producción, muchos equipos moderan tanto las entradas como las salidas. La moderación de entrada puede reducir las solicitudes inseguras antes de que lleguen a un modelo. La moderación de salida puede detectar respuestas generadas inseguras antes de que lleguen a los usuarios.

### ¿Qué es omni-moderation-latest?

Es el modelo de moderación de OpenAI para texto e imágenes. Lee `flagged`, `categories` y `category_scores` en `results` y aplica tu propia política de moderación.

### ¿Cuál es el límite de velocidad de la API de moderación de OpenAI?

La gratuidad se refiere a la facturación. Los límites de solicitudes y tokens siguen vigentes. En la [referencia del modelo](https://developers.openai.com/api/docs/models/omni-moderation-latest), RPM significa solicitudes por minuto, RPD significa solicitudes por día cuando se indica y TPM significa tokens por minuto.

Los límites de velocidad de la API de moderación de OpenAI varían según el nivel de la cuenta y pueden cambiar con el tiempo. Consulta la [documentación sobre límites de velocidad de OpenAI](https://platform.openai.com/docs/guides/rate-limits) y la [página de límites de uso](https://platform.openai.com/settings/organization/limits) de tu cuenta antes de planificar el volumen de producción.

### ¿Cómo uso la API de moderación de OpenAI en Python?

Instala el paquete `openai`, configura `OPENAI_API_KEY` y llama a `client.moderations.create()` con el modelo `omni-moderation-latest` y tu texto. Para enviar imágenes, pasa `input` como un array de objetos. Cada elemento de imagen tiene `type: "image_url"` y un objeto `image_url` que contiene `url`, como se muestra en la referencia de la API de OpenAI enlazada más abajo.
