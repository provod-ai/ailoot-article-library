# API de ChatGPT: cómo configurarla, precios y ejemplos de código (2026)

> Guía práctica para configurar la API de ChatGPT, comparar modelos y precios, y crear aplicaciones con ejemplos de código.



La API de ChatGPT ofrece a los desarrolladores acceso programático a los modelos de OpenAI. Esta guía abarca la configuración de la clave de API, la selección de modelos, los precios, ejemplos de código y prácticas para crear aplicaciones y gestionar los costes.

## ¿Qué es la API de ChatGPT?

La API de ChatGPT permite a los desarrolladores integrar capacidades de IA en aplicaciones mediante solicitudes HTTP. Las aplicaciones envían solicitudes estructuradas a OpenAI y reciben respuestas JSON que contienen los resultados del modelo.

### Cómo funciona la API de ChatGPT

El proceso consta de cuatro pasos:

**Envías una solicitud.** Tu aplicación envía una solicitud POST a OpenAI con una carga JSON que contiene el nombre de un modelo, mensajes y parámetros como la temperatura y los límites de tokens.

**OpenAI procesa la solicitud.** El modelo genera una respuesta y la devuelve en un objeto JSON. Si la transmisión está habilitada, los tokens llegan de forma incremental.

**Tu aplicación recibe la respuesta.** La respuesta incluye el contenido generado, el uso de tokens, la información del modelo y un ID de solicitud.

**Se realiza el cobro.** Los cargos dependen de los tokens procesados. Los tokens de entrada y salida pueden tener tarifas distintas.

La longitud del prompt, la selección del modelo y el almacenamiento en caché afectan al rendimiento y al coste.

## Cómo configurar la API de ChatGPT

Necesitas una clave de API para autenticar las solicitudes. Trátala como un secreto y guárdala de forma segura.

### Cómo obtener una clave de API de OpenAI

**Paso 1: Accede a OpenAI Platform**

- Visita [platform.openai.com/api-keys](https://platform.openai.com/api-keys) e inicia sesión o crea una cuenta.

**Paso 2: Crea tu clave de API**

- Abre **API Keys** en el panel de control.
- Selecciona **Create new secret key** y, si quieres, asígnale un nombre específico para el proyecto.
- Copia la clave cuando aparezca; es posible que no vuelva a mostrarse.

**Paso 3: Guárdala de forma segura**

- Guarda la clave en un gestor de contraseñas o en una variable de entorno.
- Nunca subas claves de API al control de versiones ni las expongas en código del lado del cliente.
- Si usas un archivo `.env`, añádelo a `.gitignore` y mantenlo fuera del control de versiones.

**Notas de seguridad:**

- Una clave puede conceder acceso asociado a tu cuenta y facturación.
- Si pierdes una clave, crea una de reemplazo.
- Revoca las claves que puedan haberse visto comprometidas.
- Cuando estén disponibles, usa claves distintas y con los permisos adecuados para cada proyecto.

### 1. Escribe prompts claros y específicos

Las instrucciones claras y específicas pueden mejorar la utilidad de las respuestas.

- Especifica el formato, el tono y la extensión deseados.
- Proporciona ejemplos cuando resulte útil.

Ejemplo:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.
vague = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)
print(vague.choices[0].message.content)

# Specify the audience, deliverable, and focus.

    model="gpt-4.1",
    messages=[
        {"role": "developer", "content": "Write concise advice for SaaS teams."},
        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)
print(specific.choices[0].message.content)
```

### 2. Usa salidas estructuradas para obtener datos fiables

Para JSON u otros datos estructurados, utiliza las funciones de salida estructurada de la API en lugar de analizar texto sin formato. Consulta la documentación para conocer los formatos y las restricciones compatibles.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Implementa la transmisión para mejorar la experiencia del usuario

La transmisión puede mostrar el contenido de la respuesta a medida que llega, en lugar de esperar a que se complete.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Gestiona los errores correctamente

Las solicitudes pueden fallar por problemas de red, límites de frecuencia, entradas no válidas o interrupciones del servicio. Gestiona los errores según la documentación del SDK y de la API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Usa la llamada a funciones para integrar herramientas

La llamada a funciones permite que un modelo solicite a tu aplicación que invoque una función o herramienta. Tu aplicación gestiona la llamada y devuelve los resultados según corresponda.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
