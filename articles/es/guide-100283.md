## Qué es realmente cada herramienta

### Zapier

Un Zap arranca con un desencadenador y ejecuta una o más acciones. Una acción estándar facturable completada correctamente consume una tarea de tu plan. Un desencadenador puede iniciar un Zap sin consumir ninguna tarea.

### n8n

n8n se lanzó en Berlín en 2019. Es un motor de flujos de trabajo basado en nodos y con código fuente disponible. Puedes usar la versión gestionada en Cloud o autoalojar Community Edition en tu propia infraestructura. La interfaz es un lienzo visual donde conectas nodos que realizan una operación cada uno: obtener datos, transformarlos, ramificar, llamar a una API o escribir en una base de datos.

La diferencia estructural es que n8n expone el modelo de datos subyacente. Cada nodo recibe y emite matrices de elementos. Puedes escribir JavaScript o Python en línea. Puedes guardar el JSON de los flujos de trabajo en Git. Puedes ejecutar el flujo de trabajo en una infraestructura que gestionas. Está diseñado para operadores técnicos, no para usuarios principiantes sin conocimientos técnicos, aunque el creador visual facilita el aprendizaje.

## Precios: dónde la diferencia es mayor

**Zapier cobra por tarea.** En un Classic Zap, una acción estándar facturable completada correctamente consume una tarea. Los desencadenadores, Filter, Paths y el paso Looping no consumen tareas. Las acciones facturables dentro de un bucle cuentan cada vez que se completan correctamente. AI by Zapier y los pasos Code con tiempo de ejecución ampliado tienen sus propias tarifas. Una vez agotado el cupo, los cargos adicionales o la retención de ejecuciones dependen del plan y de su configuración de facturación.

**n8n cobra por ejecución del flujo de trabajo en los planes de pago.** Cuenta las ejecuciones del flujo completo. Añadir un nodo a una ejecución en curso no suma por sí solo otra ejecución. Comprueba las condiciones de tu plan para los reintentos, los errores y los subflujos de trabajo.

Toma el consumo real de tareas de Zapier y el número de ejecuciones de n8n en una prueba representativa. Para comparar con el autoalojamiento, suma los costes de infraestructura y mantenimiento a cualquier coste de suscripción o licencia.

## Integraciones

Si dependes de una aplicación SaaS especializada, comprueba que el directorio de Zapier incluya justo el desencadenador y la acción que necesitas. En n8n, empieza por los nodos integrados o los de la comunidad. También puedes usar HTTP Request para llamar directamente a una API. Comprueba que la API ofrezca la operación que necesitas y que puedas acceder a ella desde tu despliegue.

## Código personalizado

Aquí es donde se abre la brecha.

**Zapier** ejecuta JavaScript o Python en Code by Zapier. Las acciones Code de pago admiten paquetes públicos compatibles de npm o PyPI. Los límites de tiempo de ejecución dependen del plan. Al ampliar el tiempo de ejecución, el consumo de tareas se calcula con otra tasa.

**n8n** admite JavaScript y Python en el nodo Code. n8n Cloud no permite importar bibliotecas de Python, incluida la biblioteca estándar. Si optas por el autoalojamiento, añade las bibliotecas a la lista de permitidas del task runner e instala allí las dependencias adicionales. El autoalojamiento también te permite desplegar nodos personalizados.

Prueba las bibliotecas y los endpoints que realmente necesitas antes de decidir si te basta con un paso Code alojado.

## Ramificación, lógica y flujos de trabajo complejos

Ambas herramientas gestionan bien los flujos lineales. Las diferencias aparecen rápidamente cuando la lógica se complica.

**Zapier Paths** admite hasta 10 ramas por grupo y hasta tres niveles de grupos de rutas en un Classic Zap. Las ramas que cumplen las condiciones se ejecutan en orden. Para reutilizar acciones en varias ramas, usa un Sub-Zap o repite los pasos en cada rama. Looping es un paso independiente.

**n8n** usa IF y Switch para encaminar elementos, Merge para combinar flujos, Loop Over Items para procesar por lotes y Execute Sub-workflow para reutilizar un flujo. Modela un caso real de ramificación y unión antes de decidir qué configuración es más fácil de mantener.

## Manejo de errores

**Zapier** permite añadir un controlador de errores personalizado a los pasos compatibles de los Classic Zaps de pago. Al publicar un Zap con ese controlador, se desactiva Autoreplay en ese mismo Zap. Aún puedes repetir la ejecución completa manualmente.

**n8n** permite usar la configuración On Error de un nodo para continuar o enviar elementos a una salida de error. Un flujo de errores independiente puede usar Error Trigger para reaccionar ante fallos en ejecuciones de producción, por ejemplo enviando un aviso al equipo. El nivel de detalle disponible para depurar depende de la configuración de registro y retención de ejecuciones.

## Escalabilidad y fiabilidad

**Zapier** gestiona la infraestructura. Elige un cupo de tareas que cubra las acciones previstas y comprueba los límites de tus desencadenadores y aplicaciones en los picos de actividad.

**n8n Cloud** tiene límites de ejecuciones y de concurrencia según el plan. Si autoalojas n8n, ten en cuenta los picos de concurrencia, la infraestructura y el mantenimiento continuo. El número de acciones facturables por evento y el coste de operar la infraestructura pueden cambiar cuál de las opciones sale más barata.

## Funciones de IA

Ambas plataformas pueden incorporar llamadas a modelos en una automatización. Compara los datos y las herramientas que necesita tu flujo de trabajo.

**Zapier** ofrece AI by Zapier en los planes de pago. Es compatible con varios proveedores de modelos y puede usar acciones de aplicaciones y fuentes de conocimiento como herramientas. Zapier MCP pone las acciones compatibles de las aplicaciones a disposición de un cliente MCP externo.

**n8n** ofrece nodos para modelos y componentes de LangChain para embeddings, memoria y almacenes vectoriales como Qdrant. Su nodo AI Agent puede llamar a un flujo de trabajo como herramienta. Comprueba a qué endpoints de modelos puede acceder tu despliegue.

Si usas agentes o generación aumentada por recuperación, prueba los permisos, el recorrido de los datos y cómo puedes inspeccionar los fallos.

## Control de versiones y flujos de trabajo en equipo

**Zapier** ofrece un historial de versiones dentro de la aplicación y permite crear un borrador a partir de una versión anterior en los planes Classic de pago. El periodo de retención depende del plan.

Los flujos de trabajo de **n8n** se pueden exportar en JSON y versionar manualmente en Git. El control de código fuente integrado con Git y los entornos están disponibles de forma nativa en Business y Enterprise. Business se ejecuta en tu propia infraestructura. Si necesitas esas funciones en Cloud, revisa el plan Enterprise.

Para una sola persona, esto no importa. Para los equipos que crean flujos de trabajo, el control de versiones y la promoción entre entornos sí importan.

## Curva de aprendizaje

**Zapier** está diseñado para usuarios sin conocimientos técnicos y tiene un creador paso a paso.

**n8n** tiene una curva más pronunciada. Serás productivo en un día si ya has usado Zapier o Make. Si nunca has creado una automatización de flujos de trabajo, cuenta con una semana de práctica para entender el modelo de datos. El lenguaje de expresiones y el modelo de datos por elemento son los dos conceptos que más cuesta interiorizar.

## Cuándo encaja mejor Zapier

Elige Zapier si tus aplicaciones ya tienen los desencadenadores y las acciones que necesitas, el equipo puede gestionar el Zap en el editor y un servicio gestionado cumple tus requisitos. Por ejemplo, puedes enviar un aviso a Slack cada vez que llegue una respuesta a un formulario.

## Cuándo encaja mejor n8n

Elige n8n si un flujo de trabajo necesita volver a combinar datos de varias ramas, reutilizar otros flujos o acceder a servicios de tu red desde una instancia autoalojada. Por ejemplo, puedes añadir a un pedido datos de varios registros internos y enviar a revisión solo las excepciones.

## Cuándo migrar de Zapier a n8n

Señales claras de que estás listo:

- Estás llegando a los límites de tareas y subir de nivel parece un impuesto
- Tienes flujos de trabajo del tipo «si A y B, entonces C; si no, si D, entonces E o F»: no encajan bien en las rutas de Zapier
- Necesitas gestionar datos que tu equipo legal no se siente cómodo enviando a un SaaS de terceros
- Estás creando funciones de IA que van más allá de un ChatGPT sencillo dentro de un Zap
- Tienes capacidad de ingeniería para mantener una infraestructura autoalojada (o vas a migrar a n8n Cloud)

## Cómo decidir

Un árbol de decisión sencillo:

1. **¿Es la primera automatización del equipo?** Empieza con Zapier si ya existen las acciones de las aplicaciones que necesitas y el equipo quiere un editor gestionado.
2. **¿El volumen es bajo?** Con 60 ejecuciones al mes y una acción estándar facturable en cada una, Zapier consume 60 tareas. A ese volumen, un Zap de dos pasos cabe en el cupo del plan Free.
3. **¿El volumen es alto, con varias acciones por evento?** Con 4000 ejecuciones al mes y cinco acciones de ese tipo en cada una, compara 20 000 tareas de Zapier con 4000 ejecuciones de n8n. Comprueba la carga máxima y lo que cuesta operar tu propia instancia antes de elegir entre Cloud y autoalojamiento.
4. **¿Tu volumen queda en un punto intermedio?** Con 600 ejecuciones al mes y tres acciones de ese tipo en cada una, presupuesta 1800 tareas de Zapier o 600 ejecuciones de n8n. Compara en la misma divisa los precios de los niveles que cubran esos volúmenes. Si optas por el autoalojamiento, incluye el mantenimiento y las copias de seguridad.
