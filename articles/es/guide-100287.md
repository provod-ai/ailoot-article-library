# ¿Qué es un enrutador de LLM?

> Descubre cómo los enrutadores de LLM seleccionan modelos según el costo, la latencia, la confidencialidad y la calidad, y cómo se relaciona el enrutamiento con las pasarelas y la conmutación por error.



> **Definición:** Un enrutador de LLM es una capa del plano de control entre tu aplicación y varios modelos de IA que envía cada solicitud al modelo más adecuado según el costo, la latencia, la calidad y la confidencialidad. Reduce el gasto, elimina la dependencia de un único proveedor y añade conmutación automática por error.

Un enrutador de LLM (también *pasarela de IA*, *enrutador de modelos* o *intermediario de LLM*) es una capa entre tu aplicación y muchos modelos. En vez de programar contra la API de un solo proveedor, tu aplicación llama al enrutador, que elige el mejor modelo para cada solicitud y ofrece una interfaz unificada.

- Analiza cada solicitud (tipo de tarea, complejidad, sensibilidad)
- Selecciona el modelo óptimo (un modelo económico para tareas sencillas, un modelo de vanguardia para las difíciles)
- Gestiona el balanceo de carga y la conmutación por error entre proveedores
- El enrutamiento puede reducir los costos cuando los modelos elegidos cumplen tus requisitos de calidad

## Enrutador de LLM vs. pasarela de IA: ¿cuál es la diferencia?

Se solapan. Un **enrutador** hace hincapié en la selección de modelos para cada solicitud; una **pasarela de IA** añade autenticación, gobernanza y observabilidad; un **intermediario** hace hincapié en la mediación independiente del proveedor entre muchos proveedores. Una solución robusta hace las tres cosas.

## ¿Cómo funciona el enrutamiento de LLM?

El enrutador puntúa cada solicitud según cuatro criterios:

- **Costo** — las tareas sencillas se envían a modelos económicos y los caros solo se usan cuando hace falta.
- **Latencia** — las solicitudes urgentes se envían a modelos pequeños y rápidos.
- **Confidencialidad / clase de protección** — Envía las solicitudes sensibles únicamente a servicios aprobados en ubicaciones autorizadas.
- **Calidad** — las tareas complejas se envían a modelos de vanguardia.

El enrutamiento puede ser **estático** (reglas), **dinámico** (basado en puntuación/modelos), **híbrido** o **aprendido (RL)**.

## ¿Cuánto ahorra el enrutamiento de LLM? (las pruebas)

- **RouteLLM** (UC Berkeley/LMSYS, arXiv 2406.18665): En MT Bench, los autores informaron de una reducción de costos de aproximadamente el 85 % frente a usar GPT-4 para cada solicitud, con una puntuación de alrededor del 95 % de la de GPT-4 \[R1\].
- **AWS Bedrock Intelligent Prompt Routing:** AWS estima un ahorro de costos de hasta el 30 % al enrutar solicitudes entre modelos de una misma familia [\[R2\]](https://aws.amazon.com/bedrock/intelligent-prompt-routing/).
- **Diferencia de costo:** Los precios varían según el modelo y el proveedor. Al elegir modelos, compara las tarifas vigentes de los tokens de entrada y de salida.


## Enrutamiento independiente de proveedores: cómo acaba con la dependencia de un proveedor de IA

El enrutador propio de un proveedor te encierra un nivel más arriba. Un intermediario **independiente de proveedores** abstrae la interacción entre proveedores (OpenAI, Anthropic, Google, Mistral y modelos de pesos abiertos), de modo que cambiar de modelo es cuestión de configuración, no de código. Esta es la solución directa a la dependencia de un proveedor de IA.

## Enrutamiento de LLM soberano en la UE y local

Un enrutador puede restringir el procesamiento de las solicitudes sensibles a modelos aprobados que se alojan en la UE o se ejecutan en tus instalaciones, y enviar las solicitudes públicas a modelos en la nube más económicos cuando esté permitido. Comprueba cómo procesa y almacena los datos cada servicio a la luz de los requisitos aplicables.

## Crear o comprar

El costo total de propiedad —y si las clases de protección y la soberanía de la UE deben estar integradas— determina la decisión.

## Preguntas frecuentes

**¿Qué es un enrutador de LLM?**

Un enrutador de LLM es una capa de software entre tu aplicación y varios modelos de IA que dirige cada solicitud al modelo más adecuado según el costo, la latencia, la calidad y la confidencialidad, y proporciona una API unificada.

**¿Cómo funciona el enrutamiento de LLM?**

Puntúa cada solicitud y selecciona un modelo mediante reglas estáticas, puntuación dinámica o políticas aprendidas: envía las tareas sencillas a modelos económicos y las difíciles a modelos de vanguardia.

**¿Un enrutador de LLM es lo mismo que una pasarela de IA?**

No exactamente. Un enrutador hace hincapié en la selección de modelos para cada solicitud; una pasarela añade autenticación, gobernanza y observabilidad. Las plataformas robustas combinan ambas funciones y también la intermediación independiente de proveedores.

**¿Cuánto ahorra un enrutador de LLM?**

En MT Bench, los autores de RouteLLM informaron de una reducción de costos de aproximadamente el 85 % frente a usar GPT-4 para cada solicitud, con una puntuación de alrededor del 95 % de la de GPT-4. AWS estima un ahorro de costos de hasta el 30 % dentro de una familia de modelos. El ahorro real varía según la carga de trabajo.

**¿El enrutamiento perjudica la calidad de las respuestas?**

La calidad depende de las tareas, los modelos y las reglas de enrutamiento. Prueba las reglas con solicitudes representativas de tu carga de trabajo.

**¿Puedo ejecutar un enrutador de LLM en mis instalaciones o en la UE?**

Sí, si el enrutador y los modelos admiten ese tipo de despliegue. Define qué servicios pueden encargarse de las solicitudes sensibles y verifica los requisitos aplicables al tratamiento de datos.
