# ChatGPT API: configurazione, prezzi ed esempi di codice (2026)

> Una guida pratica alla configurazione dell’API di ChatGPT, al confronto tra modelli e prezzi e alla creazione di applicazioni con esempi di codice.



L’API di ChatGPT offre agli sviluppatori l’accesso programmatico ai modelli OpenAI. Questa guida illustra la configurazione della chiave API, la scelta del modello, i prezzi, esempi di codice e le pratiche per creare applicazioni e gestire i costi.

## Che cos’è l’API di ChatGPT?

L’API di ChatGPT consente agli sviluppatori di integrare funzionalità di intelligenza artificiale nelle applicazioni tramite richieste HTTP. Le applicazioni inviano richieste strutturate a OpenAI e ricevono risposte JSON contenenti l’output del modello.

### Come funziona l’API di ChatGPT

Il processo prevede quattro passaggi:

**Invii una richiesta.** La tua applicazione invia a OpenAI una richiesta POST con un payload JSON contenente il nome di un modello, i messaggi e parametri quali la temperatura e i limiti dei token.

**OpenAI elabora la richiesta.** Il modello genera una risposta e la restituisce in un oggetto JSON. Se è attivo lo streaming, i token arrivano progressivamente.

**La tua applicazione riceve la risposta.** La risposta include il contenuto generato, l’utilizzo dei token, le informazioni sul modello e un ID della richiesta.

**Viene addebitato il costo.** Gli addebiti dipendono dai token elaborati. I token di input e di output possono avere tariffe diverse.

La lunghezza del prompt, la scelta del modello e la memorizzazione nella cache incidono sulle prestazioni e sui costi.

## Come configurare l’API di ChatGPT

Ti serve una chiave API per autenticare le richieste. Trattala come un segreto e conservala in modo sicuro.

### Come ottenere una chiave API OpenAI

**Passaggio 1: accedi alla piattaforma OpenAI**

- Visita [platform.openai.com/api-keys](https://platform.openai.com/api-keys) e accedi o crea un account.

**Passaggio 2: crea la chiave API**

- Apri **API Keys** nella dashboard.
- Seleziona **Create new secret key** e, se vuoi, assegnale un nome specifico per il progetto.
- Copia la chiave quando viene visualizzata; potrebbe non essere mostrata di nuovo.

**Passaggio 3: conservala in modo sicuro**

- Conserva la chiave in un gestore di password o in una variabile d’ambiente.
- Non inserire mai le chiavi API nel controllo delle versioni né esporle nel codice lato client.
- Se usi un file `.env`, aggiungilo a `.gitignore` e tienilo fuori dal controllo delle versioni.

**Note sulla sicurezza:**

- Una chiave può concedere l’accesso alle risorse e alla fatturazione associate al tuo account.
- Se perdi una chiave, creane una sostitutiva.
- Revoca le chiavi che potrebbero essere state compromesse.
- Quando disponibile, usa chiavi separate e con autorizzazioni adeguatamente limitate per i diversi progetti.

Per JSON o altri dati strutturati, usa le funzionalità dell’API per gli output strutturati invece di analizzare testo libero. Consulta la documentazione per conoscere i formati supportati e i relativi vincoli.

import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)

### 3. Implementa lo streaming per migliorare l’esperienza utente

Lo streaming permette di mostrare il contenuto della risposta man mano che arriva, senza aspettare che la risposta sia completa.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Gestisci gli errori in modo corretto

Le richieste possono non riuscire per problemi di rete, limiti di frequenza, input non valido o interruzioni del servizio. Gestisci gli errori secondo la documentazione dell’SDK e dell’API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Usa le chiamate a funzione per integrare gli strumenti

Le chiamate a funzione consentono a un modello di richiedere che la tua applicazione chiami una funzione o uno strumento. L’applicazione gestisce la chiamata e restituisce i risultati, se opportuno.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
