## TL;DR

- **Endpoint moderacji OpenAI jest bezpłatny dla użytkowników OpenAI API**, zgodnie z Centrum pomocy OpenAI.
- Model OpenAI `omni-moderation-latest` został zaprojektowany do wykrywania szkodliwych treści i przyjmuje tekst oraz obrazy jako dane wejściowe, zgodnie z oficjalną stroną modelu OpenAI.
- Bezpłatna cena nie eliminuje kosztów przepływu pracy, takich jak rejestrowanie, kolejki weryfikacyjne, mapowanie zasad, ponawianie prób, zachowanie awaryjne i decyzje specyficzne dla aplikacji.
- Wybierz bezpłatny endpoint OpenAI, jeśli korzystasz już bezpośrednio z OpenAI, a Twój przepływ pracy moderacji odpowiada jego kategoriom i formatowi odpowiedzi.
- Rozważ EvoLink Moderation 1.0, jeśli korzystasz już z EvoLink i w jednym procesie chcesz sprawdzać różne rodzaje danych wejściowych, otrzymywać podsumowanie ryzyka i płacić za poszczególne wywołania.

## Czy OpenAI Moderation API jest bezpłatne?

Tak. Oficjalne Centrum pomocy OpenAI stwierdza, że endpoint moderacji jest bezpłatny dla użytkowników OpenAI API, a korzystanie z tego narzędzia nie wlicza się do miesięcznych limitów użycia.

Źródło: [Centrum pomocy OpenAI: Czy korzystanie z endpointu moderacji jest bezpłatne?](https://help.openai.com/en/articles/4936833-is-the-moderation-endpoint-free-to-use)

To odpowiedź dotycząca cen. Kolejne pytanie dotyczy operacji:

**Czy bezpłatny endpoint moderacji wystarczy w Twoim produkcyjnym przepływie pracy?**

W przypadku prototypów, narzędzi wewnętrznych i prostej moderacji, w której przeważa tekst, może wystarczyć. W aplikacjach obsługujących treści tworzone przez użytkowników, przesyłanie obrazów, agentów AI lub kolejki weryfikacyjne samo wywołanie API jest tylko częścią systemu.

## Co obejmuje moderacja OpenAI?

OpenAI opisuje `omni-moderation-latest` jako model moderacji zaprojektowany do identyfikowania potencjalnie szkodliwych treści w tekście i obrazach. Oficjalna strona modelu określa go jako najpotężniejszy model moderacji OpenAI i wymienia obsługę tekstu jako wejścia/wyjścia oraz obrazów jako danych wejściowych. Źródło: [Strona modelu OpenAI dla omni-moderation-latest](https://platform.openai.com/docs/models/omni-moderation-latest) Przewodnik OpenAI po moderacji wyjaśnia również kategorie klasyfikacji treści i zaznacza, że niektóre kategorie obsługują wyłącznie tekst. Jeśli wysyłasz do `omni-moderation-latest` wyłącznie obrazy, kategorie, które nie obsługują obrazów jako danych wejściowych, zwracają wynik 0. Źródło: [Przewodnik OpenAI po moderacji](https://developers.openai.com/api/docs/guides/moderation)

Oznacza to, że zespoły powinny uważnie przeczytać tabelę kategorii, zanim założą, że każda kategoria tekstowa ma bezpośredni odpowiednik w moderacji obrazów.

## Rzeczywistym kosztem jest przepływ pracy, a nie tylko cena API

Endpoint moderacji może być bezpłatny, ale produkcyjny system moderacji nadal wymaga decyzji dotyczących:

- miejsca wykonywania kontroli: przed wywołaniami modelu, po odpowiedziach modelu czy w obu momentach
- sposobu mapowania kategorii na decyzje: zezwól, skieruj do weryfikacji lub zablokuj
- sposobu rejestrowania wyników moderacji bez niepotrzebnego przechowywania wrażliwych treści
- sposobu obsługi fałszywych trafień i odwołań
- sposobu moderowania przesyłanych obrazów niezależnie od tekstu wejściowego
- sposobu monitorowania opóźnień, błędów i limitów szybkości
- sposobu zachowania spójności zasad w różnych częściach produktu

To koszty inżynierii i operacji. Nie pojawiają się na stronie cennika, ale decydują o tym, czy warstwa moderacji jest rzeczywiście łatwa w utrzymaniu.

W typowym procesie sprawdzaj prompty przed wysłaniem do modelu, a jego odpowiedzi przed przekazaniem użytkownikom. Niejednoznaczne wyniki kieruj do weryfikacji, zapisuj tylko niezbędne informacje o decyzjach i zaplanuj obsługę ponownych prób oraz odwołań.

## Kiedy bezpłatny endpoint OpenAI sprawdza się dobrze

Bezpłatny endpoint moderacji OpenAI często jest dobrym pierwszym wyborem, gdy:

- korzystasz już bezpośrednio z OpenAI
- Twoja aplikacja opiera się głównie na tekście
- potrzebujesz tylko udokumentowanych kategorii moderacji OpenAI
- możesz zbudować własny przepływ pracy weryfikacji i eskalacji
- Twój zespół może samodzielnie odpowiadać za analizę odpowiedzi, progi i logi

W takim przypadku trudno znaleźć argument przeciwko bezpłatnemu endpointowi. Zacznij od niego, przetestuj go na rzeczywistych treściach i zmierz liczbę fałszywych trafień oraz pominiętych przypadków, zanim skierujesz do niego ruch produkcyjny.

## Kiedy warto rozważyć alternatywę zgodną z OpenAI

EvoLink Moderation 1.0 to płatna alternatywa z endpointem `/v1/moderations` zgodnym z OpenAI. EvoLink przyjmuje najwyżej jeden obraz na żądanie.

- kontrole wyłącznie tekstu, wyłącznie obrazów oraz tekstu i obrazów za pośrednictwem jednego endpointu
- 13 kategorii szkodliwych treści z wynikami dla poszczególnych kategorii
- obiekt `evolink_summary` z polami `risk_level`, `flagged`, `violations`, `max_score` i `max_category`
- stała cena za wywołanie zamiast obliczeń opartych na tokenach
- format odpowiedzi, który łatwiej mapować na logikę zezwalania, weryfikacji lub blokowania

## Jak używać OpenAI Moderation API w Pythonie

Jeśli korzystasz już z OpenAI SDK, podstawowe wywołanie moderacji tekstu wygląda tak:

```
from openai import OpenAI

client = OpenAI()

response = client.moderations.create(
    model="omni-moderation-latest",
    input="user text here"
)

print(response.results[0].flagged)
print(response.results[0].categories)
```

Aby skorzystać z EvoLink, ustaw `EVOLINK_API_KEY` na swój klucz EvoLink, a `EVOLINK_BASE_URL` na bazowy adres HTTPS API kończący się na `/v1`, podany w konfiguracji EvoLink API. Odpowiedź zawiera dodatkowy obiekt `evolink_summary`.

```python
import os

from openai import OpenAI

# EVOLINK_API_KEY=YOUR_EVOLINK_API_KEY
client = OpenAI(
    api_key=os.environ["EVOLINK_API_KEY"],
    base_url=os.environ["EVOLINK_BASE_URL"],
)

response = client.moderations.create(
    model="evolink-moderation-1.0",
    input=[{"type": "text", "text": "user text here"}],
)

summary = response.model_extra["evolink_summary"]
print(summary["risk_level"])
print(summary["violations"])
```

| Kryterium | OpenAI Moderation API | EvoLink Moderation 1.0 |
|----|----|----|

| Główny kształt endpointu | `/v1/moderations` | Zgodny z OpenAI `/v1/moderations` |
| Moderacja tekstu | Obsługiwana | Obsługiwana |
| Moderacja obrazów | Obsługiwana przez `omni-moderation-latest`, z obsługą danych wejściowych zależną od kategorii | Obsługiwana dla żądań zawierających wyłącznie obrazy oraz tekst i obrazy |
| Pola wykorzystywane w decyzjach o moderacji | Interpretuj wartości pól `flagged`, `categories` i `category_scores` w `results` | Uwzględniaj `evolink_summary.risk_level` i `violations` obok ocen poszczególnych kategorii |
| Dla kogo | Zespoły, które już wywołują OpenAI bezpośrednio | Zespoły dodające moderację do istniejącego procesu opartego na EvoLink |

## Praktyczne zalecenie

Korzystaj z bezpłatnego endpointu moderacji OpenAI, jeśli Twoja aplikacja opiera się już na OpenAI, a zasady moderacji dobrze pasują do udokumentowanych kategorii.

Jeśli Twój zespół korzysta już z EvoLink, oszacuj koszt pojedynczego wywołania i uwzględnij `evolink_summary.risk_level` jako jedną z przesłanek w regułach aplikacji dotyczących zezwalania, kierowania do weryfikacji lub blokowania.

Użyj wielowarstwowego systemu moderacji, jeśli aplikacja ma niestandardowe wymagania dotyczące zasad, które obejmują reguły dotyczące marki, weryfikację przez człowieka, odwołania lub procedury zgodności wykraczające poza możliwości dowolnego pojedynczego API moderacji.

## FAQ

### Czy OpenAI Moderation API jest bezpłatne?

Tak. Centrum pomocy OpenAI podaje, że endpoint moderacji jest bezpłatny dla użytkowników OpenAI API i nie wlicza się do miesięcznych limitów użycia.

### Czy moderacja OpenAI obsługuje obrazy?

Tak, `omni-moderation-latest` przyjmuje obrazy jako dane wejściowe, zgodnie z oficjalną stroną modelu OpenAI. Jednak przewodnik OpenAI po moderacji zaznacza, że niektóre kategorie obsługują wyłącznie tekst, więc przed poleganiem na moderacji samych obrazów zespoły powinny sprawdzić, jakie dane wejściowe obsługuje każda kategoria.

### Czy EvoLink Moderation jest tańsze od OpenAI Moderation?

Endpoint OpenAI Moderation jest bezpłatny dla użytkowników OpenAI API. EvoLink pobiera stałą opłatę za każde wywołanie. Porównaj koszty całego procesu, w tym weryfikacji i utrzymania.

### Czy mogę używać EvoLink jako alternatywy dla OpenAI Moderation API?

Tak. Użyj swojego klucza EvoLink API i modelu `evolink-moderation-1.0` w zgodnym endpoincie EvoLink `/v1/moderations`. Dostosuj obsługę odpowiedzi tak, aby uwzględniała osobny obiekt `evolink_summary` zwracany przez EvoLink.

### Czy należy moderować prompty, odpowiedzi czy jedno i drugie?

W produkcyjnych aplikacjach AI wiele zespołów moderuje zarówno dane wejściowe, jak i wyjściowe. Moderacja danych wejściowych może ograniczyć liczbę niebezpiecznych żądań docierających do modelu. Moderacja danych wyjściowych może wychwycić niebezpieczne wygenerowane odpowiedzi, zanim dotrą do użytkowników.

### Czym jest omni-moderation-latest?

To model OpenAI do moderacji tekstu i obrazów. Odczytaj wartości `flagged`, `categories` i `category_scores` w `results` i zastosuj własne zasady moderacji.

### Jaki jest limit szybkości OpenAI Moderation API?

Bezpłatny dostęp dotyczy rozliczeń. Limity liczby żądań i tokenów nadal obowiązują. W [dokumentacji modelu](https://developers.openai.com/api/docs/models/omni-moderation-latest) RPM to liczba żądań na minutę, RPD, jeśli podano ten wskaźnik, to liczba żądań na dobę, a TPM to liczba tokenów na minutę.

Limity szybkości OpenAI Moderation API zależą od poziomu konta i mogą zmieniać się z czasem. Przed planowaniem przepustowości produkcyjnej sprawdź [dokumentację limitów szybkości OpenAI](https://platform.openai.com/docs/guides/rate-limits) oraz stronę [limitów użycia Twojego konta](https://platform.openai.com/settings/organization/limits).

### Jak używać OpenAI Moderation API w Pythonie?

Zainstaluj pakiet `openai`, ustaw `OPENAI_API_KEY` i wywołaj `client.moderations.create()`, przekazując model `omni-moderation-latest` oraz swój tekst. W przypadku obrazów przekaż w `input` tablicę obiektów. Każdy element reprezentujący obraz ma `type: "image_url"` oraz obiekt `image_url` zawierający `url`, jak pokazano w podlinkowanej niżej dokumentacji OpenAI API.
