# Claude API dla początkujących: praktyczny przewodnik na start

> Przewodnik dla początkujących po Claude API: konfiguracja, pierwsze żądanie, wybór modelu, kluczowe funkcje i praktyki produkcyjne.



Wszystko, czego deweloper potrzebuje, aby wykonać pierwsze wywołanie Claude API: klucze, Messages API, wybór modelu oraz podstawowe pojęcia potrzebne do przejścia od pierwszego żądania do produkcji.

## Czym jest Claude API

Claude API to platforma Anthropic dla deweloperów. Zapewnia programowy dostęp do modeli Claude przez Messages API, wraz z promptami systemowymi, użyciem narzędzi, strumieniowaniem, obsługą obrazów i ustrukturyzowanymi wynikami.

Messages API to bezstanowy endpoint HTTP. Wysyłasz listę wiadomości użytkownika i asystenta, identyfikator modelu oraz limit tokenów, a Claude zwraca ustrukturyzowaną odpowiedź. Dodatkowe endpointy obsługują partie, pliki i liczenie tokenów.

- **Bezstanowość:** API niczego nie zapamiętuje. Przy każdym wywołaniu wyślij ponownie historię rozmowy.
- **Wybór modelu:** zmiana modelu zazwyczaj wymaga zmiany jego identyfikatora.
- **SDK:** oficjalne biblioteki Python (anthropic) i TypeScript (@anthropic-ai/sdk) używają odpowiadających sobie formatów żądań.

Zrozumienie tej architektury pomaga uniknąć częstego błędu początkujących: oczekiwania, że API zapamięta poprzednie żądanie.

## Krok 1: uzyskaj klucz i skonfiguruj Console

Przejdź do **console.anthropic.com**, utwórz konto lub organizację dla zespołu i wygeneruj klucz API w ustawieniach. Traktuj go jak hasło: przechowuj w zmiennej środowiskowej i nigdy nie umieszczaj w repozytorium kodu źródłowego.

Bezpośrednie żądania HTTP używają nagłówka **x-api-key** oraz nagłówka **anthropic-version**. SDK automatycznie odczytują **ANTHROPIC_API_KEY** ze środowiska, więc większość kodu nie obsługuje klucza bezpośrednio.

- Utwórz oddzielne klucze dla środowisk programistycznych, testowych i produkcyjnych.
- Używaj obszarów roboczych, aby izolować projekty zespołu i wydatki.
- Ustaw limity użycia w Console, zanim udostępnisz klucze większej grupie.

## Krok 2: wykonaj pierwsze wywołanie Messages API

Zainstaluj SDK poleceniem **pip install anthropic**, ustaw klucz w środowisku i uruchom:

```
import anthropic

client = anthropic.Anthropic()
msg = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Explain REST in one paragraph."}],
)
for block in msg.content:
    if block.type == "text":
        print(block.text)
```

Wymagane są trzy parametry: **model**, **max_tokens** (limit długości odpowiedzi) i **messages**. Odpowiedź zawiera listę bloków treści. Sprawdzaj typ każdego bloku, zamiast zakładać, że zawiera zwykły tekst — użycie narzędzi i myślenie mogą dodać inne typy bloków. Obiekt **usage** podaje liczbę tokenów wejściowych i wyjściowych; można go wykorzystać do monitorowania kosztów.

## Krok 3: wybierz model

Oto aktualne modele Claude firmy Anthropic i ich identyfikatory API.

- **Claude Haiku 5.5** (**claude-haiku-5-5**) — opisany jako szybki i tani, do klasyfikacji oraz prostych zadań o dużym wolumenie.
- **Claude Sonnet 5.5** (**claude-sonnet-5-5**) — opisany jako zrównoważony model do obciążeń produkcyjnych, w tym programowania.
- **Claude Opus 5.5** (**claude-opus-5-5**) — opisany jako model do trudnego wnioskowania i długotrwałych zadań agentowych.
- **Claude Fable 5.2** (**claude-fable-5-2**) — opisany jako flagowy model do wymagających zadań związanych z wnioskowaniem.

Zacznij od modelu Opus 5.5. Wypróbuj Sonnet 5.5, gdy liczy się równowaga między szybkością a jakością, Haiku 5.5 przy dużej liczbie prostych zadań, a Fable 5.2 przy złożonym wnioskowaniu. Aktualne stawki sprawdź na stronie cen Anthropic.

## Pięć kolejnych pojęć do poznania

Gdy pierwsze żądanie działa, te funkcje zaspokoją wiele potrzeb aplikacyjnych:

- **Prompty systemowe** — najwyższego poziomu parametr **system**, który ustawia rolę, ton i reguły niezależnie od wiadomości użytkownika.
- **Rozmowy wieloturowe** — dodawaj każdą odpowiedź asystenta do tablicy messages i wysyłaj ją ponownie; pierwsza wiadomość musi pochodzić od użytkownika.
- **Strumieniowanie** — zdarzenia wysyłane przez serwer przekazują tokeny w trakcie generowania, co może pomóc w interfejsach czatu i przy długich odpowiedziach.
- **Obsługa obrazów** — przekazuj obrazy jako bloki treści base64 lub URL razem z tekstem.
- **Użycie narzędzi** — definiuj funkcje za pomocą schematów JSON; Claude może zdecydować, kiedy je wywołać, a Twój kod je wykonuje i zwraca wyniki.

Gdy liczy się koszt, rozważ **buforowanie promptów** i **przetwarzanie wsadowe**; gdy dalszy kod musi analizować odpowiedź, użyj **ustrukturyzowanych wyników**.

## Od tutorialu do produkcji

Przejście od działającego skryptu do integracji produkcyjnej wymaga dyscypliny inżynierskiej:

- **Obsługa błędów:** osobno obsługuj błędy limitu szybkości (429) i błędy serwera. Źródło podaje, że SDK automatycznie ponawiają próby z narastającym opóźnieniem; sprawdź aktualne zachowanie w dokumentacji danego SDK.
- **Widoczność kosztów:** zapisuj **usage** każdej odpowiedzi w systemie metryk.
- **Wersjonowanie promptów:** traktuj prompty jak kod: przeglądaj je, wersjonuj i testuj na małym zestawie ewaluacyjnym.
- **Przypinanie modelu:** odwołuj się do identyfikatorów modeli w konfiguracji, aby aktualizacje były planowane i testowane.

### Najważniejsze wnioski

- Messages API jest bezstanowe; przy każdym wywołaniu ponownie wysyłaj historię rozmowy.
- Bezpośrednie uwierzytelnianie HTTP używa nagłówka x-api-key; SDK mogą odczytać ANTHROPIC_API_KEY ze środowiska.
- Trzy wymagane parametry żądania to model, max_tokens i messages.
- Zacznij od modelu Opus 5.5 i porównaj alternatywy na własnych danych.
- Prompty systemowe, strumieniowanie, obsługa obrazów, narzędzia i historia wieloturowa obsługują wiele wzorców aplikacji.
- Zapisuj zużycie tokenów, aby kontrolować koszty i planować przepustowość.

## FAQ

### Czy do korzystania z Claude API muszę znać uczenie maszynowe?

Nie. Claude API to REST API z oficjalnymi SDK dla Python i TypeScript. Jeśli potrafisz wywołać endpoint HTTP i analizować JSON, możesz tworzyć rozwiązania z Claude. Projektowanie promptów, obsługa błędów i zarządzanie kosztami to przydatne umiejętności inżynierskie; do pierwszego wywołania API teoria uczenia maszynowego nie jest potrzebna.

### Od którego modelu Claude powinien zacząć początkujący?

Anthropic zaleca rozpoczęcie pracy z modelem Claude Opus 5.5 (identyfikator API `claude-opus-5-5`) w przypadku większości zadań. Gdy prompty są już stabilne, porównaj pozostałe modele na własnych danych.

### Czy Claude API pamięta poprzednie rozmowy?

Nie. Messages API jest bezstanowe. Aplikacja przechowuje rozmowę i wysyła pełną historię wiadomości przy każdym żądaniu. Dzięki temu masz kontrolę nad kontekstem, możesz skracać lub streszczać starsze tury i łączyć je z buforowaniem promptów.
