ChatGPT API zapewnia programistom programowy dostęp do modeli OpenAI. Ten przewodnik omawia konfigurację klucza API, wybór modelu, ceny, przykłady kodu oraz praktyki tworzenia aplikacji i zarządzania kosztami.

## Czym jest ChatGPT API?

ChatGPT API pozwala programistom integrować możliwości AI z aplikacjami za pomocą żądań HTTP. Aplikacje wysyłają do OpenAI ustrukturyzowane żądania i otrzymują odpowiedzi JSON zawierające wyniki modelu.

### Jak działa ChatGPT API

Proces przebiega w czterech krokach:

**Wysyłasz żądanie.** Twoja aplikacja wysyła do OpenAI żądanie POST z ładunkiem JSON zawierającym nazwę modelu, wiadomości i parametry, takie jak temperatura oraz limity tokenów.

**OpenAI przetwarza żądanie.** Model generuje odpowiedź i zwraca ją w obiekcie JSON. Po włączeniu strumieniowania tokeny są przesyłane stopniowo.

**Twoja aplikacja odbiera odpowiedź.** Odpowiedź zawiera wygenerowaną treść, informacje o użyciu tokenów, informacje o modelu i identyfikator żądania.

**Następuje rozliczenie.** Opłaty zależą od przetworzonych tokenów. Stawki za tokeny wejściowe i wyjściowe mogą się różnić.

Długość promptu, wybór modelu i buforowanie wpływają na wydajność i koszt.

## Jak skonfigurować ChatGPT API

Do uwierzytelniania żądań potrzebujesz klucza API. Traktuj go jako sekret i przechowuj w bezpiecznym miejscu.

### Jak uzyskać klucz API OpenAI

**Krok 1: Otwórz platformę OpenAI**

- Odwiedź stronę [platform.openai.com/api-keys](https://platform.openai.com/api-keys) i zaloguj się lub utwórz konto.

**Krok 2: Utwórz klucz API**

- Otwórz w panelu pozycję **API Keys**.
- Wybierz **Create new secret key** i opcjonalnie nadaj mu nazwę związaną z projektem.
- Skopiuj klucz, gdy zostanie wyświetlony; może nie być widoczny ponownie.

**Krok 3: Przechowuj go bezpiecznie**

- Przechowuj klucz w menedżerze haseł lub zmiennej środowiskowej.
- Nigdy nie zapisuj kluczy API w systemie kontroli wersji ani nie ujawniaj ich w kodzie po stronie klienta.
- Jeśli używasz pliku `.env`, dodaj go do `.gitignore` i nie umieszczaj go w systemie kontroli wersji.

**Uwagi dotyczące bezpieczeństwa:**

- Klucz może zapewniać dostęp powiązany z Twoim kontem i rozliczeniami.
- Jeśli klucz zostanie zgubiony, utwórz zastępczy.
- Unieważnij klucze, które mogły zostać przejęte.
- Jeśli to możliwe, używaj osobnych kluczy o odpowiednio ograniczonym zakresie dla różnych projektów.

Przykład:

prompt.py

```python
from openai import OpenAI

client = OpenAI()  # Reads OPENAI_API_KEY from the environment.

# Vague instructions leave the topic and format open.

    model="gpt-4.1",
    messages=[{"role": "user", "content": "Write about marketing."}],
)

# Specify the audience, deliverable, and focus.

    model="gpt-4.1",

        {"role": "user", "content": (
            "Write three paragraphs on email marketing for a SaaS startup "
            "selling to small businesses. Cover deliverability, segmentation, "
            "and automation."
        )},
    ],
)

```

### 2. Używaj ustrukturyzowanych wyników, aby uzyskać wiarygodne dane

W przypadku danych w formacie JSON lub innych danych ustrukturyzowanych korzystaj z funkcji ustrukturyzowanych wyników API zamiast parsować swobodny tekst. Sprawdź w dokumentacji obsługiwany format i jego ograniczenia.

prompt.py

```python
import json

from openai import OpenAI

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4.1",
    messages=[{"role": "user", "content": (
        "Extract the product name, price in US dollars, and category: "
        "The iPhone 15 Pro costs $999 and is a smartphone."
    )}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "product_extraction",
            "strict": True,
            "schema": {
                "type": "object",
                "properties": {
                    "product_name": {"type": "string"},
                    "price": {"type": "number"},
                    "category": {"type": "string"},
                },
                "required": ["product_name", "price", "category"],
                "additionalProperties": False,
            },
        },
    },
)
choice = response.choices[0]
message = choice.message
if message.refusal:
    raise RuntimeError(message.refusal)
if choice.finish_reason != "stop" or not message.content:
    raise RuntimeError(f"No complete JSON response ({choice.finish_reason}).")
product = json.loads(message.content)
print(product)
```

### 3. Zaimplementuj strumieniowanie dla lepszej obsługi użytkownika

Strumieniowanie może wyświetlać treść odpowiedzi w miarę jej napływania, zamiast czekać na całą odpowiedź.

prompt.py

```python
from openai import OpenAI

client = OpenAI()
with client.chat.completions.create(
    model="gpt-4.1-mini",
    messages=[{"role": "user", "content": "Explain quantum computing simply."}],
    stream=True,
) as stream:
    for chunk in stream:
        if chunk.choices:
            text = chunk.choices[0].delta.content
            if text:
                print(text, end="", flush=True)
print()
```

### 5. Obsługuj błędy w kontrolowany sposób

Żądania mogą nie powieść się z powodu problemów z siecią, limitów szybkości, nieprawidłowych danych wejściowych lub awarii usługi. Obsługuj błędy zgodnie z dokumentacją SDK i API.

prompt.py

```python
from datetime import datetime, timezone
from email.utils import parsedate_to_datetime
import math
import random
import time

from openai import APIConnectionError, APIStatusError, OpenAI, RateLimitError


def retry_delay(error, attempt):
    hint = error.response.headers.get("Retry-After")
    if hint:
        try:
            seconds = float(hint)
        except ValueError:
            try:
                date = parsedate_to_datetime(hint)
                seconds = max(0.0, (date - datetime.now(timezone.utc)).total_seconds())
            except (ValueError, TypeError, OverflowError):
                seconds = -1
        if math.isfinite(seconds) and seconds >= 0:
            return seconds
    return 2**attempt + random.uniform(0, 0.25)


client = OpenAI(max_retries=0, timeout=10.0)
messages = [{"role": "user", "content": "Suggest one way to improve API reliability."}]
max_attempts = 3
for attempt in range(max_attempts):
    try:
        response = client.chat.completions.create(model="gpt-4.1-mini", messages=messages)
        print(response.choices[0].message.content)
        break
    except RateLimitError as error:
        # Retry transient rate limits. Quota and billing errors need action.
        if error.code != "rate_limit_exceeded" or attempt == max_attempts - 1:
            raise
        delay = retry_delay(error, attempt)
        if delay > 5:
            raise
        time.sleep(delay)
    except APIConnectionError as error:
        raise SystemExit("Connection failed. Check connectivity before resending.") from error
    except APIStatusError as error:
        raise SystemExit(f"API returned HTTP {error.status_code}.") from error
```

### 8. Używaj wywoływania funkcji do integracji narzędzi

Wywoływanie funkcji pozwala modelowi zażądać, aby aplikacja wywołała funkcję lub narzędzie. Aplikacja obsługuje wywołanie i w razie potrzeby zwraca wyniki.

prompt.py

```python
import json

from openai import OpenAI


def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32


client = OpenAI()
tools = [{
    "type": "function",
    "function": {
        "name": "celsius_to_fahrenheit",
        "description": "Convert a temperature from Celsius to Fahrenheit.",
        "strict": True,
        "parameters": {
            "type": "object",
            "properties": {"celsius": {"type": "number"}},
            "required": ["celsius"],
            "additionalProperties": False,
        },
    },
}]
messages = [{"role": "user", "content": "Convert 20 degrees Celsius to Fahrenheit."}]
response = client.chat.completions.create(
    model="gpt-4.1", messages=messages, tools=tools,
    tool_choice="required", parallel_tool_calls=False,
)
assistant = response.choices[0].message
if not assistant.tool_calls:
    raise RuntimeError(assistant.refusal or "The model did not request the tool.")
messages.append(assistant)
for call in assistant.tool_calls:
    if call.function.name != "celsius_to_fahrenheit":
        raise ValueError(f"Unexpected tool: {call.function.name}")
    arguments = json.loads(call.function.arguments)
    fahrenheit = celsius_to_fahrenheit(**arguments)
    messages.append({
        "role": "tool",
        "tool_call_id": call.id,
        "content": json.dumps({"fahrenheit": fahrenheit}),
    })

final = client.chat.completions.create(model="gpt-4.1", messages=messages)
print(final.choices[0].message.content)
```
